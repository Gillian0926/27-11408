## 三、五类解答题：模板 + 例题全解

### 题型 1｜极限（含变限积分）：先通分/换元，再定阶

**书写模板**

原式 = lim_{x→0} [通分后的分式]
     = lim (分子泰勒展开到与分母同阶) / (分母展开)
     = 结果

> 三条铁律：① 等价无穷小**只能替换乘除因子**；② 出现 $x-\sin x$、$\tan x-x$ 类差式，一律泰勒定阶；③ 变限积分求导 $\left(\int_{\alpha}^{\beta}f\right)'=f(\beta)\beta'-f(\alpha)\alpha'$。

**例 1** 求 $\displaystyle\lim_{x\to0}\left(\frac1{x^2}-\frac1{x\tan x}\right)$。

**解** 先通分（若直接对两项分别用等价无穷小会得到 $0$ 的错误答案）：

$$\frac1{x^2}-\frac1{x\tan x}=\frac{\sin x-x\cos x}{x^2\sin x}.$$

分子泰勒展开到 $x^5$：

$$\sin x-x\cos x=\left(x-\frac{x^3}{6}+\frac{x^5}{120}\right)-x\left(1-\frac{x^2}{2}+\frac{x^4}{24}\right)+o(x^5)=\frac{x^3}{3}-\frac{x^5}{30}+o(x^5).$$

分母 $x^2\sin x=x^3\left(1-\dfrac{x^2}6+o(x^2)\right)$。故

$$\text{原式}=\lim_{x\to0}\frac{\frac{x^3}{3}+o(x^3)}{x^3}=\boxed{\frac13}.$$

**踩分点**：写出通分式（2 分）＋ 分子展开式（3 分）＋ 分母等价（2 分）＋ 结果（2 分）。

### 题型 2｜变限积分函数的性态：求导 → 列表 → 结论

**书写模板**

F'(x) = f(x)（写出具体表达式）
令 F'(x)=0 得驻点 x = ...
列表：区间 / F' 符号 / F 单调性
故 极小值 F(...) = ...，极大值 ...
F''(x) = ...，拐点 x = ...

**例 2** 设 $\displaystyle F(x)=\int_0^x (t-1)e^{-t}\,dt$，求 $F$ 的单调区间、极值与拐点。

**解** 由变限积分求导，

$$F'(x)=(x-1)e^{-x},\qquad F'(x)=0\Rightarrow x=1 .$$

因 $e^{-x}>0$，故 $x<1$ 时 $F'<0$，$x>1$ 时 $F'>0$：$F$ 在 $(-\infty,1]$ 单调递减，在 $[1,+\infty)$ 单调递增，**极小值**

$$F(1)=\int_0^1(t-1)e^{-t}dt=\int_0^1 te^{-t}dt-\int_0^1e^{-t}dt=\left(1-\frac2e\right)-\left(1-\frac1e\right)=-\frac1e .$$

（用到 $\int te^{-t}dt=-(t+1)e^{-t}+C$。）无极大值。

又

$$F''(x)=e^{-x}-(x-1)e^{-x}=(2-x)e^{-x},$$

$x<2$ 时 $F''>0$（凹弧/下凸），$x>2$ 时 $F''<0$，故 **拐点为 $\left(2,\,F(2)\right)$**，其中

$$F(2)=-\frac1e+\int_1^2(t-1)e^{-t}dt=-\frac1e+\left[-te^{-t}\right]_1^2=-\frac1e+\left(-\frac{2}{e^2}+\frac1e\right)=-\frac{2}{e^2}.$$

即拐点 $\left(2,-\dfrac{2}{e^2}\right)$。

**踩分点**：$F'$ 表达式（2 分）＋ 单调性结论（2 分）＋ 极值计算（3 分）＋ $F''$ 与拐点（3 分）。**注意极值必须写函数值，不能只写 $x=1$。**

### 题型 3｜二重积分（极坐标）：先判对称，再定界

**书写模板**

积分区域 D = {(x,y) | ...}（写成不等式组，或说明是圆/半圆）
D 关于 x 轴对称，被积函数关于 y 为奇函数，故 ∬ y dσ = 0
采用极坐标：x = r cosθ, y = r sinθ, dσ = r dr dθ
D = { (r,θ) | θ ∈ [α,β], 0 ≤ r ≤ ρ(θ) }
∬_D ... = ∫_α^β dθ ∫_0^{ρ(θ)} ... r dr = 结果

**例 3** 计算 $\displaystyle\iint_D (x+y)\,d\sigma$，其中 $D:\ x^2+y^2\le 2x$。

**解** $D$ 即 $(x-1)^2+y^2\le 1$，是过原点的圆，**关于 $x$ 轴对称**；被积函数中 $y$ 关于 $y$ 为奇函数，故 $\iint_D y\,d\sigma=0$，只算 $\iint_D x\,d\sigma$。

边界 $x^2+y^2=2x$ 即 $r=2\cos\theta$，且 $r\ge0$ 要求 $\cos\theta\ge0$，故

$$D=\left\{(r,\theta)\ \middle|\ -\frac\pi2\le\theta\le\frac\pi2,\ 0\le r\le 2\cos\theta\right\}.$$

$$\iint_D x\,d\sigma=\int_{-\pi/2}^{\pi/2}\!\!\cos\theta\,d\theta\int_0^{2\cos\theta}\!\! r^2dr=\int_{-\pi/2}^{\pi/2}\frac{8\cos^3\theta}{3}\cdot\cos\theta\,d\theta=\frac83\int_{-\pi/2}^{\pi/2}\cos^4\theta\,d\theta .$$

由 Wallis 公式 $\int_0^{\pi/2}\cos^4\theta\,d\theta=\dfrac34\cdot\dfrac12\cdot\dfrac\pi2=\dfrac{3\pi}{16}$，偶函数折半得

$$\iint_D(x+y)\,d\sigma=\frac83\cdot2\cdot\frac{3\pi}{16}=\boxed{\pi}.$$

**踩分点**：对称性说明（2 分）＋ 极坐标定界（3 分）＋ 内层积分（2 分）＋ Wallis 与结果（3 分）。

### 题型 4｜交换积分次序：画区域 → 重写不等式

**书写模板**

原积分区域 D = {(x,y) | a ≤ x ≤ b, φ₁(x) ≤ y ≤ φ₂(x)}（配草图）
改写为 D = {(x,y) | c ≤ y ≤ d, ψ₁(y) ≤ x ≤ ψ₂(y)}
故 原式 = ∫_c^d dy ∫_{ψ₁(y)}^{ψ₂(y)} f dx

**例 4** 计算 $\displaystyle I=\int_0^1dx\int_x^1 e^{-y^2}dy$。

**解** 内层 $\int e^{-y^2}dy$ 不是初等函数，必须换序。区域

$$D=\{(x,y)\mid 0\le x\le1,\ x\le y\le1\}=\{(x,y)\mid 0\le y\le1,\ 0\le x\le y\}.$$

故

$$I=\int_0^1dy\int_0^y e^{-y^2}dx=\int_0^1 y\,e^{-y^2}dy=\left[-\frac12e^{-y^2}\right]_0^1=\boxed{\frac12\left(1-\frac1e\right)}.$$

**踩分点**：画出/写出区域（2 分）＋ 换序后不等式（3 分）＋ 内层得 $y e^{-y^2}$（2 分）＋ 结果（2 分）。

### 题型 5｜二阶常系数非齐次线性方程：通解 + 定解

**书写模板**

特征方程 r² + pr + q = 0，特征根 r₁ = ..., r₂ = ...（说明相异/重根/共轭复根）
齐次通解 Y = ...
设特解 y* = x^k Q(x) e^{λx}（说明 k 的取值理由）
代入得 ... ，故 y* = ...
通解 y = Y + y*
由 y(x₀)=y₀, y'(x₀)=y₀' 得 C₁ = ..., C₂ = ...
所求 y = ...

**例 5** 求满足 $y''-3y'+2y=4x$，$y(0)=1$，$y'(0)=1$ 的特解。

**解** 特征方程 $r^2-3r+2=0$，$r_1=1,\ r_2=2$，齐次通解

$$Y=C_1e^{x}+C_2e^{2x}.$$

右端 $4x=4x\,e^{0x}$，$\lambda=0$ **不是**特征根（$k=0$），设 $y^*=ax+b$。代入：

$$-3a+2(ax+b)=4x\ \Longrightarrow\ 2a=4,\ -3a+2b=0\ \Longrightarrow\ a=2,\ b=3 .$$

故 $y^*=2x+3$，通解

$$y=C_1e^x+C_2e^{2x}+2x+3 .$$

由 $y(0)=1$：$C_1+C_2+3=1$，即 $C_1+C_2=-2$；
由 $y'=C_1e^x+2C_2e^{2x}+2$，$y'(0)=1$：$C_1+2C_2+2=1$，即 $C_1+2C_2=-1$。
解得 $C_2=1,\ C_1=-3$，故

$$\boxed{y=-3e^{x}+e^{2x}+2x+3}.$$

**验算**：$y(0)=-3+1+3=1$ ✓；$y'(0)=-3+2+2=1$ ✓。

**踩分点**：特征根与齐次通解（3 分）＋ 特解形式说明（2 分）＋ 待定系数（2 分）＋ 定解（3 分）。

### 题型 6｜中值定理/泰勒证明：先写条件，再选点展开

**书写模板**

因为 f 在 [a,b] 上连续、在 (a,b) 内（二阶）可导，由 ... 定理，
存在 ξ ∈ (a,b)，使 ...
（若用泰勒，必须在"导数为 0 的点"或"端点关于其对称的点"展开）

**例 6** 设 $f$ 在 $[0,2]$ 上连续，在 $(0,2)$ 内二阶可导，且 $f(0)=0,\ f(1)=1,\ f(2)=0$。证明：存在 $\xi\in(0,2)$，使 $f''(\xi)\le -2$。

**证明** 在 $x_0=1$ 处把 $f$ 分别对端点 $0$、$2$ 作二阶泰勒展开（带拉格朗日余项）。由 $f$ 二阶可导，存在 $\xi_1\in(0,1),\ \xi_2\in(1,2)$，使

$$f(0)=f(1)+f'(1)(0-1)+\frac{f''(\xi_1)}{2}(0-1)^2=1-f'(1)+\frac{f''(\xi_1)}{2},$$

$$f(2)=f(1)+f'(1)(2-1)+\frac{f''(\xi_2)}{2}(2-1)^2=1+f'(1)+\frac{f''(\xi_2)}{2}.$$

代入 $f(0)=f(2)=0$，两式相加消去 $f'(1)$：

$$0=2+\frac{f''(\xi_1)+f''(\xi_2)}{2}\ \Longrightarrow\ f''(\xi_1)+f''(\xi_2)=-4 .$$

若 $f''(\xi_1)>-2$ 且 $f''(\xi_2)>-2$，则左端 $>-4$，矛盾。故 $\min\{f''(\xi_1),f''(\xi_2)\}\le-2$，取对应点为 $\xi$，即有 $\xi\in(0,2)$ 使

$$f''(\xi)\le-2.\qquad\blacksquare$$

**踩分点**：写出泰勒公式并注明 $\xi_1\in(0,1),\xi_2\in(1,2)$（4 分）＋ 相加消项得和式（3 分）＋ 反证/取小得出结论（3 分）。**只写"由泰勒公式可得"不写余项点归属，最多给一半分。**

## 四、线代 2 题（约 22～33 分）的保底动作

套卷里的线代解答题，80% 落在三个点上，每个点都有"机械动作"：

| 题面信号 | 机械动作 | 必须写出的句子 |
| --- | --- | --- |
| 求 $Ax=b$ 的通解 | 对 $(A,b)$ 作**初等行变换**化阶梯形 | "$r(A)=r(A,b)=r<n$，故有无穷多解，基础解系含 $n-r$ 个向量" |
| 求特征值/可否对角化 | 解 $|\lambda E-A|=0$；对每个 $k$ 重根算 $r(\lambda E-A)$ | "$\lambda$ 为 $k$ 重根且 $r(\lambda E-A)=n-k$，故可对角化" |
| 二次型正定/化标准形 | 顺序主子式 或 配方法 | "各阶顺序主子式均大于 0，故 $f$ 正定" |

**两个自检**：$\sum\lambda_i=\operatorname{tr}A$、$\prod\lambda_i=|A|$。算出特征值先做这两步验算，能挡住绝大多数算错。

## 六、易错点（今天必须改掉的 5 条）

1. **等价无穷小用在加减里**。$\dfrac1{x^2}-\dfrac1{x\tan x}$ 若把 $\tan x\sim x$ 直接代入得 $0$，错。凡"两项相减"，先通分或泰勒，展开到**分母的阶**。
2. **变限积分求导漏项**。$\left(\int_{\alpha(x)}^{\beta(x)}f(t)dt\right)'=f(\beta)\beta'-f(\alpha)\alpha'$；若被积函数含 $x$（如 $\int_0^x f(x-t)dt$），**先换元把 $x$ 提出积分号**再求导。
3. **极坐标两处致命错**：漏掉 $r$（$d\sigma=r\,dr\,d\theta$）；$\theta$ 范围照抄 $[0,2\pi]$。圆过原点时 $\theta$ 只有 $\pi$ 长（如 $r=2\cos\theta$ 对应 $\left[-\frac\pi2,\frac\pi2\right]$）。用前必须写"$r\ge0$ 要求 $\cos\theta\ge0$"。
4. **待定系数不判 $\lambda$ 是否特征根**。$y''-3y'+2y=4x$ 中 $\lambda=0$ 不是特征根，故 $y^*=ax+b$ 不乘 $x$；若右端是 $e^{x}$ 的多项式，$\lambda=1$ 是单根，必须设 $y^*=x(ax+b)e^x$。**乘错 $x$ 的幂次，全题作废。**
5. **证明题不写条件与区间归属**。泰勒展开必须写"存在 $\xi_1\in(0,1)$、$\xi_2\in(1,2)$"；罗尔/拉格朗日必须写"在 $[a,b]$ 连续、在 $(a,b)$ 内可导"。这是**独立给分点**，不写就白丢 2～4 分。
