## 一、Cauchy–Schwarz

**积分型**

$$\left(\int_a^b fg\right)^{2}\le\int_a^b f^{2}\cdot\int_a^b g^{2}$$

**平方型（$g\equiv1$）**

$$\left(\int_a^b f\right)^{2}\le(b-a)\int_a^b f^{2}$$

**加权 / 减均值型**（已知 $\int_0^1 f=0$）

$$\left(\int_0^1 (x-c)f\right)^{2}\le\left(\int_0^1(x-c)^2dx\right)\int_0^1 f^{2},\qquad c=\frac{\int_0^1 x\,dx}{\int_0^1 1\,dx}=\frac12$$

**变限型**（$f(0)=0$）

$$f^{2}(x)=\left(\int_0^x f'\right)^{2}\le x\int_0^x (f')^{2}\le x\int_0^1 (f')^{2}$$

**和式型**

$$\left(\sum_{k=1}^n a_kb_k\right)^{2}\le\sum_{k=1}^n a_k^{2}\sum_{k=1}^n b_k^{2}$$

**取等**：$f,g$ 线性相关（$\exists\lambda,\ f+\lambda g\equiv0$）。

$$\boxed{\ \int_0^1 f=0\ \Longrightarrow\ \left(\int_0^1 xf\right)^{2}\le\frac{1}{12}\int_0^1 f^{2}\ }$$

$$\boxed{\ f(0)=0\ \Longrightarrow\ \int_0^1 f^{2}\le\frac12\int_0^1 (f')^{2};\quad f(0)=f(1)=0\ \Longrightarrow\ \int_0^1 f^2\le\frac14\int_0^1(f')^2\ }$$

## 二、凸性与 Hermite–Hadamard（方向表）

设 $f''\ge0$（凸）在 $[a,b]$ 上：

$$f\!\left(\frac{a+b}{2}\right)\ \le\ \frac{1}{b-a}\int_a^b f(x)\,dx\ \le\ \frac{f(a)+f(b)}{2}$$

**Jensen 积分型**（$\varphi$ 凸，$g$ 连续）：

$$\varphi\!\left(\frac{1}{b-a}\int_a^b g\right)\le\frac{1}{b-a}\int_a^b\varphi(g)$$

| 函数 | 凹凸 | 结论（$[0,1]$ 上） |
| --- | --- | --- |
| $x^2$ | 凸 | $\displaystyle\int_0^1 f^2\ge\left(\int_0^1 f\right)^2$ |
| $e^{x}$ | 凸 | $\displaystyle\int_0^1 e^{g}\ge e^{\int_0^1 g}$ |
| $\ln x$ | **凹** | $\displaystyle\int_0^1\ln f\le\ln\!\left(\int_0^1 f\right)$（$\int f=1$ 时 $\le0$） |
| $\dfrac1x$ | 凸 | $\displaystyle\int_0^1\frac{dx}{f}\ge\frac{1}{\int_0^1 f}$ |
| $\sqrt x$ | **凹** | $\displaystyle\int_0^1\sqrt f\le\sqrt{\int_0^1 f}$ |

**误差常数**（$|f''|\le M$）：

$$\left|\int_0^1 f-\frac{f(0)+f(1)}{2}\right|\le\frac{M}{12},\qquad \left|\int_0^1 f-f\!\left(\tfrac12\right)\right|\le\frac{M}{24}$$

## 三、离散 → 连续

**母不等式**（$f$ 递减、正）：

$$f(k+1)<\int_k^{k+1}f(x)\,dx<f(k)\ \Longrightarrow\ \sum_{k=2}^{n+1}f(k)<\int_1^{n+1}f<\sum_{k=1}^{n}f(k)$$

（$f$ 递增时全部反向。）

**调和级数**：

$$\ln(n+1)<H_n<1+\ln n,\qquad H_n=\sum_{k=1}^n\frac1k=\ln n+\gamma+o(1),\ \gamma\approx0.5772$$

**常用推论**：

$$\frac{1}{k+1}<\ln\frac{k+1}{k}<\frac1k,\qquad \frac1k<\ln\frac{k}{k-1}\ (k\ge2)$$

**黎曼和（逆用）**：

$$\lim_{n\to\infty}\frac1n\sum_{k=1}^{n}f\!\left(\frac kn\right)=\int_0^1 f(x)\,dx$$

## 四、常数表（必默写）

| 积分 | 值 | 出现场景 |
| --- | --- | --- |
| $\displaystyle\int_0^1 x\,dx$ | $\dfrac12$ | 例 4 的 $\frac12$ 常数 |
| $\displaystyle\int_0^1 x^{2}dx$ | $\dfrac13$ | 平方型 C-S |
| $\displaystyle\int_0^1 x(1-x)dx$ | $\dfrac16$ | 梯形核、$f(0)=f'(0)=0$ 的 $\frac{M}{6}$ |
| $\displaystyle\int_0^1\!\left(x-\tfrac12\right)^{2}dx$ | $\dfrac{1}{12}$ | 减均值 C-S、梯形误差 |
| $\displaystyle\int_0^1\min\{x,1-x\}dx$ | $\dfrac14$ | 两端为零的 Poincaré 型 |
| $\displaystyle\int_0^1\!\left(x-\tfrac12\right)^{4}dx$ | $\dfrac{1}{80}$ | 四阶核 |
| $\displaystyle\int_0^1\frac{dx}{1+x}$ | $\ln2$ | 夹逼 / 黎曼和 |
| $\displaystyle\int_0^1\ln x\,dx$ | $-1$ | 反常积分对照 |
| $\displaystyle\int_0^1\frac{dx}{1+x^{2}}$ | $\dfrac{\pi}{4}$ | 黎曼和极限 |
| $\displaystyle\int_0^1 xe^{x}dx$ | $1$ | 分部积分 |

**取等示例**：$f(x)=x^{2}$、$M=2$ 时梯形误差 $\left|\frac13-\frac12\right|=\frac16=\frac{M}{12}$ ✓（界是紧的）。

## 五、30 秒选工具（决策表）

| 题面信号 | 选 | 第一步动作 |
| --- | --- | --- |
| 出现 $\left(\int f\right)^2$、$\int f^2$、$\int fg$ | C-S | 配 $g$；已知 $\int f=0$ 就减均值 |
| 出现 $f(0)=0$，要求 $\int f^2$ 与 $\int (f')^2$ 的关系 | C-S 变限 | 写成 $f=\int_0^x f'$ |
| 题给 $f''\ge0$ / $f''\le0$，问 $\int f$ 与端点值 | H-H | 化到 $[0,1]$，核 $\frac{t(1-t)}{2}$ 非负 |

## 六、易错 5 条（考前 3 分钟只看这里）

1. **减均值**：$\int_0^1 f=0$ 时配 $g=x-\frac12$（不是 $x$），常数才从 $\frac13$ 降到 $\frac1{12}$。
2. **凹凸方向**：$\ln$ 凹（$\le$），$e^x,x^2,\frac1x$ 凸（$\ge$）；把 $\ln$ 写成 $\ge$ 必零分。
3. **H-H 前提**：$f''\ge0$ 要覆盖整个 $[a,b]$；区间非 $[0,1]$ 先换元，$\frac{1}{12}$ 不通用。
4. **夹逼方向**：递减才写 $f(k+1)<\int_k^{k+1}f<f(k)$；递增要整体翻转，用"区间上 $\frac1x$ 的最值"现场判。
5. **取等与开方**：C-S 开方带 $|\cdot|$；证明末尾必须写取等条件（线性相关 / $f\equiv$ 常数），否则"最优"不成立。

$$\text{判信号}\to\text{选 C-S / H-H / 夹逼}\to\text{配权与减均值}\to\text{写取等}\to\text{报常数}$$
