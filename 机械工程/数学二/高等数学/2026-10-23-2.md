## 一、变限积分（接口 A、B、D 的公共工具）

$$\frac{d}{dx}\int_a^{\varphi(x)}f(t)\,dt=f\big(\varphi(x)\big)\varphi'(x)$$

$$\frac{d}{dx}\int_{\psi(x)}^{\varphi(x)}f(t)\,dt=f\big(\varphi(x)\big)\varphi'(x)-f\big(\psi(x)\big)\psi'(x)$$

**被积函数含 $x$ —— 先拆再导**：

$$\int_0^x(x-t)f(t)\,dt=x\int_0^xf(t)\,dt-\int_0^xtf(t)\,dt$$
$$\left(\int_0^x(x-t)f(t)\,dt\right)'=\int_0^xf(t)\,dt,\qquad \left(\cdot\right)''=f(x)$$

**参数在区域里 —— 先换序再求导**：

$$\int_0^t dx\int_x^t e^{-y^2}dy=\int_0^t y\,e^{-y^2}dy\ \Longrightarrow\ F'(t)=t\,e^{-t^2}$$

## 二、极限常用等价无穷小（$u\to0$）

$$e^{u}-1\sim u,\quad \ln(1+u)\sim u,\quad \sin u\sim u,\quad \tan u\sim u,\quad \arcsin u\sim u,\quad \arctan u\sim u$$

$$1-\cos u\sim\frac{u^{2}}{2},\quad (1+u)^{\alpha}-1\sim\alpha u,\quad a^{u}-1\sim u\ln a$$

$$u-\sin u\sim\frac{u^{3}}{6},\quad \tan u-u\sim\frac{u^{3}}{3},\quad \arcsin u-u\sim\frac{u^{3}}{6}$$

$$u-\ln(1+u)\sim\frac{u^{2}}{2},\quad e^{u}-1-u\sim\frac{u^{2}}{2},\quad \ln(1+u)-u\sim-\frac{u^{2}}{2}$$

**积分型**：$f(u)\sim g(u)$（$u\to0$，同号连续）时 $\displaystyle\int_0^{\varphi(x)}f\sim\int_0^{\varphi(x)}g$。

## 三、二重积分快算（接口 C）

**换序四步**：写不等式组 → 画图求交点 → 换方向切 → 重写限（外限常数、内限上界 > 下界）。

**必换序信号**：$e^{-y^{2}},\ e^{x^{2}},\ \dfrac{\sin y}{y},\ \sin(y^{2}),\ \sqrt{1+y^{3}},\ \dfrac{1}{\ln y}$。

**极坐标**：

$$x=r\cos\theta,\quad y=r\sin\theta,\quad \boxed{d\sigma=r\,dr\,d\theta}$$

| 区域 | $\theta$ | $r$ |
| --- | --- | --- |
| $x^{2}+y^{2}\le a^{2}$ | $[0,2\pi]$ | $[0,a]$ |
| $x^{2}+y^{2}\le 2ax$ | $\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$ | $[0,2a\cos\theta]$ |
| $x^{2}+y^{2}\le 2ay$ | $[0,\pi]$ | $[0,2a\sin\theta]$ |
| 圆环 $a^{2}\le x^{2}+y^{2}\le b^{2}$ | $[0,2\pi]$ | $[a,b]$ |

**对称三判**：区域关于 $y$ 轴对称且 $f(-x,y)=-f(x,y)$ ⇒ 积分 $=0$；$f(-x,y)=f(x,y)$ ⇒ $=2\iint_{x\ge0}$。关于 $x$ 轴对称同理。关于 $y=x$ 对称 ⇒ $\iint f(x,y)=\iint f(y,x)$。

**常用值**（$D:x^{2}+y^{2}\le R^{2}$）：

$$\iint_D x\,d\sigma=\iint_D xy\,d\sigma=0,\qquad \iint_D x^{2}d\sigma=\iint_D y^{2}d\sigma=\frac{\pi R^{4}}{4}$$

**形心验算器**：$\displaystyle\iint_D x\,d\sigma=\bar x\cdot S$，$\displaystyle\iint_D y\,d\sigma=\bar y\cdot S$。

**分片触发**：$|x^{2}+y^{2}-k|$ → 以 $r=\sqrt k$ 分片；$\min/\max(x,y)$ → 以 $y=x$ 分片。

## 四、二元极值与条件极值（接口 E）

**无条件**：驻点 $f_x=f_y=0$，记 $A=f_{xx},B=f_{xy},C=f_{yy}$：

| $AC-B^{2}$ | 结论 |
| --- | --- |
| $>0,\ A>0$ | 极小值 |
| $>0,\ A<0$ | 极大值 |
| $<0$ | 非极值（鞍点） |
| $=0$ | 失效，另判 |

**条件极值**：$L=f(x,y)+\lambda\varphi(x,y)$，

$$\begin{cases}f_x+\lambda\varphi_x=0\\ f_y+\lambda\varphi_y=0\\ \varphi(x,y)=0\end{cases}$$

**答题模板**：约束集有界闭 + $f$ 连续 ⇒ 最值存在；驻点唯一 ⇒ 该驻点即最值点；最后写出最值数值。

## 五、二阶常系数线性方程（接口 D 的收尾）

**齐次** $y''+py'+qy=0$，特征方程 $r^{2}+pr+q=0$：

| 判别 | 通解 |
| --- | --- |
| $p^{2}-4q>0$，$r_1\ne r_2$ | $C_1e^{r_1x}+C_2e^{r_2x}$ |
| $p^{2}-4q=0$，$r$ | $(C_1+C_2x)e^{rx}$ |
| $p^{2}-4q<0$，$\alpha\pm\beta i$ | $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$ |

**特解设法**（右端 $f(x)=P_n(x)e^{\alpha x}$）：设 $y_p=x^{k}Q_n(x)e^{\alpha x}$，$k$ 为 $\alpha$ 作为特征根的重数（$0,1,2$）。

常用：$f=e^{x}$ 且 $1$ 不是特征根 ⇒ $y_p=Ae^{x}$；若 $1$ 是单根 ⇒ $y_p=Axe^{x}$。

**一阶线性**：$y'+P(x)y=Q(x)$，

$$y=e^{-\int P dx}\left[\int Q\,e^{\int P dx}dx+C\right]$$

## 六、高频积分值与三角公式

$$\int_0^{\pi/2}\sin^{2}\theta\,d\theta=\int_0^{\pi/2}\cos^{2}\theta\,d\theta=\frac{\pi}{4},\qquad
\int_0^{\pi/2}\sin^{3}\theta\,d\theta=\int_0^{\pi/2}\cos^{3}\theta\,d\theta=\frac23$$

$$\int_0^{\pi/2}\sin^{n}\theta\,d\theta=\int_0^{\pi/2}\cos^{n}\theta\,d\theta=\begin{cases}\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac{1}{2}\cdot\dfrac{\pi}{2}, & n\ \text{偶}\\[8pt] \dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac{2}{3}, & n\ \text{奇}\end{cases}$$

$$\cos^{2}\theta=\frac{1+\cos2\theta}{2},\qquad \cos^{4}\theta=\frac{3+4\cos2\theta+\cos4\theta}{8}$$

$$\int_{-\pi/2}^{\pi/2}\cos^{4}\theta\,d\theta=\frac{3\pi}{8},\qquad \int_0^{2\pi}\cos^{2}\theta\,d\theta=\int_0^{2\pi}\sin^{2}\theta\,d\theta=\pi$$

**幂降阶必备**：$\displaystyle\int_0^{1}(r-r^{3})dr=\frac14$，$\displaystyle\int_1^{2}(r^{3}-r)dr=\frac94$（分片题高频）。

## 七、考场十秒判

| 看到 | 立刻做 |
| --- | --- |
| 分子是 $\int_0^{\varphi(x)}$，分母 $x^{k}$ | 洛必达 + 等价无穷小，先化简被积函数 |
| 被积函数里同时有 $x$ 和 $t$ | 先把 $x$ 提出积分号，再求导 |
| 累次积分上限含 $t$，问 $F'(t)$ | **换序**，化成一元定积分再求导，别硬穿 |
| 圆域 + 被积函数有奇次项 | 对称砍成 0，只算剩下一项 |
| 区域是过原点的圆 | $\theta$ 取半圈，写出 $r\le 2a\cos\theta$（或 $2a\sin\theta$） |
| 出现 $\left|x^{2}+y^{2}-k\right|$ | 以 $r=\sqrt k$ 分片去绝对值 |
| $f=g+\int_0^x(x-t)f(t)dt$ | 拆 → 求导两次 → $f''-f=\cdots$，初值分别从原式、一阶式取 |
| "最大面积/体积/最省料" | 目标函数 + 约束 → 拉格朗日 → 说明最值存在 |
| 算出 $\iint_D x\,d\sigma$ | 用形心 $\bar x\cdot S$ 一秒验算 |
| 结果出现负的面积/体积 | 分片时上下界写反了，回去查 |

## 八、易错 1 分钟扫

1. 变限积分上限是复合函数，**漏乘 $\varphi'(x)$**。
2. 被积函数含 $x$ 时直接套公式 → 结果必错，先拆。
3. 累次积分对参数求导**不能**穿进积分号（区域随参数变）。
4. 极坐标 **$d\sigma=r\,dr\,d\theta$**，漏 $r$；$\theta$ 范围别写整圈。
5. 二元极值判别要同时看 $AC-B^{2}>0$ 与 $A$ 的符号。
6. 积分方程初值：$f(0)$ 用原式，$f'(0)$ 用求导后的式子。
7. 数二不考无穷级数、三重积分、曲线曲面积分、空间解析几何——综合题里若"感觉要用"，一定是走错方向了，回头查接口。
