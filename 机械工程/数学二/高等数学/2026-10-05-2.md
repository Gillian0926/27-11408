# 🧮 数学二 · 第 10 讲配套 · 公式速查（积分中值定理与积分不等式）

> 默写顺序：**中值定理 → 基本不等式 → 积分不等式 → 放缩表 → 常用定积分 → 自检三问**。

---

## 一、积分中值定理

| 形式 | 条件 | 结论 |
| --- | --- | --- |
| 闭区间 | $f$ 在 $[a,b]$ 连续 | $\exists\xi\in[a,b]$，$\displaystyle\int_a^bf=f(\xi)(b-a)$ |
| 开区间 | $f$ 在 $[a,b]$ 连续 | $\exists\xi\in(a,b)$，$\displaystyle\int_a^bf=f(\xi)(b-a)$ |
| 变限形 | $f$ 连续 | $\displaystyle\int_x^{x+\Delta x}f=f(\xi)\Delta x$，$\xi$ 介于二者之间 |
| 推广形 | $f$ 连续，$g$ 可积且**不变号** | $\exists\xi\in[a,b]$，$\displaystyle\int_a^bfg=f(\xi)\int_a^bg$ |

**平均值**：$\bar f=\dfrac{1}{b-a}\displaystyle\int_a^bf(x)dx$，且 $\exists\xi$ 使 $f(\xi)=\bar f$。

**开区间形式的证明模板**：

$$F(x)=(b-a)\int_a^xf(t)dt-(x-a)\int_a^bf(t)dt,\quad F(a)=F(b)=0\ \xrightarrow{\text{罗尔}}\ F'(\xi)=0$$

## 二、常用基本不等式

$$-\big|f\big|\le f\le\big|f\big|,\qquad \left|\int_a^bf\right|\le\int_a^b|f|$$

$$m\le f\le M\ \Longrightarrow\ m(b-a)\le\int_a^bf\le M(b-a)$$

$$|f|\le M\ \Longrightarrow\ \left|\int_a^bf\right|\le M(b-a)$$

**指数 / 对数**（$x>-1$）：

$$e^x\ge1+x,\qquad \frac{x}{1+x}\le\ln(1+x)\le x$$

**三角**（$0\le x\le\dfrac\pi2$）：

$$\sin x\le x\le\tan x,\qquad 1-\frac{x^2}{2}\le\cos x\le1$$

**常用凑法**：

$$|f|\le\frac{1+f^2}{2},\qquad 2|fg|\le f^2+g^2$$

**柯西（离散）**：

$$\left(\sum a_ib_i\right)^2\le\left(\sum a_i^2\right)\left(\sum b_i^2\right)$$

## 三、积分不等式（核心）

**Schwarz 不等式**：

$$\boxed{\ \left(\int_a^bfg\right)^2\le\int_a^bf^2\cdot\int_a^bg^2\ }$$

特例（$g\equiv1$）：

$$\left(\int_a^bf\right)^2\le(b-a)\int_a^bf^2$$

等号 $\iff$ $f,g$ 线性相关。

**判别式证法**：$\displaystyle\int_a^b(f+t)^2dx\ge0\ \forall t\Rightarrow\Delta\le0$。

**分部积分换序**：

$$\int_0^1\left(\int_0^xf(t)dt\right)dx=\int_0^1(1-t)f(t)\,dt$$

$$\int_0^a\left(\int_0^xf(t)dt\right)dx=\int_0^a(a-t)f(t)\,dt$$

**单调性法模板**：

$$\Phi(x)=\int_a^x f(t)dt-G(x),\quad \Phi(a)=0,\quad \Phi'(x)\ge0\Rightarrow\Phi(b)\ge0$$

## 四、常用放缩表

| 区间 | 放缩 |
| --- | --- |
| $x\in[0,1]$ | $e^{-x^2}\ge1-x^2$，$\dfrac{1}{\sqrt{1-x^2}}\ge1$ |
| $x\in(a,b)$，$0<a<b$ | $\dfrac1b<\dfrac1x<\dfrac1a$ |
| $x\ge0$ | $x\le e^x-1$，$\dfrac{x}{1+x}\le\ln(1+x)\le x$ |
| 一般 | $\min\{x,1-x\}\le\dfrac14$（$x\in[0,1]$） |
| 含 $f'$ | $|f(x)-f(y)|\le M|x-y|$，$M=\max|f'|$ |

**双向夹逼技巧**（端点条件题）：

$$|f(x)|\le Mx\ \text{(用左端)}\quad\text{且}\quad|f(x)|\le M(1-x)\ \text{(用右端)}\ \Longrightarrow\ |f(x)|\le M\min\{x,1-x\}$$

## 五、常用定积分值

| 积分 | 值 |
| --- | --- |
| $\displaystyle\int_0^1\ln x\,dx$ | $-1$ |
| $\displaystyle\int_0^1 x\ln x\,dx$ | $-\dfrac14$ |
| $\displaystyle\int_0^1 xe^{-x}dx$ | $1-\dfrac2e$ |
| $\displaystyle\int_0^1\dfrac{dx}{1+x^2}$ | $\dfrac\pi4$ |
| $\displaystyle\int_0^1\dfrac{dx}{\sqrt{1-x^2}}$ | $\dfrac\pi2$ |
| $\displaystyle\int_0^\pi x\sin x\,dx$ | $\pi$ |
| $\displaystyle\int_0^{1}\min\{x,1-x\}dx$ | $\dfrac14$ |
| $\displaystyle\int_0^1(1-x^2)dx$ | $\dfrac23$ |
| $\displaystyle\int_0^{+\infty}e^{-x^2}dx$ | $\dfrac{\sqrt\pi}{2}$ |

**Wallis 公式**（$n$ 为正整数）：

$$\int_0^{\pi/2}\sin^nx\,dx=\int_0^{\pi/2}\cos^nx\,dx=\begin{cases}\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac12\cdot\dfrac\pi2,&n\ \text{偶}\\[2mm]\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac23\cdot1,&n\ \text{奇}\end{cases}$$

## 六、自检三问

1. **我写的是"存在 $\xi$"还是"取某点"？** 需要开区间时，是否用罗尔定理（构造端点等值辅助函数）补足？推广形式里 $g$ 不变号的条件写了吗？

2. **放缩方向对了吗？上下界在整个区间都成立吗？** 只在半边成立时，我分段了吗？含端值条件（$f(0)=f(1)=0$）时，我双向用牛顿–莱布尼茨取 $\min$ 了吗？

3. **单调性法的辅助函数在左端点等于零吗？** 结论里的每个 $b$ 都换成 $x$ 了吗？用 Schwarz 前检查了连续性吗，等号条件写对了吗？
