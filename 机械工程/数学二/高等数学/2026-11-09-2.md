## 二、单调有界准则：四步 + 常用界

$$\boxed{\text{① 猜界 } L=f(L)\quad\text{② 归纳证有界}\quad\text{③ 证单调}\quad\text{④ 取极限解方程取舍}}$$

**单调性两把刀**：

$$a_{n+1}-a_n\ \text{（差式，含平方项时用 } a_{n+1}^2-a_n^2\text{）};\qquad \frac{a_{n+1}}{a_n}\ \text{（比值，含 }\sqrt{\ }\text{或有理式时用）}$$

**常见猜界结果**：

| 递推式 | 极限 $L$ |
| --- | --- |
| $a_{n+1}=\sqrt{2+a_n}$ | $2$（舍 $-1$） |
| $a_{n+1}=\sqrt{1+a_n}$ | $\dfrac{1+\sqrt5}{2}$ |
| $a_{n+1}=\dfrac{3}{2+a_n}$ | $1$（舍 $-3$） |
| $a_{n+1}=\dfrac{4}{1+a_n}$ | $\dfrac{\sqrt{17}-1}{2}$ |
| $a_{n+1}=1+\dfrac{1}{a_n}$ | $\dfrac{1+\sqrt5}{2}$ |
| $a_{n+1}=\dfrac{a_n}{1+a_n}$ | $0$，且 $a_n=\dfrac1n$ |

> 判别式记忆：$L=f(L)$ 化为一元二次方程，**用 $a_n$ 的取值范围舍根**。

---

## 三、夹逼准则：三种放缩

$$\text{同分母}:\ \frac{n}{\sqrt{n^2+n}}\le\sum_{k=1}^{n}\frac{1}{\sqrt{n^2+k}}\le\frac{n}{\sqrt{n^2+1}}$$

$$\text{幂和开方}:\ M<\big(a_1^n+\cdots+a_m^n\big)^{1/n}<M\cdot m^{1/n},\quad M=\max a_i$$

$$\text{通式}:\ \lim_{n\to\infty}\big(a_1^{n}+\cdots+a_m^{n}\big)^{1/n}=\max\{a_1,\dots,a_m\}\ (a_i>0)$$

**常用极限值**：

$$n^{1/n}\to1,\qquad a^{1/n}\to1\ (a>0),\qquad \sqrt[n]{n!}\to+\infty,\qquad \Big(1+\frac1n\Big)^{n}\to e$$

$$\sqrt[n]{n}\to1\ \text{的证明思路}:\ \sqrt[n]{n}=1+h_n\Rightarrow n=(1+h_n)^n\ge\frac{n(n-1)}{2}h_n^{2}\Rightarrow h_n\le\sqrt{\frac{2}{n-1}}\to0$$

## 四、$n$ 项和化定积分

$$\boxed{\lim_{n\to\infty}\frac1n\sum_{k=1}^{n}f\!\left(\frac kn\right)=\int_0^1 f(x)\,dx}$$

**配方三步**：① 提出 $\dfrac1n$；② 把剩下的 $k$ 写成 $n\cdot\dfrac kn$ 并约简；③ 令 $x=\dfrac kn$，读出 $f(x)$ 与区间。

**若 $k$ 取到 $cn$**：区间为 $[0,c]$，即 $\lim\dfrac1n\sum\limits_{k=1}^{cn}f\!\left(\dfrac kn\right)=\displaystyle\int_0^{c}f(x)dx$。

**高频对照表**：

| 和式 | 值 |
| --- | --- |
| $\sum\limits_{k=1}^{n}\dfrac{k}{n^{2}+k^{2}}$ | $\dfrac{\ln2}{2}$ |
| $\sum\limits_{k=1}^{n}\dfrac{1}{n+k}$ | $\ln2$ |
| $\sum\limits_{k=1}^{n}\dfrac{n}{n^{2}+k^{2}}$ | $\dfrac{\pi}{4}$ |
| $\dfrac1n\sum\limits_{k=1}^{n}\sin\dfrac{k\pi}{n}$ | $\dfrac{2}{\pi}$ |
| $\dfrac1n\sum\limits_{k=1}^{n}\sqrt{1+\dfrac kn}$ | $\dfrac{2}{3}\big(2\sqrt2-1\big)$ |
| $\sum\limits_{k=1}^{n}\dfrac{k}{n^{2}}$ | $\dfrac12$ |

## 五、递推数列的两条备用路

**① 倒数化（等差型）**：若 $a_{n+1}=\dfrac{a_n}{\alpha a_n+\beta}$，则 $\dfrac{1}{a_{n+1}}=\dfrac{\alpha}{\beta}\cdot\dfrac{1}{a_n}+\dfrac1\beta$，转为等差/一阶线性。

**② 压缩估计（拉格朗日）**：

$$|a_{n+1}-L|=|f(a_n)-f(L)|=|f'(\xi)|\,|a_n-L|\le q|a_n-L|,\quad q=\max|f'|<1$$

$$\Longrightarrow\ |a_n-L|\le q^{\,n-1}|a_1-L|\to0$$

> **适用信号**：数列**不单调**、极限方程不便显式解、或题目直接要求"证明收敛"。关键是把 $q$ 控制在**包含整个取值范围的区间**上（如 $x\ge1$），否则 $q$ 可能取不到。

## 六、易错点核对表

| 错误 | 正确做法 |
| --- | --- |
| 直接设极限求值 | 先证单调 + 有界，再取极限 |
| 用"极限存在"证"有界" | 有界用归纳法独立证 |
| 夹逼两端极限不等 | 重估放缩，或改用定积分定义 |
| 漏提 $1/n$、$f$ 写错 | 先提 $1/n$，再把 $k$ 全换成 $n\cdot\frac kn$ |
| 二次方程两根都留 | 用 $a_n$ 范围舍根并写出理由 |
| 硬套单调有界（数列摆动） | 改走压缩估计 |

3. 有界性的归纳起点 $n=1$ 写了吗？

5. 解出的两根都验过了吗？舍根理由写了吗？
