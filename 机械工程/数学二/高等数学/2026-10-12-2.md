## 一、概念速记（选择题专用）

| 名词 | 要点 |
| --- | --- |
| 微分方程 | 含未知函数及其导数（微分）的方程 |
| 阶 | 未知函数**最高阶导数**的阶数 |
| 通解 | 含**独立**任意常数，且个数 **= 阶数** |
| 特解 | 由初始条件定出常数后的解 |
| 初始条件 | $n$ 阶方程给 $n$ 个条件 |
| 线性方程 | 关于 $y,y',y'',\dots$ 均为一次，**系数只含 $x$** |

**反例记忆**：$(y')^{2}+y=x$ 是一阶（不是二阶）；$y\,y'=x$ 非线性；$x^{2}y''+y=0$ 线性。

## 二、一阶方程识别流程（背下来）

$$y'=f(x,y)\ \Longrightarrow\
\begin{cases}
f(x)\,g(y)\ \text{形} & \to\ \text{可分离变量}\\[1mm]
f\!\left(\dfrac yx\right)\ \text{形} & \to\ \text{齐次方程}\\[1mm]
y'+P(x)y=Q(x)\ \text{形} & \to\ \text{一阶线性}\\[1mm]
\text{都不像} & \to\ \text{换元}
\end{cases}$$

> 顺序：**先整理成标准形**（$y'$ 系数化为 1）→ **再判型** → **最后求助换元**。

---

## 三、可分离变量

$$y'=f(x)g(y)\quad\Longrightarrow\quad \int\frac{dy}{g(y)}=\int f(x)\,dx+C$$

**对称型式**：

$$M_1(x)M_2(y)\,dx+N_1(x)N_2(y)\,dy=0\quad\Longrightarrow\quad \int\frac{M_1(x)}{N_1(x)}dx+\int\frac{M_2(y)}{N_2(y)}dy=C$$

**漏解提醒**：分离前先令 $g(y)=0$（或 $N_1(x)=0$、$M_2(y)=0$），检验是否有被丢掉的常数解。

---

## 四、齐次方程

$$y'=f\!\left(\frac yx\right),\qquad \text{令}\ u=\frac yx\ (y=ux,\ y'=u+xu')$$

$$\Longrightarrow\ x\frac{du}{dx}=f(u)-u\ \Longrightarrow\ \int\frac{du}{f(u)-u}=\ln|x|+C$$

**必须回代** $u=\dfrac yx$。

**准齐次**：$y'=\dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}$，$\Delta=\begin{vmatrix}a_1&b_1\\a_2&b_2\end{vmatrix}$。

| 情形 | 处理 |
| --- | --- |
| $\Delta\neq 0$ | 求两直线交点 $(x_0,y_0)$，平移 $X=x-x_0,\ Y=y-y_0$，化为齐次 |
| $\Delta=0$ | 两线平行，令 $u=a_2x+b_2y$，化为可分离 |

**常数解**：若 $f(u_0)=u_0$，则 $y=u_0x$ 是解，需单独说明。

## 五、一阶线性微分方程

**标准形**：$y'+P(x)y=Q(x)$（务必先化标准形！）

| 类型 | 通解 |
| --- | --- |
| 齐次（$Q\equiv0$） | $y=Ce^{-\int P(x)\,dx}$ |
| 非齐次 | $\displaystyle y=e^{-\int P(x)\,dx}\left[\int Q(x)e^{\int P(x)\,dx}dx+C\right]$ |

**结构**：非齐次通解 = 齐次通解 + 非齐次特解。

**记忆诀**：**外层负、里层正；$Q$ 乘里层。** 即外层 $e^{-\int P}$，内层 $e^{+\int P}$，$Q$ 与内层相乘。

**常数变易法思路**（公式忘了就现推）：

1. 先解齐次 $y=Ce^{-\int P}$；
2. 设非齐次解 $y=C(x)e^{-\int P}$，代回得 $C'(x)=Q(x)e^{\int P}$；
3. 积分得 $C(x)=\int Qe^{\int P}dx+C$。

## 六、常用换元一览

| 原式特征 | 换元 | 导数关系 |
| --- | --- | --- |
| 出现 $x+y$ | $u=x+y$ | $u'=1+y'$ |
| 出现 $ax+by$ | $u=ax+by$ | $u'=a+by'$ |
| 出现 $y/x$ | $u=y/x$ | $y'=u+xu'$ |
| 出现 $y/x$ 的倒数或 $x/y$ | $u=x/y$ | 同理反解 |
| $x$ 比 $y$ 好处理 | 令 $x=x(y)$ | $\dfrac{dx}{dy}=\dfrac1{y'}$ |

**反函数法模板**：$y'=\dfrac{1}{x+y}$ → $\dfrac{dx}{dy}-x=y$（关于 $x$ 的一阶线性）。

## 七、回代时最常用的反导数

$$\int\frac{du}{u}=\ln|u|,\qquad \int\frac{du}{1+u^{2}}=\arctan u$$

$$\int\frac{du}{1-u^{2}}=\frac12\ln\left|\frac{1+u}{1-u}\right|,\qquad \int\frac{du}{1+u^{2}}\ \text{（同上）}$$

$$\int \tan u\,du=-\ln|\cos u|,\qquad \int\sec^{2}u\,du=\tan u$$

$$\int\frac{du}{1+\cos u}=\tan\frac u2,\qquad \int\frac{du}{1-\cos u}=-\cot\frac u2$$

$$\int e^{ax}dx=\frac1a e^{ax},\qquad \int xe^{ax}dx=\frac{e^{ax}}{a^{2}}\,(ax-1)$$

$$\int\frac{dx}{x}=\ln|x|,\qquad \int\frac{dx}{x\pm a}=\ln|x\pm a|$$

## 八、应用题的"文字 → 方程"翻译表

| 题面语言 | 表达式 |
| --- | --- |
| 切线斜率 | $y'$ |
| 切线在 $y$ 轴上的截距 | $y-xy'$ |
| 切线在 $x$ 轴上的截距 | $x-\dfrac{y}{y'}$ |
| 法线斜率 | $-\dfrac{1}{y'}$ |
| 曲边梯形面积（$0\to x$） | $\displaystyle\int_0^{x}y(t)\,dt$ |
| 与自身成正比（增长/衰减/放射） | $\dfrac{dN}{dt}=kN$ |
| 与温差成正比（冷却） | $\dfrac{dT}{dt}=-k(T-T_0)$ |
| 与速度成正比（阻力） | $F=-kv$ 或 $\dfrac{dv}{dt}=-kv$ |

**列方程三步**：① 用字母写出条件对应的表达式 → ② 消去多余参数得微分方程 → ③ 用初值定常数。

## 九、自检三问 + 错误清单

**三问**：

1. 我把 $y'$ 的系数化成 1 了吗？这是标准形了吗？
2. 我判的是哪一型？依据是哪一行？
3. 常数 $C$ 加了几次？回代做了吗？定义域交代了吗？

| 错误 | 正确做法 |
| --- | --- |
| 分离变量后漏掉 $y\equiv$ 常数解 | 分离前先解 $g(y)=0$ 并验证 |
| 齐次方程不换回 $y/x$ | 三步走完：换元 → 解 $u$ → 回代 |
| 一阶线性公式两处指数写反 | 外层 $e^{-\int P}$，里层 $e^{+\int P}$，$Q$ 乘里层 |
| 未化标准形就套公式 | 先除以 $y'$ 的系数 |
| 中途代初值求 $C$ | 只用**通解**代初值 |
| 一次积分加好几个 $C$ | 最后加**一个** $C$ |
| 换元把 $u$ 当常数求导 | $y=ux\Rightarrow y'=u+xu'$；$u=x+y\Rightarrow u'=1+y'$ |
| 定义域丢三落四 | 含 $\ln$、$|\cdot|$、偶次根号时写明区间 |
