## 一、一阶方程三型

**① 可分离变量**：$y'=f(x)g(y)$
$$\int\frac{dy}{g(y)}=\int f(x)\,dx+C\qquad(g(y)\neq0)$$
另需单独检查 $g(y_0)=0\Rightarrow y\equiv y_0$ 是否为解。

**② 齐次方程**：$y'=\varphi\!\left(\dfrac{y}{x}\right)$，令 $u=\dfrac{y}{x}$
$$y=ux,\quad y'=u+xu'\ \Longrightarrow\ x\frac{du}{dx}=\varphi(u)-u$$

**③ 一阶线性**：$y'+P(x)y=Q(x)$
$$y=e^{-\int P\,dx}\left[\int Q(x)\,e^{\int P\,dx}dx+C\right]$$
积分因子 $\mu(x)=e^{\int P\,dx}$，且 $\left(\mu y\right)'=\mu Q$。

**④ 可化为可分离**：$y'=f(ax+by+c)$，令 $u=ax+by+c$，则 $u'=a+bf(u)$。

## 二、可降阶的高阶方程

| 类型 | 代换 | 结果 |
| --- | --- | --- |
| 缺 $y$：$y''=f(x,y')$ | $y'=p(x),\ y''=p'$ | $p'=f(x,p)$ |
| 缺 $x$：$y''=f(y,y')$ | $y'=p(y),\ y''=p\dfrac{dp}{dy}$ | $p\dfrac{dp}{dy}=f(y,p)$ |

开方时 $p=\pm\sqrt{F(y)}$，**用初值定支**。

---

## 三、二阶常系数齐次：$y''+py'+qy=0$，特征方程 $r^{2}+pr+q=0$

| 特征根 | 通解 |
| --- | --- |
| $r_1,r_2$ 相异实根 | $y=C_1e^{r_1x}+C_2e^{r_2x}$ |
| $r_1=r_2=r$ | $y=(C_1+C_2x)e^{rx}$ |
| $r=\alpha\pm\beta i$ | $y=e^{\alpha x}\left(C_1\cos\beta x+C_2\sin\beta x\right)$ |

---

## 四、二阶常系数非齐次：$y''+py'+qy=f(x)$，通解 $=Y+y^{*}$

| $f(x)$ | 与特征根关系 | 设 $y^{*}$ |
| --- | --- | --- |
| $P_n(x)e^{\alpha x}$ | $\alpha$ 非根 | $Q_n(x)e^{\alpha x}$ |
| $P_n(x)e^{\alpha x}$ | $\alpha$ 单根 | $xQ_n(x)e^{\alpha x}$ |
| $P_n(x)e^{\alpha x}$ | $\alpha$ 重根 | $x^{2}Q_n(x)e^{\alpha x}$ |
| $e^{\alpha x}\!\left[P_m\cos\beta x+Q_n\sin\beta x\right]$ | $\alpha\pm\beta i$ 非根 | $e^{\alpha x}\!\left[R_k\cos\beta x+S_k\sin\beta x\right]$ |
| $e^{\alpha x}\!\left[P_m\cos\beta x+Q_n\sin\beta x\right]$ | $\alpha\pm\beta i$ 是根 | $x\,e^{\alpha x}\!\left[R_k\cos\beta x+S_k\sin\beta x\right]$ |

其中 $Q_n$ 与 $P_n$ 同次，$k=\max(m,n)$。

**特例（必须记死）**：
$$f=e^{x}\Rightarrow\text{判 }\alpha=1;\qquad f=\sin x\Rightarrow\alpha=0,\beta=1;\qquad f=x^{2}+1\Rightarrow\alpha=0$$

## 五、解的结构与叠加原理

- 非齐次任意两特解之差是齐次解：$y_1-y_2$ 满足 $y''+py'+qy=0$。
- 已知 $n$ 个特解 ⇒ 可拼出 $n-1$ 个齐次解；若其中两个线性无关，则直接写出通解 $y=y_1+C_1(y_1-y_2)+C_2(y_1-y_3)$。
- 叠加：$f=f_1+f_2$ 时，分别求 $y_1^{*},y_2^{*}$，则 $y^{*}=y_1^{*}+y_2^{*}$（**各自按自己的根判乘 $x$**）。
- 由解反求方程：由 $y_2-y_1,\ y_3-y_1$ 的指数/三角形态读出特征根 → 写特征方程 → 代一个特解求 $f(x)$。

## 六、初值问题标准流程（四步）

1. **定类型**：一阶（可分离/齐次/线性）→ 可降阶 → 二阶常系数。
2. **求通解**：含全部独立任意常数（二阶两个）。
3. **代初值**：遇初值就定一个常数，别拖到最后；根式取支也用初值。
4. **验算**：代回原方程 30 秒；应用题再核物理/几何合理性（如 $x>0$、$y>0$）。

## 七、常用积分（解方程时的配套）

$$\int\frac{dx}{x}=\ln|x|+C,\qquad \int\frac{dx}{1+x^{2}}=\arctan x+C$$

$$\int\frac{du}{\sqrt{1+u^{2}}}=\ln\left(u+\sqrt{1+u^{2}}\right)+C$$

$$\int\frac{du}{1-u^{2}}=\frac12\ln\left|\frac{1+u}{1-u}\right|+C,\qquad \int\frac{du}{a^{2}+u^{2}}=\frac1a\arctan\frac ua+C$$

$$\int e^{ax}dx=\frac1a e^{ax}+C,\qquad \int x e^{ax}dx=\frac{e^{ax}}{a}\left(x-\frac1a\right)+C$$

$$\int e^{ax}\sin bx\,dx=\frac{e^{ax}}{a^{2}+b^{2}}\left(a\sin bx-b\cos bx\right)+C$$

$$\int e^{ax}\cos bx\,dx=\frac{e^{ax}}{a^{2}+b^{2}}\left(a\cos bx+b\sin bx\right)+C$$

## 八、建模式速查

| 场景 | 等式来源 | 方程形态 |
| --- | --- | --- |
| 切线/法线截距 | 切线 $Y-y=y'(X-x)$，令 $X=0$ 或 $Y=0$ | 一阶，常可分离 |
| 面积/弧长条件 | $S=\int_a^x f$、$s=\int\sqrt{1+y'^{2}}$ | 求导后成一阶/二阶 |
| 冷却（牛顿） | $\dfrac{dT}{dt}=-k(T-T_0)$ | 可分离（指数衰减） |
| 混合/浓度 | $\dfrac{dm}{dt}=$ 流入 $-$ 流出 | 一阶线性 |
| 增长受限 | $\dfrac{dN}{dt}=rN\left(1-\dfrac NK\right)$ | 可分离（Logistic） |
| 牛顿第二定律 | $m\dfrac{dv}{dt}=F(v)$ 或 $m v\dfrac{dv}{dx}=F(x)$ | 一阶，按"缺谁"选自变量 |

## 九、考场速判表

| 看到 | 立刻做 |
| --- | --- |
| $y'=f(x)g(y)$ 形式 | 分离变量，先查 $g=0$ 的解 |
| 分子分母同次（含 $y/x$） | 令 $u=y/x$，写成 $xu'=\varphi(u)-u$ |
| $y'+P(x)y=Q(x)$ | 套通解公式，$\int P$ 不加 $C$ |
| $y''$ 中**缺 $y$** | $y'=p(x)$ |
| $y''$ 中**缺 $x$** | $y'=p(y)$，$y''=p\dfrac{dp}{dy}$ |
| 二阶常系数 + 自由项 | **先写特征根，再判 $\alpha$（或 $\alpha\pm\beta i$）是否为根** |
| 自由项含 $e^{x}$ 且 $r=1$ 已是根 | 乘 $x$（单根）或 $x^{2}$（重根） |
| $f=\sin x$ 且 $r=\pm i$ | 设 $x(A\cos x+B\sin x)$（共振） |
| 题给多个特解 | 相减得齐次解，反推特征根 |
| $xf(x)=x+\int_1^x f$ 之类 | 先清分母，再两边求导，最后用原式定 $C$ |
| 给出几何/物理条件 | 先写含 $y,y'$ 的等式，再化简成方程 |

## 十、易错速记（考前 1 分钟扫）

1. 标准形 $y'$ 系数必须为 1，$P(x)$ 的**符号**不能错。
2. 除 $g(y)$ 前先找常数解，别丢 $y\equiv y_0$。
3. 开方 $p=\pm\sqrt{F}$ 用初值定支。
4. 非齐次设解**漏乘 $x$ / $x^{2}$** 是最大失分点，做完必代回。
5. 二阶通解必须有**两个**独立任意常数。
6. 初值边算边定，别把 $C_1,C_2$ 拖到最后一起解。
