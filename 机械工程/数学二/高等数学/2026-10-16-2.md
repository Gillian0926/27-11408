## 一、等价无穷小（$x\to0$）

$$x\sim\sin x\sim\tan x\sim\arcsin x\sim\arctan x\sim\ln(1+x)\sim e^{x}-1$$

$$1-\cos x\sim\frac{x^{2}}{2},\qquad (1+x)^{\alpha}-1\sim\alpha x,\qquad a^{x}-1\sim x\ln a$$

$$x-\sin x\sim\frac{x^{3}}{6},\qquad \tan x-x\sim\frac{x^{3}}{3},\qquad x-\ln(1+x)\sim\frac{x^{2}}{2},\qquad \arcsin x-x\sim\frac{x^{3}}{6}$$

$$\sqrt[n]{1+x}-1\sim\frac{x}{n},\qquad \log_a(1+x)\sim\frac{x}{\ln a}$$

## 二、泰勒展开（$x\to0$，佩亚诺余项）

$$e^{x}=1+x+\frac{x^{2}}{2!}+\cdots+\frac{x^{n}}{n!}+o(x^{n})$$

$$\sin x=x-\frac{x^{3}}{3!}+\frac{x^{5}}{5!}-\cdots,\qquad \cos x=1-\frac{x^{2}}{2!}+\frac{x^{4}}{4!}-\cdots$$

$$\ln(1+x)=x-\frac{x^{2}}{2}+\frac{x^{3}}{3}-\cdots,\qquad (1+x)^{\alpha}=1+\alpha x+\frac{\alpha(\alpha-1)}{2!}x^{2}+\cdots$$

$$\frac{1}{1-x}=1+x+x^{2}+\cdots,\qquad \arctan x=x-\frac{x^{3}}{3}+\frac{x^{5}}{5}-\cdots$$

**常用阶数对照**：$\frac{0}{0}$ 型极限中，分母是 $x^{k}$ 就把分子展开到 $x^{k}$。

## 三、导数与中值定理

**参数方程求导**（$x=\varphi(t),\ y=\psi(t)$）：

$$\frac{dy}{dx}=\frac{\psi'(t)}{\varphi'(t)},\qquad \frac{d^{2}y}{dx^{2}}=\frac{d}{dt}\!\left(\frac{\psi'}{\varphi'}\right)\Big/\varphi'(t)$$

**反函数**：$\left[f^{-1}\right]'(y_0)=\dfrac{1}{f'(x_0)}$，其中 $y_0=f(x_0)$。

| 定理 | 条件 | 结论 |
| --- | --- | --- |
| 罗尔 | $[a,b]$ 连续、$(a,b)$ 可导、$f(a)=f(b)$ | $\exists\xi,\ f'(\xi)=0$ |
| 拉格朗日 | $[a,b]$ 连续、$(a,b)$ 可导 | $f(b)-f(a)=f'(\xi)(b-a)$ |
| 柯西 | 两函数均连续可导，$g'\neq0$ | $\dfrac{f(b)-f(a)}{g(b)-g(a)}=\dfrac{f'(\xi)}{g'(\xi)}$ |
| 泰勒 | $n+1$ 阶可导 | $f(x)=\sum\limits_{k=0}^{n}\dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^{k}+R_n$ |

## 四、积分表（必背）

$$\int x^{n}dx=\frac{x^{n+1}}{n+1}\ (n\neq-1),\qquad \int\frac{dx}{x}=\ln|x|,\qquad \int a^{x}dx=\frac{a^{x}}{\ln a}$$

$$\int\frac{dx}{1+x^{2}}=\arctan x,\qquad \int\frac{dx}{\sqrt{1-x^{2}}}=\arcsin x,\qquad \int\frac{dx}{a^{2}+x^{2}}=\frac1a\arctan\frac xa$$

$$\int\frac{dx}{x^{2}-a^{2}}=\frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right|,\qquad \int\frac{dx}{\sqrt{x^{2}\pm a^{2}}}=\ln\left|x+\sqrt{x^{2}\pm a^{2}}\right|$$

$$\int\tan x\,dx=-\ln|\cos x|,\qquad \int\cot x\,dx=\ln|\sin x|,\qquad \int\sec x\,dx=\ln|\sec x+\tan x|$$

$$\int\sqrt{a^{2}-x^{2}}\,dx=\frac{x}{2}\sqrt{a^{2}-x^{2}}+\frac{a^{2}}{2}\arcsin\frac xa$$

$$\int e^{ax}\sin bx\,dx=\frac{e^{ax}\left(a\sin bx-b\cos bx\right)}{a^{2}+b^{2}},\qquad \int e^{ax}\cos bx\,dx=\frac{e^{ax}\left(a\cos bx+b\sin bx\right)}{a^{2}+b^{2}}$$

## 五、定积分计算技巧

**分部**：$\displaystyle\int_a^b u\,dv=\left[uv\right]_a^b-\int_a^b v\,du$

**区间再现**：

$$\int_0^{a}f(x)dx=\int_0^{a}f(a-x)dx,\qquad \int_0^{\pi}xf(\sin x)dx=\frac{\pi}{2}\int_0^{\pi}f(\sin x)dx$$

**奇偶**：$\int_{-a}^{a}f=2\int_0^{a}f$（$f$ 偶），$=0$（$f$ 奇）

**Wallis 公式**：

$$\int_0^{\pi/2}\sin^{n}x\,dx=\int_0^{\pi/2}\cos^{n}x\,dx=\begin{cases}\dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac12\cdot\dfrac{\pi}{2}, & n\ \text{为偶}\\[3mm] \dfrac{n-1}{n}\cdot\dfrac{n-3}{n-2}\cdots\dfrac23\cdot1, & n\ \text{为奇}\end{cases}$$

**变限积分求导**：

$$\frac{d}{dx}\int_{\alpha(x)}^{\beta(x)}f(t)\,dt=f(\beta)\beta'-f(\alpha)\alpha'$$

$$\frac{d}{dx}\int_0^{x}(x-t)f(t)\,dt=\int_0^{x}f(t)\,dt,\qquad \frac{d^{2}}{dx^{2}}\int_0^{x}(x-t)f(t)\,dt=f(x)$$

**积分中值**：$f$ 连续时 $\displaystyle\int_a^b f(x)dx=f(\xi)(b-a),\ \xi\in[a,b]$。

## 六、定积分的几何与物理应用

**面积**：$S=\displaystyle\int_a^b\left|f(x)-g(x)\right|dx$

**旋转体体积**：

$$V_x=\pi\int_a^b f^{2}(x)\,dx,\qquad V_y=2\pi\int_a^b x\left|f(x)\right|dx\ (\text{柱壳法},\ 0\le a<b)$$

**旋转体侧面积**：$S=2\pi\displaystyle\int_a^b\left|f(x)\right|\sqrt{1+f'^{2}(x)}\,dx$

**弧长**：$s=\displaystyle\int_a^b\sqrt{1+f'^{2}(x)}\,dx$；参数式 $s=\displaystyle\int_\alpha^\beta\sqrt{\varphi'^{2}+\psi'^{2}}\,dt$

**元素法三件套**：做功 $dW=F(x)dx$；水压力 $dP=\rho g\,x\cdot L(x)\,dx$；形心 $\bar{x}=\dfrac{\int x\,dA}{\int dA}$

## 七、多元函数微分学

**全微分**：$dz=f_x\,dx+f_y\,dy$（可微 $\Rightarrow$ 偏导存在；偏导连续 $\Rightarrow$ 可微）

**复合链式**（$z=z(u,v),\ u=u(x,y),\ v=v(x,y)$）：

$$\frac{\partial z}{\partial x}=\frac{\partial z}{\partial u}\cdot\frac{\partial u}{\partial x}+\frac{\partial z}{\partial v}\cdot\frac{\partial v}{\partial x}$$

**隐函数**：$F(x,y,z)=0\Rightarrow\dfrac{\partial z}{\partial x}=-\dfrac{F_x}{F_z},\ \dfrac{\partial z}{\partial y}=-\dfrac{F_y}{F_z}$

**无条件极值**：驻点处 $A=f_{xx},B=f_{xy},C=f_{yy}$

| $AC-B^{2}$ | 结论 |
| --- | --- |
| $>0$ | 极值（$A<0$ 极大，$A>0$ 极小） |
| $<0$ | 非极值 |
| $=0$ | 需另判（用定义） |

**条件极值**：$L=f+\lambda\varphi$，解 $\nabla L=0$ 得候选点。

## 八、二重积分

**直角坐标**：

$$\iint_D f\,d\sigma=\int_a^b dx\int_{y_1(x)}^{y_2(x)}f\,dy=\int_c^d dy\int_{x_1(y)}^{x_2(y)}f\,dx$$

**极坐标**：$x=r\cos\theta,\ y=r\sin\theta$，$d\sigma=r\,dr\,d\theta$

$$\iint_D f\,d\sigma=\int_\alpha^\beta d\theta\int_{r_1(\theta)}^{r_2(\theta)}f(r\cos\theta,r\sin\theta)\,r\,dr$$

**常用极坐标区域**：圆 $x^{2}+y^{2}=a^{2}$：$0\le r\le a$，$0\le\theta\le2\pi$；上半圆：$0\le\theta\le\pi$；心形线内：$0\le r\le a(1+\cos\theta)$。

**对称性**：$D$ 关于 $x$ 轴对称且 $f(x,-y)=-f(x,y)\Rightarrow\iint_D f=0$；若 $f(x,-y)=f(x,y)$ 则等于上半部分的 2 倍。

## 九、常微分方程

**一阶三类**：

| 型 | 形式 | 解法 |
| --- | --- | --- |
| 可分离 | $y'=f(x)g(y)$ | $\displaystyle\int\frac{dy}{g(y)}=\int f(x)dx+C$ |
| 齐次 | $y'=f\!\left(\frac yx\right)$ | 令 $u=\frac yx$，$y'=u+xu'$ |
| 一阶线性 | $y'+P(x)y=Q(x)$ | $y=e^{-\int P}\left[\int Qe^{\int P}dx+C\right]$ |

**可降阶三型**：$y^{(n)}=f(x)$ 逐次积分；$y''=f(x,y')$ 令 $p=y'$；$y''=f(y,y')$ 令 $p=y'$，$y''=p\dfrac{dp}{dy}$。

**二阶常系数齐次** $y''+py'+qy=0$，特征方程 $r^{2}+pr+q=0$：

| 判别式 | 根 | 通解 |
| --- | --- | --- |
| $\Delta>0$ | $r_1\neq r_2$ 实根 | $C_1e^{r_1x}+C_2e^{r_2x}$ |
| $\Delta=0$ | $r$（二重） | $(C_1+C_2x)e^{rx}$ |
| $\Delta<0$ | $\alpha\pm\beta i$ | $e^{\alpha x}\left(C_1\cos\beta x+C_2\sin\beta x\right)$ |

**非齐次通解**：$y=Y+y^{*}$；试解形式（$k$ = 重数 0/1/2）：

| $f(x)$ | 设 $y^{*}$ |
| --- | --- |
| $P_m(x)$ | $x^{k}Q_m(x)$ |
| $P_m(x)e^{\lambda x}$ | $x^{k}Q_m(x)e^{\lambda x}$ |
| $A\cos\beta x+B\sin\beta x$ | $x^{k}\left(a\cos\beta x+b\sin\beta x\right)$ |

**解的结构**：非齐减非齐得齐；两非齐特解之差是齐次解；由三个特解写通解

$$y=y_1^{*}+C_1\left(y_2^{*}-y_1^{*}\right)+C_2\left(y_3^{*}-y_1^{*}\right)\quad(\text{两差值线性无关})$$

## 十一、收官高频陷阱对照表

| 错误 | 正确 |
| --- | --- |
| 洛必达不看条件，只管求导 | 先验三条件；$\lim\frac{f'}{g'}$ 不存在 ≠ 原极限不存在 |
| $\frac{d}{dx}\int_0^{x}f(x-t)dt=f(0)$ | 先换元 $u=x-t$，得 $\int_0^x f(u)du$，导数为 $f(x)$ |
| 极坐标 $d\sigma=dr\,d\theta$ | $d\sigma=r\,dr\,d\theta$ |
| 对称性只判被积函数 | 区域对称 + 函数奇偶性，两者齐备 |
| 条件极值只有候选点就下结论 | 补"有界闭集上连续函数取到最值" |
| 证不等式直接写结论 | 构造 $F$，用单调性 / 中值定理严格过渡 |
| 一阶线性通解漏 $+C$ | $y=e^{-\int P}\left[\int Qe^{\int P}dx+C\right]$ |
| 非齐次撞根不乘 $x^{k}$ | 是 $k$ 重根就乘 $x^{k}$ |
| 初值代进特解 | 只代**通解**及其导数 |
| 建模题只列方程不定初值 | 五步法：设变量 → 翻译 → 定阶 → 定初值 → 解 + 检验 |
