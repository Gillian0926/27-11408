## 一、30 秒判别

$$\text{可分离}\ \to\ \text{齐次}\ \to\ \text{一阶线性}\ \to\ \text{可降阶}\ \to\ \text{二阶常系数}$$

| 长相 | 类型 |
| --- | --- |
| $y'=f(x)g(y)$ | 可分离 |
| $y'=\varphi(y/x)$ | 齐次 |
| $y'+P(x)y=Q(x)$ | 一阶线性 |
| $y^{(n)}=f(x)$ | 逐次积分 $n$ 次 |
| $y''=f(x,y')$（缺 $y$） | $p=y',\ y''=p'$ |
| $y''=f(y,y')$（缺 $x$） | $p=y',\ y''=p\dfrac{dp}{dy}$ |
| 常系数 + 指数/三角/多项式右端 | 特征方程 + 特解 |

## 二、一阶三类

$$\text{可分离：}\ \int\frac{dy}{g(y)}=\int f(x)dx+C\quad(\text{先查 }g(y)=0\ \text{的常解})$$

$$\text{齐次：}\ u=\frac yx,\quad y'=u+xu',\qquad \int\frac{du}{\varphi(u)-u}=\int\frac{dx}{x}+C$$

$$\text{一阶线性：}\ \boxed{\,y=e^{-\int Pdx}\left[\int Q\,e^{\int Pdx}dx+C\right]\,}\qquad\big(y'+P(x)y=Q(x)\big)$$

常系数特例：$y'+ay=b\Rightarrow y=\dfrac ba+Ce^{-ax}$；$y'+ay=0\Rightarrow y=Ce^{-ax}$。

---

## 三、可降阶三型

$$y''=\frac{dp}{dx}=\frac{dp}{dy}\cdot\frac{dy}{dx}=p\frac{dp}{dy}\qquad(\text{缺 }x\text{ 型核心})$$

| 型 | 方程 | 换元 | 化为 |
| --- | --- | --- | --- |
| Ⅰ | $y^{(n)}=f(x)$ | — | 积分 $n$ 次，$n$ 个常数 |
| Ⅱ | $y''=f(x,y')$ | $p=y'(x)$ | $p'=f(x,p)$ |
| Ⅲ | $y''=f(y,y')$ | $p=y'(x)$ | $p\dfrac{dp}{dy}=f(y,p)$ |

Ⅲ 型收尾：$\dfrac{dy}{dx}=p(y)\Rightarrow\displaystyle\int\frac{dy}{p(y)}=x+C$。

**凑导数常用**：$yy''+(y')^{2}=(yy')'$；$\dfrac{y''y-(y')^{2}}{y^{2}}=\left(\dfrac{y'}{y}\right)'$。

## 四、二阶常系数线性方程（核心表）

**齐次** $y''+py'+qy=0$，特征方程 $r^{2}+pr+q=0$：

| 特征根 | 通解 $Y$ |
| --- | --- |
| $r_1\neq r_2$ 实 | $C_1e^{r_1x}+C_2e^{r_2x}$ |
| $r$ 二重 | $(C_1+C_2x)e^{rx}$ |
| $\alpha\pm\beta i$ | $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$ |

**非齐次** $y''+py'+qy=f(x)$，设 $y^{*}=x^{k}\cdot(\text{同型})$，$k$ = 对应根的重数：

| 右端 $f(x)$ | 特解设法 | $k$ |
| --- | --- | --- |
| $P_m(x)$ | $x^{k}Q_m(x)$ | $0$ 是几重根 |
| $P_m(x)e^{\lambda x}$ | $x^{k}Q_m(x)e^{\lambda x}$ | $\lambda$ 是几重根 |
| $e^{\alpha x}\big(P_l\cos\beta x+Q_n\sin\beta x\big)$ | $x^{k}e^{\alpha x}\big(R_m^{(1)}\cos\beta x+R_m^{(2)}\sin\beta x\big)$，$m=\max(l,n)$ | $\alpha\pm\beta i$ 是根取 $1$，否则 $0$ |

> **三角右端必须 $\cos,\sin$ 成对设**；右端只给 $\cos$ 也要设两项。

**平移简化（考场利器）**：令 $y=e^{\lambda x}u$，则

$$(D-\lambda)^{n}\big(e^{\lambda x}u\big)=e^{\lambda x}u^{(n)}$$

例：$y''-4y'+4y=e^{2x}\Rightarrow u''=1\Rightarrow u=\dfrac{x^{2}}{2}$。

**特解可加性**：$f=f_1+f_2\Rightarrow y^{*}=y_1^{*}+y_2^{*}$（分开设、分别代，别合并系数）。

## 五、解的结构与「由解反求」

**结构**：非齐次通解 $=$ 齐次通解 $+$ 一个特解；两解之差是齐次解；三解 $y_1,y_2,y_3$ 的通解

$$y=y_1+C_1(y_2-y_1)+C_2(y_3-y_1)$$

**反求方程**（由解读根）：

$$e^{r_1x},e^{r_2x}:\ y''-(r_1+r_2)y'+r_1r_2y=0$$
$$e^{rx},xe^{rx}:\ y''-2ry'+r^{2}y=0$$
$$e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x:\ y''-2\alpha y'+(\alpha^{2}+\beta^{2})y=0$$

## 六、建模四类

**① 冷却**（$T_s$ 环境温度）：$\ \dfrac{dT}{dt}=-k(T-T_s)\Rightarrow T=T_s+(T_0-T_s)e^{-kt}$

**② 增长 / 衰减 / Logistic**：

$$\frac{dN}{dt}=rN\Rightarrow N=N_0e^{rt};\qquad \frac{dN}{dt}=rN\Big(1-\frac NK\Big)\Rightarrow N=\frac{K}{1+\left(\frac{K}{N_0}-1\right)e^{-rt}}$$

**③ 混合**：$\ \dfrac{dQ}{dt}=c_{\text{in}}q_{\text{in}}-\dfrac{Q}{V(t)}q_{\text{out}},\quad V(t)=V_0+(q_{\text{in}}-q_{\text{out}})t$

**④ 带阻力直线运动**（运动方向为正）：

$$m\frac{dv}{dt}=mg-kv\Rightarrow v=\frac{mg}{k}+\Big(v_0-\frac{mg}{k}\Big)e^{-kt/m},\quad v_\infty=\frac{mg}{k}$$
$$x(t)=\int_0^{t}v(s)\,ds\quad(\text{必须再积一次})$$

**几何型**：切线/法线斜率、曲边梯形面积、弧长 → 先写「几何条件 = 导数表达式」再解方程。

## 七、交卷前 8 条自查

1. 一阶线性：$\int Pdx$ 算了吗？$e^{\int Pdx}$ 在积分号内、$e^{-\int Pdx}$ 在外，位置对吗？
2. 齐次方程：$y'=u+xu'$ 写了吗？$u$ 最后换回 $y/x$ 了吗？
3. 缺 $x$ 型：用的是 $p\dfrac{dp}{dy}$ 吗？分离掉的 $p\equiv0$ 交代了吗？
4. 特解：共振重数 $k$ 按**重数**取了吗？三角右端 $\cos,\sin$ 成对设了吗？回代验证了吗？
5. 通解之后**代初值**了吗？开方按初值定正负支了吗？
6. 定义域写了吗（$x>0$、$t\ge0$、$|x|<\!$某值）？建模题带**单位**了吗？
7. 问「再过多长时间」「还需多少」时，减掉已用量了吗？
8. 二阶题若含「解在 $x\to+\infty$ 有界 / 极限存在」条件：指数增长项系数必须为 $0$。

## 八、现查积分

$$\int\frac{dx}{x}=\ln|x|,\quad \int\frac{dx}{1+x^{2}}=\arctan x,\quad \int\frac{dx}{a^{2}+x^{2}}=\frac1a\arctan\frac xa$$
$$\int\frac{dx}{x^{2}-a^{2}}=\frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right|,\quad \int\frac{dx}{\sqrt{a^{2}-x^{2}}}=\arcsin\frac xa$$
$$\int e^{ax}dx=\frac{e^{ax}}{a},\quad \int xe^{ax}dx=\frac{e^{ax}}{a}\Big(x-\frac1a\Big),\quad \int\ln x\,dx=x\ln x-x$$
$$\int\frac{dy}{y(K-y)}=\frac1K\ln\left|\frac{y}{K-y}\right|\quad(\text{Logistic})$$
