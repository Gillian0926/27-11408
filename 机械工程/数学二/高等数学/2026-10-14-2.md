## 一、建模五步法

$$\text{设变量}\ \to\ \text{翻译（列等式）}\ \to\ \text{定阶数}\ \to\ \text{定初值}\ \to\ \text{解 + 检验}$$

- 一阶导出现 → 一阶方程；二阶导出现 → 二阶方程。
- 检验方式：把解代回**原题的文字条件**（不是代回微分方程）。

| 切线斜率 | $k_{\text{切}}=y'$ |

## 四、一阶方程速判（第 17 讲复习）

$$y'=f(x,y)\ \Longrightarrow\ \begin{cases}
f(x)g(y)\ \text{形} & \to\ \text{可分离：}\displaystyle\int\frac{dy}{g(y)}=\int f(x)dx+C\\[2mm]
f\!\left(\dfrac yx\right)\ \text{形} & \to\ \text{齐次：}u=\dfrac yx,\ y'=u+xu'\\[2mm]
y'+P(x)y=Q(x) & \to\ \text{线性：}\displaystyle y=e^{-\int P}\left[\int Qe^{\int P}dx+C\right]
\end{cases}$$

**常用积分因子** $\mu=e^{\int P\,dx}$ 速查：

| $P(x)$ | $\mu$ |
| --- | --- |
| $a$（常数） | $e^{ax}$ |
| $\dfrac1x$ | $x$ |
| $-\dfrac1x$ | $\dfrac1x$ |
| $\dfrac{n}{a+x}$ | $(a+x)^{n}$ |
| $-\dfrac{n}{a+x}$ | $(a+x)^{-n}$ |

## 五、线性方程解的结构（五条）

设 $y''+p(x)y'+q(x)y=f(x)$。

| # | 内容 |
| --- | --- |
| 1 | 齐次解的线性组合仍是齐次解 |
| 2 | 两线性无关齐次解 → $Y=C_1y_1+C_2y_2$ 是齐次通解 |
| 3 | 非齐次通解 $y=Y+y^{*}$ |
| 4 | **非齐减非齐得齐**：$y_1^{*}-y_2^{*}$ 是齐次解 |
| 5 | 叠加原理：$f=f_1+f_2\Rightarrow y^{*}=y_1^{*}+y_2^{*}$ |

**由三个特解写通解**：

$$y=y_1^{*}+C_1\left(y_2^{*}-y_1^{*}\right)+C_2\left(y_3^{*}-y_1^{*}\right)\quad(\text{两差值须线性无关})$$

**由特解反求方程**：两两作差 → 定特征根 → 写齐次方程 → 代一个特解定 $f(x)$。

## 六、二阶常系数：特征根表（必背）

$$y''+py'+qy=0\ \Longleftrightarrow\ r^{2}+pr+q=0,\qquad r_{1,2}=\frac{-p\pm\sqrt{p^{2}-4q}}{2}$$

| 判别式 | 根 | 通解 |
| --- | --- | --- |
| $\Delta>0$ | $r_1\neq r_2$（实） | $C_1e^{r_1x}+C_2e^{r_2x}$ |
| $\Delta=0$ | $r$（二重） | $(C_1+C_2x)e^{rx}$ |
| $\Delta<0$ | $\alpha\pm\beta i$ | $e^{\alpha x}\left(C_1\cos\beta x+C_2\sin\beta x\right)$ |

**特例表**：

| 方程 | 特征根 | 通解 |
| --- | --- | --- |
| $y''-y=0$ | $\pm1$ | $C_1e^{x}+C_2e^{-x}$ |
| $y''+y=0$ | $\pm i$ | $C_1\cos x+C_2\sin x$ |
| $y''+k^{2}y=0$ | $\pm ki$ | $C_1\cos kx+C_2\sin kx$ |
| $y''+2y'+y=0$ | $-1$（二重） | $(C_1+C_2x)e^{-x}$ |
| $y''-3y'+2y=0$ | $1,\ 2$ | $C_1e^{x}+C_2e^{2x}$ |
| $y''-4y'+13y=0$ | $2\pm3i$ | $e^{2x}\left(C_1\cos3x+C_2\sin3x\right)$ |

## 七、非齐次待定系数：试解表（必背）

$k$ = $\lambda$（或 $\alpha\pm\beta i$）作为特征根的**重数**（0 / 1 / 2）。

| 自由项 $f(x)$ | 条件 | 设 $y^{*}$ |
| --- | --- | --- |
| $P_m(x)$ | $0$ 不是特征根 | $Q_m(x)$ |
| $P_m(x)$ | $0$ 是 $k$ 重根 | $x^{k}Q_m(x)$ |
| $P_m(x)e^{\lambda x}$ | $\lambda$ 不是特征根 | $Q_m(x)e^{\lambda x}$ |
| $P_m(x)e^{\lambda x}$ | $\lambda$ 是 $k$ 重根 | $x^{k}Q_m(x)e^{\lambda x}$ |
| $A\cos\beta x+B\sin\beta x$ | $\pm\beta i$ 不是特征根 | $a\cos\beta x+b\sin\beta x$ |
| $A\cos\beta x+B\sin\beta x$ | $\pm\beta i$ 是 $k$ 重根 | $x^{k}\left(a\cos\beta x+b\sin\beta x\right)$ |
| $e^{\alpha x}\!\left(P_l\cos\beta x+P_n\sin\beta x\right)$ | 一般 | $x^{k}e^{\alpha x}\!\left(R_m\cos\beta x+S_m\sin\beta x\right)$，$m=\max\{l,n\}$ |

**多项式次数对照**：

| $P_m$ | 设 $Q_m$ |
| --- | --- |
| 常数 $A$ | $a$ |
| 一次 | $Ax+B$ |
| 二次 | $Ax^{2}+Bx+C$ |

**降阶公式（提速利器）**：令 $y=e^{\lambda x}u$，

$$y''+py'+qy=e^{\lambda x}\left[u''+(2\lambda+p)u'+(\lambda^{2}+p\lambda+q)u\right]$$

| 情形 | 退化为 |
| --- | --- |
| $\lambda$ 不是特征根 | 三项全在 |
| $\lambda$ 是单根 | $e^{\lambda x}\left[u''+(2\lambda+p)u'\right]$ |
| $\lambda$ 是二重根 | $e^{\lambda x}u''$ |

## 八、可降阶三型（第 18 讲复习）

| 型 | 方程 | 换元 | 关键 |
| --- | --- | --- | --- |
| Ⅰ | $y^{(n)}=f(x)$ | — | 逐次积分，每次添**一个**常数 |
| Ⅱ | $y''=f(x,y')$ | $y'=p(x)$ | $y''=p'$，解出 $p$ 后**再积一次** |
| Ⅲ | $y''=f(y,y')$ | $y'=p(y)$ | $\boxed{y''=p\dfrac{dp}{dy}}$，再解 $\dfrac{dy}{dx}=\varphi(y)$ |

## 九、积分方程 / 变限积分套路

**核心恒等式**（第 09 讲）：

$$\frac{d}{dx}\int_0^{x}(x-t)f(t)\,dt=\int_0^{x}f(t)\,dt,\qquad \frac{d^{2}}{dx^{2}}\int_0^{x}(x-t)f(t)\,dt=f(x)$$

**标准流程**：

1. 原式令 $x=0$ 得 $f(0)$；
2. 两边求导一次，再令 $x=0$ 得 $f'(0)$；
3. 求导到只剩 $f$ 的微分方程为止（含二阶导即停）；
4. 按第 18 讲解方程，最后代初值。

> 若被积函数含 $x$ 且不能直接求导，先把 $x$ 提到积分号外：$\displaystyle\int_0^{x}x f(t)dt=x\int_0^{x}f(t)dt$。

## 十、高频陷阱对照表

| 错误 | 正确 |
| --- | --- |
| $y$ 轴截距写 $y+xy'$ | $b=y-xy'$ |
| 混合问题用 $x$ 当浓度 | 流出项 $\dfrac{x}{V(t)}q_{\text{出}}$ |
| $V(t)$ 当常数 | $V(t)=V_0+(q_{\text{入}}-q_{\text{出}})t$ |
| 积分方程求导后不补初值 | 补 $f(0)$、$f'(0)$ |
| 重根写 $Ce^{rx}$ | $(C_1+C_2x)e^{rx}$ |
| 撞根不乘 $x^{k}$ | 是 $k$ 重根就乘 $x^{k}$ |
| 只写 $y^{*}$ | $y=Y+y^{*}$ |
| 初值代进 $y^{*}$ | 只代进**通解**及其导数 |
| 型 Ⅲ 写 $y''=\dfrac{dp}{dy}$ | $y''=p\dfrac{dp}{dy}$ |
| 型 Ⅱ 求出 $p$ 就收笔 | 还要 $\int p\,dx$ 再积一次 |
| 反求通解时差值不独立 | 先验证两差值线性无关 |

## 十一、常用反导数（回代必备）

$$\int e^{ax}dx=\frac{e^{ax}}{a},\qquad \int xe^{ax}dx=\frac{e^{ax}}{a^{2}}(ax-1),\qquad \int x^{2}e^{ax}dx=\frac{e^{ax}}{a^{3}}\left(a^{2}x^{2}-2ax+2\right)$$

$$\int\frac{dx}{x}=\ln|x|,\qquad \int\frac{dx}{1+x^{2}}=\arctan x,\qquad \int\frac{dx}{1-x^{2}}=\frac12\ln\left|\frac{1+x}{1-x}\right|$$

$$\int\frac{dx}{a+x}=\ln|a+x|,\qquad \int(a+x)^{n}dx=\frac{(a+x)^{n+1}}{n+1}\ (n\neq-1)$$

$$\int e^{ax}\cos bx\,dx=\frac{e^{ax}}{a^{2}+b^{2}}\left(a\cos bx+b\sin bx\right),\qquad \int e^{ax}\sin bx\,dx=\frac{e^{ax}}{a^{2}+b^{2}}\left(a\sin bx-b\cos bx\right)$$

## 十二、自检清单（做题后逐条打钩）

1. 变量、单位、定义域写了吗？谁是谁的函数清晰吗？
2. 每一句中文条件都翻译成等式了吗？有没有遗漏条件？
3. 方程阶数对吗？初值条件个数等于阶数吗？
4. 一阶方程"认型"准确吗（可分离 / 齐次 / 线性 / 换元）？
5. 二阶非齐次：$k$ 判对了吗？$Q_m$ 与 $P_m$ 同次吗？$x$ 最高次项自动消掉了吗？
6. 结果是**通解 + 初值**还是**特解**？常数个数对吗？
7. 代回**原题文字条件**验证了吗（截距、浓度、极限速度等）？
8. 约掉的因子（$p\equiv0$、$g(y)=0$、$y\equiv C$）单独验过吗？
