## 二、不定积分：先识别结构，再动笔

### 1. 结构 → 动作 对照表

| 被积函数形态 | 首选动作 |
| --- | --- |
| $f(ax+b)$ | 凑 $d(ax+b)=\frac1a d(ax+b)$ 的倍数 |
| $f(x^{n})\cdot x^{n-1}$ | 凑 $d(x^{n})$ |
| $\dfrac{P(x)}{Q(x)}$ 假分式 | **先多项式除法**，再拆部分分式 |
| $\sqrt{a^{2}-x^{2}}$ | $x=a\sin t$；$\sqrt{a^{2}+x^{2}}$ 用 $x=a\tan t$；$\sqrt{x^{2}-a^{2}}$ 用 $x=a\sec t$ |
| 幂函数 × 指数/三角 | 分部，$u$ 取**幂函数**（降次） |
| 含 $\ln x,\ \arctan x,\ \arcsin x$ | 分部，$u$ 取**反三角/对数**（求导后变有理） |
| 三角偶次幂 | 降幂：$\sin^{2}x=\dfrac{1-\cos 2x}{2}$，$\cos^{2}x=\dfrac{1+\cos 2x}{2}$ |
| 三角奇次幂 | 拆出一个凑微分：$\sin^{3}x\,dx=-(1-\cos^{2}x)d\cos x$ |
| $\dfrac{1}{x^{2}+px+q}$（判别式 $<0$） | 配方 → $\arctan$ |
| 有理式含 $e^{x}$ 且分子分母同次 | 令 $t=e^{x}$ 或分子分母同除 $e^{x}$ |

### 2. 例 1（凑微分 + 分部，二轮典型"看着难其实一步"）

求 $\displaystyle I=\int\frac{xe^{x}}{(1+x)^{2}}\,dx$。

**解**：关键观察
$$\left(\frac{1}{1+x}\right)'=-\frac{1}{(1+x)^{2}}\ \Longrightarrow\ \frac{dx}{(1+x)^{2}}=-d\!\left(\frac{1}{1+x}\right)$$

于是
$$I=-\int xe^{x}\,d\!\left(\frac{1}{1+x}\right)=-\left[\frac{xe^{x}}{1+x}-\int\frac{1}{1+x}\left(e^{x}+xe^{x}\right)dx\right]$$

而 $\dfrac{e^{x}(1+x)}{1+x}=e^{x}$，故
$$I=-\frac{xe^{x}}{1+x}+\int e^{x}dx=-\frac{xe^{x}}{1+x}+e^{x}+C=\frac{e^{x}}{1+x}+C$$

**验算**：$\left(\dfrac{e^{x}}{1+x}\right)'=\dfrac{e^{x}(1+x)-e^{x}}{(1+x)^{2}}=\dfrac{xe^{x}}{(1+x)^{2}}$ ✓

> **二轮心法**：不定积分做完**必须求导验算一次**（10 秒），这是性价比最高的防错手段。

## 三、定积分三把刀：对称性、周期性、换元配对

### 1. 第一把刀：对称性（先看区间再动笔）

$$\int_{-a}^{a}f(x)\,dx=\begin{cases}0,& f\ \text{奇}\\ 2\displaystyle\int_{0}^{a}f(x)\,dx,& f\ \text{偶}\end{cases}$$

**进阶（数二高频）**：若 $f$ 为偶函数，则对任意常数 $k$ 有
$$\int_{-a}^{a}\frac{f(x)}{1+e^{kx}}\,dx=\frac12\int_{-a}^{a}f(x)\,dx=\int_{0}^{a}f(x)\,dx$$

> 证法固定：令 $x=-t$ 把 $I$ 写成另一个积分，与 $I$ **相加**，$\dfrac{1}{1+e^{kt}}+\dfrac{1}{1+e^{-kt}}=1$。

**另一常用配对**（区间 $[0,\pi]$ 上的"$\sin$ 型"）：
$$\int_{0}^{\pi}xf(\sin x)\,dx=\frac{\pi}{2}\int_{0}^{\pi}f(\sin x)\,dx$$
> 令 $x=\pi-t$，两式相加得 $2I=\pi\int_0^\pi f(\sin t)dt$。

### 2. 例 2（配对 + 对称，两把刀一起用）

求 $\displaystyle\int_{-\pi/2}^{\pi/2}\frac{\sin^{2}x}{1+e^{x}}\,dx$。

**解**：$f(x)=\sin^{2}x$ 为偶函数，$a=\dfrac{\pi}{2}$，由上面的进阶公式
$$\int_{-\pi/2}^{\pi/2}\frac{\sin^{2}x}{1+e^{x}}dx=\int_{0}^{\pi/2}\sin^{2}x\,dx=\frac{\pi}{4}$$

（用 $\int_0^{\pi/2}\sin^2x\,dx=\dfrac12\cdot\dfrac{\pi}{2}=\dfrac{\pi}{4}$。）

### 3. 例 3（换元配对："分子分母互换"型）

求 $\displaystyle I=\int_{0}^{\pi/2}\frac{\sin^{3}x}{\sin^{3}x+\cos^{3}x}\,dx$。

**解**：令 $x=\dfrac{\pi}{2}-t$，则 $dx=-dt$，$\sin x\to\cos t$，上下限互换：
$$I=\int_{0}^{\pi/2}\frac{\cos^{3}t}{\cos^{3}t+\sin^{3}t}\,dt=I$$
（$I$ 与自身相等，说明该换元是"恒等"的）。改用**相加**思路更直接：设
$$J=\int_{0}^{\pi/2}\frac{\cos^{3}x}{\sin^{3}x+\cos^{3}x}dx$$
由换元 $x\to\dfrac{\pi}{2}-x$ 得 $J=I$，而 $I+J=\displaystyle\int_{0}^{\pi/2}1\,dx=\frac{\pi}{2}$，故
$$I=\frac{\pi}{4}$$

> **识别信号**：被积函数是 $\dfrac{g(x)}{g(x)+g(\pi/2-x)}$ 形式 ⇒ 答案恒为 $\dfrac12\times$ 区间长。

### 4. 第三把刀：周期性

$$\int_{a}^{a+T}f(x)\,dx=\int_{0}^{T}f(x)\,dx\quad(f\ \text{以}\ T\ \text{为周期})$$
$$\int_{0}^{nT}f(x)\,dx=n\int_{0}^{T}f(x)\,dx$$

## 四、变限积分：四类题型，四个固定动作

### 1. 求导（含参型必先拆）

**基本型**：
$$\frac{d}{dx}\int_{\alpha(x)}^{\beta(x)}f(t)\,dt=f\big(\beta(x)\big)\beta'(x)-f\big(\alpha(x)\big)\alpha'(x)$$

**含参型（最高频错误点）**：$\displaystyle F(x)=\int_{0}^{x}(x-t)f(t)\,dt$ 中 $x$ 同时出现在**上限与 integrand**，
$$\boxed{F(x)=x\int_{0}^{x}f(t)\,dt-\int_{0}^{x}tf(t)\,dt}$$
$$F'(x)=\int_{0}^{x}f(t)\,dt+xf(x)-xf(x)=\int_{0}^{x}f(t)\,dt,\qquad F''(x)=f(x)$$

> **绝对不要**写 $F'(x)=(x-x)f(x)=0$。同类还有 $\int_0^x f(x-t)dt$：先令 $u=x-t$ 化成 $\int_0^x f(u)du$ 再求导。

### 2. 例 4（变限积分 + 极值/凹凸）

设 $f$ 在 $[0,+\infty)$ 上连续且 $f(x)>0$，$F(x)=\displaystyle\int_{0}^{x}(x-t)f(t)\,dt$。判断 $x=0$ 是否为极值点，并说明 $F$ 的凹凸性。

**解**：由上，$F'(x)=\displaystyle\int_0^xf(t)dt$，$F''(x)=f(x)>0$。
- $x>0$ 时 $F'(x)=\int_0^x f>0$（被积函数正）；$x=0$ 时 $F'(0)=0$。故 $F$ 在 $[0,+\infty)$ 单调增，$x=0$ 是**极小值点**（端点意义上的最小值点），$F(0)=0$。
- $F''=f>0$ ⇒ $F$ 在 $[0,+\infty)$ **凹**（曲线开口向上）。

### 3. 例 5（变限积分 + 极限，洛必达与等价的分工）

求 $\displaystyle\lim_{x\to0}\frac{\int_{0}^{x}(x-t)\sin t\,dt}{x^{3}}$。

**解**：先拆变量：分子 $=x\displaystyle\int_0^x\sin t\,dt-\int_0^xt\sin t\,dt$。这是 $\dfrac00$ 型，洛必达（分子求导用乘积法则 + 变限求导）：
$$N'(x)=\int_{0}^{x}\sin t\,dt+x\sin x-x\sin x=1-\cos x$$
故
$$\lim_{x\to0}\frac{N(x)}{x^{3}}=\lim_{x\to0}\frac{1-\cos x}{3x^{2}}=\lim_{x\to0}\frac{\frac{x^{2}}{2}}{3x^{2}}=\frac16$$

> **顺序**：变限积分的极限题，**先洛必达退掉积分号，再用等价无穷小**。反过来（直接对积分做等价替换）容易出错。

## 五、积分不等式：三条标准路

| 路线 | 适用 | 关键动作 |
| --- | --- | --- |
| **单调性** | 证明 $\int_a^b f\ge \text{某式}$，或含变上限 | 构造 $\Phi(x)=\int_a^x f-\text{右端}$，证 $\Phi'\ge0$、$\Phi(a)=0$ |
| **积分中值 / 估值** | 被积函数有界、要"某一值" | $m(b-a)\le\int_a^b f\le M(b-a)$；$\int_a^b f=f(\xi)(b-a)$ |
| **柯西（平方展开）** | 出现 $\left(\int f\right)^2$ 或 $\int f\cdot\int\frac1f$ | 用 $\int(\cdots)^2\ge0$ 或判别式 |

### 例 6（柯西型，写"判别式"最省字）

设 $f$ 在 $[0,1]$ 上连续且 $f(x)>0$。证明
$$\int_{0}^{1}f(x)\,dx\cdot\int_{0}^{1}\frac{dx}{f(x)}\ge1$$

**证**：对任意实数 $\lambda$，
$$0\le\int_{0}^{1}\left(\sqrt{f(x)}-\frac{\lambda}{\sqrt{f(x)}}\right)^{2}dx=\int_{0}^{1}f\,dx-2\lambda+\lambda^{2}\int_{0}^{1}\frac{dx}{f}$$
右端是 $\lambda$ 的二次式且恒 $\ge0$，故判别式 $\le0$：
$$4-4\int_{0}^{1}f\,dx\cdot\int_{0}^{1}\frac{dx}{f}\le0\ \Longrightarrow\ \int_{0}^{1}f\cdot\int_{0}^{1}\frac1f\ge1$$
等号当 $\sqrt f=\lambda/\sqrt f$ 即 $f\equiv$ 常数时成立。∎

### 例 7（积分方程，二轮必会套路）

设 $f$ 连续且满足 $f(x)=x^{2}+\displaystyle\int_{0}^{1}xf(t)\,dt$，求 $f(x)$。

**解**：积分 $\displaystyle\int_0^1 f(t)dt$ 是**常数**，记为 $A$，则 $f(x)=x^{2}+Ax$。代回：
$$A=\int_{0}^{1}\left(t^{2}+At\right)dt=\frac13+\frac{A}{2}\ \Longrightarrow\ \frac{A}{2}=\frac13\ \Longrightarrow\ A=\frac23$$
故 $f(x)=x^{2}+\dfrac{2}{3}x$。

> **要点**：定积分（上下限为常数）是**数**，立刻设成 $A$；变限积分是**函数**，不能设常数。

## 六、例 8（Wallis 点火公式，数二高频小题）

求 $\displaystyle\int_{0}^{\pi/2}\sin^{4}x\,dx$ 与 $\displaystyle\int_{0}^{\pi/2}\cos^{5}x\,dx$。

**解**：记 $I_n=\displaystyle\int_0^{\pi/2}\sin^n x\,dx$，由分部积分得递推 $I_n=\dfrac{n-1}{n}I_{n-2}$，$I_0=\dfrac{\pi}{2}$，$I_1=1$。于是
$$I_4=\frac34\cdot\frac12\cdot\frac{\pi}{2}=\frac{3\pi}{16},\qquad I_5=\frac45\cdot\frac23\cdot1=\frac{8}{15}$$

> **口诀**：**偶数带 $\dfrac{\pi}{2}$，奇数带 $1$；从 $n$ 往下每次减 2，分子分母同步降。**
> 且 $\displaystyle\int_0^{\pi/2}\cos^n x\,dx=\int_0^{\pi/2}\sin^n x\,dx$（令 $x=\frac\pi2-t$）。

## 七、易错点（每条都对应真实失分）

1. **含参变限积分直接求导**
   $F(x)=\displaystyle\int_0^x(x-t)f(t)dt$ 必须先拆成 $x\displaystyle\int_0^xf-\int_0^xtf$。写成 $F'(x)=(x-x)f(x)=0$ 是零分答案。

2. **变限积分做等价无穷小替换时"局部替换"**
   正确顺序：**洛必达先把积分号退掉**，再对被积函数用等价。如例 5，不能直接说"$\sin t\sim t$ 所以分子 $\sim\int_0^x(x-t)t\,dt$"——这一步虽碰巧对，但遇到 $x\to\infty$、或积分下限不为 0 时会崩。考场统一走洛必达。

3. **对称性乱用**：$\displaystyle\int_{-a}^{a}$ 上若 $f$ 既不奇也不偶，绝不能写 0。遇到 $\dfrac{f(x)}{1+e^{x}}$ 类，先**配对相加**（令 $x=-t$），不要硬凑奇偶。

4. **换元不同步**：$x=\varphi(t)$ 必须**单调可导**，且 $dx$、上下限**同时换**。反例：$\displaystyle\int_0^{\pi}\frac{dx}{1+\sin^{2}x}$ 若令 $t=\sin x$（在 $[0,\pi]$ 上不单调）必错；应先用对称性化为 $2\displaystyle\int_0^{\pi/2}$，再用 $t=\tan x$。

5. **分部积分循环型的符号**
   $\displaystyle\int e^{x}\sin x\,dx$ 两次分部后出现原积分，移项得 $2I=e^{x}(\sin x-\cos x)$。移项时**把整块 $I$ 移到左边**，别只移一半；同时 $+C$ 不能丢。

6. **定积分与不定积分混淆**：$\displaystyle\int_0^1 f$ 是**数**（可设 $A$），$\displaystyle\int f$ 是**函数族**（带 $+C$）。求导时 $\left(\displaystyle\int_0^x f\right)'=f(x)$，但 $\left(\displaystyle\int f\right)'=f(x)$ 也成立——区别在于前者是函数在 $x$ 处的值，后者是原函数。
