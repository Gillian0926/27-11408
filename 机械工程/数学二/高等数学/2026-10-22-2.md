# 🧮 数学二 · 第 27 讲配套 · 公式速查（二重积分 · 强化版）

> 默写顺序：**定义性质 → 直角坐标两型 → 换序四步 → 对称三判 → 极坐标（含 $\theta$ 表）→ 分片 → 应用（体积/形心/中值）→ 考场速判**。整套约 8 分钟。

---

## 一、定义与性质

$$\iint_D f(x,y)\,d\sigma=\lim_{\lambda\to0}\sum_{k=1}^{n}f(\xi_k,\eta_k)\Delta\sigma_k$$

- 线性：$\iint(\alpha f+\beta g)=\alpha\iint f+\beta\iint g$。
- 可加：$D=D_1\cup D_2$（内部不重叠）时 $\iint_D=\iint_{D_1}+\iint_{D_2}$。
- 保号：$f\le g$ 于 $D$ $\Rightarrow$ $\iint_D f\le\iint_D g$；$\left|\iint_D f\right|\le\iint_D|f|$。
- 估值：$mS\le\iint_D f\le MS$，其中 $S$ 为 $D$ 的面积，$m,M$ 为 $f$ 在 $D$ 上的最小、最大值。
- 中值定理：$f$ 连续于闭区域 $D$ $\Rightarrow$ $\exists(\xi,\eta)\in D$，
$$\iint_D f\,d\sigma=f(\xi,\eta)\cdot S.$$

---

## 二、直角坐标下的两种次序

**X 型（竖切）**
$$\iint_D f\,d\sigma=\int_a^b dx\int_{\varphi_1(x)}^{\varphi_2(x)}f(x,y)\,dy$$

**Y 型（横切）**
$$\iint_D f\,d\sigma=\int_c^d dy\int_{\psi_1(y)}^{\psi_2(y)}f(x,y)\,dx$$

**铁律**：外限必为常数，内限可含变量，且恒有上界 $>$ 下界。

---

## 三、换序四步

1. 由四个限写出 $D$ 的不等式组；
2. 画边界曲线、求交点；
3. 换方向切（固定另一变量）；
4. 重写限并检验端点衔接。

**必须换序的信号**（对 $y$ 无初等原函数）：
$$e^{-y^{2}},\quad e^{x^{2}}\ (\text{先对 }x),\quad \frac{\sin y}{y},\quad \sin(y^{2}),\quad \sqrt{1+y^{3}},\quad \frac{1}{\ln y}$$

**典型三角区**：$\displaystyle\int_0^1dx\int_x^{\sqrt{x}}f\,dy=\int_0^1dy\int_{y^{2}}^{y}f\,dx$；$\displaystyle\int_0^1dx\int_x^{1}f\,dy=\int_0^1dy\int_0^{y}f\,dx$。

---

## 四、对称性三判

| $D$ 的对称性 | 条件 | 结论 |
| --- | --- | --- |
| 关于 $y$ 轴对称 | $f(-x,y)=-f(x,y)$ | $\iint_D f=0$ |
| 关于 $y$ 轴对称 | $f(-x,y)=f(x,y)$ | $\iint_D f=2\iint_{D_{x\ge0}}f$ |
| 关于 $x$ 轴对称 | $f(x,-y)=-f(x,y)$ | $\iint_D f=0$ |
| 关于 $x$ 轴对称 | $f(x,-y)=f(x,y)$ | $\iint_D f=2\iint_{D_{y\ge0}}f$ |
| 关于 $y=x$ 对称（轮换） | — | $\iint_D f(x,y)=\iint_D f(y,x)$ |

**常用结论**（$D:x^{2}+y^{2}\le R^{2}$）：
$$\iint_D x\,d\sigma=\iint_D y\,d\sigma=\iint_D xy\,d\sigma=0,\qquad \iint_D x^{2}d\sigma=\iint_D y^{2}d\sigma=\frac{\pi R^{4}}{4}$$

## 五、极坐标

$$x=r\cos\theta,\quad y=r\sin\theta,\quad \boxed{d\sigma=r\,dr\,d\theta}$$
$$\iint_D f\,d\sigma=\int_{\theta_1}^{\theta_2}d\theta\int_{r_1(\theta)}^{r_2(\theta)}f(r\cos\theta,r\sin\theta)\,r\,dr$$

**适用判据**：区域为圆、扇形、圆环；被积函数含 $x^{2}+y^{2}$、$\sqrt{x^{2}+y^{2}}$、$\dfrac{y}{x}$、$\arctan\dfrac{y}{x}$。

**$\theta$ 范围表**

| 区域 | $\theta$ | $r$ |
| --- | --- | --- |
| $x^{2}+y^{2}\le a^{2}$ | $[0,2\pi]$ | $[0,a]$ |
| $x^{2}+y^{2}\le 2ax$（圆心 $(a,0)$） | $\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$ | $[0,2a\cos\theta]$ |
| $x^{2}+y^{2}\le 2ay$（圆心 $(0,a)$） | $[0,\pi]$ | $[0,2a\sin\theta]$ |
| 圆环 $a^{2}\le x^{2}+y^{2}\le b^{2}$ | $[0,2\pi]$ | $[a,b]$ |
| 上半圆 $x^{2}+y^{2}\le R^{2},\,y\ge0$ | $[0,\pi]$ | $[0,R]$ |
| 扇形 $0\le y\le x$ | $\left[0,\frac{\pi}{4}\right]$ | 按边界定 |

**高频积分**：
$$\int_0^{2\pi}\cos^{2}\theta\,d\theta=\int_0^{2\pi}\sin^{2}\theta\,d\theta=\pi,\qquad \int_{-\pi/2}^{\pi/2}\cos^{3}\theta\,d\theta=\frac43$$
$$\int_0^{\pi/2}\sin^{2}\theta\,d\theta=\int_0^{\pi/2}\cos^{2}\theta\,d\theta=\frac{\pi}{4},\qquad \int_0^{\pi/2}\sin^{3}\theta\,d\theta=\frac23$$

## 六、分片三情形

| 触发条件 | 分界 |
| --- | --- |
| $|f|$ 中含 $x^{2}+y^{2}-k$ | $x^{2}+y^{2}=k$（极坐标即 $r=\sqrt{k}$） |
| $\min(x,y)$ / $\max(x,y)$ | $y=x$ |
| 体积题两曲面交叉 | 由 $z_1=z_2$ 解出交线，投影为分界 |

分片后：各片限首尾衔接，不重不漏。

## 七、几何与物理应用

**体积**（$z_{\text{上}}\ge z_{\text{下}}$）
$$V=\iint_D\left[z_{\text{上}}(x,y)-z_{\text{下}}(x,y)\right]d\sigma$$

**平面薄片**（面密度 $\rho=1$ 时为几何量）
$$M=\iint_D\rho\,d\sigma,\qquad \bar x=\frac{1}{M}\iint_D x\rho\,d\sigma,\qquad \bar y=\frac{1}{M}\iint_D y\rho\,d\sigma$$

**转动惯量**
$$I_x=\iint_D y^{2}\rho\,d\sigma,\qquad I_y=\iint_D x^{2}\rho\,d\sigma,\qquad I_O=\iint_D(x^{2}+y^{2})\rho\,d\sigma$$

**面积**：$S=\iint_D 1\,d\sigma$（直接二重积分，不是曲线积分）。

## 八、考场速判表

| 看到 | 立刻做 |
| --- | --- |
| 内层是 $e^{-y^{2}},\frac{\sin y}{y},\sqrt{1+y^{3}}$ | **换序**，别试原函数 |
| 区域写成 $a\le x\le b,\ \varphi_1\le y\le\varphi_2$ 但边界反了 | 分片，各自保证上界 $>$ 下界 |
| 区域是圆/圆环/扇形 | 极坐标，先定 $\theta$ 再定 $r$ |
| 区域过原点且圆心在轴上 | $\theta$ 只取半圈（$\pm\frac{\pi}{2}$ 或 $[0,\pi]$） |
| 被积函数含 $xy$、$x$、$y$ 的奇次项 | 查对称性，优先判 0 |
| $D$ 关于 $y=x$ 对称 | 用 $\iint x^{2}=\iint y^{2}=\frac12\iint(x^{2}+y^{2})$ |
| 出现 $|x^{2}+y^{2}-1|$ | 以 $r=1$ 分片去绝对值 |
| 求两曲面围成的体积 | 先求交线定投影 $D$，再 $\iint(z_{\text{上}}-z_{\text{下}})$ |
| 累次积分上限含 $t$，求导 | 先换序算出显式，再求导 |
| 求面积 | $S=\iint_D 1\,d\sigma$ |

## 九、易错 1 分钟扫

1. 极坐标 **$d\sigma=r\,dr\,d\theta$**，漏 $r$ 是最常见错误。
2. 过原点圆的 $\theta$ **不是** $[0,2\pi]$。
3. 换序后必回代一点验算（如取 $y=\frac12$ 看 $x$ 区间是否合理）。
4. 对称性必须"区域对称 + 函数奇偶"同时成立。
5. 体积题 $z_{\text{上}}-z_{\text{下}}$ 变号要分片，结果不能为负。
6. 二重积分不涉及三重积分与曲线/曲面积分（数二不考），别混用公式。
