## 一、五法判型（30 秒）

| 题目长相 | 方法 | 首步动作 |
| --- | --- | --- |
| 证 $f\ge g$，区间固定 | 单调性 | 令 $F=f-g$，求 $F'$，找 $F(x_0)=0$ |
| $F'$ 变号 / 含参数 | 最值法 | 求驻点 + 端点值（或端点极限） |
| "求 $a$ 使 … 恒成立" | 参数分离 | $a\ge\max\phi$ 或 $a\le\min\phi$，验最值是否取到 |
| 出现 $f(b)-f(a)$、$b-a$ | 拉格朗日 | $\dfrac{f(b)-f(a)}{b-a}=f'(\xi)$，用 $f'$ 的界夹 |
| 出现 $\dfrac{f(a)+f(b)}{2}$、$f\!\left(\frac{a+b}{2}\right)$ | 凹凸性 | 求 $f''$，切线 / 弦放缩 |
| 积分与 $\dfrac1n$、$\ln$ 混出 | 积分放缩 | 用单调性给上下界，再逐项求和 |

## 二、单调性五步模板

$$\boxed{F=f-g\ \to\ F'\ \to\ \text{定号}\ \to\ F(x_0)=0\ \text{（或}\ \lim_{x\to x_0}F=0\text{）}\ \to\ \text{结论}}$$

**逐阶下推链（一次求导定不了号时）**：

$$F''>0\Rightarrow F'\nearrow;\quad F'(x_0)=0\Rightarrow F'\ \text{符号}\Rightarrow F\ \text{单调}\Rightarrow F\ \text{与}\ 0\ \text{比较}$$

**求导常用结果**：

$$\left(\ln(1+x)\right)'=\frac{1}{1+x},\quad \left(\arctan x\right)'=\frac{1}{1+x^2},\quad \left(x-\sin x\right)'=1-\cos x\ge0$$

$$\left(\ln(1+x)-x+\tfrac{x^2}{2}\right)'=\frac{x^2}{1+x}\ge0$$

$$\left(\arctan x+\frac1x\right)'=-\frac{1}{x^2(1+x^2)}<0$$

## 三、最值法与参数分离

$$F(x)\ge0\ (\forall x\in I)\iff\min_{x\in I}F(x)\ge0;\qquad F(x)\le0\ (\forall x\in I)\iff\max_{x\in I}F(x)\le0$$

$$a\ge\phi(x)\ (\forall x)\iff a\ge\max\phi;\qquad a\le\phi(x)\ (\forall x)\iff a\le\min\phi$$

**标准例**：$\ln x\le ax\ (x>0)\iff a\ge\max\limits_{x>0}\dfrac{\ln x}{x}=\dfrac1e\iff a\ge\dfrac1e$。

> 检查清单：驻点值、不可导点、**两端极限**三项都算过吗？$\max$ 是否真的取到？

## 四、中值定理 · 凹凸 · 积分放缩

**拉格朗日**：

$$f(b)-f(a)=f'(\xi)(b-a),\quad \xi\in(a,b)$$

$$m\le f'\le M\ \Longrightarrow\ m(b-a)\le f(b)-f(a)\le M(b-a)$$

**对数平均（$0<a<b$）**：

$$\frac{b-a}{b}<\ln\frac{b}{a}<\frac{b-a}{a}$$

**凹凸性几何不等式**：

$$f''>0:\quad f(x)\ge f(x_0)+f'(x_0)(x-x_0),\qquad f\!\left(\frac{a+b}{2}\right)\le\frac{f(a)+f(b)}{2}$$

$$f''<0:\quad f(x)\le f(x_0)+f'(x_0)(x-x_0),\qquad f\!\left(\frac{a+b}{2}\right)\ge\frac{f(a)+f(b)}{2}$$

**积分放缩**（$f$ 连续，$a<b$）：

$$f\ \text{单调增}:\ f(a)(b-a)\le\int_a^b f(x)\,dx\le f(b)(b-a)$$

$$f\ \text{单调减}:\ f(b)(b-a)\le\int_a^b f(x)\,dx\le f(a)(b-a)$$

$$\frac{1}{n+1}<\int_n^{n+1}\frac{dx}{x}=\ln\!\left(1+\frac1n\right)<\frac1n$$

$$\ln(n+1)<\sum_{k=1}^{n}\frac1k<1+\ln n$$

## 五、必背不等式表（含成立范围与等号）

| 不等式 | 范围 | 等号 |
| --- | --- | --- |
| $e^x\ge 1+x$ | $\forall x\in\mathbb R$ | $x=0$ |
| $e^x\ge 1+x+\dfrac{x^2}{2}$ | $x\ge0$ | $x=0$ |
| $e^{-x}\le 1-x+\dfrac{x^2}{2}$ | $x\ge0$ | $x=0$ |
| $\ln(1+x)\le x$ | $x>-1$ | $x=0$ |
| $\ln(1+x)\ge\dfrac{x}{1+x}$ | $x>-1$ | $x=0$ |
| $\ln(1+x)\ge x-\dfrac{x^2}{2}$ | $x\ge0$ | $x=0$ |
| $\dfrac{x}{1+x}\le\ln(1+x)\le x$ | $x\ge0$ | $x=0$ |
| $\sin x\le x$ | $x\ge0$ | $x=0$ |
| $\sin x\ge\dfrac{2}{\pi}x$ | $0\le x\le\dfrac{\pi}{2}$ | $x=0,\dfrac{\pi}{2}$ |
| $\sin x\ge x-\dfrac{x^3}{6}$ | $x\ge0$ | $x=0$ |
| $\tan x\ge x$ | $0\le x<\dfrac{\pi}{2}$ | $x=0$ |
| $\arctan x\le x$ | $x\ge0$ | $x=0$ |
| $\arctan x+\dfrac1x>\dfrac{\pi}{2}$ | $x>0$ | 严格 |
| $\cos x\ge 1-\dfrac{x^2}{2}$ | $\forall x$ | $x=0$ |
| $(1+x)^\alpha\ge 1+\alpha x$ | $x>-1$，$\alpha\ge1$ 或 $\alpha\le0$ | $x=0$ |
| $(1+x)^\alpha\le 1+\alpha x$ | $x>-1$，$0\le\alpha\le1$ | $x=0$ |

> 使用铁律：**先写范围，再写不等式**。范围错（尤其 $\ln$ 的 $x>-1$）直接判错。

## 六、交卷前自查 8 条
