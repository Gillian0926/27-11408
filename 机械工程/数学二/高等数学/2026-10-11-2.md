# 🧮 数学二 · 第 16 讲配套 · 公式速查（二重积分综合：换序 · 对称 · 中值 · 体积）

> 默写顺序：**定义 → 两张定限表 → 换序四步 → 极坐标 → 对称性 → 圆域常见值 → 中值 → 体积 → 自检**。

---

## 一、定义与基本性质

设 $f(x,y)$ 在有界闭区域 $D$ 上可积：

$$\iint_D f(x,y)\,d\sigma=\lim_{\lambda\to 0}\sum_{k=1}^{n}f(\xi_k,\eta_k)\Delta\sigma_k$$

| 性质 | 表达式 |
| --- | --- |
| 线性 | $\iint_D(\alpha f+\beta g)\,d\sigma=\alpha\iint_D f+\beta\iint_D g$ |
| 区域可加 | $D=D_1\cup D_2$（内部不重叠）$\Rightarrow\iint_D=\iint_{D_1}+\iint_{D_2}$ |
| 保号 | $f\le g\Rightarrow\iint_D f\le\iint_D g$ |
| 面积 | $f\equiv 1\Rightarrow\iint_D 1\,d\sigma=S_D$ |
| 估值 | $mS_D\le\iint_D f\,d\sigma\le MS_D$ |
| 绝对值 | $\left|\iint_D f\,d\sigma\right|\le\iint_D|f|\,d\sigma$ |
| **中值定理** | $f$ 连续 $\Rightarrow\exists(\xi,\eta)\in D,\ \iint_D f\,d\sigma=f(\xi,\eta)S_D$ |

---

## 二、直角坐标定限（两型）

**X 型**（先 $y$ 后 $x$）：

$$D:\ a\le x\le b,\ y_1(x)\le y\le y_2(x)\quad\Longrightarrow\quad \iint_D f\,d\sigma=\int_a^b dx\int_{y_1(x)}^{y_2(x)}f\,dy$$

**Y 型**（先 $x$ 后 $y$）：

$$D:\ c\le y\le d,\ x_1(y)\le x\le x_2(y)\quad\Longrightarrow\quad \iint_D f\,d\sigma=\int_c^d dy\int_{x_1(y)}^{x_2(y)}f\,dx$$

**铁律**：外层上下限必为常数；内层上下限只能含**外层变量**或常数。

---

## 三、交换积分次序 —— 四步法

$$\boxed{\ \text{写区域}\ \to\ \text{画图}\ \to\ \text{换方向}\ \to\ \text{重定限}\ }$$

**定限口诀**：**外层常数、内层函数；平行于内层变量的直线穿区域，先穿进为下限，后穿出为上限。**

**必换序信号**（内层原函数非初等）：

$$\int e^{-y^2}dy,\quad \int \sin(y^2)\,dy,\quad \int\frac{\sin y}{y}\,dy,\quad \int\frac{1}{\ln y}\,dy,\quad \int\sqrt{1+y^3}\,dy$$

**经典模型**：$\displaystyle\int_0^1 dx\int_x^1 \sin(y^2)dy=\frac{1-\cos 1}{2}$。

---

## 四、极坐标

$$x=r\cos\theta,\qquad y=r\sin\theta,\qquad J=r,\qquad \boxed{d\sigma=r\,dr\,d\theta}$$

$$\iint_D f\,d\sigma=\int_\alpha^\beta d\theta\int_{r_1(\theta)}^{r_2(\theta)}f(r\cos\theta,r\sin\theta)\,r\,dr$$

**定限三情形**：

| 极点 $O$ 位置 | $\theta$ | $r$ |
| --- | --- | --- |
| 在 $D$ 内 | $0\sim 2\pi$ | $0\sim r(\theta)$ |
| 在 $D$ 边界 | 由曲线定 | $0\sim r(\theta)$ |
| 在 $D$ 外 | 由射线扫过定 | $r_1(\theta)\sim r_2(\theta)$ |

**常见转换**：$x^2+y^2\le 2x\Rightarrow r\le 2\cos\theta,\ \theta\in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$；$x^2+y^2\le 2y\Rightarrow r\le 2\sin\theta,\ \theta\in[0,\pi]$。

**常用角度积分**：$\displaystyle\int_0^{\pi/2}\cos^4\theta\,d\theta=\frac{3\pi}{16}$，$\displaystyle\int_0^{\pi/2}\cos^2\theta\,d\theta=\frac{\pi}{4}$。

## 五、对称性（用前双条件：区域对称 + 函数奇偶匹配）

| 区域对称 | 函数条件 | 结论 |
| --- | --- | --- |
| 关于 $x$ 轴 | $f(x,-y)=-f(x,y)$ | $\iint_D f=0$ |
| 关于 $x$ 轴 | $f(x,-y)=f(x,y)$ | $=2\iint_{D_{\text{上}}}f$ |
| 关于 $y$ 轴 | $f(-x,y)=-f(x,y)$ | $\iint_D f=0$ |
| 关于 $y$ 轴 | $f(-x,y)=f(x,y)$ | $=2\iint_{D_{\text{右}}}f$ |
| 关于原点 | $f(-x,-y)=-f(x,y)$ | $\iint_D f=0$ |
| 关于 $y=x$（轮换） | — | $\iint_D f(x,y)\,d\sigma=\iint_D f(y,x)\,d\sigma$ |

**轮换配对大法**：若 $f(x,y)+f(y,x)\equiv g$ 好算，则

$$\iint_D f\,d\sigma=\frac{1}{2}\iint_D g\,d\sigma$$

**典型应用**：$\displaystyle D:\ x^2+y^2\le R^2,\quad \iint_D\frac{x^2}{x^2+y^2}d\sigma=\frac{\pi R^2}{2}$。

---

## 六、圆域 / 常用区域的现成结果

$$D:\ x^2+y^2\le a^2$$

$$\iint_D x\,d\sigma=\iint_D y\,d\sigma=\iint_D xy\,d\sigma=0$$

$$\iint_D x^2\,d\sigma=\iint_D y^2\,d\sigma=\frac{1}{2}\iint_D(x^2+y^2)\,d\sigma=\frac{\pi a^4}{4}$$

$$\iint_D\left(x^2+y^2\right)d\sigma=\frac{\pi a^4}{2}$$

$$D:\ x^2+y^2\le 2x\ \Longrightarrow\ \iint_D\left(x^2+y^2\right)d\sigma=\frac{3\pi}{2}$$

---

## 七、与极限结合（中值定理模式）

设 $f$ 连续，$D_t=\{x^2+y^2\le t^2\}$：

$$\frac{1}{t^2}\iint_{D_t}f\,d\sigma=\underbrace{\frac{S_{D_t}}{t^2}}_{=\pi}\cdot f(\xi_t,\eta_t)\xrightarrow[t\to 0^+]{}\pi f(0,0)$$

**通用套路**：

$$\lim_{t\to 0^+}\frac{1}{t^{n}}\iint_{D_t}f\,d\sigma=\left(\lim_{t\to0^+}\frac{S_{D_t}}{t^n}\right)\cdot f(0,0)$$

（正方形 $0\le x,y\le t$：$S=t^2$，故 $\dfrac{1}{t^2}\iint\to f(0,0)$。）

---

## 八、几何应用

**曲顶柱体体积**（$f\ge 0$，底面 $D$）：

$$V=\iint_D f(x,y)\,d\sigma$$

**两曲面围成立体**：先联立求交线的投影区域 $D$，再判上下：

$$V=\iint_D\left(z_{\text{上}}-z_{\text{下}}\right)d\sigma$$

**底面面积**：$S_D=\iint_D 1\,d\sigma$。

**常用模型**：$z=x^2+y^2$ 与 $z=a$（$a>0$）围成

$$V=\iint_{x^2+y^2\le a}\left(a-x^2-y^2\right)d\sigma=\frac{\pi a^2}{2}$$

## 九、自检三问 + 错误清单

**三问**：
1. 图画了吗？交点坐标算了吗？
2. 外层上下限是常数吗？内层上下限只含外层变量吗？
3. 极坐标补 $r$ 了吗？对称性双条件满足了吗？

| 错误 | 正确做法 |
| --- | --- |
| 换序不看图 | 先画图，标交点 |
| 换序后内层出现非外层变量 | 内层只能是常数或外层变量 |
| 区域不对称却用奇偶性 | 区域必须对称 |
| 轮换对称用于非 $y=x$ 对称区域 | 只在圆、正方形、$\lvert x\rvert+\lvert y\rvert\le1$ 等上使用 |
| $dx\,dy$ 直接换成 $dr\,d\theta$ | 必须补 $r$：$dx\,dy=r\,dr\,d\theta$ |
| 极限题面积算错 | 圆面积 $\pi t^2$；正方形 $t^2$，与分母配平 |
| 体积题上下曲面搞反 | 取区域内一点验证 |
| 区域需分段却整体积 | 找 $\lvert f\rvert=0$ 或换边界处切开 |
