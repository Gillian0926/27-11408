## 二、单调有界准则：四步与三种"界"

$$\boxed{\text{① 猜界 } L=f(L)\ \to\ \text{② 归纳/AM–GM 证有界}\ \to\ \text{③ 证单调}\ \to\ \text{④ 取极限、舍根}}$$

**界的三种来源**：

$$\text{(a) AM–GM}:\quad \frac12\left(a+\frac{c}{a}\right)\ge\sqrt c\quad(a,c>0)$$

$$\text{(b) 值域锁定}:\quad a_n\in I\ \text{且}\ f(I)\subset I\ \Longrightarrow\ a_n\in I\ (\forall n)$$

$$\text{(c) 极限方程}:\quad L=f(L)\ \text{的解反过来当界（须另证）}$$

**单调性两把刀**：

$$a_{n+1}-a_n\ (\text{含平方项，或可写 } a_{n+1}^2-a_n^2);\qquad \frac{a_{n+1}}{a_n}\ (\text{含}\sqrt{\ }\text{、有理式})$$

**高频递推的极限**：

| 递推式 | $L$ | 界来源 |
| --- | --- | --- |
| $a_{n+1}=\sqrt{2+a_n}$ | $2$ | 归纳 |
| $a_{n+1}=\sqrt{2a_n+3}$ | $3$ | 归纳 |
| $a_{n+1}=\sqrt{1+a_n}$ | $\dfrac{1+\sqrt5}{2}$ | 归纳 |
| $a_{n+1}=\dfrac12\left(a_n+\dfrac{2}{a_n}\right)$ | $\sqrt2$ | AM–GM |
| $a_{n+1}=\dfrac12\left(a_n+\dfrac{c}{a_n}\right)$ | $\sqrt c$ | AM–GM |
| $a_{n+1}=\dfrac{a_n}{1+a_n}$ | $0$，且 $a_n=\dfrac1n$ | 倒数化 |
| $a_{n+1}=1+\dfrac12\sin a_n$ | 隐式 $L=1+\dfrac12\sin L$ | 值域 + 压缩 |

**牛顿型误差恒等式（可直接引用）**：

$$a_{n+1}-\sqrt2=\frac{\left(a_n-\sqrt2\right)^2}{2a_n}\quad\left(a_{n+1}=\frac12\left(a_n+\frac{2}{a_n}\right)\right)$$

## 三、压缩估计：规范三段式

$$\boxed{\text{① 定值域 } I\ \to\ \text{② 求 } q=\max_{x\in I}\lvert f'(x)\rvert<1\ \to\ \text{③ 拉格朗日递推}}$$

$$\left|a_{n+1}-L\right|=\left|f(a_n)-f(L)\right|=\left|f'(\xi)\right|\left|a_n-L\right|\le q\left|a_n-L\right|$$

$$\Longrightarrow\quad \left|a_n-L\right|\le q^{\,n-1}\left|a_1-L\right|\ \xrightarrow{\ q<1\ }\ 0$$

**常用压缩因子**：

| $f(x)$ | 区间 $I$ | $q$ |
| --- | --- | --- |
| $1+\dfrac12\sin x$ | $[1,\tfrac32]$ | $\dfrac12$ |
| $\dfrac12\cos x$ 型 | 任意 | $\le\dfrac12$ |
| $\dfrac{1}{3-x}$ | $[0,1]$ | $\dfrac14$ |
| $1+\dfrac12 x$ | 任意 | $\dfrac12$ |

> 说明书：$f'$ 在 $I$ 上要**先证不变号**（保单调），再取 $\max\lvert f'\rvert$；$q<1$ 只在 $I$ 上成立，脱离 $I$ 无效。

## 四、和式与积分型数列：三条出口

**出口 A · 定积分定义**

$$\lim_{n\to\infty}\frac1n\sum_{k=1}^{n}f\!\left(\frac kn\right)=\int_0^1 f(x)\,dx;\qquad \lim_{n\to\infty}\frac1n\sum_{k=1}^{cn}f\!\left(\frac kn\right)=\int_0^{c}f(x)\,dx$$

**出口 B · 夹逼**

$$\frac12\int_0^1 x^n dx\le\int_0^1\frac{x^n}{1+x}dx\le\int_0^1 x^n dx\ \Longrightarrow\ a_n\sim\frac{1}{2n}$$

$$\cos\frac1n\le n\int_0^{1/n}\frac{\sin x}{x}dx\le1\ \Longrightarrow\ \lim=1$$

**出口 C · 乘法取对数**

$$\ln\sqrt[n]{A_n}=\frac1n\ln A_n=\frac1n\sum_{k=1}^{n}\ln\frac{n+k}{n}\to\int_0^1\ln(1+x)dx$$

**常用积分值（必背）**：

$$\int_0^1\frac{dx}{1+x}=\ln2,\qquad \int_0^1\frac{dx}{1+x^{2}}=\frac{\pi}{4},\qquad \int_0^1 x^{n}dx=\frac{1}{n+1}$$

$$\int_0^1\ln(1+x)\,dx=2\ln2-1,\qquad \int_0^1 x\ln(1+x)\,dx=\frac14$$

$$\int_0^1\frac{x^{n}}{1+x}dx\sim\frac{1}{2n},\qquad \int_0^1\frac{x^{n}}{1+x^{2}}dx\sim\frac{1}{4n}$$

**高频和式对照**：

| 和式 | 极限 |
| --- | --- |
| $\dfrac1n\sum\limits_{k=1}^{n}\dfrac{1}{1+(k/n)^2}$ | $\dfrac{\pi}{4}$ |
| $\sum\limits_{k=1}^{n}\dfrac{1}{n+k}$ | $\ln2$ |
| $\sum\limits_{k=1}^{n}\dfrac{k}{n^2+k^2}$ | $\dfrac{\ln2}{2}$ |
| $\sum\limits_{k=1}^{n}\dfrac{n}{n^2+k^2}$ | $\dfrac{\pi}{4}$ |
| $\sqrt[n]{\dfrac{(2n)!}{n!\,n^{n}}}$ | $\dfrac{4}{e}$ |
| $\dfrac1n\sum\limits_{k=1}^{n}\sin\dfrac{k\pi}{n}$ | $\dfrac{2}{\pi}$ |

## 五、易错点核对表

| 错误 | 正确做法 |
| --- | --- |
| 用极限方程解出的 $L$ 当"有界" | $L$ 只是目标，界要另证（AM–GM / 归纳） |
| 递减判断未引用下界 | $a_{n+1}-a_n=\dfrac{c-a_n^{2}}{2a_n}$ 需 $a_n^{2}\ge c$ |
| $q$ 取在整个定义域 | $q$ 只取在**已锁定的值域区间** $I$ 上 |
| 夹逼两端不相等 | 重估放缩；两端都要算出具体数 |
| 定积分定义里 $k$ 只换一半 | 每个 $k$ 写成 $n\cdot\dfrac kn$ |
| 积分型数列直接等价代换 | 一律改用夹逼严格写 |
| 重根/双正根不说明取舍 | 用 $a_n$ 取值范围写出舍根理由 |

## 六、交卷前自查 8 条

1. 有界性是独立证的吗（没偷用"极限存在"）？
2. 单调性用差式还是比值？平方项用差式，$\sqrt{\ }$ / 有理式用比值。
3. 归纳起点 $n=1$ 写了吗？$f(I)\subset I$ 验了吗？
4. 题目要"证明收敛"，我写了**存在性 + 速度**两段吗？
5. 压缩因子 $q$ 的区间与值域一致吗？$q<1$ 说明了吗？
6. 夹逼两端极限是我**算出来**的吗（不是"看起来一样"）？
7. 定积分定义里 $f(x)$ 与区间端点，是从 $\dfrac kn$ 读出来的吗？
8. 取极限时代入的是 $a_{n+1}=f(a_n)$ 的原式吗？舍根理由写了吗？
