## 一、概念判定

**全增量与可微**

$$\Delta z=A\Delta x+B\Delta y+o(\rho),\quad \rho=\sqrt{\Delta x^{2}+\Delta y^{2}},\quad A=z_x,\ B=z_y$$

**可微判定的极限式**

$$\lim_{(\Delta x,\Delta y)\to(0,0)}\frac{\Delta z-z_x\Delta x-z_y\Delta y}{\sqrt{\Delta x^{2}+\Delta y^{2}}}=0$$

**全微分**

$$dz=z_x\,dx+z_y\,dy$$

**关系链**

$$\text{偏导连续}\Rightarrow\text{可微}\Rightarrow\begin{cases}\text{连续}\\[2pt]\text{偏导存在}\end{cases}$$

> 反向均不成立。反例：$f=\dfrac{xy}{\sqrt{x^{2}+y^{2}}}$（原点处偏导为 $0$，不可微）。

## 二、复合函数求导（链式法则）

**一层**

$$z=f(u,v),\ u=u(x,y),\ v=v(x,y)$$

$$z_x=f_1'u_x+f_2'v_x,\qquad z_y=f_1'u_y+f_2'v_y$$

**二层（抽象函数二阶）**

$$\frac{\partial}{\partial x}f_1'=f_{11}''u_x+f_{12}''v_x,\qquad \frac{\partial}{\partial x}f_2'=f_{21}''u_x+f_{22}''v_x$$

$$f_{12}''=f_{21}''\ (\text{二阶连续})$$

**全导数**：$z=f(u,v),\ u=u(t),\ v=v(t)$

$$\frac{dz}{dt}=f_1'u'+f_2'v'$$

**常用特例**：$z=f(x+y,\ xy)$

$$z_x=f_1'+yf_2',\qquad z_{xy}=f_{11}''+(x+y)f_{12}''+xyf_{22}''+f_2'$$

---

## 三、隐函数求导

**一个方程 $F(x,y,z)=0$**

$$z_x=-\frac{F_x}{F_z},\qquad z_y=-\frac{F_y}{F_z}\qquad(F_z\neq0)$$

**二阶**：对 $z_x$ 再求导，**把 $z_x,z_y$ 全部回代**，最终只留 $x,y,z$。

**由 $F(x,y)=0$ 定 $y=y(x)$**

$$\frac{dy}{dx}=-\frac{F_x}{F_y},\qquad \frac{d^{2}y}{dx^{2}}=-\frac{F_{xx}F_y^{2}-2F_{xy}F_xF_y+F_{yy}F_x^{2}}{F_y^{3}}$$

---

## 四、极值

**无条件极值**：驻点（$f_x=f_y=0$）+ 判别

$$A=f_{xx},\quad B=f_{xy},\quad C=f_{yy},\quad \Delta=AC-B^{2}$$

| $\Delta$ | 结论 |
| --- | --- |
| $>0,\ A>0$ | 极小 |
| $>0,\ A<0$ | 极大 |
| $<0$ | 非极值 |
| $=0$ | 失效 |

**条件极值（拉格朗日）**

$$L=f(x,y)+\lambda\varphi(x,y)$$

$$\begin{cases}f_x+\lambda\varphi_x=0\\ f_y+\lambda\varphi_y=0\\ \varphi(x,y)=0\end{cases}$$

**闭区域最值三件套**：内部驻点 → 边界（代入化一元）→ 全部候选值列表比较。

## 五、二重积分的两种坐标

**直角坐标**

$$\iint_D f\,d\sigma=\int_a^b\!dx\int_{y_1(x)}^{y_2(x)}f\,dy\quad(\text{X 型})$$

$$\iint_D f\,d\sigma=\int_c^d\!dy\int_{x_1(y)}^{x_2(y)}f\,dx\quad(\text{Y 型})$$

**换序口诀**：画图 → 看投影 → 穿孔定上下限。积不出原函数的（$e^{x^{2}},e^{-y^{2}},\sin y^{2},\frac{\sin y}{y}$）**必须换序**。

**极坐标**

$$\iint_D f\,d\sigma=\int_{\theta_1}^{\theta_2}\!d\theta\int_{r_1(\theta)}^{r_2(\theta)}f(r\cos\theta,r\sin\theta)\;r\,dr$$

**常见区域边界**

| 区域 | 极坐标下 |
| --- | --- |
| $x^{2}+y^{2}\le R^{2}$ | $0\le r\le R,\ 0\le\theta\le2\pi$ |
| $x^{2}+y^{2}\le 2ax$ | $0\le r\le2a\cos\theta,\ -\frac{\pi}{2}\le\theta\le\frac{\pi}{2}$ |
| $x^{2}+y^{2}\le 2ay$ | $0\le r\le2a\sin\theta,\ 0\le\theta\le\pi$ |
| $x^{2}+y^{2}\le a^{2},\ x\ge0$ | $0\le r\le a,\ -\frac{\pi}{2}\le\theta\le\frac{\pi}{2}$ |
| $y\le x,\ x^{2}+y^{2}\le1$ | $0\le r\le1,\ -\frac{3\pi}{4}\le\theta\le\frac{\pi}{4}$ |

## 六、对称性与常用结论

**奇偶性（区域关于 $x$ 轴对称）**

$$\iint_D f\,d\sigma=\begin{cases}0,&f(x,-y)=-f(x,y)\\[4pt]2\displaystyle\iint_{D_{\text{上}}}f\,d\sigma,&f(x,-y)=f(x,y)\end{cases}$$

关于 $y$ 轴对称同理（看 $f(-x,y)$）。

**轮换对称**（$D$ 关于 $y=x$ 对称）

$$\iint_D f(x,y)\,d\sigma=\iint_D f(y,x)\,d\sigma$$

**圆域通式**

$$\iint_{x^{2}+y^{2}\le R^{2}}f(x^{2}+y^{2})\,d\sigma=2\pi\int_0^{R}f(r^{2})r\,dr$$

**变限型二重积分求导**

$$F(t)=\iint_{x^{2}+y^{2}\le t^{2}}f\,d\sigma\ \Longrightarrow\ F'(t)=t\int_0^{2\pi}f(t\cos\theta,t\sin\theta)\,d\theta$$

**面积**

$$S_D=\iint_D 1\,d\sigma$$

## 七、考场速判表

| 看到 | 立刻做 |
| --- | --- |
| $z=f(x+y,xy)$、$f(xy,x+y)$ | 画树，二阶**先写 $f_1',f_2'$ 再各自链式**，别漏裸项 |
| 隐函数求二阶 | 先写 $z_x=-\frac{F_x}{F_z}$，再两边对 $x$ 求导回代 |
| 问"是否可微" | 先算 $z_x,z_y$，再验极限式；偏导不存在直接否 |
| 闭区域最值 | 内部驻点（在区域外就丢）→ 边界参数化 → 比较 |
| $x^{2}+y^{2}=2ax$ | 极坐标 $r\le2a\cos\theta$，$\theta\in[-\frac\pi2,\frac\pi2]$ |
| 被积含 $e^{-y^{2}},\frac{\sin y}{y}$ | 换序，先画图重写上下限 |
| 被积含 $\lvert\cdot\rvert$、$\max,\min$ | 找分界线**分片**，逐片去符号 |
| 区域对称 + 被积为奇 | 直接写 $0$，不计算 |
| $D$ 关于 $y=x$ 对称 | 用轮换对称把 $x,y$ 互换凑成熟悉形式 |
| 二重积分上限含 $t$ | 极坐标化一元积分再求导，或套 $F'(t)$ 通式 |
