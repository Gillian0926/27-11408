# 🧮 数学二 · 第 03 讲配套 · 公式速查（向量组 · 相关性 · 秩）

> 默写顺序：**表示判据 → 相关四等价 → 八性质 → 极大无关组三步 → 秩不等式 → 十秒判**。整套约 8 分钟。

---

## 一、线性表示的判据

设 $A=(\alpha_1,\ldots,\alpha_s)$，$\beta$ 为 $n$ 维列向量：

$$\beta\ \text{可由}\ \alpha_1,\ldots,\alpha_s\ \text{表示}\iff Ax=\beta\ \text{有解}\iff r(A)=r(A,\beta)$$

| 秩关系 | 结论 |
| --- | --- |
| $r(A)<r(A,\beta)$ | 不能表示 |
| $r(A)=r(A,\beta)=s$ | 能表示，**唯一** |
| $r(A)=r(A,\beta)<s$ | 能表示，**无穷多组** |

**组合形式**：$k_1\alpha_1+\cdots+k_s\alpha_s=\beta$，系数即 $Ax=\beta$ 的解。

---

## 二、线性相关 / 无关的四等价（$A=(\alpha_1,\ldots,\alpha_s)$）

$$\alpha_1,\ldots,\alpha_s\ \text{相关}\iff Ax=0\ \text{有非零解}\iff r(A)<s\iff \exists\ \text{某向量可由其余表示}$$

$$\alpha_1,\ldots,\alpha_s\ \text{无关}\iff Ax=0\ \text{只有零解}\iff r(A)=s\iff \text{任一向量都不能由其余表示}$$

**定义式**：存在不全为零的 $k_i$ 使 $\displaystyle\sum_{i=1}^{s}k_i\alpha_i=0$。

---

## 三、判定速查

| 情形 | 判据 |
| --- | --- |
| $s=n$ | $\det(\alpha_1,\ldots,\alpha_n)=0\iff$ 相关 |
| $s>n$ | **必相关**（$r\le n<s$） |
| $s<n$ | 只能算秩：$r<s$ 相关，$r=s$ 无关 |
| 单个向量 | 相关 $\iff\alpha=0$ |
| 两个向量 | 相关 $\iff$ 分量成比例 |

---

## 四、八条性质

1. 含零向量 $\Rightarrow$ 相关。
2. 单个 $\alpha$ 相关 $\iff\alpha=0$。
3. 两个相关 $\iff$ 成比例。
4. **部分相关 $\Rightarrow$ 整体相关**（反向不成立）。
5. **整体无关 $\Rightarrow$ 部分无关**。
6. 无关组**接长**仍无关；相关组**截短**仍相关。
7. $s>n\Rightarrow$ 必相关。
8. 若 $\alpha_1,\ldots,\alpha_s$ 无关、$\alpha_1,\ldots,\alpha_s,\beta$ 相关，则 $\beta$ 可**唯一**地由前者表示。

$$r(\alpha_1,\ldots,\alpha_s)=r\ \Longrightarrow\ \text{任取}\ r\ \text{个线性无关者即为极大无关组}$$

---

## 五、极大无关组与秩（求法三步）

1. **按列排** $A=(\alpha_1,\ldots,\alpha_s)$；
2. **只作行变换**化行最简形；
3. 读出：**非零行数 $=$ 秩**；**主元所在列对应的原向量** $=$ 极大无关组；其余列的数即表示系数。

**核心原理**：初等行变换不改变列向量之间的线性关系。

**两条注意**：

- 极大无关组**不唯一**，所含个数**唯一**（$=$ 秩）；
- 秩 $=r$ 时不能随便挑 $r$ 个，必须线性无关。

$$\boxed{\ \text{向量组的秩}=r(A)\ }$$

---

## 六、向量组等价

(I) 与 (II) **等价** $\iff$ 双方互相可表示。

- (I) 可由 (II) 表示 $\Rightarrow r(\mathrm{I})\le r(\mathrm{II})$；
- 向量组与其极大无关组等价；
- 等价 $\Rightarrow$ 秩相等；**秩相等 $\not\Rightarrow$ 等价**。

---

## 七、秩不等式（五条）

$$r(\alpha_1,\ldots,\alpha_s,\beta)\le r(\alpha_1,\ldots,\alpha_s)+1$$

$$r(\alpha_1,\ldots,\alpha_s,\beta_1,\ldots,\beta_t)\le r(\alpha)+r(\beta)$$

$$r(A+B)\le r(A)+r(B)$$

$$r(AB)\le\min\{r(A),\,r(B)\}$$

$$r(A)=r(A^{T})=r(A^{T}A)=r(AA^{T})$$

**部分组不等式**：部分组的秩 $\le$ 整体的秩。

---

## 八、参数题的两种写法

**法一（$s=n$，推荐）**：算 $\det A$ → 因式分解 → 按根分段。

**法二（$s\ne n$ 或想一次到底）**：直接行变换到阶梯形，按"主元是否为零"分类讨论。

**收尾铁律**：参数值**必须回代**原矩阵，重算秩与表示式；用含参式子作除数时，先单独讨论除数为零。

## 九、考场十秒判

| 看到 | 立刻做 |
| --- | --- |
| "判断线性相关性"且个数 $=$ 维数 | 直接算行列式，非零即无关 |
| 个数 $>$ 维数 | 不必算，直接写"必线性相关" |
| "能否线性表示" | 算 $r(A)$ 与 $r(A,\beta)$，比大小 |
| "表示是否唯一" | 看 $r(A)$ 是否等于 $s$ |
| "求极大无关组 / 秩" | 按列排、行最简、看主元列 |
| "把其余向量表示出来" | 读行最简形对应列的系数，回代验证 |
| "$\beta_1,\beta_2,\beta_3$ 是 $\alpha$ 的组合，判无关" | 写 $(\beta)=(\alpha)K$，算 $\det K\neq0$ |
| "已知两组秩，证某向量不能表示" | 反设 + 整体秩不变 + 部分组秩 $\le$ 整体秩，矛盾 |
| "$\alpha_1,\ldots,\alpha_s$ 无关，加 $\beta$ 后相关" | $\beta$ 可**唯一**表示 |

---

## 十、易错 1 分钟扫

1. 求极大无关组：**必须按列排、只行变换**；按行排的主元列不对应向量编号。
2. $r(A)=r(A,\beta)$ 只说明"能表示"，**唯一性另需 $r=s$**。
3. "整体相关"推不出"部分相关"；性质方向只有"部分 $\Rightarrow$ 整体"。
4. 秩为 $r$ 时随便挑 $r$ 个向量当极大无关组 $\to$ 错；要挑**线性无关**的。
5. 含参数解出 $a$ 后**不回代** $\to$ 全题失效。
6. 数二**不考**向量空间、基与维数、坐标、过渡矩阵、施密特正交化——见到直接跳过。
