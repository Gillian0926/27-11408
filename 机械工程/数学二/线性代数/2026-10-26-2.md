# 🧮 数学二 · 第 02 讲配套 · 公式速查（矩阵 · 逆 · 伴随 · 秩）

> 默写顺序：**运算禁忌 → 行列式 → 逆 → 伴随四式 → 伴随的秩 → 初等矩阵 → 秩的不等式 → 分块 → 特殊幂 → 十秒判**。整套约 8 分钟。

---

## 一、运算律与三条禁忌

$$(AB)C=A(BC),\quad A(B+C)=AB+AC,\quad (B+C)A=BA+CA,\quad k(AB)=(kA)B=A(kB)$$

$$(A+B)^{T}=A^{T}+B^{T},\qquad \boxed{(AB)^{T}=B^{T}A^{T}},\qquad (ABC)^{T}=C^{T}B^{T}A^{T}$$

$$A^{k}A^{l}=A^{k+l},\qquad (A^{k})^{l}=A^{kl}$$

| 禁忌 | 错误写法 | 正确 |
| --- | --- | --- |
| 不可交换 | $AB=BA$ | 一般 $AB\ne BA$ |
| 平方展开 | $(A+B)^{2}=A^{2}+2AB+B^{2}$ | $A^{2}+AB+BA+B^{2}$ |
| 幂的分配 | $(AB)^{k}=A^{k}B^{k}$ | $ABAB\cdots$，仅可交换时成立 |
| 零因子 | $AB=O\Rightarrow A=O$ 或 $B=O$ | 不成立 |
| 消去律 | $AB=AC\Rightarrow B=C$ | 仅 $A$ 可逆时成立 |

---

## 二、方阵行列式

$$\boxed{|AB|=|A|\,|B|},\qquad |A^{T}|=|A|,\qquad \boxed{|kA|=k^{n}|A|},\qquad |A^{k}|=|A|^{k}$$

$$|A^{-1}|=\frac{1}{|A|},\qquad \boxed{|A^{*}|=|A|^{\,n-1}},\qquad |(A^{*})^{-1}|=\frac{1}{|A|^{\,n-1}}$$

$$|cA^{-1}|=\frac{c^{n}}{|A|}\quad(\text{最爱考的一步})$$

**无公式**：$|A+B|$、$|A-B|$ 一律不能拆。

---

## 三、逆矩阵

$$(A^{-1})^{-1}=A,\qquad \boxed{(AB)^{-1}=B^{-1}A^{-1}},\qquad (A^{T})^{-1}=(A^{-1})^{T},\qquad (kA)^{-1}=\frac{1}{k}A^{-1}$$

$$A\text{ 可逆}\iff |A|\ne0\iff r(A)=n\iff \text{行(列)向量组无关}\iff Ax=0\text{ 只有零解}$$

$$\iff A\text{ 与 }E\text{ 等价}\iff A=\text{有限个初等矩阵之积}\iff A^{*}\text{ 可逆}$$

**二阶速记**（主对调、副变号）：

$$A=\begin{pmatrix}a&b\\c&d\end{pmatrix}\Rightarrow A^{*}=\begin{pmatrix}d&-b\\-c&a\end{pmatrix},\qquad A^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$$

---

## 四、伴随矩阵四式（核心中的核心）

$$\boxed{AA^{*}=A^{*}A=|A|E}$$

$$\boxed{A^{*}=|A|A^{-1}}\qquad\Longleftrightarrow\qquad \boxed{A^{-1}=\frac{1}{|A|}A^{*}}$$

$$|A^{*}|=|A|^{\,n-1},\qquad (A^{*})^{*}=|A|^{\,n-2}A,\qquad (kA)^{*}=k^{\,n-1}A^{*},\qquad (A^{*})^{T}=(A^{T})^{*}$$

$$(A^{*})^{-1}=(A^{-1})^{*}=\frac{1}{|A|}A$$

**伴随的秩**：

$$r(A^{*})=\begin{cases}n, & r(A)=n\\ 1, & r(A)=n-1\\ 0, & r(A)\le n-2\end{cases}$$

---

## 五、初等矩阵（左行右列）

$$\text{左乘}=\text{行变换},\qquad \text{右乘}=\text{列变换}$$

| 初等矩阵 | 操作 | 行列式 | 逆 |
| --- | --- | --- | --- |
| $E(i,j)$ | 互换 $i,j$ 行(列) | $-1$ | $E(i,j)$ |
| $E(i(k)),\ k\ne0$ | 第 $i$ 行(列) 乘 $k$ | $k$ | $E(i(1/k))$ |
| $E(i,j(k))$ | 第 $j$ 行(列) 的 $k$ 倍加到第 $i$ 行(列) | $1$ | $E(i,j(-k))$ |

**求逆**：$[A\mid E]\xrightarrow{\ \text{仅行变换}\ }[E\mid A^{-1}]$

**求秩/化标准形**：只用行变换化行阶梯形，非零行数 $=r(A)$。

---

## 六、矩阵的秩

$$r(A)=r(A^{T})=r(A^{T}A)=r(AA^{T})$$

$$\boxed{r(AB)\le\min\{r(A),r(B)\}},\qquad r(A+B)\le r(A)+r(B)$$

$$\boxed{r(A)+r(B)-n\le r(AB)}\quad(A_{m\times n},B_{n\times s})$$

$$AB=O\Rightarrow r(A)+r(B)\le n$$

$$A\text{ 列满秩}\Rightarrow r(AB)=r(B);\qquad B\text{ 行满秩}\Rightarrow r(AB)=r(A);\qquad P,Q\text{ 可逆}\Rightarrow r(PAQ)=r(A)$$

**秩 1 矩阵**（$A=\alpha\beta^{T}\ne O$）：

$$r(A)=1,\qquad A^{2}=(\beta^{T}\alpha)A,\qquad A^{n}=(\beta^{T}\alpha)^{n-1}A,\qquad \mathrm{tr}(A)=\beta^{T}\alpha$$

---

## 七、分块矩阵

$$\begin{pmatrix}A_{1}&&\\&\ddots&\\&&A_{s}\end{pmatrix}^{-1}=\begin{pmatrix}A_{1}^{-1}&&\\&\ddots&\\&&A_{s}^{-1}\end{pmatrix},\qquad |\Lambda|=\prod|A_{i}|$$

$$\begin{pmatrix}A&B\\O&C\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&-A^{-1}BC^{-1}\\O&C^{-1}\end{pmatrix},\qquad \left|\begin{matrix}A&B\\O&C\end{matrix}\right|=|A|\,|C|$$

$$\begin{pmatrix}A&O\\C&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&O\\-B^{-1}CA^{-1}&B^{-1}\end{pmatrix}$$

$$\begin{pmatrix}O&B\\C&O\end{pmatrix}^{-1}=\begin{pmatrix}O&C^{-1}\\B^{-1}&O\end{pmatrix},\qquad \left|\begin{matrix}O&B\\C&O\end{matrix}\right|=(-1)^{mn}|B|\,|C|$$

（$B$ 为 $m$ 阶、$C$ 为 $n$ 阶；分块求逆后**乘回去验一次**。）

---

## 八、特殊矩阵的幂与逆

| 条件 | 结论 |
| --- | --- |
| $A^{2}=A$（幂等） | $A^{k}=A$；若 $A$ 可逆则 $A=E$ |
| $A^{2}=E$（对合） | $A^{-1}=A$ |
| $A^{2}=O$ | $(E-A)^{-1}=E+A$，$(E+A)^{-1}=E-A$ |
| $A^{3}=O$ | $(E-A)^{-1}=E+A+A^{2}$ |
| $A=\alpha\beta^{T}$ | $A^{n}=(\beta^{T}\alpha)^{n-1}A$ |
| $A^{2}-3A+2E=O$ | $(A+E)^{-1}=\dfrac{4E-A}{6}$（凑因式） |

**凑因式法模板**：由 $A^{2}+pA+qE=O$，令 $(A+aE)(A+bE)=cE$，展开对照定 $a,b$，得 $(A+aE)^{-1}=\dfrac{1}{c}(A+bE)$。

## 九、考场十秒判

| 看到 | 立刻做 |
| --- | --- |
| $A^{*}$ 出现在任何式子 | 换成 $\|A\|A^{-1}$，全式化纯 $A^{-1}$ |
| $\|(2A)^{-1}+A^{*}\|$ 型 | 化 $cA^{-1}$，用 $\|cA^{-1}\|=c^{n}/\|A\|$ |
| $\|kA\|$ | $k^{n}\|A\|$，$n$ 是阶数 |
| $r(A)=n-1$ 求 $r(A^{*})$ | 答 $1$ |
| “第 $j$ 行的 $k$ 倍加到第 $i$ 行” | 左乘 $E(i,j(k))$，其逆 $E(i,j(-k))$ |
| “互换两列” | 右乘 $E(i,j)$，$\|E(i,j)\|=-1$ |
| $AX+2X=A$ | $(A+2E)X=A$，右提；左提则 $XA+2X=X(A+2E)$ |
| $AXB=C$ | $X=A^{-1}CB^{-1}$（顺序不可乱） |
| 含参求秩 | 先算 $\|A\|$ 分解，根上代回数非零行 |
| 各行成比例 | $A=\alpha\beta^{T}$，$A^{n}=(\beta^{T}\alpha)^{n-1}A$ |
| $AB=O$ | $r(A)+r(B)\le n$ |
| $A$ 满足多项式关系 | 凑 $(A+aE)(\ast)=cE$ 求逆 |
| 分块对角/副对角 | 对角块各自求逆，副对角先换位 |
| 3 阶以上求逆 | $[A\mid E]\to[E\mid A^{-1}]$，全程只做行变换 |

## 十、易错 1 分钟扫

1. $(A+B)^{2}$、$(AB)^{2}$、$(AB)^{T}$、$(AB)^{-1}$ —— 四个"顺序陷阱"，一律先检查顺序。
2. $|kA|=k^{n}|A|$；$(kA)^{-1}=\frac1k A^{-1}$；$(kA)^{*}=k^{n-1}A^{*}$ —— 三个 $k$ 的指数不同，别串。
3. 提公因子必须**同侧**；解完代回原方程验算。
4. 伴随矩阵是代数余子式的**转置**；2 阶口诀不外推。
5. 含参秩：$|A|=0$ 只是起点，代回化简才是终点。
6. 求逆算完乘一次，20 秒；分块求逆乘一次，10 秒。**不验算是最贵的省时。**
