# 🧮 数学二 · 第 01 讲配套 · 公式速查（行列式）

> 默写顺序：**定义 → 七性质 → 展开与伴随 → 五种算法 → 抽象公式 → 分块 → 十秒判**。整套约 8 分钟。

## 一、定义与低阶公式

$$D=\sum_{p_1\cdots p_n}(-1)^{\tau(p_1\cdots p_n)}a_{1p_1}\cdots a_{np_n}\qquad(n!\text{ 项})$$

$$\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc$$

三阶：主对角三线和 $-$ 副对角三线和（**仅限二、三阶**）。

三角 / 对角：

$$\begin{vmatrix}a_{11}&a_{12}&\cdots&a_{1n}\\0&a_{22}&\cdots&a_{2n}\\ \vdots&&\ddots&\vdots\\0&0&\cdots&a_{nn}\end{vmatrix}=a_{11}a_{22}\cdots a_{nn}$$

## 二、七条性质

| # | 性质 | 要点 |
| --- | --- | --- |
| 1 | $\lvert A^{T}\rvert=\lvert A\rvert$ | 行列地位等价 |
| 2 | 换两行 $\Rightarrow$ 变号 | 造零时补负号 |
| 3 | 某行乘 $k$ $\Rightarrow$ 值乘 $k$ | 推论 $\lvert kA\rvert=k^{n}\lvert A\rvert$ |
| 4 | 两行相同或成比例 $\Rightarrow 0$ | 判零首选 |
| 5 | 单行可拆 | $D=D_\alpha+D_\beta$ |
| 6 | 某行加另一行 $k$ 倍 $\Rightarrow$ 不变 | **化三角唯一合法操作** |
| 7 | 有零行 $\Rightarrow 0$ | — |

$$\lvert E\rvert=1,\qquad \lvert -A\rvert=(-1)^{n}\lvert A\rvert,\qquad A\text{ 可逆}\iff\lvert A\rvert\ne0$$

## 三、展开定理与伴随

$$A_{ij}=(-1)^{i+j}M_{ij},\qquad D=\sum_{j=1}^{n}a_{ij}A_{ij}$$

$$\boxed{\sum_{j=1}^{n}a_{ij}A_{kj}=0\quad(i\ne k)}\qquad(\text{异行展开为零})$$

$$A^{*}=\left(A_{ij}\right)^{T},\qquad AA^{*}=A^{*}A=\lvert A\rvert E,\qquad A^{-1}=\frac{A^{*}}{\lvert A\rvert}$$

---

## 四、五种算法模板

**① 化三角形**：用第 $i$ 行消第 $i$ 列下方全部元素为 0，只用倍加；最后取对角线之积。

**② 降阶**：先倍加造一行（列）中尽可能多的 0，再按该行（列）展开。

**③ 行和相等**：

$$D_n=\begin{vmatrix}a&b&\cdots&b\\b&a&\cdots&b\\\vdots&&&\vdots\\b&b&\cdots&a\end{vmatrix}=\left[a+(n-1)b\right](a-b)^{n-1}$$

流程：各列加到第 1 列 $\to$ 提公因子 $\to r_i-r_1$。

**④ 爪型**：

$$\begin{vmatrix}a_1&b_2&\cdots&b_n\\c_2&a_2&&\\\vdots&&\ddots&\\c_n&&&a_n\end{vmatrix}=a_1a_2\cdots a_n\left(1-\sum_{i=2}^{n}\frac{b_ic_i}{a_1a_i}\right)$$

**⑤ 三对角递推**：

$$D_n=pD_{n-1}-qD_{n-2}\ \Rightarrow\ \text{特征方程 }\lambda^{2}-p\lambda+q=0$$

$$\lambda_1\ne\lambda_2:\ D_n=C_1\lambda_1^{n}+C_2\lambda_2^{n};\qquad \lambda_1=\lambda_2=\lambda:\ D_n=(C_1+C_2n)\lambda^{n}$$

**⑥ 范德蒙德**：

$$V_n=\begin{vmatrix}1&1&\cdots&1\\x_1&x_2&\cdots&x_n\\ \vdots&&&\vdots\\x_1^{n-1}&x_2^{n-1}&\cdots&x_n^{n-1}\end{vmatrix}=\prod_{1\le j<i\le n}(x_i-x_j)$$

## 五、抽象行列式公式表

$$\lvert AB\rvert=\lvert A\rvert\lvert B\rvert=\lvert BA\rvert$$

$$\lvert kA\rvert=k^{n}\lvert A\rvert,\qquad \lvert A^{m}\rvert=\lvert A\rvert^{m},\qquad \lvert A^{-1}\rvert=\frac{1}{\lvert A\rvert}$$

$$\lvert A^{*}\rvert=\lvert A\rvert^{\,n-1},\qquad \left\lvert (A^{*})^{*}\right\rvert=\lvert A\rvert^{\,(n-1)^{2}}$$

$$\lvert A\rvert=\prod_{i=1}^{n}\lambda_i,\qquad \operatorname{tr}A=\sum_{i=1}^{n}\lambda_i=\sum_{i=1}^{n}a_{ii}$$

$$\lvert A^{T}A\rvert=\lvert A\rvert^{2},\qquad \lvert A^{-1}BA\rvert=\lvert B\rvert$$

> ⚠️ **不可拆**：$\lvert A+B\rvert\ne\lvert A\rvert+\lvert B\rvert$，$\lvert A-B\rvert\ne\lvert A\rvert-\lvert B\rvert$。

## 六、分块行列式

$$\begin{vmatrix}A&0\\0&B\end{vmatrix}=\begin{vmatrix}A&C\\0&B\end{vmatrix}=\begin{vmatrix}A&0\\C&B\end{vmatrix}=\lvert A\rvert\lvert B\rvert$$

$$\begin{vmatrix}0&A\\B&0\end{vmatrix}=(-1)^{mn}\lvert A\rvert\lvert B\rvert\qquad(A:m\text{ 阶},\ B:n\text{ 阶})$$

$$\begin{vmatrix}A&C\\D&B\end{vmatrix}\ \text{一般无简单公式（除非 }AC=CA\text{ 等特殊条件）}$$

## 七、考场十秒判

| 看到 | 立刻做 |
| --- | --- |
| 三阶以内数字题 | 直接对角线法则 / 按含 0 多的行展开 |
| 每行和相同 | 各列加到第 1 列，提公因子 |
| 除对角线与第一行（列）外全 0 | 爪型通式 |
| 三对角、阶数 $n$ | 按第一行展开得递推，补 $D_1,D_2$ |
| $1,x,x^{2}$ 结构 | 范德蒙德，$\prod_{j<i}(x_i-x_j)$ |
| $\lvert kA\rvert$ | $k^{n}\lvert A\rvert$，先数阶数 |
| $\lvert A^{*}\rvert$ 或 $A^{*}$ 组合式 | 先化 $A^{*}=\lvert A\rvert A^{-1}$，做矩阵化简再取行列式 |
| 含 $\lvert A+B\rvert$ 且要求定值 | 答案多为"不能确定"，举反例 |
| 分块有整块 0 | 三角分块 $\lvert A\rvert\lvert B\rvert$；副对角补 $(-1)^{mn}$ |
| 求"代数余子式之和" | 用 $\sum a_{ij}A_{kj}=0$ 或构造新行列式（把该行换成 1） |

## 八、易错 1 分钟扫

1. $\lvert kA\rvert=k^{n}\lvert A\rvert$，$n$ 是**阶数**，不是元素个数。
2. 化三角只能用**倍加**；换行补负号，乘行改值。
3. 展开式里符号 $(-1)^{i+j}$ 不能漏；异行展开为 $0$。
4. $\lvert A^{*}\rvert=\lvert A\rvert^{n-1}$，别写成 $\lvert A\rvert^{n}$。
5. 副对角分块的 $(-1)^{mn}$ 最易丢；$m,n$ 为两块各自的阶数。
6. 递推题必须写初值 $D_1,D_2$；重根通项带 $n$。
7. 四阶及以上禁止画对角线。
