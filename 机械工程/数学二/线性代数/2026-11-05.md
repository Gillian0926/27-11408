## 〇、本讲要解决的三个问题

拿到 $Ax=b$，只问三句：

1. **有没有解？** —— 比较 $r(A)$ 与 $r(A\mid b)$；
2. **有多少解？** —— 看 $n-r(A)$（$n$ 为未知数个数）；
3. **解长什么样？** —— 特解 $+$ 齐次基础解系。

三问之外，还有一类"反问题"：已知若干解，反推通解、反求 $A$、证明基础解系——考频同样高，本讲第四节专攻。

---

## 一、齐次线性方程组 $Ax=0$

设 $A$ 为 $m\times n$ 矩阵，$x=(x_1,\dots,x_n)^{T}$。

### 1.1 解集的结构

若 $\xi,\eta$ 都是 $Ax=0$ 的解，$k$ 为任意常数，则

$$A(k\xi)=kA\xi=0,\qquad A(\xi+\eta)=A\xi+A\eta=0$$

即解的任意线性组合仍是解。故解集

$$S=\{x\in\mathbb{R}^{n}\mid Ax=0\}$$

构成 $\mathbb{R}^{n}$ 的一个子空间（**解空间 / 零空间**，记 $N(A)$），

$$\boxed{\dim N(A)=n-r(A)}$$

这条式子是全讲的"总开关"：**基础解系含 $n-r(A)$ 个向量**。

### 1.2 解的判定

| 条件 | 结论 |
| --- | --- |
| $r(A)=n$（列满秩） | 只有零解 |
| $r(A)<n$ | 有非零解，基础解系含 $n-r(A)$ 个向量 |

**两条常考推论**：

- 方程个数少于未知数（$m<n$）时必有非零解（因 $r(A)\le m<n$）；
- $n$ 阶方阵 $A$：$Ax=0$ 有非零解 $\iff |A|=0\iff r(A)<n$。

### 1.3 基础解系的求法（四步固定流程）

> **定义**：$\xi_1,\dots,\xi_{n-r}$ 是 $Ax=0$ 的一组解，线性无关，且任一解都可由它们线性表示。

**①** 对 $A$ 只作**初等行变换**，化为行阶梯形，再化为**行最简形**（RREF）。
**②** 主元所在列对应**主元变量**，其余为**自由未知量**（自由未知量个数 $=n-r(A)$）。
**③** 让自由未知量依次取 $(1,0,\dots,0),(0,1,\dots,0),\dots,(0,\dots,0,1)$，回代求出主元变量，得到 $\xi_1,\dots,\xi_{n-r}$。
**④** 通解 $x=k_1\xi_1+\dots+k_{n-r}\xi_{n-r}$（$k_i$ 任意）。

> ⚠️ **只能用行变换**。列变换会改变未知量的对应关系，得到的"解"不是原方程的解。

### 1.4 例题 1（基础流程，必练）

求齐次方程组

$$\begin{cases}x_1+x_2+2x_3-x_4=0\\ 2x_1+x_2+3x_3+2x_4=0\\ 3x_1+2x_2+5x_3+x_4=0\end{cases}$$

的基础解系与通解。

**解**：对系数矩阵作行变换：

$$\begin{pmatrix}1&1&2&-1\\2&1&3&2\\3&2&5&1\end{pmatrix}\xrightarrow[r_3-3r_1]{r_2-2r_1}\begin{pmatrix}1&1&2&-1\\0&-1&-1&4\\0&-1&-1&4\end{pmatrix}\xrightarrow{r_3-r_2}\begin{pmatrix}1&1&2&-1\\0&-1&-1&4\\0&0&0&0\end{pmatrix}$$

继续化为行最简形（第二行乘 $-1$，再用它消第一行）：

$$\xrightarrow{r_2\times(-1)}\begin{pmatrix}1&1&2&-1\\0&1&1&-4\\0&0&0&0\end{pmatrix}\xrightarrow{r_1-r_2}\begin{pmatrix}1&0&1&3\\0&1&1&-4\\0&0&0&0\end{pmatrix}$$

于是 $r(A)=2$，$n=4$，基础解系含 $4-2=2$ 个向量。同解方程组为

$$\begin{cases}x_1=-x_3-3x_4\\ x_2=-x_3+4x_4\end{cases}$$

取 $(x_3,x_4)=(1,0)$ 得 $\xi_1=(-1,-1,1,0)^{T}$；取 $(x_3,x_4)=(0,1)$ 得 $\xi_2=(-3,4,0,1)^{T}$。

$$\boxed{x=c_1(-1,-1,1,0)^{T}+c_2(-3,4,0,1)^{T},\quad c_1,c_2\in\mathbb{R}}$$

**回验**（考场上务必做）：$A\xi_1=(-1-1+2-0,\ -2-1+3+0,\ -3-2+5+0)^{T}=(0,0,0)^{T}$ ✓。

## 二、非齐次线性方程组 $Ax=b$

### 2.1 判定定理（核心）

设 $\bar{A}=(A\mid b)$ 为增广矩阵，则 $r(A)\le r(\bar{A})\le r(A)+1$，且

| 秩关系 | 结论 |
| --- | --- |
| $r(A)<r(\bar{A})$（即 $r(\bar{A})=r(A)+1$） | **无解** |
| $r(A)=r(\bar{A})=n$ | **唯一解** |
| $r(A)=r(\bar{A})=r<n$ | **无穷多解**，通解含 $n-r$ 个任意常数 |

> 记忆口诀：**秩不等则无解；秩等看是否满列秩。**

### 2.2 解的四条性质（选择填空高频）

设 $\eta_1,\eta_2$ 是 $Ax=b$ 的解，$\xi$ 是 $Ax=0$ 的解：

1. $\eta_1-\eta_2$ 是 $Ax=0$ 的解；
2. $\eta_1+\xi$ 仍是 $Ax=b$ 的解；
3. $k_1\eta_1+k_2\eta_2$ 是 $Ax=b$ 的解 $\iff k_1+k_2=1$；
4. $k_1\eta_1+k_2\eta_2$ 是 $Ax=0$ 的解 $\iff k_1+k_2=0$。

### 2.3 通解结构

$$\boxed{x=\eta^{*}+k_1\xi_1+\dots+k_{n-r}\xi_{n-r}}$$

即**一个特解 + 齐次通解**。$r(A)=r(\bar{A})=n$ 时基础解系为空，通解就是唯一特解。

### 2.4 例题 2（含参数讨论，解答题标准型）

设方程组

$$\begin{cases}x_1+x_2+x_3=1\\ x_1+2x_2+3x_3=2\\ x_1+4x_2+ax_3=b\end{cases}$$

问 $a,b$ 取何值时无解、有唯一解、有无穷多解？有无穷多解时求通解。

**解**：只作行变换，**不对 $a,b$ 提前除**：

$$\begin{pmatrix}1&1&1&1\\1&2&3&2\\1&4&a&b\end{pmatrix}\xrightarrow[r_3-r_1]{r_2-r_1}\begin{pmatrix}1&1&1&1\\0&1&2&1\\0&3&a-1&b-1\end{pmatrix}\xrightarrow{r_3-3r_2}\begin{pmatrix}1&1&1&1\\0&1&2&1\\0&0&a-7&b-4\end{pmatrix}$$

- $a\ne 7$：$r(A)=r(\bar{A})=3=n$，**唯一解**；
- $a=7,\ b\ne 4$：$r(A)=2<r(\bar{A})=3$，**无解**；
- $a=7,\ b=4$：$r(A)=r(\bar{A})=2<3$，**无穷多解**。

此时同解方程组为 $x_1+x_2+x_3=1,\ x_2+2x_3=1$，即

$$x_2=1-2x_3,\qquad x_1=1-x_2-x_3=x_3$$

取特解 $\eta^{*}=(0,1,0)^{T}$（令 $x_3=0$），齐次基础解系 $\xi=(1,-2,1)^{T}$（令 $x_3=1$），故

$$\boxed{x=(0,1,0)^{T}+k(1,-2,1)^{T},\ k\in\mathbb{R}}$$

**矩阵方程推广**：$AX=B$ 有解 $\iff r(A)=r(A\mid B)$（把 $B$ 的每一列看作一个 $b$，逐列处理）。

## 三、含参方程组的固定讨论流程

> 数二解答题最爱的套路，按这四步走不会漏情况。

**第一步·数未知数**：确定 $n$，明确解空间维数是 $n-r(A)$。
**第二步·算行列式**（当 $A$ 为方阵且含参）：令 $|A|=0$ 解出参数的分界值；对 $|A|\ne0$ 的部分直接下"唯一解"（必要时用克拉默法则或直接回代）。
**第三步·逐值讨论**：对每个使 $|A|=0$ 的参数值，把它代回**增广矩阵**做行变换，比较 $r(A)$ 与 $r(\bar{A})$。
**第四步·写全结论**：每个参数范围对应一种结论，无穷多解时要写出通解。

### 3.1 例题 3（"有非零解"型，几乎必考）

问 $\lambda$ 取何值时，方程组

$$\begin{cases}\lambda x_1+x_2+x_3=0\\ x_1+\lambda x_2+x_3=0\\ x_1+x_2+\lambda x_3=0\end{cases}$$

有非零解？并求此时的通解。

**解**：齐次方程组有非零解 $\iff|A|=0$。

$$|A|=\begin{vmatrix}\lambda&1&1\\1&\lambda&1\\1&1&\lambda\end{vmatrix}\xrightarrow{r_1+r_2+r_3}\begin{vmatrix}\lambda+2&\lambda+2&\lambda+2\\1&\lambda&1\\1&1&\lambda\end{vmatrix}=(\lambda+2)\begin{vmatrix}1&1&1\\1&\lambda&1\\1&1&\lambda\end{vmatrix}=(\lambda+2)(\lambda-1)^{2}$$

故 $\lambda=1$ 或 $\lambda=-2$。

- **$\lambda=1$**：三个方程都是 $x_1+x_2+x_3=0$，$r(A)=1$，解空间维数 $3-1=2$，
$$\xi_1=(-1,1,0)^{T},\quad \xi_2=(-1,0,1)^{T},\quad x=c_1\xi_1+c_2\xi_2$$

- **$\lambda=-2$**：$r(A)=2$（行不成比例且 $|A|=0$），解空间维数 $1$，取 $x_1=x_2=x_3$，
$$\xi=(1,1,1)^{T},\quad x=c\,\xi$$

> 检验：$\lambda=-2$ 时第一行 $-2x_1+x_2+x_3=0$，代入 $(1,1,1)$ 得 $0$ ✓。

## 四、解的结构类"反问题"

### 4.1 例题 4（由若干解反推通解）

设 $A$ 为 3 阶矩阵，$r(A)=1$，且 $\eta_1=(1,2,3)^{T},\ \eta_2=(2,3,4)^{T},\ \eta_3=(1,0,1)^{T}$ 都是 $Ax=b$ 的解，求 $Ax=b$ 的通解。

**解**：$n-r(A)=3-1=2$，通解中应有 2 个任意常数，故须从"差的组合"中找出**两个线性无关**的齐次解。

$$\xi_1=\eta_2-\eta_1=(1,1,1)^{T},\qquad \xi_2=\eta_3-\eta_1=(0,-2,-2)^{T}$$

$\xi_1,\xi_2$ 分量不成比例，线性无关，恰好构成基础解系（个数 $=2$ 已够，无需再找）。取 $\eta_1$ 为特解：

$$\boxed{x=(1,2,3)^{T}+c_1(1,1,1)^{T}+c_2(0,-2,-2)^{T}}$$

> **关键判断**：先算 $n-r(A)$ 确定要几个 $\xi$，再检查差分是否线性无关，不够就换一对解作差。

### 4.2 例题 5（证明题：基础解系的判定）

设 $\xi_1,\xi_2,\xi_3$ 是 $Ax=0$ 的基础解系，证明 $\xi_1+\xi_2,\ \xi_2+\xi_3,\ \xi_3+\xi_1$ 也是基础解系。

**证明**：
① 三者都是 $Ax=0$ 的解（解空间对加法封闭），且个数仍为 $n-r(A)=3$；
② 只需证线性无关。设

$$k_1(\xi_1+\xi_2)+k_2(\xi_2+\xi_3)+k_3(\xi_3+\xi_1)=0$$

整理得 $(k_1+k_3)\xi_1+(k_1+k_2)\xi_2+(k_2+k_3)\xi_3=0$。由 $\xi_1,\xi_2,\xi_3$ 线性无关，

$$\begin{cases}k_1+k_3=0\\ k_1+k_2=0\\ k_2+k_3=0\end{cases}\qquad \begin{vmatrix}1&1&0\\0&1&1\\1&0&1\end{vmatrix}=2\ne0$$

只有零解 $k_1=k_2=k_3=0$，故三者线性无关。个数等于 $n-r(A)$ 的无关解组即为基础解系。$\blacksquare$

> **一句话写法**：新旧解组的过渡矩阵行列式为 $2\ne0$（可逆）$\Rightarrow$ 等价 $\Rightarrow$ 同为基础解系。

## 五、秩的不等式工具箱（方程组的幕后主角）

| 结论 | 用法提示 |
| --- | --- |
| $r(A)=r(A^{T})$ | 行秩 $=$ 列秩 |
| $r(A\pm B)\le r(A)+r(B)$ | 和的秩不会超过秩之和 |
| $r(AB)\le\min\{r(A),r(B)\}$ | 乘积秩不会变大 |
| $AB=0\Rightarrow r(A)+r(B)\le n$ | $B$ 的每一列都是 $Ax=0$ 的解 |
| $r(A)=k\iff$ 存在 $k$ 阶非零子式，所有 $k+1$ 阶子式为 $0$ | 定义法求秩 |
| 初等变换不改变秩 | 求秩只能靠行/列变换 |
| $r(\bar{A})\le r(A)+1$ | 增广矩阵最多多一秩 |

**小例**：$A$ 为 $4\times3$，$B$ 为 $3\times2$，$AB=0$，$r(A)=2$，则 $B$ 的列都是 $Ax=0$ 的解，解空间维数 $3-2=1$，故 $r(B)\le1$。

## 六、易错点（5 条，逐条对照自查）

1. **用列变换求基础解系** —— 求 $Ax=0$ 的解只允许**行变换**；列变换只可用于求秩、求行列式。
2. **基础解系个数写错** —— 恒为 $n-r(A)$。非齐次时也看 $r(A)$（有解时 $r(A)=r(\bar{A})$），**不是** $n-r(\bar{A})$、更不是 $n$。
3. **没验证就写通解** —— 含参题在 $r(A)<r(\bar{A})$ 时是**无解**，此时写"通解"直接判错。讨论顺序永远是：先判无解，再判唯一/无穷。
4. **含参讨论漏根** —— $|A|=0$ 若有重根（如 $(\lambda-1)^2(\lambda+2)$），每个**不同的**根都要单独代回讨论；$\lambda=1$ 与 $\lambda=-2$ 的秩可能不同，结论不能合并。
5. **混用解的性质** —— 两非齐次解**相加一般不再是解**（需系数和为 1）；系数和为 0 的组合才落回齐次方程。
