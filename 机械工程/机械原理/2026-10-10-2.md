# ⚙️ 机械原理 · 第 15 讲配套 · 公式与速查卡（急回 · 压力角/传动角 · 死点）

> 第 4 章第 2 张速查卡｜全部为**必背**内容，考前默写用。

## 一、急回特性

| 项目 | 公式 / 结论 |
| --- | --- |
| 行程速比系数 | $K=\dfrac{t_{工作}}{t_{空回}}=\dfrac{180^\circ+\theta}{180^\circ-\theta}\ \ge1$ |
| 极位夹角 | $\theta=180^\circ\cdot\dfrac{K-1}{K+1}$ |
| 无急回 | $K=1\Leftrightarrow\theta=0$（对心曲柄滑块、平行四边形机构） |
| 极限位置 | 曲柄与连杆**两次共线**（拉直、重叠）时摇杆到达两极限位置 |
| 作图求 $\theta$ | 以 $C_1$、$C_2$ 为圆心、曲柄长 $a$ 为半径画弧交于 $A$，$\theta=\angle C_1AC_2$ |
| 常用取值 | 牛头刨床、往复输送 $K=1.1\sim2$；$K$ 越大急回越强但传力变差 |

## 二、压力角与传动角

| 项目 | 公式 / 结论 |
| --- | --- |
| 压力角 | $\alpha$＝力方向与受力点速度方向的锐角 |
| 传动角 | $\gamma=\angle BCD$（连杆与从动件所夹**锐角**），$\gamma=90^\circ-\alpha$ |
| 传力要求 | $\gamma$ 越大越省力；设计准则 $\gamma_{\min}\ge40^\circ$，重载高速 $\ge50^\circ$ |
| 最小传动角位置（曲柄摇杆） | 曲柄与**机架**两次共线处：$BD=d-a$、$BD=d+a$，取两者中较小者 |
| 余弦定理求角 | $\cos\angle BCD=\dfrac{b^2+c^2-BD^2}{2bc}$；若 $>90^\circ$ 取补角 |
| 对心曲柄滑块 $\gamma_{\min}$ | $\gamma_{\min}=\arccos\dfrac{\sqrt{b^2-a^2}}{b}=90^\circ-\arcsin\dfrac{a}{b}$ |
| 对心曲柄滑块的 $\gamma_{\min}$ 位置 | 曲柄**垂直于滑块导路**时 |

## 三、死点

| 项目 | 公式 / 结论 |
| --- | --- |
| 定义 | 从动件与连杆共线 ⇒ $\gamma=0$、$\alpha=90^\circ$，驱动力矩为零 |
| 曲柄摇杆 | 摇杆主动时，两极限位置即死点；曲柄主动时**无死点** |
| 主要区别 | 死点＝几何共线；自锁＝摩擦（$\beta\le\varphi$） |
| 消除方法 | 加飞轮借惯性、多组机构错列 |
| 利用场合 | 飞机起落架、夹具、快速夹钳 |

## 四、解题口诀（默写）

1. **先判类型**：最短杆 $+$ 杆长和条件 → 曲柄摇杆 / 双曲柄 / 双摇杆。
2. **再算 $\theta$**：$K\leftrightarrow\theta$ 两式互推，锐角取值。
3. **传动角两算**：曲柄与机架共线两处，算 $\angle BCD$，**大于 90° 取补角**，取小者为 $\gamma_{\min}$。
4. **最后校核**：$\gamma_{\min}\ge40^\circ$ 一句话不能省。
5. **作图三件套**：圆规画弧定极限位置、直尺连矢量、铅笔按比例，角度用弧线加字母标注。

## 五、数字速记

- $K=1.4\Rightarrow\theta=30^\circ$；$K=1.5\Rightarrow\theta=36^\circ$；$K=2\Rightarrow\theta=60^\circ$。
- $K=1.2\Rightarrow\theta=16.4^\circ$；$K=1.1\Rightarrow\theta\approx8.6^\circ$。
- 常见杆长题中 $a+d\le b+c$ 是最短杆为曲柄的**必要校核式**，务必先写。
