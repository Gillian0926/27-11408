# ⚙️ 机械原理 · 第 27 讲配套 · 公式与速查卡（轮系分类 · 定轴轮系传动比）

> 全部为**必背**内容。801 不带计算器，公式必须默写到条件反射。

## 一、轮系分类（必背判定）

| 类型 | 判定依据 | 自由度 |
| --- | --- | --- |
| 定轴轮系 | **所有**齿轮轴线相对机架固定 | — |
| 周转轮系 · 差动 | 有行星轮，且**中心轮均可转动** | $F=2$ |
| 周转轮系 · 行星 | 有行星轮，且**一个中心轮固定** | $F=1$ |
| 复合（混合）轮系 | 定轴 + 周转，或多个周转组合 | — |

**定轴再分**：平面定轴（全圆柱齿轮、轴线平行）／空间定轴（含锥齿轮、蜗杆蜗轮）。

## 二、定轴轮系传动比（核心公式）

$$i_{1k}=\frac{n_1}{n_k}=\frac{\omega_1}{\omega_k}$$

$$|i_{1k}|=\frac{\prod z_{\text{从动}}}{\prod z_{\text{主动}}}=\frac{z_2 z_3\cdots z_k}{z_1 z_{2'}\cdots z_{(k-1)'}}$$

$$\boxed{\,i_{1k}=(-1)^m\frac{\prod z_{\text{从动}}}{\prod z_{\text{主动}}}\,}\quad\text{（仅限平面定轴轮系）}$$

- $m$ = **外啮合圆柱齿轮的对数**（内啮合不计，同轴固连不算啮合）
- $i>0$：首末轮**同向**；$i<0$：首末轮**反向**
- 输出转速：$n_k=n_1/i_{1k}$；功率不变时 $\eta$ 可另乘

## 三、惰轮（中介轮）三句话

1. **不改变传动比大小**（齿数在分子分母中约去）；
2. **改变从动轮转向**（每加一个外啮合惰轮，转向反转一次，$m$ 加 1）；
3. 可用来**凑中心距**、实现远距离传动。

## 四、空间定轴轮系转向判定（口诀）

> **「平行看内外，锥齿指节点，蜗杆分左右」**

| 传动 | 判定规则 |
| --- | --- |
| 圆柱齿轮 · 外啮合 | 两轮转向**相反** |
| 圆柱齿轮 · 内啮合 | 两轮转向**相同** |
| 锥齿轮 | 啮合点处两箭头**同时指向节点**或**同时背离节点** |
| 蜗杆蜗轮 | **右旋用右手、左旋用左手**：四指顺蜗杆转向握住轴线，**拇指指向 = 蜗轮啮合点的圆周速度方向** |

⚠️ 空间轮系**禁止**用 $(-1)^m$，只能画箭头。

## 五、蜗杆蜗轮速查

$$i_{12}=\frac{n_1}{n_2}=\frac{z_2}{z_1}\qquad(z_1=\text{蜗杆头数}=1,2,4;\ z_2=\text{蜗轮齿数})$$

- $z_1=1$ 时 $i=z_2$，单级可达 $40\sim80$，**反行程常自锁**；
- 蜗杆头数越多，传动比越小、效率越高、越不易自锁。

## 六、其它常用速查

| 量 | 公式 |
| --- | --- |
| 一对齿轮传动比 | $i_{12}=\dfrac{n_1}{n_2}=\dfrac{z_2}{z_1}=\dfrac{d_2}{d_1}$（标准齿轮） |
| 锥齿轮传动比 | $i_{12}=\dfrac{z_2}{z_1}=\dfrac{d_2}{d_1}=\dfrac{\sin\delta_2}{\sin\delta_1}$，轴交角 $90^\circ$ 时 $i=\tan\delta_2=\cot\delta_1$ |
| 齿轮齿数 | $z=d/m$，$d=mz$ |
| 轮系总效率（串联） | $\eta=\eta_1\eta_2\cdots\eta_k$ |

## 七、答题模板（定轴轮系计算题）

1. **判别类型**：定轴？平面还是空间？
2. **列式**：$i_{1k}=(-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$，写清各轮主/从身份；
3. **代入**：先约分后相乘，写出中间约分式（防算错，也拿步骤分）；
4. **求转速**：$n_k=n_1/i_{1k}$，带单位 $\mathrm{r/min}$；
5. **定方向**：符号法或箭头法，**图上画出箭头**并文字说明「与轮 1 同向/反向」。

## 八、自测答案

- 平面定轴 $z_1=18,z_2=54,z_{2'}=20,z_3=60,z_{3'}=24,z_4=72$：$m=2$，$i_{14}=+\dfrac{54\times60\times72}{18\times20\times24}=+27$，$n_4=960/27\approx35.56\ \mathrm{r/min}$，与轮 1 同向。
- 左旋蜗杆 → 用**左手**判定。
