# ⚙️ 机械原理 · 第 09 讲配套 · 公式与速查卡（运动副摩擦与总反力）

> 全篇**必背**｜801 力分析大题"第一分钟"要用的全部东西｜考场上不带计算器也能用

## 一、摩擦基本量

| 量 | 公式 | 说明 |
| --- | --- | --- |
| 摩擦力 | $F_f=fF_N$ | $f$：摩擦系数 |
| 摩擦角 | $\tan\varphi=f$，$\varphi=\arctan f$ | 总反力与法线的夹角 |
| 总反力大小 | $F_R=\sqrt{F_N^2+F_f^2}=\dfrac{F_N}{\cos\varphi}$ | 方向由摩擦角确定 |

## 二、移动副（必背）

- 平面移动副：$F_f=fF_N$，$\varphi=\arctan f$
- 楔形槽（半楔角 $\theta$）：$f_v=\dfrac{f}{\sin\theta}$，$\varphi_v=\arctan f_v$，$F_f=f_vQ$
  - $\theta=90^\circ\Rightarrow f_v=f$（退化平面）；$\theta=45^\circ\Rightarrow f_v=1.414f$；$\theta=30^\circ\Rightarrow f_v=2f$
- **方向口诀**：总反力偏在相对运动的**反侧**，与 $v_{12}$ 夹角恒为 $90^\circ+\varphi$

## 三、斜面机构 / 螺旋副

| 工况 | 公式 |
| --- | --- |
| 等速上滑（水平驱动力） | $F=Q\tan(\alpha+\varphi)$ |
| 等速下滑（维持力） | $F'=Q\tan(\alpha-\varphi)$ |
| 斜面自锁 | $\alpha\le\varphi$ |
| 螺纹升角 | $\alpha=\arctan\dfrac{s}{\pi d_2}$（$s$ 为导程） |
| 螺旋副拧紧力矩 | $M=\dfrac{d_2}{2}Q\tan(\alpha+\varphi_v)$ |
| 螺旋副自锁 | $\alpha\le\varphi_v$ |

## 四、转动副与摩擦圆 ★必考

$$M_f=f_v\,G\,r,\qquad \boxed{\rho=f_v\,r}$$

- $\rho$ **与载荷 $G$ 无关**，只与 $r$、$f_v$ 有关
- $f_v$ 取值：**非跑合** $1.57f$；**跑合** $1.27f$；题给从题
- **总反力三要素**：
  1. 必切于摩擦圆（半径 $\rho$）；
  2. 对轴心之力矩方向与相对角速度 $\omega_{12}$ **相反**；
  3. 大小由平衡方程求出。

> **口诀：一切圆（切摩擦圆）· 二反速（矩反于 $\omega_{12}$）· 三凭衡（大小靠平衡）**

## 五、平面高副

- $F_f=fF_N$，总反力偏离**公法线** $\varphi=\arctan f$
- 纯滚动（滚子、滚轮）：$\varphi\approx0$，总反力沿公法线

## 六、效率与自锁（第 11 讲展开，先记结论）

$$\eta=\frac{W_r}{W_d}=\frac{P_r}{P_d},\qquad \text{串联：}\ \eta=\eta_1\eta_2\cdots\eta_k$$

- 自锁判据：$\eta\le0$（正行程 $\eta>0$、反行程 $\eta'\le0$ 即为自锁）
- 斜面自锁：$\alpha\le\varphi$；螺旋副自锁：$\alpha\le\varphi_v$

## 七、作图速查（无计算器也画得出）

1. **转动副** → 先按比例画摩擦圆（圆心在轴心，半径 $\rho$）
2. **二力杆** → 先判受拉 / 受压，再作与两端摩擦圆相切的力作用线
3. **移动副** → 力作用线偏离法线 $\varphi$，偏转方向"阻碍相对运动"
4. **高副** → 力沿接触点公法线（或偏 $\varphi$）
