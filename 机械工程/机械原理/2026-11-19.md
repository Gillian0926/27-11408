## 一、填空 / 选择（40 分，每题 4 分，只写结论）

1. 两构件作平面相对运动时，速度瞬心是________；构件与机架之间的瞬心称为________。
2. 转动副中的摩擦圆半径 $\rho =$ ________，其大小与________、________有关，与载荷大小无关。
3. 曲柄滑块机构中，曲柄转角 $\theta=90^\circ$（连杆与导路垂直）时，连杆的角速度 $\omega_{BC}=$ ________。
4. 斜齿圆柱齿轮的________面参数为标准值，其当量齿数 $z_v=$ ________。
5. 刚性转子静平衡的条件是________；动平衡必须满足________和________两个条件。
6. 为减小飞轮转动惯量，飞轮应装在机械的________轴上。

**答案**：1. 相对速度为零的重合点；绝对瞬心。2. $f_v r$；摩擦系数、轴颈半径。3. $0$。4. 法；$z/\cos^3\beta$。5. $\sum m_i r_i = 0$；$\sum m_i r_i = 0$、$\sum m_i r_i l_i = 0$。6. 转速最高。

## 二、计算与作图（110 分）

### 题 1（15 分）自由度计算
机构含 6 个活动构件、8 个低副、1 个高副；其中滚子处为局部自由度，左右对称布置的两条导路构成虚约束（去掉一处移动副）。

**解**：滚子与从动件固连（去掉 1 个构件、1 个高副，增加 1 个低副）；去掉一处虚约束移动副。
$$F = 3n - 2P_L - P_H = 3\times 5 - 2\times 7 - 0 = 1$$
**答**：$F=1$，与原动件数相等，机构有确定运动。

### 题 2（25 分）速度与加速度分析（作图 + 计算）
曲柄滑块机构 $AB = 100\,\text{mm}$，$BC = 300\,\text{mm}$，$\omega_1 = 10\ \text{rad/s}$ 逆时针，$\theta_1 = 90^\circ$。求滑块速度 $v_C$、加速度 $a_C$。

**解**：$v_B = \omega_1 \cdot AB = 10\times0.1 = 1\ \text{m/s}$，方向 $\perp AB$ 即沿导路方向。
$$\vec v_C = \vec v_B + \vec v_{CB}$$
$\theta_1=90^\circ$ 时 $BC \perp$ 导路，$\vec v_{CB}\perp BC$ 为竖直方向，而 $\vec v_C$ 沿导路，故由速度多边形得 $v_{CB}=0$：
$$v_C = v_B = 1\ \text{m/s}\ (\text{向左})$$
加速度：$a_B = \omega_1^2 \cdot AB = 100\times0.1 = 10\ \text{m/s}^2$，由 $B$ 指向 $A$（$\perp$ 导路）；$a_{CB}^n = v_{CB}^2/BC = 0$。
$$\vec a_C = \vec a_B + \vec a_{CB}^{\,n} + \vec a_{CB}^{\,\tau}$$
取 $\sin\varphi = AB/BC = 1/3$，$\cos\varphi = 0.9428$。由加速度多边形竖直方向平衡：
$$a_{CB}^{\tau}\cos\varphi = a_B \Rightarrow a_{CB}^{\tau} = \frac{10}{0.9428} = 10.61\ \text{m/s}^2$$
$$a_C = a_{CB}^{\tau}\sin\varphi = 10.61\times\frac{1}{3} = 3.54\ \text{m/s}^2\ (\text{向右，滑块减速})$$

### 题 3（20 分）偏心圆盘凸轮
偏心圆盘半径 $R = 30\,\text{mm}$，偏心距 $e = 20\,\text{mm}$，尖顶直动从动件对心布置。求基圆半径、行程、最大压力角，并说明最大压力角出现位置。

**解**：
$$r_0 = R - e = 10\ \text{mm},\qquad h = 2e = 40\ \text{mm}$$
$$\sin\alpha_{\max} = \frac{e}{R} = \frac{20}{30} = 0.6667 \Rightarrow \alpha_{\max} = 41.8^\circ$$
最大压力角出现在从动件位移 $s = h/2 = 20\,\text{mm}$ 处，即接触点与回转中心连线垂直于导路时。

### 题 4（25 分）齿轮尺寸与啮合角
外啮合标准直齿圆柱齿轮 $m=4\,\text{mm}$，$z_1=20$，$z_2=40$，$\alpha=20^\circ$。求各基本尺寸、标准中心距；若实际中心距 $a'=121\,\text{mm}$，求啮合角 $\alpha'$。

**解**：
$$d_1 = mz_1 = 80\ \text{mm},\quad d_2 = 160\ \text{mm},\quad a = \frac{m(z_1+z_2)}{2} = 120\ \text{mm}$$
$$d_{a1} = m(z_1+2) = 88\ \text{mm},\ d_{a2} = 168\ \text{mm};\quad d_{f1} = m(z_1-2.5) = 70\ \text{mm},\ d_{f2} = 150\ \text{mm}$$
$$i_{12} = \frac{z_2}{z_1} = 2$$
由 $a\cos\alpha = a'\cos\alpha'$：
$$\cos\alpha' = \frac{120\cos 20^\circ}{121} = \frac{120\times0.9397}{121} = 0.9319 \Rightarrow \alpha' \approx 21.3^\circ$$

### 题 5（15 分）混合轮系
$z_1=18$、$z_2=36$ 为定轴部分；$z_{2'}=20$ 与 $z_2$ 固连，与固定内齿轮 $z_3=40$、行星轮 $z_4=10$、系杆 $H$ 组成周转部分。求 $i_{1H}$。

**解**：先分轮系：1–2 定轴，$2'$–3–4–$H$ 周转。
$$i_{12} = -\frac{z_2}{z_1} = -2$$
周转部分（$n_3 = 0$）：
$$i_{2'3}^{H} = \frac{n_{2'}-n_H}{n_3-n_H} = -\frac{z_3}{z_{2'}} = -2 \Rightarrow \frac{n_{2'}-n_H}{-n_H} = -2 \Rightarrow n_{2'} = 3n_H$$
$$i_{1H} = i_{12}\cdot i_{2'H} = (-2)\times 3 = -6$$
即 $n_H = -n_1/6$，输出与输入**转向相反**，速比 6。

### 题 6（10 分）飞轮设计
等效阻力矩一周期内四段各占 $\pi/2$：$M_e = 10,\ 30,\ 20,\ 0\ \text{N·m}$；$M_d$ 为常数，$\omega_m = 100\ \text{rad/s}$，$\delta = 0.05$。求 $A_{\max}$ 与 $J_F$。

**解**：$M_d = \dfrac{10+30+20+0}{4} = 15\ \text{N·m}$。各段盈亏功：$+2.5\pi,\ -7.5\pi,\ -2.5\pi,\ +7.5\pi$，累积功最大 $+2.5\pi$、最小 $-7.5\pi$：
$$A_{\max} = 2.5\pi - (-7.5\pi) = 10\pi \approx 31.4\ \text{J}$$
$$J_F = \frac{A_{\max}}{\omega_m^2\,\delta} = \frac{31.4}{100^2\times0.05} = 0.0628\ \text{kg·m}^2$$

## 三、易错点

1. **复合铰链数**：$m$ 个构件汇交于一处，转动副数为 $m-1$，不是 $m$，也不是 1。
2. **局部自由度与虚约束必须写明处理方式**：滚子固连后"$n$ 减 1、高副转低副"，只写结论不写处理会扣分；虚约束要先说"对称布置/重复导路"再剔除。
3. **加速度多边形方向**：$a^n$ 由该点**指向回转中心**，$a^{\tau}\perp$ 构件；作图时先标箭头指向再按比例量取，不要凭直觉画。
4. **偏心圆盘凸轮压力角**用 $\sin\alpha_{\max}=e/R$，不是 $e/r_0$；行程 $h=2e$ 是"偏心距的两倍"，不是圆盘直径。
5. **飞轮盈亏功**取累积功曲线的**最大落差**（同一周期内最高点减最低点），不是某一段的最大值，且注意 $M_e>M_d$ 段为负功。
