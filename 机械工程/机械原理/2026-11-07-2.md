## 一、结构分析（第一章）

| 项目 | 必背 |
| --- | --- |
| ★自由度 | $F=3n-2P_L-P_H$ |
| 复合铰链 | $m$ 构件汇交 → 转动副 $=m-1$ |
| 局部自由度 | 滚子自转、凸轮滚子 → **不计入 $n$**（或最后减去） |
| 虚约束 | 平行等长杆、对称结构、重复高副 → **先剔除再算** |
| 高副低代 | 一高副 → 一构件两低副（代换后自由度不变） |
| 杆组 | $3n-2P_L=0$；$\mathrm{II}$ 级组 $n=2,P_L=3$ |
| 确定运动条件 | $F=$ 原动件数 |

## 二、运动分析（第二章）

$$\vec v_C=\vec v_B+\vec v_{CB},\quad v_{CB}=\omega\,l_{BC}\ (\perp BC)$$
$$\vec a_C=\vec a_B+\vec a_{CB}^n+\vec a_{CB}^t,\quad a_{CB}^n=\frac{v_{CB}^2}{l_{BC}}\ (C\to B),\quad a_{CB}^t\perp BC$$
| 项目 | 必背 |
| --- | --- |
| ★瞬心 | 两构件相对速度为零的重合点；$v_P=\omega_{12}\cdot\overline{P_{12}P}$ |
| 瞬心数 | $N=\dfrac{k(k-1)}{2}$ |
| 三心定理 | 三构件三个瞬心必共线 |
| 比例尺 | $\mu_v=\dfrac{\text{实际速度}}{\text{图长}}$，$\mu_a$ 同理；图上必须标注 |

## 三、力分析（第三章）

| 项目 | 必背 |
| --- | --- |
| 摩擦角 | $\tan\varphi=f$ |
| 摩擦圆半径 | $\rho=f_v\,r$（$f_v$ 当量摩擦系数，$r$ 轴颈半径） |
| 总反力方向口诀 | **"与相对速度方向成 $90^\circ+\varphi$"**（转动副：与相对转向相反侧、切于摩擦圆） |
| 移动副 | 总反力与法线成 $\varphi$ |
| 效率 | $\eta=\dfrac{P_{\text{出}}}{P_{\text{入}}}=\dfrac{M_{\text{出}}\omega_{\text{出}}}{M_{\text{入}}\omega_{\text{入}}}$ |
| ★自锁 | $\eta\le0$（正行程）；螺旋副自锁 $\lambda\le\varphi_v$ |
| 斜面 | $F=F_0\tan(\lambda+\varphi_v)$，$\eta=\dfrac{\tan\lambda}{\tan(\lambda+\varphi_v)}$ |

## 四、连杆机构（第四章）

| 项目 | 必背 |
| --- | --- |
| ★曲柄存在条件 | ① 最短杆为连架杆或机架；② 最短杆 + 最长杆 ≤ 其余两杆之和 |
| 极位夹角 | $\theta=180^\circ\dfrac{K-1}{K+1}$，$K=\dfrac{180^\circ+\theta}{180^\circ-\theta}$ |
| 压力角/传动角 | $\alpha+\gamma=90^\circ$，$\gamma_{\min}$ 出现在曲柄与机架共线两位置之一 |
| 死点 | $\gamma=0^\circ$；靠飞轮惯性或错列布置通过 |
| 摇杆摆角/滑块行程 | 由两极限位置作图量取 |
| 图解法 | 按 $K$ 设计：作 $\angle C_1AC_2=\theta$，以外接圆定 $A$ 点 |

## 五、凸轮机构（第五章）

| 项目 | 必背 |
| --- | --- |
| ★反转法 | 导路按 $-\omega$ 反转等分，各位置量取 $s_i$ 连线 |
| 基圆 | 理论轮廓最小半径 $r_0$ |
| 偏心圆盘 | $r_0=R-e$，$h=2e$，$\sin\alpha_{\max}=\dfrac{e}{R}$ |
| 压力角 | $\tan\alpha=\dfrac{\mathrm ds/\mathrm d\varphi\pm e_1}{s+r_0}$（偏置取"−"更优） |
| 滚子半径 | $\rho_{\min}>r_r$，否则变尖/失真 |
| 运动规律 | 等速→刚性冲击；等加速等减速、余弦→柔性冲击；正弦→无冲击 |
| 位移公式 | 等加速段 $s=\dfrac{2h}{\Phi^2}\varphi^2$，减速段 $s=h-\dfrac{2h}{\Phi^2}(\Phi-\varphi)^2$ |

## 六、齿轮机构（第六章）

| 项目 | 必背 |
| --- | --- |
| ★基本公式 | $d=mz$，$d_a=m(z+2)$，$d_f=m(z-2.5)$，$p=\pi m$，$a=\dfrac{m(z_1+z_2)}{2}$ |
| 渐开线性质 | $r_b=r\cos\alpha$；同一基圆渐开线形状相同；法线切于基圆 |
| 啮合定律 | $i_{12}=\dfrac{\omega_1}{\omega_2}=\dfrac{r_{b2}}{r_{b1}}=\dfrac{r_2'}{r_1'}$（定传动比） |
| ★根切 | $z_{\min}=17$（$\alpha=20^\circ$，$h_a^*=1$）；$z_{\min}=\dfrac{2h_a^*}{\sin^2\alpha}$ |
| ★不根切最小变位 | $x_{\min}=\dfrac{17-z}{17}$（$z<17$） |
| ★变位 | $a'=a+x_1m+x_2m$（高度变位/角变位需算 $\alpha'$）；$a\cos\alpha=a'\cos\alpha'$ |
| 重合度 | $\varepsilon_\alpha=\dfrac{1}{2\pi}\left[z_1(\tan\alpha_{a1}-\tan\alpha')+z_2(\tan\alpha_{a2}-\tan\alpha')\right]>1$ |
| ★斜齿轮 | $m_n=m_t\cos\beta$，$d=m_tz=\dfrac{m_nz}{\cos\beta}$，$a=\dfrac{m_n(z_1+z_2)}{2\cos\beta}$ |
| 锥齿轮 | $\tan\delta_1=\dfrac{z_1}{z_2}$，$R=\dfrac{m}{2}\sqrt{z_1^2+z_2^2}$，$i=\dfrac{z_2}{z_1}$ |
| 蜗杆蜗轮 | $i=\dfrac{z_2}{z_1}$，$a=\dfrac{m(q+z_2)}{2}$，$d_1=mq$；转向用**左右手法则** |

## 七、轮系（第七章）

| 项目 | 必背 |
| --- | --- |
| ★定轴 | $i_{1n}=\dfrac{n_1}{n_n}=(-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$ |
| ★周转 | $i_{1k}^{H}=\dfrac{n_1-n_H}{n_k-n_H}=(-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$ |
| 混合轮系三步 | ① 分定轴/行星（找行星架 $H$ 与太阳轮）；② 分别列式；③ 用"同一构件转速相等"联立 |
| 符号 | 外啮合 $(-1)^m$；内啮合取"+"；锥齿轮用箭头判向 |
| 行星效率 | 转化机构效率 $\eta^H$ 反推，注意 $i$ 与 $\eta$ 符号关系 |

## 八、等效动力学与调速（第八章）

$$J_e=\sum_i\left[J_i\left(\frac{\omega_i}{\omega_1}\right)^2+m_i\left(\frac{v_i}{\omega_1}\right)^2\right],\qquad
M_e=\sum_i\left[M_i\frac{\omega_i}{\omega_1}+F_i\frac{v_i}{\omega_1}\right]$$
$$M_d=\frac{1}{2\pi}\int_0^{2\pi}M_e\,\mathrm d\varphi,\qquad
A_{\max}=\Delta W_{\max}-\Delta W_{\min}$$
| 项目 | 必背 |
| --- | --- |
| ★飞轮 | $J_F=\dfrac{A_{\max}}{\omega_m^2\delta}$；给 $n$ 时 $J_F=\dfrac{900A_{\max}}{\pi^2n^2\delta}$ |
| 不均匀系数 | $\delta=\dfrac{\omega_{\max}-\omega_{\min}}{\omega_m}$，$\omega_m=\dfrac{\omega_{\max}+\omega_{\min}}{2}$ |
| 周期性波动 | 用**飞轮**调节（储能/放能） |
| 非周期性波动 | 用**调速器**调节（改变输入功） |

## 九、平衡（第九章）

| 项目 | 必背 |
| --- | --- |
| 静平衡 | $\sum m_i r_i=0$（单面校正，适用于 $b/D<0.2$ 的盘类） |
| 动平衡 | $\sum m_ir_i=0$ 且 $\sum m_ir_il_i=0$（双面校正，长转子） |
| 结论 | 动平衡必静平衡，静平衡不一定动平衡 |
| 平衡精度 | $e=\dfrac{[e]\cdot\omega}{1000}$（mm/s），$[e]$ 为许用偏心距 |

## 十、手算常数与考场动作（不带计算器）

- $\pi\approx3.14$，$\pi^2\approx9.87\approx10$，$\sqrt2\approx1.414$，$\sqrt3\approx1.732$
- $\sin30^\circ=0.5$，$\cos30^\circ=0.866$，$\sin45^\circ=\cos45^\circ=0.707$，$\tan20^\circ\approx0.364$
