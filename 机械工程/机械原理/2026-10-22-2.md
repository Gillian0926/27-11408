# ⚙️ 机械原理 · 第 24 讲配套 · 公式与速查卡（变位齿轮尺寸 · 传动类型 · 斜齿轮）

> 全部为**必背**内容。考场无计算器，本页公式必须能默写。

## 一、变位齿轮几何尺寸（$x$ 外正内负）

| 项目 | 公式 | 备注 |
| --- | --- | --- |
| 分度圆 | $d=mz$ | **不随变位改变** |
| 基圆 | $d_b=d\cos\alpha$ | **不随变位改变** |
| 分度圆齿厚 | $s=\dfrac{\pi m}{2}+2xm\tan\alpha$ | 正变位齿厚增大 |
| 齿顶高 | $h_a=(h_a^*+x-\Delta y)m$ | $\Delta y$ 勿漏 |
| 齿根高 | $h_f=(h_a^*+c^*-x)m$ | 正变位齿根高减小 |
| 齿顶圆 | $d_a=(z+2h_a^*+2x-2\Delta y)m$ | |
| 齿根圆 | $d_f=(z-2h_a^*-2c^*+2x)m$ | |
| 齿顶高变动系数 | $\Delta y=(x_1+x_2)-y$ | **核心** |

## 二、中心距 · 啮合角 · 无侧隙方程

$$a=\frac{m(z_1+z_2)}{2},\qquad a'=a+ym,\qquad y=\frac{a'-a}{m}$$

$$\cos\alpha'=\frac{a}{a'}\cos\alpha\qquad(\text{基圆不变推出})$$

$$\mathrm{inv}\alpha'=\mathrm{inv}\alpha+\frac{2(x_1+x_2)}{z_1+z_2}\tan\alpha,\qquad \mathrm{inv}\alpha=\tan\alpha-\alpha\ (\text{弧度})$$

反解变位系数和：
$$x_1+x_2=\frac{(\mathrm{inv}\alpha'-\mathrm{inv}\alpha)(z_1+z_2)}{2\tan\alpha}$$

节圆与分度圆：
$$d'=d\cdot\frac{\cos\alpha}{\cos\alpha'},\qquad r'=r\frac{\cos\alpha}{\cos\alpha'}$$

## 三、传动类型判定卡（看 $x_1+x_2$ 的符号！）

| 类型 | 条件 | $a'$ | $\alpha'$ | $\Delta y$ | 齿顶 |
| --- | --- | --- | --- | --- | --- |
| 标准 | $x_1+x_2=0,\ x_1=x_2=0$ | $=a$ | $=\alpha$ | $0$ | 标准 |
| 等变位 | $x_1=-x_2\ne0$ | $=a$ | $=\alpha$ | $0$ | 各自变化 |
| 正传动 | $x_1+x_2>0$ | $>a$ | $>\alpha$ | $>0$ | 降低 |
| 负传动 | $x_1+x_2<0$ | $<a$ | $<\alpha$ | $<0$ | 抬高 |

口诀：**正传动——正变位和、大中心距、大啮合角、齿顶压低；等变位——中心距不动、齿顶不降；负传动——和负距小、齿顶反抬。**

## 四、不根切最小变位系数

$$z_{min}=\frac{2h_a^*}{\sin^2\alpha}=17\ (\alpha=20^\circ,\ h_a^*=1)$$

$$x_{min}=h_a^*\frac{z_{min}-z}{z_{min}}\qquad(z<z_{min}\ \text{时取正})$$

一般取值约束：$x\ge x_{min}$，且正变位不宜过大（齿顶变尖、重合度 $\varepsilon_\alpha$ 下降）。

## 五、斜齿圆柱齿轮速查

| 项目 | 公式 |
| --- | --- |
| 端面 / 法面模数 | $m_t=\dfrac{m_n}{\cos\beta}$ |
| 分度圆 | $d=m_t z=\dfrac{m_n z}{\cos\beta}$ |
| **中心距** | $a=\dfrac{m_n(z_1+z_2)}{2\cos\beta}$ |
| 凑中心距反解 | $\cos\beta=\dfrac{m_n(z_1+z_2)}{2a'}$ |
| 当量齿数 | $z_v=\dfrac{z}{\cos^3\beta}$ |
| 正确啮合条件 | $m_{n1}=m_{n2},\ \alpha_{n1}=\alpha_{n2},\ \beta_1=-\beta_2$（外啮合旋向相反） |
| 重合度 | $\varepsilon_\gamma=\varepsilon_\alpha+\varepsilon_\beta$，$\varepsilon_\beta=\dfrac{b\sin\beta}{\pi m_n}$ |

常用螺旋角范围 $8^\circ\sim20^\circ$（人字/大宽度可到 $30^\circ$ 以上）；$\beta$ 增大 → 重合度增大、传动平稳、轴向力增大。

## 六、模板题四步流程（默写）

1. 算 $a=m(z_1+z_2)/2$ 与 $y=(a'-a)/m$；
2. 由 $\cos\alpha'=\dfrac{a\cos\alpha}{a'}$ 求 $\alpha'$，再查 $\mathrm{inv}\alpha'$；
3. 无侧隙方程求 $x_1+x_2$ → 判类型；算 $\Delta y=(x_1+x_2)-y$；
4. 代入 $h_a,d_a,d_f$；若问斜齿轮，用 $\cos\beta=\dfrac{m_n(z_1+z_2)}{2a'}$ 收尾。

## 七、易错点一行版

- $d,d_b$ 不变；$d_a,d_f,s$ 变；$\Delta y$ 只有非等变位才不为零。
- inv 用弧度；$\alpha=20^\circ$ 时 $\mathrm{inv}\alpha=0.014904$。
- 等变位 $x_1+x_2=0$，别当正传动。
- 负传动齿顶**抬高**，重合度下降。
- 斜齿轮凑中心距只调 $\beta$，不必变位；$\cos\beta>1$ 说明 $a'$ 小于标准中心距，方案不成立。
