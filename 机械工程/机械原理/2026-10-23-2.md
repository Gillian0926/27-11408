# ⚙️ 机械原理 · 第 25 讲配套 · 公式与速查卡（斜齿轮 · 锥齿轮 · 蜗杆蜗轮 · 第六章总表）

> 全部为**必背**内容。考场无计算器，靠公式 + 心算 + 作图。

## 一、斜齿圆柱齿轮 · 必背六式

| 项目 | 公式 |
| --- | --- |
| 模数换算 | $m_t=\dfrac{m_n}{\cos\beta}$ |
| 压力角换算 | $\tan\alpha_t=\dfrac{\tan\alpha_n}{\cos\beta}$ |
| 分度圆 | $d=m_tz=\dfrac{m_nz}{\cos\beta}$ |
| 中心距 | $a=\dfrac{m_n(z_1+z_2)}{2\cos\beta}$ |
| 反求螺旋角 | $\cos\beta=\dfrac{m_n(z_1+z_2)}{2a}$ |
| 当量齿数 | $z_v=\dfrac{z}{\cos^3\beta}$，$d_v=\dfrac{d}{\cos^2\beta}$，$m_v=m_n$ |

- 齿顶圆 $d_a=d+2m_n$；齿根圆 $d_f=d-2.5m_n$（$h_a^*=1,c^*=0.25$）。
- 重合度 $\varepsilon_\gamma=\varepsilon_\alpha+\varepsilon_\beta$，$\varepsilon_\beta=\dfrac{b\sin\beta}{\pi m_n}$。
- 不根切最少齿数 $z_{\min}=17\cos^3\beta$。
- 传动比 $i_{12}=\dfrac{z_2}{z_1}=\dfrac{d_2}{d_1}=\dfrac{d_{a2}}{d_{a1}}$（同螺旋角，仍成立）。

## 二、正确啮合条件 · 三种对照（必背，填空题原题）

| 类型 | 条件 |
| --- | --- |
| 直齿圆柱齿轮 | $m_1=m_2$，$\alpha_1=\alpha_2$ |
| 斜齿圆柱齿轮 | $m_{n1}=m_{n2}$，$\alpha_{n1}=\alpha_{n2}$，$\beta_1=\pm\beta_2$（外啮合取 $-$，内啮合取 $+$） |
| 直齿锥齿轮 | 大端 $m$、$\alpha$ 相等，且 $\delta_1+\delta_2=\Sigma$ |
| 蜗杆蜗轮 | $m_{x1}=m_{t2}$，$\alpha_{x1}=\alpha_{t2}$，$\gamma_1=\beta_2$ **且旋向相同** |

## 三、直齿锥齿轮 · 必背五式

$$\tan\delta_1=\frac{z_1}{z_2}=\frac{\sin\delta_1}{\sin\delta_2},\qquad \delta_1+\delta_2=\Sigma\ (\text{常取 }90°)$$

$$R=\frac{m}{2}\sqrt{z_1^2+z_2^2},\qquad b\le\frac{R}{3},\qquad z_v=\frac{z}{\cos\delta}$$

$$d=mz,\quad d_a=m(z+2\cos\delta),\quad d_f=m(z-2.4\cos\delta)$$

$$i_{12}=\frac{z_2}{z_1}=\frac{d_2}{d_1}=\frac{\sin\delta_2}{\sin\delta_1}\overset{90°}{=}\tan\delta_2=\cot\delta_1$$

口诀：**「大端定模数，背锥量齿高，锥距三分宽」**。

## 四、蜗杆蜗轮 · 必背七式

| 项目 | 公式 |
| --- | --- |
| 直径系数 | $q=\dfrac{d_1}{m}$，$d_1=mq$ |
| 蜗轮分度圆 | $d_2=mz_2$ |
| 传动比 | $i_{12}=\dfrac{z_2}{z_1}\ne\dfrac{d_2}{d_1}$ |
| 导程角 | $\tan\gamma=\dfrac{z_1}{q}=\dfrac{z_1m}{d_1}$，$p_x=\pi m$，导程 $p_z=z_1p_x$ |
| 中心距 | $a=\dfrac{m(q+z_2)}{2}$ |
| 效率 | $\eta=\dfrac{\tan\gamma}{\tan(\gamma+\varphi_v)}$ |
| 自锁条件 | $\gamma\le\varphi_v$（$z_1=1$、$q$ 大时易自锁） |

- 中间平面：蜗杆=齿条、蜗轮=渐开线齿轮，$m_{x1}=m_{t2}$，$\alpha=20°$。
- 转向：**右手蜗杆用右手**，四指顺蜗杆转向，拇指所指即蜗轮啮合点速度方向。

## 五、三大传动横向对比（选择题常考）

| 项目 | 斜齿轮 | 锥齿轮 | 蜗杆蜗轮 |
| --- | --- | --- | --- |
| 两轴位置 | 平行 | 相交 | 交错（垂直） |
| 标准参数位置 | 法面 | 大端 | 中间平面（轴向/端面） |
| 传动比 | $z_2/z_1$ | $z_2/z_1$ | $z_2/z_1$（单级可达 80） |
| 当量齿数 | $z/\cos^3\beta$ | $z/\cos\delta$ | 无 |
| 主要缺点 | 轴向力 | 制造安装要求高 | 效率低、发热大、需贵金属 |

## 六、第六章全章骨架（10-19 ~ 10-24 回顾）

1. **基本定律**：$i_{12}=\dfrac{\omega_1}{\omega_2}=\dfrac{O_2P}{O_1P}$，节点 $P$ 为相对速度瞬心。
2. **渐开线五性质**：①$NK$ 为曲率半径、$N$ 为曲率中心；②法线切于基圆；③$BK=BK_0$；④形状只取决于 $r_b$；⑤$r_b=r\cos\alpha$。
3. **标准直齿轮**：$d=mz$，$p=\pi m$，$d_b=d\cos\alpha$，$a=\frac{m(z_1+z_2)}{2}$，$i=z_2/z_1$。
4. **重合度**：$\varepsilon_\alpha=\dfrac{1}{2\pi}\left[z_1(\tan\alpha_{a1}-\tan\alpha')+z_2(\tan\alpha_{a2}-\tan\alpha')\right]\ge1$。
5. **根切**：$z<z_{\min}=17$（$20°$、$h_a^*=1$）必根切；$x_{\min}=\dfrac{17-z}{17}$。
6. **变位**：$x_\Sigma=x_1+x_2$，$x_\Sigma=0$ 零传动（等变位/标准），$>0$ 正传动，$<0$ 负传动；$a'=a+x_\Sigma m$（外啮合高度变位、角度变位按 $a'$ 反算 $\alpha'$）。
7. **斜齿轮**：法面标准，$\beta$ 凑中心距；$\varepsilon_\beta$ 使传动平稳。
8. **锥齿轮**：大端定标，$z_v=z/\cos\delta$。
9. **蜗杆蜗轮**：$q$ 定直径，$i=z_2/z_1$，$\gamma\le\varphi_v$ 自锁。

## 七、口诀与结论速记

- **「法面标准端面算，三次方里出当量」**（斜齿轮）。
- **「大端模数背锥高，锥距三分之一宽」**（锥齿轮）。
- **「蜗杆头数定传动，直径系数定直径」**（蜗杆）。
- **「外反内同蜗同向」**——外啮合斜齿轮旋向相反、内啮合相同、蜗杆蜗轮相同。
- **「斜齿胜过直齿稳，轴向力要用八字顶」**（人字齿）。
- 无计算器估算：$\cos15°\approx0.966$，$\cos20°\approx0.940$，$\cos11.5°\approx0.980$，$\sqrt2\approx1.414$，$\sqrt5\approx2.236$，$\pi\approx3.14$。
