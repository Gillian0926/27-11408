## 二、逐题精析

### 题 1（填空，8 分）
(1) 转动副摩擦圆半径 $\rho = f_v r$，其大小与 ______、______ 有关，与径向载荷 $F_R$ ______（填“有关/无关”）。
**答**：轴颈半径 $r$、当量摩擦系数 $f_v$；**无关**。
(2) 曲柄滑块机构以曲柄为原动件时 ______ 死点，以滑块为原动件时 ______ 死点。
**答**：无；有（曲柄与连杆共线处，共两个）。

### 题 2（自由度，15 分）
某冲压机构：活动构件 7 个（其中 1 个为凸轮从动件端部滚子），低副 9 个（含 1 个复合铰链，已按 2 个转动副计入），高副 2 个（凸轮—滚子、一对齿轮啮合）。求 $F$。

**解**：滚子绕自身轴转动为局部自由度，把滚子与从动件固连为一个构件：
$$n = 7-1 = 6,\quad p_L = 9-1 = 8,\quad p_H = 2-1 = 1$$
$$F = 3n - 2p_L - p_H = 3\times6 - 2\times8 - 1 = 1$$
$F=1$，与原动件数相等，机构有确定运动。若要作结构分析，须先**高副低代**（1 个高副 = 1 个虚拟构件 + 2 个低副）。

### 题 3（运动分析，15 分）
对心曲柄滑块：$l_{AB}=30$ mm，$l_{BC}=50$ mm，$\omega_1=10$ rad/s，$\varphi=90°$。求 $v_C$、$\omega_2$、$a_C$、$\alpha_2$。

**解**：$v_B=\omega_1 l_{AB}=0.3$ m/s，沿导轨（$+x$）。由 $\vec{v}_C=\vec{v}_B+\vec{v}_{CB}$，$\vec{v}_{CB}\perp BC$，两绝对速度均沿导轨，投影到 $BC$ 方向得 $v_C\cos\beta = v_B\cos\beta$，故 $v_C=0.3$ m/s，$v_{CB}=0$，$\omega_2=0$。

$a_B=\omega_1^2 l_{AB}=3$ m/s²（B→A），$\sin\beta = 30/50 = 0.6$，$\beta=36.87°$；因 $\omega_2=0$ 有 $a_{CB}^n=0$：
沿 $BC$ 投影：$a_C\cos\beta = a_B\sin\beta \Rightarrow a_C = 3\times0.75 = 2.25$ m/s²
垂直 $BC$：$a_{CB}^t = a_C\sin\beta + a_B\cos\beta = 1.35+2.4 = 3.75$ m/s²
$$\alpha_2 = \frac{a_{CB}^t}{l_{BC}} = \frac{3.75}{0.05} = 75\ \text{rad/s}^2$$

### 题 4（凸轮，15 分）
偏心圆盘凸轮：$R=30$ mm，$e=20$ mm，对心尖顶直动从动件。求 $r_0$、$h$、$\alpha_{max}$。

**解**：$r_0 = R-e = 10$ mm；$h = 2e = 40$ mm。接触点法线过偏心圆心，最大压力角出现在 $OP\perp OO'$ 时：
$$\sin\alpha_{max} = \frac{e}{R} = \frac{2}{3},\qquad \alpha_{max} = 41.8°$$

### 题 5（齿轮，20 分）
$z_1=14,\ z_2=35,\ m=5$ mm，$\alpha=20°$，$h_a^*=1$，$c^*=0.25$。
(1) 求标准中心距与 $d_1,d_2,d_{a1}$；(2) 判根切并求 $x_{min}$；(3) 改用斜齿轮使中心距增至 125 mm，求 $\beta$。

**解**：
(1) $a = m(z_1+z_2)/2 = 122.5$ mm；$d_1 = mz_1 = 70$ mm，$d_2 = 175$ mm，$d_{a1}=m(z_1+2h_a^*)=80$ mm。
(2) $z_{min} = 2h_a^*/\sin^2 20° = 2/0.117 \approx 17 > 14$，**会根切**。
$$x_{min} = \frac{h_a^*(z_{min}-z_1)}{z_{min}} = \frac{17-14}{17} = 0.18$$
(3) $\cos\beta = \dfrac{m_n(z_1+z_2)}{2a} = \dfrac{5\times49}{2\times125} = 0.98$，$\beta = 11.48°$。

### 题 6（轮系，20 分）
$z_1=20$，$z_2=40$（1、2 外啮合，2 与中心轮 3 固连），$z_3=20$，行星轮 $z_4=40$，内齿圈 $z_5=100$ 固定，系杆 H 输出，$n_1=1200$ r/min。求 $i_{1H}$、$n_H$、$n_4$。

**解**：周转部分（3-4 外啮合取负，4-5 内啮合取正）：
$$i_{35}^H = \frac{n_3-n_H}{n_5-n_H} = -\frac{z_5}{z_3} = -5,\quad n_5=0 \Rightarrow n_3 = 6n_H$$
定轴部分：$i_{12} = -\dfrac{z_2}{z_1} = -2$，$n_3 = n_2 = -\dfrac{n_1}{2}$。
$$n_H = \frac{n_3}{6} = -\frac{n_1}{12},\quad i_{1H} = -12,\quad n_H = -100\ \text{r/min（反向）}$$
$$\frac{n_3-n_H}{n_4-n_H} = -\frac{z_4}{z_3} = -2 \Rightarrow n_4 = -\frac{3}{2}n_H = 150\ \text{r/min}$$

### 题 7（飞轮，15 分）
稳定运转，周期 $2\pi$：$0\sim\pi$ 阻力矩 20 N·m，$\pi\sim2\pi$ 阻力矩 60 N·m，$M_d$ 为常数，$n_m=477$ r/min，$\delta=0.04$，忽略其余惯量。求 $M_d$、$A_{max}$、$J_F$。

**解**：
$$M_d = \frac{20\pi+60\pi}{2\pi} = 40\ \text{N·m}$$
亏功 $= (20-40)\pi = -20\pi$，盈功 $= +20\pi$，故 $A_{max} = 20\pi = 62.8$ J。
$\omega_m = 2\pi n_m/60 = 50$ rad/s：
$$J_F = \frac{A_{max}}{\omega_m^2\delta} = \frac{62.8}{2500\times0.04} = 0.628\ \text{kg·m}^2$$

### 题 8（平衡，8 分）
$b/D = 0.6$ 的转子应作何种平衡？写出条件。
**答**：$b/D = 0.6 > 0.2$，必须**动平衡**。静平衡条件 $\sum m_i\vec{r}_i = 0$；动平衡条件 $\sum m_i\vec{r}_i = 0$ 且 $\sum m_i\vec{r}_i l_i = 0$，需在两个平面内加（减）配重。

## 三、易错点

1. **局部自由度三项同步修正**：剔除滚子时 $n\downarrow1$、$p_L\downarrow1$，而“凸轮—滚子”高副要换成“凸轮—从动件”高副，$p_H$ 总数不变。只减 $n$ 会多算或少算自由度。
2. **$\omega_2=0$ 不等于 $\alpha_2=0$**：本题 $\varphi=90°$ 时 $v_{CB}=0$，但 $a_{CB}^t=3.75$ m/s²、$\alpha_2=75$ rad/s²。加速度题绝不能沿用速度结论。
3. **凸轮基圆**：偏心圆盘凸轮 $r_0 = R-e$ 而非 $R$；行程是 $2e$；$\sin\alpha_{max}=e/R$ 只对**对心尖顶**成立，偏置时要修正。
4. **混合轮系符号**：$i_{35}^H=-\dfrac{z_5}{z_3}$ 的负号来自 3-4 **外啮合**，4-5 内啮合取正；必须先用 $n_5=0$ 再代入，顺序颠倒必错。
5. **飞轮单位**：$n_m$（r/min）先换 rad/s（$\div9.55$）；$A_{max}$ 用 J；若给出原有惯量 $J$，则 $J_F = \dfrac{A_{max}}{\omega_m^2\delta} - J$。
