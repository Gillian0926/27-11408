# ⚙️ 机械原理 · 第 42 讲配套 · 公式与速查卡（真题第二轮 · 2017 卷必背）

> 全部为**必背**：考场无计算器，公式必须条件反射式写出。

## 一、结构分析 · 自由度

$$F = 3n - 2p_L - p_H$$

- 复合铰链：$m$ 个构件汇交 $\Rightarrow (m-1)$ 个转动副；
- 局部自由度（滚子）：焊死，$n$ 与 $p_L$ 各减 1；
- 虚约束：先剔除再计数；
- 高副低代：以“一杆两低副”代一个高副；
- 判定：**原动件数 = F** 才有确定运动。

## 二、运动分析

**瞬心**：$P_{12}$ 绝对瞬心、$P_{12}'$ 相对瞬心；三心定理——三构件之三瞬心共线。

$$v_{P} = \omega_i \cdot \overline{P_{ij}P_{ik}}$$

**相对运动图解法**：

$$\vec v_B = \vec v_A + \vec v_{BA},\qquad v_{BA} = \omega_{AB}\cdot l_{AB} \perp AB$$

$$\vec a_B = \vec a_A + \vec a_{BA}^{n} + \vec a_{BA}^{t},\qquad a_{BA}^{n} = \omega_{AB}^2 l_{AB},\quad a_{BA}^{t} = \varepsilon_{AB} l_{AB}$$

**重合点**：

$$\vec a_B = \vec a_{B'} + \vec a_{BB'}^{k} + \vec a_{BB'}^{r},\qquad a^{k} = 2\omega v_r$$

## 三、摩擦 · 总反力 · 效率自锁

$$\varphi = \arctan f,\qquad \rho = f_v r\ (\text{摩擦圆半径})$$

- 总反力与摩擦圆**相切**，方向恒**阻碍相对运动**；
- 移动副总反力偏斜 $\varphi$；平面高副法线偏斜 $\varphi$；
- $\eta = \dfrac{W_r}{W_d}$；**$\eta \le 0$ 即自锁**；
- 斜面：$\eta = \dfrac{\tan\lambda}{\tan(\lambda+\varphi)}$，$\lambda \le \varphi$ 时自锁。

## 四、平面连杆

- 曲柄存在条件：**最短杆 + 最长杆 ≤ 其余两杆之和**，且最短杆为连架杆或机架；
- 极位夹角与行程速比系数：

$$\theta = 180^\circ\frac{K-1}{K+1},\qquad K = \frac{180^\circ+\theta}{180^\circ-\theta}$$

- 最小传动角（曲柄摇杆，$a$ 曲柄、$b$ 连杆、$c$ 摇杆、$d$ 机架）：

$$\gamma_{min} = \arccos\frac{b^2+c^2-(d-a)^2}{2bc}\quad(\text{取锐角，钝角取补角})$$

- 死点：$\gamma = 0^\circ$，靠飞轮惯性或错列通过。

## 五、凸轮

- 偏心圆盘（对心尖底）：$r_0 = R - e$，$h = 2e$，$\sin\alpha_{max} = \dfrac{e}{R}$；
- 对心尖底盘形凸轮：$\tan\alpha = \dfrac{v}{\omega r_0 + s}$ · 即 $\tan\alpha = \dfrac{\mathrm{d}s/\mathrm{d}\varphi}{r_0 + s}$；
- 许用压力角：推程 $[\alpha]=30^\circ\sim38^\circ$，回程 $[\alpha]=70^\circ\sim80^\circ$；
- 滚子半径：外凸 $\rho_r < \rho_{min}$（否则失真/变尖）；
- **反转法**：按 $-\omega$ 等分转角，射线上量 $s_i$，光滑连线，滚子再包络。

## 六、齿轮

$$d = mz,\quad d_a = m(z+2h_a^*),\quad d_f = m(z-2h_a^*-2c^*),\quad p = \pi m,\quad a = \frac{m(z_1+z_2)}{2}$$

$$x_{min} = \frac{17 - z}{17}\ (\alpha = 20^\circ,\ h_a^* = 1)$$

$$\varepsilon_\alpha = \frac{1}{2\pi}\left[z_1(\tan\alpha_{a1}-\tan\alpha') + z_2(\tan\alpha_{a2}-\tan\alpha')\right] \ge 1$$

- 变位传动：$x_\Sigma = x_1+x_2$，$x_\Sigma>0$ 正传动（$a'>a$），$x_\Sigma=0$ 等变位，$x_\Sigma<0$ 负传动；
- 斜齿轮凑中心距：$\cos\beta = \dfrac{m_n(z_1+z_2)}{2a'}$；
- 锥齿轮：$\tan\delta_1 = \dfrac{z_1}{z_2}$，$R = \dfrac{m}{2}\sqrt{z_1^2+z_2^2}$；
- 蜗杆：$i = \dfrac{z_2}{z_1}$，$z_1$ 为头数，转向按左右手定则。

## 七、轮系

- 定轴：$i_{1n} = \dfrac{n_1}{n_n} = (-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$；
- 周转：$i_{1k}^{H} = \dfrac{n_1-n_H}{n_k-n_H} = (-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$（转化机构）；
- 混合轮系：**先找行星架 $H$ 与太阳轮 → 分轮系 → 分别列式 → 联立**。

## 八、等效动力学与飞轮

$$J_e = \sum J_i\left(\frac{\omega_i}{\omega}\right)^2 + \sum m_i\left(\frac{v_i}{\omega}\right)^2$$

$$M_e = \sum M_i\frac{\omega_i}{\omega} + \sum F_i\frac{v_i\cos\theta_i}{\omega}$$

$$M_d = \frac{1}{2\pi}\int_0^{2\pi} M_e\,\mathrm{d}\varphi,\qquad A_{max} = \int |M_d - M_e|\,\mathrm{d}\varphi$$

$$J_F = \frac{A_{max}}{\omega_m^2\,\delta},\qquad \delta = \frac{\omega_{max}-\omega_{min}}{\omega_m},\qquad \omega = \frac{2\pi n}{60}$$

- 非周期性波动：靠**调速器**；周期性波动：靠**飞轮**。

## 九、刚性转子平衡

- 静平衡（$b/D < 1/5$）：$\sum m_i r_i = 0$，单面加重/去重；
- 动平衡（$b/D \ge 1/5$）：$\sum m_i r_i = 0$ **且** $\sum m_i r_i l_i = 0$，需两个平衡基面。

## 十、口诀（考前默念）

> 复合铰链 $m$ 减一，滚子焊死虚约束剔；
> 基圆 $R$ 减 $e$，行程两倍 $e$；
> 周转列式先代零，外啮变号内啮停；
> 盈亏面积取最大，飞轮除以 $\omega^2\delta$。
