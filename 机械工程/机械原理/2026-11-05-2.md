## 一、轮系（年年必考，混合轮系为重点）

**定轴轮系**

$$i_{1n}=\frac{n_1}{n_n}=(-1)^{m}\frac{z_2 z_3\cdots z_n}{z_1 z_2'\cdots z_{n-1}}=\frac{\prod z_{\text{从动}}}{\prod z_{\text{主动}}}$$

- $m$：外啮合圆柱齿轮对数；**锥齿轮、蜗杆蜗轮只判转向不算符号**。
- 空间轮系转向用**箭头法**：平行轴箭头同向/反向；锥齿轮箭头同时指向节点或同时背离；蜗杆蜗轮用**左右手法则**（右旋用右手）。

**周转轮系（转化轮系法）**

$$i_{1k}^{H}=\frac{n_1-n_H}{n_k-n_H}=(-1)^{m}\frac{\prod z_{\text{从动}}}{\prod z_{\text{主动}}}$$

**混合轮系三步法（必背口诀）**

> **一分、二定、三联立**——先分出定轴与周转（找行星架 $H$，轴线不固定者为行星轮），定轴单独求，周转用转化式，最后靠**同轴固连件转速相等**联立。

**常用结论**：$2K\text{-}H$ 型 $i_{1H}=1+\dfrac{z_3}{z_1}$（1 主动、3 固定）；$i_{1H}=1-\dfrac{z_3}{z_1}$（3 主动、$H$ 输出需注意符号）。

## 二、齿轮（尺寸链必背）

| 量 | 标准直齿 | 斜齿（法面 $m_n$） |
| --- | --- | --- |
| 分度圆 | $d=mz$ | $d=m_t z=\dfrac{m_n z}{\cos\beta}$ |
| 齿顶圆 | $d_a=m(z+2)$ | $d_a=d+2m_n$（正常齿） |
| 齿根圆 | $d_f=m(z-2.5)$ | $d_f=d-2.5m_n$ |
| 基圆 | $d_b=d\cos\alpha$ | $d_b=d\cos\alpha_t$ |
| 中心距 | $a=\dfrac{m(z_1+z_2)}{2}$ | $a=\dfrac{m_n(z_1+z_2)}{2\cos\beta}$ |
| 传动比 | $i=\dfrac{z_2}{z_1}=\dfrac{d_2}{d_1}$ | 同左（用分度圆） |

- 齿距 $p=\pi m$；齿厚 $s=\dfrac{\pi m}{2}$；$\cos\alpha'=\dfrac{a\cos\alpha}{a'}$。
- 根切：$z_{\min}=17$（$\alpha=20^\circ$、$h_a^*=1$）；$x_{\min}=\dfrac{17-z}{17}$。
- 变位：$x_1+x_2=0$ 高度变位（$a'=a$）；$x_1+x_2>0$ 正传动（$a'>a$）；$<0$ 负传动。
- 重合度：$\varepsilon_\alpha=\dfrac{1}{2\pi}\left[z_1(\tan\alpha_{a1}-\tan\alpha')+z_2(\tan\alpha_{a2}-\tan\alpha')\right]\ge 1$。
- 斜齿当量齿数：$z_v=\dfrac{z}{\cos^{3}\beta}$；$\beta$ 一般 $8^\circ\sim20^\circ$。

## 三、飞轮与速度波动（三件套）

$$M_{ed}=\frac{W_r}{\varphi_T}=\frac{1}{2\pi}\int_0^{2\pi}M_{er}\,\mathrm{d}\varphi\quad(\text{稳定运转一周 } W_d=W_r)$$

$$A_{\max}=\left(\int M_{ed}\mathrm{d}\varphi-\int M_{er}\mathrm{d}\varphi\right)_{\max}-\left(\ \right)_{\min}\quad(\text{盈亏功峰谷差})$$

$$\delta=\frac{\omega_{\max}-\omega_{\min}}{\omega_m},\qquad \omega_m=\frac{\omega_{\max}+\omega_{\min}}{2}=\frac{2\pi n}{60}$$

$$\boxed{\,J_F=\frac{A_{\max}}{\delta\,\omega_m^{2}}\,}\qquad J_F=\frac{900\,A_{\max}}{\pi^{2}n^{2}\delta}$$

- 装飞轮后 $\omega_m$ 近似不变，飞轮只**削减波动幅度**，不能消除波动；
- 非周期性波动靠**调速器**，周期性波动靠**飞轮**（能量"吞吐"）。

## 四、凸轮（几何量必背）

| 量 | 公式/结论 |
| --- | --- |
| 偏心圆盘·对心 | $r_0=R-e$，$h=2e$，$\alpha_{\max}=\arcsin\dfrac{e}{R}$ |
| 偏置直动 | $\tan\alpha=\dfrac{|ds/d\varphi\mp e|}{s+\sqrt{r_0^{2}-e^{2}}}$，偏距 $e$ 取"使 $\alpha$ 减小"的方向 |
| 摆动从动件 | $\tan\alpha=\dfrac{|ds/d\varphi\mp l\,\mathrm{d}\psi/\mathrm{d}\varphi|}{s\sqrt{\ }}$（按教材式，重概念） |
| 许用压力角 | 直动推程 $[\alpha]=30^\circ$，摆动推程 $[\alpha]=35^\circ\sim45^\circ$，回程 $[\alpha']=70^\circ\sim80^\circ$ |
| 滚子半径 | $\rho_{\min}>r_r$，且 $\rho_{\min}\ge(1\sim5)\ \mathrm{mm}$ 防失真 |
| 反转法 | **凸轮不动、从动件反转**：沿 $-\omega$ 方向按位移规律取点连线 |

柔性冲击：等加速等减速、简谐运动（首末及中点）；刚性冲击：等速运动（首末）。

## 五、手算技巧口诀（无计算器考场）

> **分数优先、$\pi$ 后置、平方凑整、结果看量级。**

- 常见值：$\pi\approx3.14$、$2\pi\approx6.28$、$\pi^2\approx9.87$、$\sqrt{2}\approx1.41$、$\sqrt{3}\approx1.73$；
- $\omega=2\pi n/60\approx0.105n$（$n=600\to62.8$）；
- $\omega^2\approx(0.105n)^2$，先平方 $n$ 再乘 $0.011$；
- $\arcsin0.5=30^\circ$、$\arccos0.98\approx11.5^\circ$、$\arcsin0.667\approx41.8^\circ$。
