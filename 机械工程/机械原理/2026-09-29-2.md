# ⚙️ 机械原理 · 第 04 讲配套 · 公式与速查卡（速度瞬心法）

> 用法：早读 3 分钟默写一遍；睡前遮住右列自测。以下全部为**必背**内容。

## 一、定义（填空高频）

| 项目 | 必背表述 |
| --- | --- |
| 速度瞬心 | 互作平面相对运动的**两构件上瞬时绝对速度相等的重合点** |
| 绝对瞬心 | 绝对速度**为零**的瞬心（两构件之一是机架） |
| 相对瞬心 | 绝对速度**不为零**的瞬心 |
| 特性 | **瞬时性**：机构位置变，瞬心一般也变 |

## 二、瞬心数目

$$N=\frac{k(k-1)}{2}\qquad(k\ \text{为构件总数，含机架})$$

四杆 $N=6$；曲柄滑块 $N=6$；五杆 $N=10$。

## 三、瞬心位置四规则（必背）

| 运动副 | 瞬心位置 |
| --- | --- |
| 转动副 | **转动副中心** |
| 移动副 | **垂直于导路方向的无穷远处** |
| 平面高副·纯滚动 | **接触点** |
| 平面高副·滚动带滑动 | 接触点的**公法线**上 |

## 四、三心定理

$$P_{ij},\ P_{ik},\ P_{jk}\ \text{三点共线}\qquad(\text{任意三个平面平行运动构件})$$

四杆 $ABCD$ 常用结论：

$$P_{13}=BC\cap AD,\qquad P_{24}=AB\cap CD$$

曲柄滑块（导路过 $A$）：$P_{13}=$「过 $A$ 作导路垂线」$\cap BC$；$P_{24}=$「过 $C$ 作导路垂线」$\cap AB$。

## 五、核心计算式

$$v_{P_{ij}}=\omega_i\overline{P_iP_{ij}}=\omega_j\overline{P_jP_{ij}}$$

$$\frac{\omega_i}{\omega_j}=\frac{\overline{P_jP_{ij}}}{\overline{P_iP_{ij}}}$$

- 滑块速度：$v_C=\omega_1\overline{AP_{13}}$
- 连杆角速度：$\omega_2=\dfrac{v_B}{\overline{P_{24}B}}$
- 任意点速度：$v=\omega r$，$r$ 为该点到该构件**绝对瞬心（回转中心）**的距离，方向**垂直于该连线**。

## 六、方向判断口诀

> **「上点左行、下点右行」**：构件逆时针转时，位于转心**正上方**的点速度指向**左**；顺时针则相反。
> 通用式（平面）：$\vec{v}=\vec{\omega}\times\vec{r}=\omega(-r_y,\ r_x)$。

## 七、必背结论（选择/填空）

1. 瞬心法**只能求速度，不能求加速度**。
2. 两构件组成**移动副**时，瞬心在垂直于导路方向的无穷远处，两构件**角速度相等**。
3. 平面高副**纯滚动**时，接触点即瞬心，两构件在接触点速度相同。
4. 瞬心处两构件速度**大小相等、方向相同**（同一个矢量）。
5. 绝对瞬心必在机架上，其绝对速度为零；求某点速度必须用**该构件自己的绝对瞬心**量距。
6. 沿 $P_iP_j$ 连线看：$P_{ij}$ 在**同侧** → $\omega_i$、$\omega_j$ **同向**；**异侧** → 反向。
7. 三心定理对**任意三个**平面平行运动构件都成立，不限四杆。

## 八、60 秒自测

1. 五杆机构有几个瞬心？（10 个）
2. 两构件用移动副相连，瞬心在哪？（垂直于导路方向的无穷远处）
3. $P_{13}$ 怎么求？（$P_{12}P_{23}$ 与 $P_{14}P_{34}$ 两直线交点）
4. 瞬心法能求加速度吗？（不能）
5. $\omega_i/\omega_j$ 公式中两段距离各从哪里量？（各自绝对瞬心到公共瞬心 $P_{ij}$）

## 九、口诀总卡

> 转动副中心、移动副无穷、高副法线找；
> 三心定理连直线，间接瞬心自然出；
> 速度相等是同一矢量，量距须从自身轴；
> 只求速度不求加速度，转向用叉乘不靠猜。
