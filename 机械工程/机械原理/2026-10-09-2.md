# ⚙️ 机械原理 · 第 14 讲配套 · 公式与速查卡（四杆机构型式与曲柄条件）

> 全部为**必背**内容。默写标准：能在 3 分钟内写出判据两步法 + 三型式结论表。

## 一、构件与运动副命名

| 名称 | 定义 |
| --- | --- |
| 机架 | 固定不动的构件 |
| 连架杆 | 与机架直接相连的构件 |
| 连杆 | 不与机架直接相连的构件，作平面复合运动 |
| 曲柄 | 能绕机架铰链**整周回转（360°）**的连架杆 |
| 摇杆 | 只能**往复摆动**（转角 < 360°）的连架杆 |

> 口诀：**"连架定型式，连杆不定名。"**

## 二、曲柄存在条件（格拉肖夫判据）★核心必背

设四杆长 $a,b,c,d$，$l_{\min}$ 为最短杆，$l_{\max}$ 为最长杆。

**第一步（杆长和条件）**：
$$l_{\min}+l_{\max}\ \le\ \text{其余两杆长度之和}$$

**第二步（最短杆位置）**：

| 最短杆身份 | 结论 |
| --- | --- |
| 连架杆 | 曲柄摇杆机构 |
| 机架 | 双曲柄机构 |
| 连杆 | 双摇杆机构 |
| —— | 第一步不满足 → **一律双摇杆** |

**口诀**：**"最短杆当连架——曲柄摇杆；当机架——双曲柄；当连杆——双摇杆；杆长和不够——全双摇杆。"**

## 三、含移动副机构

| 机构 | 曲柄存在条件 |
| --- | --- |
| 对心曲柄滑块 | $a\le b$ |
| 偏置曲柄滑块 | $a+e\le b$（$e$ 为偏距） |
| 偏心轮机构 | 偏心距 $e$ = 原曲柄长度 $a$（运动特性不变） |

## 四、演化四途径（速记）

1. **变杆长**：摇杆长度→∞ → 曲柄滑块；
2. **变运动副**：转动副↔移动副 → 曲柄滑块、导杆、摇块、定块；
3. **扩大转动副** → 偏心轮机构；
4. **换机架** → 同一运动链得到不同型式（机架变换法）。

> 口诀：**"长变、副变、轮变大、换机架。"**

## 五、极位夹角与行程速比系数（下一讲主用，先背下）

$$K=\frac{180^\circ+\theta}{180^\circ-\theta}\qquad\Longleftrightarrow\qquad \theta=180^\circ\cdot\frac{K-1}{K+1}$$

- $K=1\Rightarrow\theta=0^\circ$（无急回特性，如对心曲柄滑块）；
- $K>1\Rightarrow\theta>0^\circ$（有急回特性）；
- 常用值：$K=1.4\Rightarrow\theta=30^\circ$；$K=1.5\Rightarrow\theta=36^\circ$。

## 六、考场提示（801 专用）

1. 判型式题**必须写两步**：先杆长和条件、后最短杆位置，再给结论，最后注明"哪根是曲柄、哪根是摇杆"。
2. 不带计算器，$\theta$ 与 $K$ 的换算要**手算熟练**，优先记 $K=1.4\to30^\circ$、$K=1.5\to36^\circ$、$K=2\to60^\circ$。
3. 涉及作图时先统一比例尺，标清字母 $A,B,C,D$；换机架题在新图上重新标机架符号。
4. 结论句模板：**"因 $l_{\min}+l_{\max}=…\le …$，满足杆长和条件；又最短杆 $XX$ 为（连架杆/机架/连杆），故该机构为 ______ 机构，其中 ___ 为曲柄。"**
