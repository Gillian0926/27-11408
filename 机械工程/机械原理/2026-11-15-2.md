## 一、填空/选择必背结论（默写级）

| 考点 | 必背表述 |
| --- | --- |
| 瞬心 | 两构件**相对速度为零**的重合点；绝对瞬心 $v=0$，相对瞬心 $v\ne0$ |
| 三心定理 | 三构件三个瞬心**必在同一直线**上；用于求不直接接触构件的瞬心 |
| 摩擦圆 | 半径 $\rho=f_v r$，与 $f_v$、$r$ 有关，**与载荷无关**；总反力必与摩擦圆相切，且对轴心之矩与 $\omega$ 反向 |
| 自锁 | 驱动力作用在**摩擦角（摩擦锥）内**则自锁；螺旋副自锁条件 $\lambda\le\varphi_v$ |
| 死点 | 连杆与从动曲柄共线，$\gamma=0^\circ$，机构不能起动，靠惯性或错列通过 |
| 曲柄存在条件 | 最短杆 + 邻杆 $\le$ 其余两杆之和；最短杆为机架 → 双曲柄；为连杆 → 双摇杆 |
| 连续传动 | 重合度 $\varepsilon_\alpha\ge1$，$\varepsilon_\alpha=\frac{1}{2\pi}\left[z_1(\tan\alpha_{a1}-\tan\alpha')+z_2(\tan\alpha_{a2}-\tan\alpha')\right]$ |
| 根切 | $z<z_{\min}=17$（$\alpha=20^\circ$、$h_a^*=1$）必根切 |
| 平衡 | $b/D\le0.2$ 只需**静平衡**；$b/D>0.2$ 必须**动平衡**；动平衡必满足静平衡 |
| 速度波动 | 周期性波动用**飞轮**调节；非周期性波动用**调速器** |

## 二、自由度与结构

$$F=3n-2P_L-P_H\quad(\text{已剔除局部自由度、虚约束})$$

- 复合铰链：$m$ 个构件汇交 → $m-1$ 个转动副
- 局部自由度：滚子自转，**不计入 $n$**
- 虚约束：对称、平行、重复导向、高副接触点法线重合——先剔除再计数
- 高副低代：以**曲率中心**代高副，代换后 $F$ 不变

## 三、运动分析（作图必写）

$$\vec v_C=\vec v_B+\vec v_{CB},\qquad v_{CB}=\omega_2\,l_{BC}$$

$$\vec a_C=\vec a_B+\vec a_{CB}^n+\vec a_{CB}^t,\qquad a_{CB}^n=\frac{v_{CB}^2}{l_{BC}}=\omega_2^2 l_{BC}$$

- $a^n$ 方向：由该点**指向**曲率中心；$a^t$ 方向：垂直于连线
- 曲柄滑块 $\theta_1=90^\circ$ 特殊位：$v_C$ 最大、$a_C=0$
- 瞬心法：$v_P=\omega\,l_{PA}$，其中 $A$ 为绝对瞬心

## 四、齿轮（必背三式 + 变位）

$$a=\frac{m(z_1+z_2)}{2},\qquad \cos\alpha'=\frac{a\cos\alpha}{a'}$$

$$x_{\min}=\frac{z_{\min}-z}{z_{\min}}=\frac{17-z}{17}\ (\alpha=20^\circ,\ h_a^*=1)$$

$$\text{斜齿凑中心距：}\ \cos\beta=\frac{m_n(z_1+z_2)}{2a'}$$

- $x_1+x_2=0$：**等变位（高度变位）**，$a'=a$，$\alpha'=\alpha$
- $x_1+x_2>0$：**正传动**，$a'>a$，$\alpha'>\alpha$
- $x_1+x_2<0$：**负传动**，$a'<a$，$\alpha'<\alpha$
- 标准直齿：$d=mz$，$d_a=m(z+2h_a^*)$，$d_f=m(z-2h_a^*-2c^*)$，$p=\pi m$，$s=\pi m/2$
- 斜齿：$d=m_t z=m_n z/\cos\beta$，$a=(d_1+d_2)/2$

## 五、轮系（必背模板）

$$\text{定轴：}\ i_{1k}=\frac{n_1}{n_k}=(-1)^m\frac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$$

$$\text{周转：}\ i_{AB}^{H}=\frac{n_A-n_H}{n_B-n_H}=(-1)^m\frac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$$

- 固定构件代入 $n=0$；负号只数**外啮合对数**，内啮合不改号
- 混合轮系三步：**分（划出定轴/周转）→ 列（各写方程）→ 联立（消 $n_H$）**
- 蜗杆 $z_1=1$ 时 $i=z_2$；转向用**左右手法则**判

## 六、等效动力学与飞轮（三件套）

$$J_e=\sum_i\left[m_i\left(\frac{v_i}{\omega}\right)^2+J_i\left(\frac{\omega_i}{\omega}\right)^2\right],\qquad M_e=\sum_i\left[F_i\frac{v_i}{\omega}\pm M_i\frac{\omega_i}{\omega}\right]$$

$$M_d=\frac{1}{2\pi}\int_0^{2\pi}M_e\,\mathrm d\varphi\ (\text{稳定运转，一周期})$$

$$A_{\max}=\left[\Delta E\right]_{\max}-\left[\Delta E\right]_{\min},\qquad J_F=\frac{A_{\max}}{\omega_m^2\,\delta},\qquad \delta=\frac{\omega_{\max}-\omega_{\min}}{\omega_m}$$

$$\omega_m=\frac{2\pi n}{60}\approx\frac{n}{9.55}$$

- $A_{\max}$ 是**累积盈亏功的极差**，不是单段功
- $J_F\propto 1/\delta$，$J_F\propto 1/\omega_m^2$；飞轮装在**高速轴**上更省惯量
