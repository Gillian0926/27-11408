# ⚙️ 机械原理 · 第 30 讲配套 · 公式与速查卡（轮系全章 · 必背）

## 一、分类判据（一句话）

| 类型 | 判据 |
| --- | --- |
| 定轴轮系 | **所有**齿轮轴线固定 |
| 周转轮系 | 至少一个齿轮轴线**绕主轴公转**（行星轮） |
| 混合轮系 | 定轴 + 周转组合 |

- 自由度 $F=1$ → **行星轮系**；$F=2$ → **差动轮系**（需两个输入，不能直接求 $i$）。

## 二、定轴轮系传动比

$$i_{1k}=\frac{n_1}{n_k}=(-1)^m\frac{z_2 z_3\cdots z_k}{z_1 z_{2'}\cdots z_{k-1}'}$$
- $m$：**外啮合次数**；内啮合不改号。
- 首末轮**轴线平行**才可用 $(-1)^m$；含锥齿轮、蜗杆蜗轮 → **画箭头**。

## 三、周转轮系传动比（转化机构法）

$$\boxed{\,i_{ab}^{H}=\frac{n_a-n_H}{n_b-n_H}=(-1)^m\frac{\prod z_{从}}{\prod z_{主}}\,}$$
- 转化机构：给整个轮系加 $-\,n_H$，行星架"冻结"，$H$ 变机架，周转 → 定轴。
- 符号：圆柱齿轮 $(-1)^m$；**圆锥齿轮 / 蜗杆蜗轮必须画箭头**。
- 固定件代 $0$，注意分母为 $-n_H$。

## 四、必背结论（内齿圈 5、太阳轮 3′、行星轮 4）

| 固定件 | 传动比 | 说明 |
| --- | --- | --- |
| 内齿圈固定 | $i_{3'H}=1+\dfrac{z_5}{z_{3'}}$ | 最常见，同向减速 |
| 太阳轮固定 | $i_{5H}=\dfrac{z_5}{z_{3'}+z_5}$ | 内齿圈输入 |
| 行星架固定 | 变为定轴，$i_{3'5}=-\dfrac{z_5}{z_{3'}}$ | 退化情形 |
| 同心条件 | $z_5=z_{3'}+2z_4$ | 标准齿轮必验算 |

> 差动轮系已知两输入可求第三件：$n_b=\dfrac{n_a-(1-i_{ab}^H)n_H}{i_{ab}^H}$。

## 五、其它轮系

- 蜗杆蜗轮：$i_{12}=\dfrac{n_1}{n_2}=\dfrac{z_2}{z_1}$（$z_1$ 为**头数**，常为 1、2、4）；转向用**左/右手定则**，蜗杆主动。
- 直齿锥齿轮：$i_{12}=\dfrac{z_2}{z_1}$，转向**画箭头**（两轴垂直）。
- 斜齿轮传动比同直齿，转向由螺旋方向 + 转向共同判定。

## 六、混合轮系五步口诀

> **先找行星后找架，中心轮定剩下轴；转化机构列方程，同向取正反向负；桥件相连再联立，代回验算不出错。**

## 七、易错清单（考前 30 秒扫读）

1. $(-1)^m$ 只对平行轴圆柱齿轮成立。
2. 分母 $0-n_H=-n_H$，别丢负号。
3. 双重行星轮齿数**不可约简**。
4. 行星架不一定是"杆"，也可能是大齿轮带动的圆盘——认轴线，不认形状。
5. 结果必须标注**转向**（同向/反向 或 箭头）。

## 八、真题数据（2009–2023）

- 轮系题**年年出现**，分值 15~20 分，多为**混合轮系**（2010、2012B、2013 均考）。
- 常见"换数字重考"：定轴 + 单级 2K-H 行星轮系串联，输出为行星架或内齿圈。
- 蜗杆 $z_1=1$、锥齿轮换向为高频小问。
