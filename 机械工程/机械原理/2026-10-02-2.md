# ⚙️ 机械原理 · 第 07 讲配套 · 公式与速查卡（运动分析综合）

> 全卡内容均为**必背**：定义、公式、方向判据、口诀、得分清单。

---

## 🧭 一、速度瞬心 · 必背

1. **定义**：两构件上**绝对速度相同**的重合点（瞬时等速重合点）。
2. **数目**：$K=\dfrac{N(N-1)}{2}$（$N$ 为构件总数，**含机架**）。
3. **绝对瞬心**：两构件之一是机架，该点绝对速度为零；否则为相对瞬心。
4. **三心定理**：三个作平面平行运动的构件共有 3 个瞬心，**必在同一直线上**。
5. **位置速查表**

| 运动副 | 瞬心位置 |
| --- | --- |
| 转动副 | 副的**转动中心** |
| 移动副 | **垂直于相对移动方向**的无穷远处 |
| 纯滚动高副 | **接触点** |
| 滚动兼滑动高副 | 接触点的**公法线**上 |

6. **核心公式**（构件 1 为机架）

$$v_{P_{ij}}=\omega_i\overline{P_{1i}P_{ij}}=\omega_j\overline{P_{1j}P_{ij}}$$

$$\frac{\omega_i}{\omega_j}=\frac{\overline{P_{1j}P_{ij}}}{\overline{P_{1i}P_{ij}}}$$

> 距离比只给**大小**，**转向必须单独判断**（看 $v_{P_{ij}}$ 的方向）。

## 🚀 二、相对运动图解法 · 速度

1. **同一构件两点** $B$、$C$：

$$\vec v_C=\vec v_B+\vec v_{CB},\qquad \vec v_{CB}\perp BC,\qquad v_{CB}=\omega_{BC}l_{BC}$$

2. **含移动副（重合点法）**：

$$\vec v_{B3}=\vec v_{B2}+\vec v_{B3B2},\qquad \vec v_{B3B2}\parallel\text{导路}$$

3. **速度影像定理**：同一构件上三点构成的多边形，与速度多边形中同名点构成的多边形**相似且字母顺序相同**（**只对同一刚体成立**）。
4. **比例尺**：

$$\mu_v=\frac{v\ (\mathrm{m/s})}{\overline{pv}\ (\mathrm{mm})}\quad(\mathrm{m\cdot s^{-1}/mm})$$

5. **角速度还原**：$\omega=\dfrac{\mu_v\,\overline{bc}}{l_{BC}}$，转向由 $\vec v_{CB}$ 的指向定。

---

## 🎯 三、相对运动图解法 · 加速度

1. **同一构件两点**：

$$\vec a_C=\vec a_B+\underbrace{\vec a_{CB}^{\,n}}_{\omega_{BC}^2l_{BC},\ \ C\to B}+\underbrace{\vec a_{CB}^{\,t}}_{\varepsilon_{BC}l_{BC},\ \perp BC}$$

2. **含移动副**：

$$\vec a_{B3}=\vec a_{B2}+\underbrace{\vec a_{B3B2}^{\,r}}_{\parallel\text{导路}}+\underbrace{\vec a_{B3B2}^{\,k}}_{a_k=2\omega v_r}$$

科氏方向：把 $\vec v_r$ 顺着 $\omega$ 的转向**扳 90°**。

3. **曲柄等速转动**：$\vec a_B=\omega_1^2l_{AB}$，方向 $B\to A$，**切向分量为零**。
4. **比例尺**：$\mu_a=\dfrac{a}{\overline{\pi a}}\ (\mathrm{m\cdot s^{-2}/mm})$。
5. **角加速度还原**：$\varepsilon=\dfrac{\mu_a\overline{b'c'}}{l_{BC}}$。

## 🧠 四、必背口诀

| 口诀 | 含义 |
| --- | --- |
| **三心一线** | 三个构件的三个瞬心必共线 |
| **移动副去无穷** | 移动副瞬心在垂直于滑道的无穷远 |
| **法向指圆心，切向垂杆线** | $a^n$ 指向转动中心，$a^t$ 垂直于杆线 |
| **科氏两倍 $\omega$ 乘 $v_r$，顺着 $\omega$ 扳 90°** | $a_k=2\omega v_r$ 的大小与方向 |
| **速度影像相似，字母顺序不错位** | 仅对同一刚体成立 |
| **瞬心只给速度，加速度要靠图解** | 防止工具用错 |

## 🔢 六、手算速用数值（**不准用计算器**）

$$1\ \mathrm{rad}\approx57.3^\circ,\qquad \omega=\frac{2\pi n}{60}=\frac{\pi n}{30}\approx0.105n\ (\mathrm{rad/s})$$

$$\sqrt2\approx1.414,\quad \sqrt3\approx1.732,\quad \sqrt5\approx2.236,\quad \sqrt{10}\approx3.162$$

$$\sin30^\circ=0.5,\ \sin45^\circ\approx0.707,\ \sin60^\circ\approx0.866,\ \cos60^\circ=0.5$$

> 考试不带计算器，几何量（斜边、角度）多用 3-4-5、1-$\sqrt3$-2、1-1-$\sqrt2$ 特殊三角形凑出，**作图时优先选特殊角位置**。
