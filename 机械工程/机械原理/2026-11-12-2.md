# ⚙️ 机械原理 · 第 45 讲配套 · 公式与速查卡（真题第二轮 · 2020 卷必背）

## 一、结构分析（第一章）

- 自由度：$F = 3n - 2P_L - P_H - F' + P'$（$n$ 为活动构件数，$F'$ 局部自由度，$P'$ 虚约束）
- **复合铰链**：$m$ 个构件同点汇交 $\Rightarrow m-1$ 个转动副
- **局部自由度**：滚子自转、凸轮滚子——只减不删
- **虚约束**：平行双导杆、对称重复、同轴重复、轨迹重合——先剔除再数副
- 高副低代：以"一杆两低副"代替一个高副，代换后 $F$ 不变
- 杆组：$3n - 2P_L = 0$；II 级组 $n=2,\ P_L=3$；机构级别 = 最高杆组级别
- 确定运动条件：**原动件数 = $F$**

## 二、运动分析（第二章）

- 瞬心：两构件相对速度为零的重合点；绝对瞬心 $v=0$，相对瞬心 $v\neq 0$
- 三心定理：三构件三个瞬心共线
- 高副瞬心在**接触点公法线**上
- 矢量方程：$\vec v_C = \vec v_B + \vec v_{CB}$，$\vec a_C = \vec a_B + \vec a^n_{CB} + \vec a^t_{CB}$
- 大小：$v = \omega l$；$a^n = \omega^2 l = v^2/l$；$a^t = \alpha l$
- 方向口诀：$v \perp$ 杆；$a^n$ 沿杆指向转动中心；$a^t \perp$ 杆
- 影像定理：同一构件上三点加速度构成与机构图形**相似且同字母顺序同向**的图形
- 曲柄滑块（对心，$\theta=90^\circ$）：$\omega_{BC}=0,\ v_C=\omega_1 l_{AB},\ a_C = \omega_1^2 l_{AB}\cot\angle$（本卷 $a_C=2250$ mm/s²）

## 三、力分析（第三章）

- 摩擦角 $\varphi = \arctan f$；当量摩擦系数 $f_v$（半圆轴颈 $f_v = 1.27f$）
- **摩擦圆半径** $\rho = f_v r$，总反力恒切于摩擦圆、对轴心取矩方向与 $\omega_{12}$ 相反
- 移动副总反力：与法线成 $\varphi$，方向与相对滑动反向
- 效率：$\eta = \frac{\text{输出功}}{\text{输入功}} = \frac{M_0}{M}$；串联 $\eta = \prod\eta_i$
- 自锁：$\eta \le 0$（正行程）；螺旋副自锁 $\lambda \le \varphi_v$，$\tan\lambda = \frac{zp}{\pi d_2}$

## 四、连杆机构（第四章）

- 曲柄存在条件：①最短杆 + 最长杆 ≤ 其余两杆之和；②最短杆为**连架杆或机架**
- 极位夹角 $\theta$：$K = \frac{180^\circ+\theta}{180^\circ-\theta}$，$\theta = 180^\circ\frac{K-1}{K+1}$
- 摇杆摆角 $\psi$；行程 $H = 2l_{AB}\sin\frac{\psi}{2}$（对心曲柄滑块 $H=2r$）
- 传动角 $\gamma$ = 连杆与从动件所夹锐角；$\gamma_{\min}$ 出现在**曲柄与机架共线**处：
$$\cos\gamma = \frac{b^2+c^2-(d\mp a)^2}{2bc}$$
- 死点：$\gamma = 0^\circ$，出现在以摇杆（或滑块）为原动件、连杆与曲柄共线时；克服靠飞轮惯性或错列

## 五、凸轮机构（第五章）

- 运动规律：等速 $s = h\frac{\delta}{\Phi}$（刚性冲击）；等加速等减速 $s = \frac{2h}{\Phi^2}\delta^2$（柔性冲击）；简谐、摆线（无冲击）
- 反转法：导路绕凸轮中心反转 $\delta$，量取对应位移，得理论轮廓；滚子从动件实际轮廓为理论轮廓的**内包络**
- 压力角（对心直动）：$\tan\alpha = \frac{\mathrm ds/\mathrm d\delta}{s + r_0}$；偏置：$\tan\alpha = \frac{\mathrm ds/\mathrm d\delta \mp e}{s+\sqrt{r_0^2 - e^2}}$
- 许用：推程 $[\alpha]=30^\circ\!\sim\!40^\circ$，回程 $[\alpha]=70^\circ\!\sim\!80^\circ$
- **偏心圆盘凸轮**：$r_0 = R - e$，$h = 2e$，$\sin\alpha_{\max} = \frac{e}{R}$
- 滚子半径：$\rho_r \le 0.8\rho_{\min}$；$\rho_r > \rho_{\min}$ 失真，$\rho_r = \rho_{\min}$ 变尖

## 六、齿轮机构（第六章）

- $d = mz$，$d_a = m(z+2h_a^*)$，$d_f = m(z-2h_a^*-2c^*)$，$p = \pi m$，$s = e = \pi m/2$
- $d_b = d\cos\alpha$，标准中心距 $a = \frac{m(z_1+z_2)}{2}$，$a\cos\alpha = a'\cos\alpha'$
- 重合度 $\varepsilon_\alpha = \frac{z_1(\tan\alpha_{a1}-\tan\alpha') + z_2(\tan\alpha_{a2}-\tan\alpha')}{2\pi} \ge 1$
- 根切：$z_{\min} = \frac{2h_a^*}{\sin^2\alpha} = 17$（$\alpha=20^\circ$）
- 变位：$d' = d$，$d_a = m(z+2h_a^*+2x-2\Delta y)$，无侧隙 $inv\alpha' = inv\alpha + \frac{2(x_1+x_2)\tan\alpha}{z_1+z_2}$，$\Delta y = x_1+x_2-y$，$y = \frac{a'-a}{m}$
- 传动类型：$x_1+x_2>0$ 正传动，$=0$ 零传动（等变位 $x_1=-x_2$ 为标准？注意：$x_1+x_2=0$ 且 $x_1\neq0$ 为等变位），$<0$ 负传动
- 斜齿轮：$m_n = m_t\cos\beta$，$\tan\alpha_n = \tan\alpha_t\cos\beta$，$z_v = \frac{z}{\cos^3\beta}$，$a = \frac{m_n(z_1+z_2)}{2\cos\beta}$
- 锥齿轮：$\tan\delta_1 = \frac{z_1}{z_2}$，$R = \frac{m}{2}\sqrt{z_1^2+z_2^2}$，$i = \frac{z_2}{z_1}$
- 蜗杆蜗轮：$q = d_1/m$，$\tan\gamma = \frac{z_1}{q}$，$a = \frac{m(q+z_2)}{2}$，$i = \frac{z_2}{z_1}$，**转向用左右手定则**

## 七、轮系（第七章）

- 定轴：$i_{1k} = \frac{n_1}{n_k} = (-1)^m\frac{z_2 z_4\cdots z_k}{z_1 z_3\cdots z_{k-1}}$
- 周转：$i^H_{ik} = \frac{n_i - n_H}{n_k - n_H} = (-1)^m\frac{\prod z_{\text{从动}}}{\prod z_{\text{主动}}}$
- **混合三步口诀**：先分定轴周转 → 各列方程 → 找共有构件联立
- 本卷结论：$i_{1H} = 160$；内齿轮固定时 $n_H = n_3/4$ 型关系常考

## 八、运转与速度波动（第八章）

- 等效：$J_e = \sum m_i\left(\frac{v_i}{\omega}\right)^2 + \sum J_i\left(\frac{\omega_i}{\omega}\right)^2$，$M_e = \sum F_i\frac{v_i}{\omega}\cos\alpha_i + \sum M_i\frac{\omega_i}{\omega}$
- 运动方程：$M_e = J_e\alpha + \frac{\omega^2}{2}\frac{\mathrm dJ_e}{\mathrm d\varphi}$
- 周期性波动：$M_d = \frac{1}{2\pi}\int_0^{2\pi}M_r\,\mathrm d\varphi$
- 不均匀系数 $\delta = \frac{\omega_{\max}-\omega_{\min}}{\omega_m}$，$\omega_m = \frac{\omega_{\max}+\omega_{\min}}{2}$
- **飞轮**：$J_F = \frac{A_{\max}}{\omega_m^2\delta}$；$A_{\max}$ = 累积盈亏功曲线**峰谷差**
- 非周期性波动：调速器（机械式/液压式）

## 九、平衡（第九章）

- 静平衡：$\sum m_i r_i = 0$（单面加重/去重），$m_b r_b = \sqrt{(\sum m_ir_i\cos\theta_i)^2+(\sum m_ir_i\sin\theta_i)^2}$
- 动平衡：$\sum \vec F = 0$ 且 $\sum \vec M = 0$，需在**两个平面**内配重；长径比 $b/D>0.2$ 必须动平衡
- 平衡精度：$A = \frac{e\omega}{1000}$（mm/s），许用偏心距 $e = \frac{G\times1000}{\omega}$
