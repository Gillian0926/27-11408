# ⚙️ 机械原理 · 第 52 讲配套 · 公式与速查卡（模拟冲刺 · 卷 C 必背）

## 一、自由度（每卷必考）

$$F = 3n - 2P_L - P_H$$

- 复合铰链：$m$ 构件汇交 → $m-1$ 个转动副；
- 局部自由度：滚子固连，$n$ 减 1、高副转低副；
- 虚约束：对称/重复导路/重复传动，先说明再剔除；
- 高副低代：以曲率中心代高副，代换前后 $F$ 不变；
- 判定：$F>0$ 且 $F=$ 原动件数 → 有确定运动。

## 二、运动分析

$$\vec v_C = \vec v_B + \vec v_{CB},\qquad \vec a_C = \vec a_B + \vec a_{CB}^{n} + \vec a_{CB}^{\tau}$$

$$v = \omega l,\qquad a^n = \omega^2 l = \frac{v^2}{l},\qquad a^{\tau} = \varepsilon l$$

- 瞬心法：$v_P = \omega \cdot \overline{P_{12}P}$；三心定理求瞬心；
- 曲柄滑块 $\theta=90^\circ$：$\omega_{BC}=0$，$v_C=v_B=\omega_1 r$，$a_C = \omega_1^2 r\dfrac{r/l}{\sqrt{1-(r/l)^2}}$；
- 作图口诀：**"先定极点，再按方程逐项加，方向箭头最后标"**。

## 三、凸轮（偏心圆盘三结论）

$$r_0 = R - e,\qquad h = 2e,\qquad \sin\alpha_{\max} = \frac{e}{R}$$

- 最大压力角位置：接触点与回转中心连线 $\perp$ 导路（$s = h/2$）；
- 反转法：反转 $\delta$ 角 → 从动件位移 $s$ → 求各点 → 连成廓线；
- 滚子半径：$\rho_{\min} > r_r$，否则失真（变尖/失真）；
- 基圆半径增大 → 压力角减小 → 传力性能改善。

## 四、齿轮

$$d = mz,\quad d_a = m(z+2),\quad d_f = m(z-2.5),\quad a = \frac{m(z_1+z_2)}{2}$$

$$i_{12} = \frac{z_2}{z_1},\qquad a\cos\alpha = a'\cos\alpha'$$

- 根切最少齿数：标准直齿 $z_{\min}=17$，变位 $x_{\min}=\dfrac{17-z}{17}$；
- 斜齿轮：$z_v = z/\cos^3\beta$，$a = \dfrac{m_n(z_1+z_2)}{2\cos\beta}$（凑中心距用）；
- 锥齿轮：$i = \dfrac{z_2}{z_1} = \tan\delta_2$，$R = \dfrac{m}{2}\sqrt{z_1^2+z_2^2}$；
- 蜗杆蜗轮：$i = z_2/z_1$，$a = \dfrac{m(q+z_2)}{2}$，转向用左右手法则。

## 五、轮系（三步法，必背）

1. **分轮系**：先找行星轮 → 找系杆 $H$ → 找中心轮，其余为定轴；
2. **定轴**：$i = \dfrac{n_1}{n_k} = (-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$；
3. **周转**：$i_{1k}^{H} = \dfrac{n_1-n_H}{n_k-n_H} = (-1)^m\dfrac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$（固定轮 $n=0$）。

> 口诀：**"先找行星后找架，转化机构定符号，联立方程解未知"**。

## 六、等效动力学与飞轮

$$J_e = \sum\left[m_i\left(\frac{v_i}{\omega}\right)^2 + J_i\left(\frac{\omega_i}{\omega}\right)^2\right],\quad M_e = \sum\left[F_i\frac{v_i}{\omega} + M_i\frac{\omega_i}{\omega}\right]$$

$$A_{\max} = \int_{0}^{2\pi}(M_d - M_e)\,\mathrm{d}\varphi\ \Big|_{\max\ \text{落差}},\qquad \delta = \frac{\omega_{\max}-\omega_{\min}}{\omega_m}$$

$$J_F = \frac{A_{\max}}{\omega_m^2\,\delta},\qquad \omega_m = \frac{2\pi n}{60}$$

- $\delta$ 越小 → $J_F$ 越大；飞轮装在**高速轴**上最省惯量；
- 周期性波动用飞轮，非周期性波动用**调速器**。

## 七、平衡

$$\sum m_i r_i = 0\ (\text{静平衡}),\qquad \sum m_i r_i = 0,\ \sum m_i r_i l_i = 0\ (\text{动平衡})$$

- $\dfrac{b}{D} < 0.2$ 且转速低 → 只做静平衡；长转子（$b/D \ge 0.2$）必须动平衡；
- 平衡精度：$[e] = \dfrac{G\,[\,\text{mm/s}\,]}{\omega}$。
