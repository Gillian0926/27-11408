## 一、凸轮机构是什么

**组成**：凸轮（主动件，等速回转或往复移动）+ 推杆（从动件）+ 机架。凸轮与推杆之间为**高副**（点/线接触）。

**特点**
- 优点：只要把凸轮轮廓设计成相应形状，就能使从动件获得**任意预期的运动规律**；结构简单紧凑，设计方便。
- 缺点：高副接触压强高、易磨损；轮廓加工复杂；从动件行程不宜过大。

**典型应用**：内燃机配气机构（凸轮轴驱动气门）、自动机床的进给与夹紧、送料机构、纺织机械、印刷机械等。

## 二、凸轮机构的分类（选择/填空高频）

| 分类依据 | 类型 | 要点 |
| --- | --- | --- |
| 凸轮形状 | **盘形凸轮** | 最常用，绕固定轴转动，从动件在垂直于轴的平面内运动，行程受限 |
| | 移动凸轮 | 凸轮作往复直线移动，可视为回转半径无穷大的盘形凸轮 |
| | 圆柱凸轮 | 在圆柱面上开曲线槽，可获较大行程，属**空间**凸轮机构 |
| 从动件端部形状 | **尖顶** | 构造简单、能实现任意复杂规律，但**磨损快**，只用于低速轻载 |
| | **滚子** | 滚动摩擦、磨损小，**最常用** |
| | **平底** | 受力好、易形成油膜、效率高；但要求凸轮轮廓**处处外凸**（$r_b$ 足够大） |
| 从动件运动形式 | 直动 | 又分**对心**与**偏置**（偏置可改善压力角，偏置方向有讲究） |
| | 摆动 | 从动件绕固定轴摆动 |
| 锁合方式 | 力锁合 | 靠弹簧力、重力保持接触 |
| | 形锁合 | 靠沟槽、等宽、等径等几何形状保持接触 |

## 三、从动件常用运动规律（本讲核心）

**术语**：基圆半径 $r_b$；推程运动角 $\Phi$、远休止角 $\Phi_s$、回程运动角 $\Phi'$、近休止角 $\Phi_s'$，四者满足
$$\Phi+\Phi_s+\Phi'+\Phi_s'=2\pi$$
$h$ 为行程，$\omega$ 为凸轮角速度，$\varphi$ 为**从推程起点量起**的凸轮转角。

**统一的导数关系**（务必记住）：
$$v=\omega\frac{\mathrm{d}s}{\mathrm{d}\varphi},\qquad a=\omega^{2}\frac{\mathrm{d}^{2}s}{\mathrm{d}\varphi^{2}}$$
即 $s\text–\varphi$ 线图的斜率越大，速度越大；斜率的突变对应加速度突变。

### 1. 等速运动规律（推程 $0\le\varphi\le\Phi$）
$$s=\frac{h}{\Phi}\varphi,\qquad v=\frac{h\omega}{\Phi}=\text{const},\qquad a=0$$
起、止点加速度理论上为无穷大 → **刚性冲击**。只宜低速轻载。

### 2. 等加速等减速运动规律
推程前半段（加速，$0\le\varphi\le\Phi/2$）：
$$s=\frac{2h}{\Phi^{2}}\varphi^{2},\qquad v=\frac{4h\omega}{\Phi^{2}}\varphi,\qquad a=\frac{4h\omega^{2}}{\Phi^{2}}$$
后半段对称减速，$a=-\dfrac{4h\omega^{2}}{\Phi^{2}}$。起止点与中点加速度**有限突变** → **柔性冲击**，适用于中速。

### 3. 余弦加速度运动规律（简谐运动）
$$s=\frac{h}{2}\left[1-\cos\frac{\pi\varphi}{\Phi}\right],\quad
v=\frac{\pi h\omega}{2\Phi}\sin\frac{\pi\varphi}{\Phi},\quad
a=\frac{\pi^{2}h\omega^{2}}{2\Phi^{2}}\cos\frac{\pi\varphi}{\Phi}$$
两端 $|a|=\dfrac{\pi^{2}h\omega^{2}}{2\Phi^{2}}\ne 0$ → **柔性冲击**（注意：$s$ 曲线端点切线水平但加速度不为零！）。中低速可用。

### 4. 正弦加速度运动规律（摆线运动）
$$s=h\left[\frac{\varphi}{\Phi}-\frac{1}{2\pi}\sin\frac{2\pi\varphi}{\Phi}\right],\quad
v=\frac{h\omega}{\Phi}\left[1-\cos\frac{2\pi\varphi}{\Phi}\right],\quad
a=\frac{2\pi h\omega^{2}}{\Phi^{2}}\sin\frac{2\pi\varphi}{\Phi}$$
两端 $a=0$，全程**无冲击**，适合高速。

**选择原则**：低速轻载→等速或等加速等减速；中速→余弦加速度（或等加速等减速）；高速→正弦加速度。

## 四、典型例题

**题目**：某盘形凸轮以等角速度 $\omega=10\ \text{rad/s}$ 回转，推程运动角 $\Phi=120^\circ$，行程 $h=30\ \text{mm}$，从动件按**等加速等减速**规律上升。求 $\varphi=30^\circ$、$\varphi=60^\circ$ 时的位移、速度、加速度，并判断该规律的冲击性质。

**解**：$\Phi=120^\circ=\dfrac{2\pi}{3}\ \text{rad}$，$\Phi/2=60^\circ=\dfrac{\pi}{3}$。

**(1) $\varphi=30^\circ$**（在等加速段，$\dfrac{\varphi}{\Phi}=\dfrac14$）：
$$s=2h\left(\frac{\varphi}{\Phi}\right)^{2}=2\times30\times\frac{1}{16}=3.75\ \text{mm}$$
$$v=\frac{4h\omega}{\Phi}\cdot\frac{\varphi}{\Phi}=\frac{4\times30\times10}{2\pi/3}\times\frac14=\frac{900}{2\pi}\approx143.2\ \text{mm/s}$$
$$a=\frac{4h\omega^{2}}{\Phi^{2}}=\frac{4\times30\times100}{(2\pi/3)^{2}}\approx2735.6\ \text{mm/s}^{2}\approx2.74\ \text{m/s}^{2}$$

**(2) $\varphi=60^\circ$**（恰为加速段终点）：
$$s=2h\left(\frac12\right)^{2}=15\ \text{mm}=\frac{h}{2},\qquad
v=\frac{2h\omega}{\Phi}\approx286.5\ \text{mm/s}\ (\text{最大}),\qquad
a\approx2735.6\ \text{mm/s}^{2}$$

**结论**：起、止点及中点处加速度发生**有限突变** → **柔性冲击**；可用于中速、轻载场合，不宜高速。
（对比：若改为**等速运动**，$v=\dfrac{h\omega}{\Phi}\approx143.2\ \text{mm/s}$ 恒定，但起止点 $a\to\infty$，为**刚性冲击**。）

**动手练习**：在同一张纸上画出四种规律的 $s\text–\varphi$ 曲线（斜直线 / 两段抛物线 / 余弦 / 摆线），并标出 $v_{max}$ 的位置（中点 vs 全程 vs 中点），这是作图题与填空题的共同基础。

## 五、易错点（背下来）

1. **刚性冲击 vs 柔性冲击**：等速运动端点 $a\to\infty$，是**刚性**冲击；等加速等减速、余弦加速度是加速度**有限突变**，是**柔性**冲击。两者不能混。
2. **余弦加速度不是"无冲击"**：它在两端速度为零但加速度不为零（$|a|=\pi^{2}h\omega^{2}/(2\Phi^{2})$），属柔性冲击；只有**正弦加速度（摆线）**两端 $a=0$，全程无冲击。
3. **$\varphi$ 的起算点**：公式中的 $\varphi$ 一律从**该段行程起点**量起，$\Phi$ 是该段自己的运动角。回程要另设转角并把 $h$ 换成 $h-s$ 的形式，不能直接照抄推程公式。
4. **四角之和必须 $=360^\circ$**：$\Phi+\Phi_s+\Phi'+\Phi_s'=2\pi$，用于校验位移线图；若分配角度时忘了某段休止角，画出的凸轮"转不满一圈"。
5. **从动件端部形状的限制**：平底从动件要求凸轮轮廓**处处外凸**（凸轮半径不够就不能用）；尖顶从动件磨损快、只用于低速轻载——选择题常在这里设陷阱。
