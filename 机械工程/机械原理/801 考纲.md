# 801 机械原理 · 考试大纲（2027）

> 来源：北京信息科技大学 2027 年硕士研究生入学考试 801《机械原理》考试大纲（思岐本地 `考纲.pdf` 整理）。

## 一、考试基本要求及适用范围

- **基本要求**：需携带考试所需常规文具（**不含计算器**）和**绘图工具**：圆规、量角器、直尺、铅笔。
- **适用范围**：0802 机械工程（学术学位）、085501 机械工程（专业学位）、085502 车辆工程、085507 工业设计工程、085510 机器人工程 的初试。

## 二、题型结构

1. 填空题；2. 选择题；3. **作图题**；4. **计算题**。

## 三、考试内容（九章）

| 章节 | 名称 | 重点掌握内容 |
| --- | --- | --- |
| （一） | 平面机构的结构分析 | ①机构运动简图；②**自由度计算**；③机构组成原理和结构分析 |
| （二） | 平面机构的运动分析 | ①**相对运动图解法**；②综合运用**速度瞬心法**和相对运动图解法对平面机构进行运动分析 |
| （三） | 平面机构的力分析 | ①考虑摩擦时力的分析方法；②转动副、移动副和平面高副中**总反力的确定**；③机械的效率和**自锁**（概念） |
| （四） | 平面连杆机构及其设计 | ①四杆机构运动和传力性能概念；②**曲柄存在条件**、压力角、传动角、极位夹角、摇杆最大摆角（滑块行程）、最大压力角（最小传动角）求法；③典型平面连杆机构的设计 |
| （五） | 凸轮机构及其设计 | ①从动件常用运动规律及选择原则，基圆、压力角、任意位置位移概念；②盘形凸轮廓线设计的**反转法（倒转法）**原理及灵活运用 |
| （六） | 齿轮机构及其设计 | ①齿轮啮合基本定律、**渐开线性质**、齿轮基本参数及啮合特性；②标准渐开线直齿圆柱齿轮传动基本尺寸计算；③渐开线圆柱齿轮加工及**根切**现象；④**变位**圆柱齿轮传动基本尺寸计算；⑤其它类型齿轮传动特点与尺寸计算 |
| （七） | 轮系及其设计 | ①定轴轮系传动比；②**周转轮系**传动比；③**重点：混合轮系传动比计算** |
| （八） | 机械系统的运转及其速度波动的调节 | ①单自由度机械系统**等效动力学模型**；②等效质量、等效力、等效转动惯量、等效力矩求法；③周期性/非周期性速度波动调节原理，**飞轮转动惯量**近似计算 |
| （九） | 机械的平衡设计与实验（概念） | 刚性转子**静平衡、动平衡**的原理和方法 |
