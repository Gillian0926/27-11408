## 二、齿廓啮合基本定律

$$i_{12}=\frac{\omega_1}{\omega_2}=\frac{\overline{O_2P}}{\overline{O_1P}}=\frac{r_2'}{r_1'}$$

- **口诀**：**"公法线必过节点，传动比才不变"**。
- 节点 $P$、节圆 $r_1',r_2'$、共轭齿廓。
- 渐开线齿廓：$i_{12}=\dfrac{r_{b2}}{r_{b1}}=\dfrac{d_{b2}}{d_{b1}}=\dfrac{z_2}{z_1}$。

## 三、渐开线性质（5 条速记）

1. $\overline{KB}=\overset{\frown}{AB}$（滚过长度 = 基圆弧长）
2. 法线恒切基圆，$\overline{KB}$ = 曲率半径
3. 离基圆越远越平直，基圆处曲率半径 $=0$
4. 形状只由 $r_b$ 定，$r_b\to\infty$ 变直线（齿条）
5. **基圆内无渐开线**

**渐开线方程**
$$r_K=\frac{r_b}{\cos\alpha_K},\qquad \theta_K=\tan\alpha_K-\alpha_K=\operatorname{inv}\alpha_K$$

**任意圆齿厚**
$$s_K=s\frac{d_K}{d}-d_K(\operatorname{inv}\alpha_K-\operatorname{inv}\alpha)$$

## 四、标准直齿圆柱齿轮几何尺寸（$h_a^*=1,\ c^*=0.25,\ \alpha=20^\circ$）

| 名称 | 公式 | 速算（$m=1$ 基准） |
|---|---|---|
| 分度圆 | $d=mz$ | $z$ |
| 齿顶高 | $h_a=h_a^*m=m$ | $1$ |
| 齿根高 | $h_f=(h_a^*+c^*)m=1.25m$ | $1.25$ |
| 齿全高 | $h=2.25m$ | $2.25$ |
| 齿顶圆 | $d_a=m(z+2)$ | $z+2$ |
| 齿根圆 | $d_f=m(z-2.5)$ | $z-2.5$ |
| 基圆 | $d_b=mz\cos\alpha$ | $0.9397z$ |
| 齿距 | $p=\pi m$ | $3.1416$ |
| 齿厚=槽宽 | $s=e=\pi m/2$ | $1.5708$ |
| 基圆齿距 | $p_b=\pi m\cos\alpha$ | $2.9521$ |

**标准中心距（标准安装）**
$$a=r_1+r_2=\frac{m(z_1+z_2)}{2},\qquad \alpha'=\alpha,\ \text{节圆}=\text{分度圆},\ \text{无侧隙}$$

**中心距变动后**
$$a\cos\alpha'=a'\cos\alpha\quad(\text{即 } r_{b1}+r_{b2}=a'\cos\alpha')$$

## 五、正确啮合与连续传动

- **正确啮合条件（直齿）**：$m_1=m_2=m$，$\alpha_1=\alpha_2=\alpha$（与齿数无关！）
- **连续传动条件**：$\varepsilon_\alpha\ge1$（工程实用 $\ge1.1\sim1.4$）
$$\varepsilon_\alpha=\frac{z_1(\tan\alpha_{a1}-\tan\alpha')+z_2(\tan\alpha_{a2}-\tan\alpha')}{2\pi}$$
- **齿顶圆压力角**：$\cos\alpha_{a}=\dfrac{d_b}{d_a}$
- 标准安装时 $\alpha'=\alpha=20^\circ$

## 六、必背结论 / 判断题高频

1. 渐开线齿轮**中心距可分**——中心距变化，传动比不变，但 $\alpha'$、节圆、侧隙改变。
2. 渐开线齿廓上**各点压力角不等**：$r_K\uparrow\Rightarrow\alpha_K\uparrow$；基圆上 $\alpha=0$。
3. 分度圆压力角为标准值 $20^\circ$；节圆压力角 = 啮合角 $\alpha'$。
4. 齿条：$r_b\to\infty$，齿廓为**直线**，各点压力角恒等于 $\alpha$，齿距处处相等。
5. 标准齿轮 $z<41.45$ 时 $d_f<d_b$，齿根非渐开线。
6. 一对标准齿轮**标准安装**：顶隙 $c=c^*m=0.25m$，无侧隙，$\alpha'=\alpha$。
7. 模数 $m$ 是**长度量纲**、已标准化；$m=p/\pi$，$m$ 越大轮齿越大、抗弯越强。
8. 四线合一：**啮合线 = 公法线 = 两基圆内公切线 = 压力线**。

## 七、易错清单（默写时对照）

- $d_b=d\cos\alpha$ ✔ ／ $d_b=d\cos\alpha'$ ✘
- $p_b=\pi m\cos\alpha$ ✔ ／ $p_b=\pi m$ ✘
- $d_a=m(z+2h_a^*)$ ✔ ／ $d_a=mz+2$ ✘（漏乘 $m$）
- 分度圆≠节圆；压力角≠啮合角；齿距≠基圆齿距
