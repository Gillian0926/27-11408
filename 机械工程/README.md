# ⚙️ 机械工程模块 · 总览（北京信息科技大学）

> 报考：北京信息科技大学 · 机电学院 · **机械工程（085501，专业学位）**
> 初试四科：思想政治理论(101) + **英语二(204)** + **数学二(302)** + **机械原理(801)**
> 本模块 = **机械原理（801）** + **数学二**。

## 一、专业课 801 机械原理

- 考试科目代码 **801**，满分 150 分，考试时长 3 小时。
- 题型：**填空题 / 选择题 / 作图题 / 计算题**。
- **允许文具**：常规文具 + 绘图工具（圆规、量角器、直尺、铅笔）；**不带计算器**。
- 参考书目（官方指定）：
  1. **赵自强、张春林《机械原理》**，高等教育出版社，2020.4（第二版）
  2. **孙桓、葛文杰《机械原理》**，高等教育出版社，2021.5（第九版）
- 大纲九章见《机械原理/801 考纲.md》，逐章卡片按大纲顺序推进。

## 二、数学二（302）

- 数学二 = **高等数学 + 线性代数**，**不考概率论**、不考无穷级数、不考三重积分/曲线曲面积分/空间解析几何。
- 分值约：高等数学 ~82%、线性代数 ~22%（以当年大纲为准）。
- 卡片按「**高等数学 → 线性代数**」两站轮换，每天 2 张（第 1 张含例题与易错点，第 2 张公式速查）。

## 三、复习节奏

- 每日更新：**机械原理 + 数学二 + 英语（二）+ 政治**。
- 机械原理按九章顺序逐章过：结构分析 → 运动分析 → 力分析 → 连杆 → 凸轮 → 齿轮 → 轮系 → 运转与调速 → 平衡。
