## 1. 中办、国办印发《关于分类推进高校改革的意见》🎓

**要点**：新华社权威快报发布，中共中央办公厅、国务院办公厅印发《关于分类推进高校改革的意见》，明确按不同类型高校实行分类管理、分类评价，引导高校在不同领域、不同赛道办出特色、争创一流，深化教育综合改革，优化学科专业结构和高等教育布局，更好服务国家战略需求。

**🎯 考点链接**（毛中特 / 教育强国 / 科教兴国）：
- **教育强国建设**：党的二十大提出到 2035 年建成教育强国——教育是**国之大计、党之大计**
- **教育、科技、人才"三位一体"**：统筹推进**教育强国、科技强国、人才强国**建设，形成推动高质量发展的倍增效应
- **办好人民满意的教育**：坚持**立德树人**根本任务，把培养社会主义建设者和接班人作为根本目标
- **教育评价改革**：分类评价直指"**五唯**"顽瘴痼疾——破除唯分数、唯升学、唯文凭、唯论文、唯帽子的评价导向

## 2. 我国成功发射卫星互联网低轨 26 组卫星 🛰️

**要点**：我国在近期成功发射卫星互联网低轨 26 组卫星，卫星顺利进入预定轨道，发射任务取得圆满成功。卫星互联网是国家战略性新兴产业和新型基础设施的重要方向，将加快构建天地一体的信息网络体系，为通信、导航、应急等提供支撑。

**🎯 考点链接**（毛中特 / 科技创新 / 新质生产力）：
- **科技自立自强**：坚持**创新在我国现代化建设全局中的核心地位**，把关键核心技术掌握在自己手中
- **新型举国体制**：集中力量办大事——**国家战略科技力量**是航天重大工程的制度优势所在
- **新质生产力**：卫星互联网属于**战略性新兴产业与未来产业**，是发展新质生产力、培育新动能的典型载体
- **航天强国 + 网络强国 + 数字中国**：航天与信息通信深度融合，服务**制造强国、网络强国、数字中国**建设

## 3. 我国将开展第二次全国非遗普查，《非物质文化遗产保护传承"十五五"规划》印发 🏮

**要点**：文化和旅游部印发《非物质文化遗产保护传承"十五五"规划》，我国将开展第二次全国非物质文化遗产普查，建立非遗资源总目录，健全非遗保护传承体系，推动非遗融入现代生活、走近群众。

**🎯 考点链接**（毛中特 / 文化自信 / 思修）：
- **文化自信是更基础、更广泛、更深厚的自信**：非遗是**中华优秀传统文化**的重要载体，是最深厚的文化软实力
- **"两创"方针**：坚持**创造性转化、创新性发展**，让古老文脉在当代焕发活力
- **"两个结合"**：坚持把马克思主义基本原理同中国具体实际相结合、**同中华优秀传统文化相结合**
- **中华文明的突出特性**：连续性、创新性、统一性、包容性、和平性——非遗普查是守护文明**连续性**的基础工程

## 4. 民政部：我国养老服务保障水平持续提升，"十五五"将推动制定养老服务法 👵

**要点**：民政部表示，我国养老服务保障水平持续提升，多层次养老服务体系加快健全；"十五五"时期将推动制定养老服务法，以法治方式保障老年人权益。同期全国托育服务宣传月开展，着力让更多家庭"托得上、托得好"，"一老一小"民生服务同步推进。

**🎯 考点链接**（毛中特 / 民生保障 / 以人民为中心）：
- **以人民为中心的发展思想**：**为民造福是立党为公、执政为民的本质要求**
- **民生建设**：加强**普惠性、基础性、兜底性**民生建设，坚持尽力而为、量力而行
- **积极应对人口老龄化国家战略**：健全多层次社会保障体系，实现**老有所养、幼有所育**
- **共同富裕**：民生"七有"是共同富裕的底线要求，法治化保障让民生更可持续

- **正确政绩观**：**为民造福是最大政绩**，反对"政绩工程""形象工程"，力戒形式主义、官僚主义
- **政治建设统领**：以党的政治建设为统领，全面加强党的**政治建设、思想建设、组织建设、作风建设、纪律建设**，把制度建设贯穿其中
