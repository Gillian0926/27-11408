## 2. “就业友好型”：给人工智能发展装上民生标尺 🤖

**要点**：**国务院办公厅印发《关于适应人工智能技术发展助力构建就业友好型发展方式的意见》**。文件把“就业友好”作为人工智能发展的重要取向：一方面，人工智能催生新职业、新岗位，是发展**新质生产力**的重要引擎；另一方面，替代效应会冲击部分岗位，需要**技能培训、转岗衔接、社会保障与劳动者权益保护**同步跟上。“就业友好型发展方式”的实质，是把**以人民为中心**嵌入技术路线选择——评价一项技术，不只看效率提升，也看它是否扩大了劳动者的选择空间、是否稳住了就业基本盘。发展必须是高质量发展，技术进步必须服务于人的全面发展，这正是“**就业是最基本的民生**”在数智时代的现实展开。

**🎯 考点链接**（毛中特·高质量发展与新质生产力 / 马原·科技的社会作用 / 时政）：
- **新质生产力**以科技创新为核心，**因地制宜**发展；高质量发展是**体现新发展理念**的发展
- **以人民为中心**的发展思想；**就业是最基本的民生**，坚持**就业优先战略**
- **马原**：科学技术是**推动社会发展的强大杠杆**，其社会作用具有**双刃剑**性质，取决于社会制度与人的使用
- **时政记忆**：文件全称《关于适应人工智能技术发展助力构建**就业友好型发展方式**的意见》

## 3. “一老一残一中医”：民生保障的精准刻度 🧡

**要点**：**养老服务消费补贴惠及243万失能老年人**；**《国家残疾预防行动计划（2026—2030年）》发布**，推动不同人群降低致残风险；**百姓有望在“家门口”体验到15项以上中医适宜技术**；**人大常委会执法检查报告显示我国无障碍设施建设全面提速**。四条消息对应“老、残、病、行”四类需求，共同指向民生保障的**精准化**：补贴补到失能照护的痛点上，残疾预防关口前移，中医服务下沉到社区，无障碍设施从“有没有”转向“好不好用”。民生不是抽象概念，而是由一项项可感可及的制度安排构成；**共同富裕**也不是平均主义，而是让困难群体先被看见、先被兜住，这正是**社会主义本质要求**的日常呈现。

**🎯 考点链接**（毛中特·以人民为中心与共同富裕 / 思修·为人民服务 / 时政）：
- **共同富裕**是社会主义的本质要求，是**全体人民**的共同富裕，是**物质生活和精神生活**都富裕
- **健康中国战略**：把**人民健康**放在优先发展的战略地位；**兜底线、织密网、建机制**
- **思修**：**为人民服务**是社会主义道德的核心；人的价值在于**贡献**

## 4. 立法修法：让改革与权利都由法治定型 ⚖️

**要点**：**可再生能源法修订草案提请审议**，为绿色低碳转型提供法律依据；**刑事诉讼法拟作修改，禁止有罪推定、完善人身强制措施**，强化人权司法保障；**无障碍设施建设执法检查报告**显示建设全面提速；**新能源车险从“政策驱动”走向“法治定型”**。立法、修法、执法检查、行业法治化，构成**全面依法治国**的具体环节：立法要主动适应改革和经济社会发展需要，把成熟政策上升为法律，做到**科学立法、民主立法、依法立法**；司法要做到**惩治犯罪与保障人权相统一**，无罪推定是刑事法治的底线；法律的生命力在于实施，执法检查就是让法律“长出牙齿”，实现**良法善治**。

**🎯 考点链接**（法治·全面依法治国 / 思修·宪法与人权 / 时政）：
- **全面依法治国**：**科学立法、严格执法、公正司法、全民守法**；**良法是善治之前提**
- **尊重和保障人权**是宪法原则；**无罪推定**、**疑罪从无**体现刑事司法文明
- **法治与改革**：**重大改革于法有据**，立法主动适应改革发展需要
- **时政记忆**：可再生能源法**修订草案**；刑事诉讼法修改（**禁止有罪推定**、完善人身强制措施）

## 5. 从16件到22件：创新质量的“密度指标” 📈

**要点**：**国家知识产权局印发《专利和商标审查“十五五”规划》**；报道**“从16件到大于22件——每万人口高价值发明专利拥有量如何大幅跃升”**；**张雪机车“出圈”映照创新力量**；**“十五五”专项规划观察聚焦新质生产力发展前景**。知识产权是创新成果的**制度化确权**，审查周期与审查质量直接决定创新回报的速度和确定性；**每万人口高价值发明专利拥有量**是衡量创新质量的国际可比指标，从**16件到大于22件**的跃升，说明创新正从“数量扩张”转向“质量提升”；企业“出圈”靠的是长期研发积累而非流量。新质生产力“新”在技术突破，“质”在要素配置效率，**制度供给**是其中关键一环。

**🎯 考点链接**（毛中特·创新驱动与科技自立自强 / 新质生产力 / 时政）：
- **创新是引领发展的第一动力**；**科技自立自强**是国家发展的战略支撑；**知识产权强国**
- **新质生产力**：以科技创新为核心，以**高技术、高效能、高质量**为特征
- **政府与市场**：发挥**市场在资源配置中的决定性作用**，更好发挥政府作用，保护创新收益
- **时政记忆**：《专利和商标审查**“十五五”规划**》；每万人口高价值发明专利拥有量从**16件到大于22件**
