3. **机械原理 ①（07:30–09:20，1:50）——瞬心的概念与数目**
   - 定义：**瞬心**＝两构件上瞬时**绝对速度相等**的重合点（等速重合点）。
     - **绝对瞬心**：两构件之一为机架（绝对速度为零）；**相对瞬心**：两构件均为活动构件（绝对速度不为零，但相对速度为零）
   - **瞬心数目**：$K=\dfrac{N(N-1)}{2}$，$N$ 为**活动构件数 + 1（机架）**
     - 四杆机构：$K=\dfrac{4\times3}{2}=6$；曲柄滑块：$K=6$；六杆机构：$K=15$——**数目一多就别再用瞬心法**（这是它最大的局限）
   - 记牢：瞬心法**只求速度、不求加速度**，且不能求构件上任意一点的加速度——这是它和下一讲"相对运动图解法"的分工
4. **机械原理 ②（09:40–11:20，1:40）——位置四规则 + 三心定理实战**
   - **位置四规则**（直接接触的两构件，瞬心直接判定）：
     1. 组成**转动副** → 瞬心在**转动副中心**
     2. 组成**移动副** → 瞬心在**垂直于导路方向的无穷远处**
     3. 组成**纯滚动高副** → 瞬心在**接触点**
     4. 组成**滑动兼滚动高副**（非纯滚动） → 瞬心在**过接触点的公法线上**（具体位置由三心定理定）
   - **三心定理**：三个彼此作平面平行运动的构件，其三个瞬心**必在同一直线上**
   - **求速度的标准套路**（画图 + 量比例）：
     1. 数 $K$，列出全部瞬心，先标出四规则能直接定的
     2. 用三心定理"两线求交点"补出间接瞬心（**先求 $P_{13}$、$P_{24}$ 这类跨构件瞬心**）
     3. 用 $\omega_i \cdot \overline{P_{1i}P_{ij}} = \omega_j \cdot \overline{P_{1j}P_{ij}}$ 列等速关系
   - **铰链四杆机构（机架1｜曲柄2 AB｜连杆3 BC｜摇杆4 CD）**：
     - 直接得：$P_{12}=A,\ P_{14}=D,\ P_{23}=B,\ P_{34}=C$
     - $P_{13}$：直线 $AB$ 与直线 $DC$ 的交点；$P_{24}$：直线 $AD$ 与直线 $BC$ 的交点
     - 传动比：$\dfrac{\omega_4}{\omega_2}=\dfrac{\overline{P_{12}P_{24}}}{\overline{P_{14}P_{24}}}$（由 $v_{P_{24}}=\omega_2\overline{P_{12}P_{24}}=\omega_4\overline{P_{14}P_{24}}$）
     - 连杆角速度：$v_{P_{23}}=\omega_2\overline{P_{12}P_{23}}=\omega_3\overline{P_{13}P_{23}}\Rightarrow \omega_3=\omega_2\dfrac{\overline{P_{12}P_{23}}}{\overline{P_{13}P_{23}}}$
   - **曲柄滑块机构**：$P_{13}$ 在垂直导路的**无穷远**；$P_{14}$＝直线 $AB$ 与"过 $C$ 垂直导路"的交点；$P_{23}$＝直线 $BC$ 与"过 $A$ 垂直导路"的交点
     - 滑块速度：$v_C=\omega_2\overline{AB}\cdot\dfrac{\overline{P_{14}C}}{\overline{P_{14}B}}$
   - ⚠️ **画图要求**：按比例画（取 $\mu_l$），瞬心位置量出来要用**圆规 + 直尺 + 量角器**，标注要写清下标（$P_{13}$ 与 $P_{31}$ 是同一个点，但下标顺序别乱）

6. **数学二 ①（13:20–14:50，1:30）——原函数与基本积分表**
   - 原函数：$F'(x)=f(x)\Rightarrow F$ 是 $f$ 的一个原函数；不定积分 $\int f(x)dx=F(x)+C$（**$C$ 不能丢**）
   - **原函数存在定理**（易考选择题）：
     - 区间上**连续** $\Rightarrow$ 必有原函数（可构造 $\int_a^x f(t)dt$）
     - 含**第一类间断点**（可去、跳跃）$\Rightarrow$ 在该区间上**没有**原函数
     - 含**第二类间断点**可能有原函数（例：$f(x)=x^2\sin\frac1x$ 相关构造）
   - **基本积分表（默写，反向激活导数表）**：
     - $\displaystyle\int x^\mu dx=\frac{x^{\mu+1}}{\mu+1}+C\ (\mu\ne-1)$，$\displaystyle\int\frac{dx}{x}=\ln|x|+C$
     - $\displaystyle\int e^xdx=e^x+C$，$\displaystyle\int a^xdx=\frac{a^x}{\ln a}+C$
     - $\displaystyle\int\sin x\,dx=-\cos x+C$，$\displaystyle\int\cos x\,dx=\sin x+C$
     - $\displaystyle\int\sec^2x\,dx=\tan x+C$，$\displaystyle\int\csc^2x\,dx=-\cot x+C$
     - $\displaystyle\int\sec x\tan x\,dx=\sec x+C$，$\displaystyle\int\csc x\cot x\,dx=-\csc x+C$
     - $\displaystyle\int\frac{dx}{1+x^2}=\arctan x+C$，$\displaystyle\int\frac{dx}{\sqrt{1-x^2}}=\arcsin x+C$
     - $\displaystyle\int\tan x\,dx=-\ln|\cos x|+C$，$\displaystyle\int\cot x\,dx=\ln|\sin x|+C$
     - $\displaystyle\int\sec x\,dx=\ln|\sec x+\tan x|+C$，$\displaystyle\int\csc x\,dx=\ln|\csc x-\cot x|+C$
     - $\displaystyle\int\frac{dx}{a^2+x^2}=\frac1a\arctan\frac xa+C$，$\displaystyle\int\frac{dx}{\sqrt{a^2-x^2}}=\arcsin\frac xa+C$
     - $\displaystyle\int\frac{dx}{x^2-a^2}=\frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right|+C$，$\displaystyle\int\frac{dx}{\sqrt{x^2\pm a^2}}=\ln\left|x+\sqrt{x^2\pm a^2}\right|+C$
7. **数学二 ②（15:10–16:40，1:30）——凑微分、换元、分部**
   - **第一类换元（凑微分）**：$\displaystyle\int f[\varphi(x)]\varphi'(x)dx=\int f(u)du$，常用微分式必须条件反射：
     - $x\,dx=\frac12 d(x^2)$｜$\dfrac{dx}{x}=d\ln|x|$｜$\dfrac{dx}{\sqrt x}=2d\sqrt x$｜$\dfrac{dx}{x^2}=-d\dfrac1x$
     - $e^xdx=de^x$｜$\dfrac{dx}{1+x^2}=d\arctan x$｜$\dfrac{dx}{\sqrt{1-x^2}}=d\arcsin x$｜$\dfrac{dx}{\sqrt{1+x^2}}=d\ln(x+\sqrt{1+x^2})$
     - 线性：$\displaystyle\int f(ax+b)dx=\frac1a\int f(ax+b)\,d(ax+b)$
   - **第二类换元（根式代换，代完要回代画直角三角形）**：
     - $\sqrt{a^2-x^2}\Rightarrow x=a\sin t$｜$\sqrt{a^2+x^2}\Rightarrow x=a\tan t$｜$\sqrt{x^2-a^2}\Rightarrow x=a\sec t$
     - 简单根式可试 $\sqrt{ax+b}=t$；**回代别忘**
   - **分部积分**：$\displaystyle\int u\,dv=uv-\int v\,du$，选 $u$ 的口诀 **"反对幂指三"**（反三角、对数、幂函数、指数、三角，**排前者当 $u$**）
     - 必练：$\int xe^xdx$、$\int x\sin x\,dx$、$\int x\arctan x\,dx$、$\int\ln x\,dx$、$\int\arctan x\,dx$
     - **循环法**：$\int e^x\sin x\,dx$ 连用两次分部，移项解出
   - ⚠️ 有理函数部分分式（$\frac{P(x)}{Q(x)}$ 拆分）放到第 05 讲，今天不碰，先把"表 + 凑 + 换 + 分部"练熟
