- **今日两大技能点**

  **① `A is B but C`——"两面句"的对称与落点**
  - 结构：主语 + 系动词 + **形容词 + 名词**，`but` 连接两个**同构表语**：`a useful servant` / `a dangerous master`，形容词对形容词、名词对名词；
  - 语用：**先肯定、后警示**，态度落点永远在 `but` 之后。阅读里问"作者态度"，先找 `but / yet / however / while`，答案八成在其后；

  - ⚠️ **别写失衡**：`Technology is useful but a danger.` —— 左边形容词、右边名词，句式塌了。

  **② `the + 比较级 …, the + 比较级 …`——越……越……**
  - 结构：前句是条件，后句是结果，两句都以 `the + 比较级` 起首，主句可省略系动词；
  - 例：`The more powerful the tool, the greater the responsibility.`（= `The more powerful the tool is, the greater the responsibility is.`）
  - 科技题配伍：`The faster we innovate, the more urgently we need to govern what we invent.`

  **三级拆分（做题时的三步）**
  1. **圈标记**：扫 `but / yet / while / whereas / however`，圈出转折点；
  2. **查平行**：看转折两端是不是同一成分、同一词性（名词对名词、形容词对形容词）；
  3. **定落点**：转折之前是"让步/铺垫"，转折之后才是**作者真正的主张**。

### 3. 机械原理 ①（07:30–09:20，1:50）：第 19 讲 · 凸轮机构的应用与分类

**一、组成与特点**
- 组成：**凸轮**（主动件）+ **推杆**（从动件）+ 机架；凸轮与推杆之间为**高副**（点接触或线接触）。
- 优点：结构简单紧凑；只需设计凸轮轮廓，就能使推杆实现**任意预定的运动规律**。
- 缺点：高副易磨损、承载能力小、不宜高速、轮廓加工复杂。
- 典型应用：内燃机配气机构、自动机床进给与送料、缝纫机、钟表机构、印刷机。

**二、四维分类法（考选择/填空的高频点）**

| 分类依据 | 类别 | 要点 |
| --- | --- | --- |
| 凸轮形状 | 盘形凸轮 | 最基本形式，绕固定轴转动，向径变化 |
| | 移动凸轮 | 凸轮往复直线移动，可视为回转半径无穷大的盘形凸轮 |
| | 圆柱凸轮 | 在圆柱面上开曲线槽，可视为把移动凸轮卷成圆柱 |
| 从动件形状 | 尖顶 | 能实现任意运动规律、构造最简单，但尖端**极易磨损**→ 低速轻载 |
| | 滚子 | 滚动摩擦、磨损小、可承较大载荷 → **最常用** |
| | 平底 | 受力平稳、易形成油膜、效率高（不计摩擦时作用力恒垂直于平底）→ **高速**；但不能用于有内凹轮廓的凸轮 |
| 运动形式 | 直动（对心 / 偏置）、摆动 | 偏置可改善受力，摆动式用于空间受限场合 |
| 锁合方式 | 力锁合 | 靠弹簧力或重力保持接触 |
| | 形锁合 | 靠凹槽、等宽、等径等几何形状保持接触 |

**三、基本名词与参数**
- **基圆**：以凸轮轴心为圆心、以凸轮轮廓**最小向径** $r_b$ 为半径所作的圆；
- **推程与推程运动角** $\Phi$；**远休止角** $\Phi_s$；**回程运动角** $\Phi'$；**近休止角** $\Phi'_s$；
- **行程** $h$：推杆的最大位移；
- **位移线图** $s\text{-}\varphi$：横轴是凸轮转角 $\varphi$（或时间 $t$），纵轴是推杆位移 $s$；
- 四角关系：$\Phi+\Phi_s+\Phi'+\Phi'_s = 2\pi$。

### 4. 机械原理 ②（09:40–11:20，1:40）：从动件四大常用运动规律（本节核心）

设推程运动角为 $\Phi$（**代入时用弧度**），凸轮角速度 $\omega$，推程位移为 $h$。

| 运动规律 | 位移 $s$（推程） | 速度 $v$ | 加速度 $a$ | $v_{\max}$ | $a_{\max}$ | 冲击 |
| --- | --- | --- | --- | --- | --- | --- |
| 等速（一次） | $h\dfrac{\varphi}{\Phi}$ | $\dfrac{h\omega}{\Phi}$ | $0$（除起止点） | $\dfrac{h\omega}{\Phi}$ | — | **刚性冲击** |
| 等加速等减速（二次） | 前半：$2h\left(\dfrac{\varphi}{\Phi}\right)^2$ | 前半：$\dfrac{4h\omega}{\Phi^2}\varphi$ | $\pm\dfrac{4h\omega^2}{\Phi^2}$ | $\dfrac{2h\omega}{\Phi}$ | $\dfrac{4h\omega^2}{\Phi^2}$ | **柔性冲击** |
| 余弦加速度（简谐） | $\dfrac{h}{2}\left[1-\cos\dfrac{\pi\varphi}{\Phi}\right]$ | $\dfrac{\pi h\omega}{2\Phi}\sin\dfrac{\pi\varphi}{\Phi}$ | $\dfrac{\pi^2h\omega^2}{2\Phi^2}\cos\dfrac{\pi\varphi}{\Phi}$ | $\dfrac{\pi h\omega}{2\Phi}\approx1.57\dfrac{h\omega}{\Phi}$ | $\approx4.93\dfrac{h\omega^2}{\Phi^2}$ | **柔性冲击** |
| 正弦加速度（摆线） | $h\left[\dfrac{\varphi}{\Phi}-\dfrac{1}{2\pi}\sin\dfrac{2\pi\varphi}{\Phi}\right]$ | $\dfrac{h\omega}{\Phi}\left[1-\cos\dfrac{2\pi\varphi}{\Phi}\right]$ | $\dfrac{2\pi h\omega^2}{\Phi^2}\sin\dfrac{2\pi\varphi}{\Phi}$ | $\dfrac{2h\omega}{\Phi}$ | $\dfrac{2\pi h\omega^2}{\Phi^2}\approx6.28\dfrac{h\omega^2}{\Phi^2}$ | **无冲击** |

**冲击判据（一句话记住）**
- **速度突变 → 理论加速度无穷大 → 刚性冲击**（等速运动在两个端点；只能用于低速）；
- **加速度有限但突变 → 柔性冲击**（等加速等减速在中点由 $+\frac{4h\omega^2}{\Phi^2}$ 突变为 $-\frac{4h\omega^2}{\Phi^2}$；余弦加速度在起止点与休止段的零加速度对接处）；适用中速；
- **加速度连续（首末为零）→ 无冲击**（正弦加速度，但 $a_{\max}$ 最大）；适用高速轻载。

**今日作图任务（必须在草稿纸上手画一遍）**
1. 取横轴 $\varphi$，划出推程 $\Phi$、远休 $\Phi_s$、回程 $\Phi'$、近休 $\Phi'_s$ 四段；
2. 在同一坐标系下叠画 $s$、$v$、$a$ 三条曲线（四条规律各画一组，共 4 张图）；
3. 对照检查：$v$ 图有没有跳变？$a$ 图有没有跳变？起止点是不是零？——三个问题就能反推冲击类型。

**今日重点结论（写进本子）**
- 「等速看两端，等加看中间，余弦看两头，正弦全程柔」——四种规律的冲击位置口诀；
- 高速场合优先 **正弦加速度（摆线）**；中速常用 **余弦加速度或等加速等减速**；低速可用 **等速**；
- 工程上还常用**组合运动规律**（改进型等速、改进型梯形加速度），本质是"把冲击段磨圆"。

### 6. 数学二 ①（13:20–14:50，1:30）：第 19 讲 · 常微分方程的建模应用

**一、建模式题的三个入口**
1. **几何关系** → 切线斜率、法线、与坐标轴围成面积、曲率；
2. **变化率语言** → "变化率与……成正比/成反比""增长率""衰变率"；
3. **微元平衡** → "进 − 出"（混合、电路、人口、药物代谢）。

**二、四类必练模型（每题都走"设变量 → 列方程 → 定初值 → 求解 → 回代检验"五步）**

**① 几何切线模型**
曲线上任一点 $(x,y)$ 处切线：$Y-y=y'(X-x)$，与 $x$ 轴交点横坐标 $X_0=x-\dfrac{y}{y'}$。
例：曲线过 $(1,1)$，且任一点切线与 $x$ 轴交点横坐标为 $\dfrac{x}{2}$，则 $x-\dfrac{y}{y'}=\dfrac{x}{2}\Rightarrow y'=\dfrac{2y}{x}\Rightarrow y=Cx^2$，代入得 $y=x^2$。

**② 变化率模型**
`dy/dx = k y` → $y=Ce^{kx}$；`dy/dx = -k(y-a)` → $y=a+Ce^{-kx}$。

**③ 冷却模型（牛顿冷却定律）**
$$\frac{dT}{dt}=-k(T-T_0)$$
例：$T_0=20^\circ$，$T(0)=100^\circ$，$T(10)=60^\circ$，求 $T=25^\circ$ 的时刻。
解：$T-20=80e^{-kt}$，由 $40=80e^{-10k}$ 得 $k=\dfrac{\ln 2}{10}$；令 $5=80e^{-kt}$ 得
$$t=\frac{10\ln16}{\ln2}=\frac{10\times4\ln2}{\ln2}=40\ \text{(min)}$$

**④ 混合（稀释）模型**
设 $S(t)$ 为溶质总量，$V$ 为溶液体积（进出流量相等时 $V$ 恒定）：
$$\frac{dS}{dt}=c_1q_1-\frac{S}{V}q_2 \quad(\text{输入}-\text{输出})$$
标准形式是一阶线性方程 $S'+\dfrac{q_2}{V}S=c_1q_1$，套公式即可。

**⑤ 积分方程 → 微分方程**
例：$f(x)=\displaystyle\int_0^xf(t)\,dt+x^2$。两边求导：$f'(x)=f(x)+2x$，且由原式取 $x=0$ 得 $f(0)=0$。
解 $f'-f=2x$：$f(x)=e^{x}\!\left[\int 2xe^{-x}dx+C\right]=-2x-2+Ce^{x}$，代入 $f(0)=0$ 得 $C=2$，
$$\boxed{f(x)=2e^{x}-2x-2}$$

**⑥ 一阶线性通解公式（默写级）**
$$y=e^{-\int P dx}\left[\int Q\,e^{\int P dx}dx+C\right]$$
⚠️ 公式里的 $\int P\,dx$ **只取一个原函数**，不带任意常数。

### 7. 数学二 ②（15:10–16:40，1:30）：常微分方程全章综合串讲（高数收官）

**一、知识树**
- **基本概念**：阶、通解（含独立任意常数个数 = 阶数）、特解、初值问题、积分曲线；
- **一阶方程**：可分离变量 → 齐次方程 $y'=f\!\left(\frac{y}{x}\right)$ 令 $u=\frac{y}{x}$（$y'=u+xu'$）→ 一阶线性（公式法）。（伯努利方程不在数二大纲，跳过）
- **可降阶高阶方程**：
  - $y''=f(x)$：直接两次积分；
  - $y''=f(x,y')$：令 $p=y'$，化为 $p'=f(x,p)$；
  - $y''=f(y,y')$：令 $p=y'$ 并以 $y$ 为自变量，$y''=p\dfrac{dp}{dy}$；
- **二阶常系数线性**：
  - 齐次：$r^2+pr+q=0$，两根三种情形（互异实根 / 重根 / 共轭复根 $\alpha\pm\beta i$）；
  - 非齐次：$y=Y+y^{*}$，特解待定形式表：

| $f(x)$ 形式 | 特解 $y^{*}$ 形式 | $k$ 取值 |
| --- | --- | --- |
| $P_m(x)$ | $x^{k}Q_m(x)$ | $\lambda=0$：不是特征根取 0，单根取 1，重根取 2 |
| $P_m(x)e^{\lambda x}$ | $x^{k}Q_m(x)e^{\lambda x}$ | 同上，按 $\lambda$ 判断 |
| $e^{\alpha x}(A\cos\beta x+B\sin\beta x)$ | $x^{k}e^{\alpha x}(a\cos\beta x+b\sin\beta x)$ | $\alpha\pm\beta i$ 是特征根取 1，否则取 0 |

  - **叠加原理**：若 $f=f_1+f_2$，则 $y^{*}=y_1^{*}+y_2^{*}$。
- **解的结构两定理**：非齐次通解 = 对应齐次通解 + 非齐次一个特解；两个非齐次解之差是齐次解。

**二、6 大陷阱（今天必须能背出来）**
1. **丢解**：分离变量时 $g(y)=0$ 给出的常值函数解容易漏；
2. **常数个数**：通解中独立任意常数个数必须等于方程阶数；
3. **公式不带常数**：一阶线性公式中 $\int P\,dx$ 不写 $+C$；
4. **忘乘 $x^k$**：待定特解时，$\lambda$ 或 $\alpha\pm\beta i$ 恰是特征根，必须乘 $x^k$；
5. **降阶变量选错**：$y''=f(y,y')$ 必须把 $p$ 看成 $y$ 的函数，$y''=p\frac{dp}{dy}$，不能写成 $\frac{dp}{dx}$；
6. **不检验**：解完一定回代原方程 + 验证初值，尤其积分方程题必须回原式取 $x=0$ 定初值。
