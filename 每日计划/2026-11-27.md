### ③ 五大必考串联精讲（S → M → C → G → F）

#### S｜自由度（链头，约 25 分）

$$F = 3n - 2P_L - P_H$$

**三步法**：① 数**活动构件** $n$（机架不计）→ ② 数低副 $P_L$（转动副 + 移动副）→ ③ 数高副 $P_H$（凸轮-滚子、齿轮啮合各 1）。

三个必查项：

- **复合铰链**：$m$ 个构件汇于一点 → 该处有 $(m-1)$ 个转动副。
- **局部自由度**：滚子绕自身轴转动不影响输出 → 计算时**把滚子与从动件固连**，滚子-从动件的转动副不计，凸轮-滚子高副仍计 1 个。等效记法：$F = 3n - 2P_L - P_H - F'$。
- **虚约束**：平行双导轨、对称布置、重复的同一轨迹约束 → **先删虚约束再算**，并在答案里写一句"已去除虚约束 × 处"（**这句话是给分点**）。

> **交接规则 S→M**：$n$、$P_L$ 的计数结果直接决定速度分析里"几个构件、几个未知量"。写完自由度后**立刻把构件编号表抄到第二问开头**，不许凭记忆。

#### M｜运动分析（链节，约 30 分）

**瞬心法**：绝对瞬心处 $v = 0$；构件 $i$、$j$ 的相对瞬心 $P_{ij}$ 满足

$$v_{P_{ij}} = \omega_i \cdot \overline{P_{i0}P_{ij}} = \omega_j \cdot \overline{P_{j0}P_{ij}} \;\Rightarrow\; \frac{\omega_i}{\omega_j} = \frac{\overline{P_{j0}P_{ij}}}{\overline{P_{i0}P_{ij}}}$$

（"**转速比 = 瞬心到两绝对瞬心距离的反比**"，方向由瞬心位置内外判断。）

**相对运动图解法**（同一构件两点）：

$$\vec v_C = \vec v_B + \vec v_{CB},\qquad \vec a_C = \vec a_B + \vec a_{CB}^{\,n} + \vec a_{CB}^{\,t}$$

$$a_{CB}^{\,n} = \omega_{BC}^2\, l_{BC}\ (\text{方向 } C\to B),\qquad a_{CB}^{\,t} = \varepsilon_{BC}\, l_{BC}\ (\perp BC)$$

**两构件重合点**（移动副）：

$$\vec v_{B_2} = \vec v_{B_1} + \vec v_{B_2B_1},\qquad \vec a_{B_2} = \vec a_{B_1} + \vec a_{B_2B_1}^{\,r} + \vec a_{B_2B_1}^{\,k}$$

$$\boxed{\,a^{k} = 2\omega_1 v_{B_2B_1}\,}\quad \text{方向：把 } \vec v_{B_2B_1} \text{ 沿 } \omega_1 \text{ 转 } 90^\circ$$

> **交接规则 M→M（最高频失分点）**：**只有当导路随构件一起转动时才有哥氏加速度**。导路固定（如机架上的直导轨）时 $a^k = 0$，此时 $a_{B_2} = a_{B_1} + a^r$。答题时先写一句"**导路 1 作转动，故有哥氏加速度**"或"**导路固定，故无哥氏加速度**"——这一句本身就是分。

#### C｜凸轮（链节，约 25 分）

**四种基本运动规律的冲击特性**（必背表）：

| 运动规律 | $s$ | 冲击 | 适用 |
| --- | --- | --- | --- |
| 等速 | $s = h\dfrac{\theta}{\Phi}$ | **刚性冲击**（$v$ 突变，$a\to\infty$） | 低速轻载 |
| 等加速等减速 | $s = \dfrac{2h\theta^2}{\Phi^2}$（前段） | **柔性冲击**（$a$ 有限突变） | 中速 |
| 余弦加速度（简谐） | $s = \dfrac{h}{2}\left[1-\cos\dfrac{\pi\theta}{\Phi}\right]$ | **柔性冲击** | 中高速 |
| 正弦加速度（摆线） | $s = h\left[\dfrac{\theta}{\Phi} - \dfrac{1}{2\pi}\sin\dfrac{2\pi\theta}{\Phi}\right]$ | **无冲击** | 高速 |

**反转法六步**（滚子偏置直动从动件，一步都不能跳）：

1. 取比例尺 $\mu_l$，画**基圆** $r_b$ 与**偏距圆** $e$；
2. 定从动件初始位置：导路线与偏距圆相切，滚子中心在 $B_0$（距轴心 $s_0 + r_r$ 处，$s_0=\sqrt{r_b^2-e^2}$）；
3. 沿 $\omega$ 的**反向**等分推程角 $\Phi$（一般 6~12 等分）；
4. 在每一反转位置的导路线上，从初始位置量取对应位移 $s_i$。位移从凸轮转角的 $s$—$\theta$ 线上量取后**同比例搬运**；
5. 得滚子中心一系列位置 $B_1,B_2,\dots$，光滑连接 → **理论轮廓**；
6. 以理论轮廓上各点为圆心、$r_r$ 为半径画圆族，作**内包络线** → **实际轮廓**；标注 $r_b$、$r_r$、$e$、$\Phi$、$\Phi'$。

**压力角校核**（对心直动）：

$$\tan\alpha = \frac{\dfrac{ds}{d\theta}}{s + r_b}\;\Rightarrow\; r_b \ge \frac{\dfrac{ds}{d\theta}}{\tan[\alpha]} - s$$

许用压力角：推程直动 $[\alpha]\le 30^\circ$，摆动 $\le 45^\circ$，回程可放宽至 $70^\circ\sim80^\circ$。

> **交接规则 C→C**：凸轮这一问的"转角 $\theta$"和运动分析里的"曲柄转角 $\varphi$"**必须用同一个零位**。若卷面给的零位不同，第一天就要在图上标出来，否则位移全错。

#### G｜齿轮 + 轮系（链节，约 30 分）

**标准直齿圆柱齿轮**（$\alpha=20^\circ$，$h_a^*=1$，$c^*=0.25$）：

$$d = mz,\quad d_a = m(z+2),\quad d_f = m(z-2.5),\quad p=\pi m,\quad d_b = d\cos\alpha$$

$$a = \frac{m(z_1+z_2)}{2},\qquad z_{\min} = \frac{2h_a^*}{\sin^2\alpha} = 17$$

**斜齿**：$d = \dfrac{m_n z}{\cos\beta}$，$a = \dfrac{m_n(z_1+z_2)}{2\cos\beta}$，$z_v = \dfrac{z}{\cos^3\beta}$。

**定轴轮系**：

$$i_{1n} = \frac{n_1}{n_n} = (-1)^m \frac{\prod z_{\text{从}}}{\prod z_{\text{主}}}$$

（$m$ = 外啮合对数；空间轮系用箭头判向，**不能**用 $(-1)^m$。）

**周转轮系（转化机构法）**：

$$i_{1H}^{H} = \frac{n_1 - n_H}{n_k - n_H} = \pm \frac{\prod z_{\text{从}}}{\prod z_{\text{主}}}\Big|_{\text{转化机构}}$$

> **交接规则 G→F（第二大失分点）**：符号必须在**转化机构（行星架固定）**下判，判完再代回。混合轮系先"**分基本轮系**"（找行星架 → 找太阳轮/行星轮 → 其余为定轴），分段求，再联立。

#### F｜飞轮（链尾，约 25 分）

$$M_e = \frac{1}{2\pi}\int_0^{2\pi} M\,d\varphi \quad(\text{等效驱动力矩为常数时})$$

$$\delta = \frac{\omega_{\max}-\omega_{\min}}{\omega_m},\qquad \omega_m = \frac{\omega_{\max}+\omega_{\min}}{2}$$

忽略其他构件转动惯量时：

$$W_{\max} = \Delta E_{\max} = J_F\,\omega_m^2\,\delta \;\Rightarrow\; J_F = \frac{W_{\max}}{\omega_m^2\,\delta} = \frac{900\,W_{\max}}{\pi^2 n^2 \delta}\ \ (n:\text{r/min})$$

**能量指示图**：以 $M_{ed}-M_{er}$ 的符号累加画折线，**最高点与最低点的纵差 = $W_{\max}$**（不是最大值本身！）。

**必答的两句话**（简答常考）：

- 飞轮的**调速原理**：只在 $W_{\max}$ 区间内吸收/释放动能，起"**能量仓库**"作用；
- 飞轮**不能使机器匀速运转**，只能把速度波动**限制在允许范围内**（$\delta$ 减小 → $J_F$ 增大，但结构尺寸、成本限制其上限）。

> **交接规则 F→全卷**：等效构件选谁，全部力矩/转动惯量都要折算到谁身上；折算公式 $M_e = \sum M_i \dfrac{\omega_i}{\omega}$、$J_e = \sum J_i\left(\dfrac{\omega_i}{\omega}\right)^2 + \sum m_i\left(\dfrac{v_i}{\omega}\right)^2$。**卷面务必写一句"取主轴为等效构件"**。

## 🧮 数学二 #57：冲刺定点补漏——五个"小而必考"的切口

> 今天**不做整卷**。五个切口，每个 20 分钟精讲 + 90 分钟 15 题自测。目标：**把这五类题做成"条件反射"**，考场上见到就出手。

### 切口 1｜定积分定义（黎曼和）

$$\lim_{n\to\infty}\sum_{k=1}^{n} f\!\left(a+\frac{k}{n}(b-a)\right)\frac{b-a}{n} = \int_a^b f(x)\,dx$$

最常用退化形：

$$\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^{n} f\!\left(\frac{k}{n}\right) = \int_0^1 f(x)\,dx$$

**识别口诀**：**提出 $\frac{1}{n}$，剩下凑 $\frac{k}{n}$**。若凑不出 $\frac{k}{n}$，改用夹逼。

**例**：$\displaystyle\lim_{n\to\infty}\left(\frac{1}{n+1}+\frac{1}{n+2}+\cdots+\frac{1}{n+n}\right)$

$$\text{原式}=\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^{n}\frac{1}{1+\frac{k}{n}}=\int_0^1\frac{dx}{1+x}=\ln 2$$

**⚠️ 三个坑**：① 项数必须是 $n$（不是 $n$ 项时先补/减）；② 因子 $\frac{1}{n}$ 必须**恰好**提出，别把 $\frac{1}{n^2+k}$ 硬凑；③ 乘积型（$\prod$）先取对数化成 $\sum\ln$。

### 切口 2｜参数方程 / 隐函数的二阶导

**参数方程**：

$$\frac{dy}{dx}=\frac{y'(t)}{x'(t)},\qquad \boxed{\frac{d^2y}{dx^2}=\frac{1}{x'(t)}\cdot\frac{d}{dt}\left(\frac{y'(t)}{x'(t)}\right)}$$

**⚠️ 最高频错误**：算出 $\dfrac{d}{dt}\left(\dfrac{y'}{x'}\right)$ 就直接当答案，**忘了再除一次 $x'(t)$**。

**例**：$x=a(\cos t+t\sin t)$，$y=a(\sin t-t\cos t)$

$$x'=at\cos t,\quad y'=at\sin t\ \Rightarrow\ \frac{dy}{dx}=\tan t$$
$$\frac{d^2y}{dx^2}=\frac{1}{at\cos t}\cdot\sec^2 t=\frac{1}{at\cos^3 t}$$

**隐函数**：$F(x,y)=0$，$y'=-\dfrac{F_x}{F_y}$；二阶导**直接对一阶导方程再求导**（把 $y$ 当 $x$ 的函数，$y'$ 已知代入），比背公式稳：

$$y''=-\frac{F_{xx}F_y^2-2F_{xy}F_xF_y+F_{yy}F_x^2}{F_y^3}$$

**例**：$e^y+xy=e$，在 $x=0$ 处。由原式 $y=1$；求导 $e^yy'+y+xy'=0\Rightarrow y'=-\dfrac{y}{e^y+x}$，故 $y'(0)=-\dfrac1e$。再求导：$e^y(y')^2+e^yy''+2y'+xy''=0$，代入得 $ey''=\dfrac1e$，即 $y''(0)=\dfrac{1}{e^2}$。

### 切口 3｜反常积分判敛

**基准尺**（必须背到条件反射）：

$$\int_1^{+\infty}\frac{dx}{x^p}\ \text{收敛}\iff p>1;\qquad \int_0^{1}\frac{dx}{x^p}\ \text{收敛}\iff p<1$$

$$\int_2^{+\infty}\frac{dx}{x\ln^p x}\ \text{收敛}\iff p>1;\qquad \int_0^{+\infty}\frac{\sin x}{x^p}dx\ \text{收敛}\ (p>0),\ \text{绝对收敛}\ (p>1)$$

**比较判别法（极限形式）**：若 $\lim\limits_{x\to\infty}\dfrac{f(x)}{g(x)}=c\in(0,+\infty)$，则 $\int f$ 与 $\int g$ 同敛散。

**综合判据**（$x\to+\infty$ 与 $x\to0^+$ 分段看）：

$$\int_0^{+\infty}\frac{x^{a}}{1+x^{b}}dx\ \text{收敛}\iff a>-1\ \text{且}\ a<b-1$$

**⚠️ 三个坑**：① 瑕点可能在**内部**（如 $\int_0^2\frac{dx}{x-1}$），必须拆成两段分别判，**一段发散即整体发散**；② 等价无穷小替换只判阶，**别用来算值**；③ 收敛 ≠ 能求出原函数（$\int_0^\infty\frac{\sin x}{x}dx$ 收敛但非初等）。

### 切口 4｜二元函数可微性判定

**定义式**（唯一判据）：

$$f\ \text{在}\ (x_0,y_0)\ \text{可微}\iff \Delta z = f_x\Delta x+f_y\Delta y+o(\rho),\quad \rho=\sqrt{\Delta x^2+\Delta y^2}$$

**操作三步**：① 求 $f_x,f_y$（分段点用定义）；② 写出差式 $f(x_0+\Delta x,y_0+\Delta y)-f(x_0,y_0)-f_x\Delta x-f_y\Delta y$；③ 除以 $\rho$，令 $\rho\to0$，看是否 $=0$。

**例 1（不可微）**：$f=\dfrac{x^2y}{x^2+y^2}\ (x,y)\ne(0,0)$，$f(0,0)=0$。$f_x(0,0)=f_y(0,0)=0$。取 $y=x$：

$$\frac{f(x,x)-0}{\sqrt{2}\,|x|}=\frac{x^3}{2x^2\cdot\sqrt2|x|}=\frac{1}{2\sqrt2}\not\to 0\ \Rightarrow\ \textbf{不可微}$$

**例 2（可微）**：$f=\dfrac{xy}{\sqrt{x^2+y^2}}$，$f(0,0)=0$，$f_x=f_y=0$，

$$\left|\frac{f(x,y)}{\rho}\right|=\frac{|xy|}{x^2+y^2}\le\frac12\to 0\ \Rightarrow\ \textbf{可微}$$

**⚠️ 逻辑链必背**：偏导连续 $\Rightarrow$ 可微 $\Rightarrow$（连续 + 偏导存在）。**逆向全不成立**。做题时先看"偏导是否连续"，能证连续就别碰定义。

### 切口 5｜一阶线性「换位」与伯努利

**标准形**：$y'+P(x)y=Q(x)$，

$$y=e^{-\int P\,dx}\left(\int Q\,e^{\int P\,dx}dx+C\right)$$

**换位思想**：当方程对 $y$ 非线性、但对 $x$ 是线性时，**把 $x$ 看成 $y$ 的函数**：$\dfrac{dx}{dy}+P(y)\,x=Q(y)$。

**例**：$y'=\dfrac{1}{x+y}$。取倒数：$\dfrac{dx}{dy}=x+y$，即

$$x'-x=y\ \Rightarrow\ x=e^{y}\left(\int y e^{-y}dy+C\right)=Ce^{y}-(y+1)$$

**伯努利**：$y'+Py=Qy^{n}\ (n\ne0,1)$，令 $z=y^{1-n}$，化为

$$z'+(1-n)Pz=(1-n)Q$$

**⚠️ 三个坑**：① 换位后**积分因子是关于 $y$ 的**，别混用；② 换位前先确认 $y'\ne0$（分母不为零的区间）；③ 伯努利换元后**别忘了回代**，且 $n>0$ 时 $y=0$ 往往是丢掉的解。
