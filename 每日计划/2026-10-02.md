### 3. 机械原理 ①（07:30–09:20，1:50）——瞬心法：定义、数目、三心定理、比例式

**（1）瞬心的定义与分类**

- 瞬心：两构件上**瞬时绝对速度相同的重合点**（等速重合点）。
- 绝对瞬心：两构件之一为机架时，该点绝对速度为零；
- 相对瞬心：两构件都在动，该点绝对速度不为零但彼此相等。

**（2）瞬心数目**

$$N=\frac{k(k-1)}{2}\qquad (k\ \text{为构件总数，含机架})$$

四杆机构 $k=4 \Rightarrow N=6$；曲柄滑块 $k=4 \Rightarrow N=6$。

**（3）直接观察可定的瞬心（必背四种）**

| 两构件联接方式 | 瞬心位置 |
| --- | --- |
| 转动副 | 转动副中心 |
| 移动副 | 垂直于导路方向的**无穷远处** |
| 纯滚动高副 | 高副接触点 |
| 滑动兼滚动高副 | 过接触点的**公法线**上 |

**（4）三心定理**

> 三个彼此作平面平行运动的构件，共有三个瞬心，且**必位于同一条直线上**。

用法：$P_{13}$ 与 $P_{14}$、$P_{34}$ 共线，又与 $P_{12}$、$P_{23}$ 共线 → 两条直线的交点即为 $P_{13}$。若两线平行或重合，说明该瞬心在无穷远（典型：两构件均为滑块）。

**（5）瞬心法求角速度的核心比例式**

$$\frac{\omega_i}{\omega_j}=\frac{\overline{P_{j1}P_{ij}}}{\overline{P_{i1}P_{ij}}}$$

即：**两构件角速度之比，等于机架到该瞬心的两段距离的反比**（"距离短的一侧转得快"）。

**（6）两法联用流程（第 07 讲精髓，直接照抄成模板）**

1. 画机构运动简图，定比例尺 $\mu_l$，给构件编号 1、2、3、4；
2. 列出全部 $N$ 个瞬心；先写直接观察的，再用三心定理补间接的；
3. **瞬心法**：快速求出各构件角速度与关键点速度（方向靠"距离反比 + 转向判断"）；
4. **图解法速度多边形**：$\vec{v}_C=\vec{v}_B+\vec{v}_{CB}$，用 $\mu_v$ 量取，与第 3 步互相校核；
5. **加速度分析**：矢量方程 + 法向/切向分解 + 科氏项（昨天 #06 的内容）；
6. 收尾检查：方向是否自洽、单位是否统一、有无漏件。

**（7）⚠️ 三个致命易错点**

- 把**相对瞬心**当**绝对瞬心**用（前者速度不为零，不能直接当转心求速度）；
- 三心定理用错对象（必须是"同一个三构件组"的三个瞬心才共线）；
- 瞬心落在构件延长线之外就怀疑自己——那是对的，瞬心本来就可以在实体之外，甚至无穷远。

### 4. 机械原理 ②（09:40–11:20，1:40）——两道必做综合题（务必动圆规）

**例 1：铰链四杆机构（瞬心法求 $\omega_2$、$\omega_3$ 与 $v_C$）**

已知 $l_{AB}=30$ mm，$l_{BC}=80$ mm，$l_{CD}=60$ mm，$l_{AD}=90$ mm，$\omega_1=10\ \text{rad/s}$（顺时针）。

- 定瞬心：$P_{14}=A$、$P_{12}=B$、$P_{23}=C$、$P_{34}=D$；
- $P_{13}$：与 $A$、$D$ 共线（在直线 $AD$ 上），又与 $B$、$C$ 共线（在直线 $BC$ 上）→ **直线 $AD$ 与直线 $BC$ 的交点**；
- $P_{24}$：与 $B$、$A$ 共线（在 $AB$ 上），又与 $C$、$D$ 共线（在 $CD$ 上）→ **直线 $AB$ 与直线 $CD$ 的交点**；
- 求角速度：

$$\frac{\omega_3}{\omega_1}=\frac{\overline{AP_{13}}}{\overline{DP_{13}}},\qquad \frac{\omega_2}{\omega_1}=\frac{\overline{AB}}{\overline{P_{24}B}}$$

- 求速度：$v_C=\omega_3\,l_{CD}$；再用构件 2 校核：$v_C=\omega_2\,\overline{P_{24}C}$，两值应相等；
- 方向：由 $\omega_1$ 定 $\vec{v}_B$ 方向 → 定 $\omega_2$ 方向 → 定 $\vec{v}_C$、$\omega_3$ 方向。
- 🗝️ 线段长度一律**按比例尺作图量取**（考场上没有计算器，这正是作图题的得分点）。

**例 2：对心曲柄滑块机构（瞬心法速求滑块速度）**

- $P_{13}$：与 $B$、$C$ 共线（在直线 $BC$ 上）；又因滑块与机架为移动副，$P_{34}$ 在垂直于导路的无穷远，故 $P_{13}$ 在**过 $A$ 且垂直于导路的直线**上 → 交点即为 $P_{13}$；
- 结论式子极简：

$$v_C=\omega_1\cdot\overline{AP_{13}}$$

- 再与图解法结果对照：$\vec{v}_C=\vec{v}_B+\vec{v}_{CB}$，两条路走到同一个答案，说明你的瞬心没找错。

### 6. 数学二 ①（13:20–14:50，1:30）——平面图形的面积

**（1）直角坐标**

$$A=\int_a^b\big|f(x)-g(x)\big|\,dx$$

- 三步走：**先解交点定上下限 → 再判上下关系 → 最后带绝对值分段**；
- 上下关系在区间内可能变，一定要用交点切段。

**（2）参数方程**（$x=\varphi(t),\ y=\psi(t)$，$x$ 在区间上单调）

$$A=\int_{\alpha}^{\beta}\psi(t)\,\varphi'(t)\,dt\qquad(\text{注意 } \varphi'(t) \text{ 的符号，必要时加绝对值})$$

**（3）极坐标**

$$A=\frac12\int_{\alpha}^{\beta}\rho^2(\theta)\,d\theta,\qquad \text{两曲线之间： } A=\frac12\int_{\alpha}^{\beta}\big(\rho_2^2-\rho_1^2\big)\,d\theta$$

- ⚠️ 常见丢分：忘记系数 $\frac12$、忘记 $\rho$ 要平方、角度上下限取错（要画图找射线扫过的范围）。

**（4）经典例题**

- 心形线 $\rho=a(1+\cos\theta)$ 所围面积：

$$A=\frac12\int_0^{2\pi}a^2(1+\cos\theta)^2d\theta=\frac{a^2}{2}\Big(2\pi+0+\pi\Big)=\frac{3\pi a^2}{2}$$

- $y=\ln x$ 与 $y=0$、$x=e$ 围成图形的面积：

$$A=\int_1^e\ln x\,dx=\big[x\ln x-x\big]_1^e=1$$

### 7. 数学二 ②（15:10–16:40，1:30）——旋转体体积与弧长

**（1）旋转体体积（三种情形，先判"绕谁转"）**

- 绕 $x$ 轴（圆盘法）：

$$V_x=\pi\int_a^b f^2(x)\,dx$$

- 绕 $y$ 轴（柱壳法，最常用）：

$$V_y=2\pi\int_a^b x\,|f(x)|\,dx$$

- 两曲线之间绕 $x$ 轴：$V=\pi\displaystyle\int_a^b\big(f^2-g^2\big)dx$；
- 绕直线 $x=k$：$V=2\pi\displaystyle\int_a^b|x-k|\,|f(x)-g(x)|\,dx$；
- 绕 $y$ 轴改用圆环法时，必须把 $x$ 解成 $y$ 的函数并**分段**：$V=\pi\displaystyle\int_c^d\big(x_2^2(y)-x_1^2(y)\big)dy$；
- 参数方程：$V_x=\pi\displaystyle\int_{\alpha}^{\beta}\psi^2(t)\,|\varphi'(t)|\,dt$。

**（2）平面曲线的弧长**

$$s=\int_a^b\sqrt{1+y'^2}\,dx\quad(\text{直角坐标})$$
$$s=\int_{\alpha}^{\beta}\sqrt{\varphi'^2(t)+\psi'^2(t)}\,dt\quad(\text{参数})$$
$$s=\int_{\alpha}^{\beta}\sqrt{\rho^2+\rho'^2}\,d\theta\quad(\text{极坐标})$$

**（3）旋转体侧面积**（数二大纲收录，别和体积混）

$$S=2\pi\int_a^b|y|\sqrt{1+y'^2}\,dx$$

⚠️ 记忆锚点：**侧面积 = 周长 $\times$ 弧长微元**，所以带 $\sqrt{1+y'^2}$；**体积不带根号**。

**（4）经典例题**

- 摆线一拱 $x=a(t-\sin t),\ y=a(1-\cos t),\ t\in[0,2\pi]$ 的弧长：

$$s=\int_0^{2\pi}a\sqrt{2-2\cos t}\,dt=\int_0^{2\pi}2a\left|\sin\frac t2\right|dt=8a$$

- $y=\ln x$ 与 $y=0$、$x=e$ 围成图形绕 $x$ 轴与 $y$ 轴：

$$V_x=\pi\int_1^e\ln^2x\,dx=\pi(e-2),\qquad V_y=2\pi\int_1^e x\ln x\,dx=\frac{\pi(e^2+1)}{2}$$

- 练习（自己算）：$y=x^2$ 与 $y=x$ 围成图形绕 $y$ 轴的体积，答案 $\dfrac{\pi}{6}$。
