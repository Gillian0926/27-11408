# ✍️ 英语作文技巧 03 · 高分句型与替换词

> 同水平作文，用词和句式的"高级感"决定 3-5 分差距。**替换词表 + 句型库，直接套用。**

## 🔄 高频替换词表（低级 → 高级）

| 低级 | 高级 | 场景 |
|---|---|---|
| important | crucial / vital / of great significance | 万能 |
| many | numerous / a multitude of | 数量 |
| more and more | increasingly | 趋势 |
| think | hold the view that / maintain | 观点 |
| good | beneficial / favorable | 好处 |
| bad | detrimental / harmful | 坏处 |
| people | individuals / citizens | 人 |
| very | remarkably / exceedingly | 程度 |
| solve | address / tackle / resolve | 解决问题 |
| show | demonstrate / illustrate / reveal | 展示 |
| because | in that / owing to / due to the fact that | 原因 |
| but | nevertheless / whereas | 转折 |

## 📝 高分句型库

### 开头（描述/引出）
- As is vividly depicted in the picture, ...
- It is universally acknowledged that ...
- With the rapid development of ..., ...

### 中间（分析/论证）
- There is no denying that ...
- This phenomenon can be attributed to the following factors.
- What's more, ... ; Furthermore, ...
- A case in point is ...
- 强调句：It is ... that ...（例：It is persistence that leads to success.）
- 倒装：Only by doing ... can we ... / Not only ... but also ...

### 结尾（总结/建议）
- In conclusion, / To sum up, ...
- It is advisable that we should ...
- Only in this way can we ...

## 🎯 连接词串联（让段落流畅）

- 递进：furthermore / moreover / in addition / what's more
- 转折：however / nevertheless / whereas / on the contrary
- 因果：therefore / consequently / as a result / thus
- 举例：for instance / for example / a case in point is
- 总结：in conclusion / to sum up / in a nutshell

## ⚠️ 使用提醒
1. **高级词 ≠ 堆砌**：每段用 2-3 个就够，用错词性反而扣分
2. 句式要**长短结合**：全用长句显得刻意，一句长一句短最自然
3. 背熟 10 个句型 + 20 个替换词，作文就够用了
