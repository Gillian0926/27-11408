> **题源**：考研作文素材库 · 科技主题（15 大主题轮换，今日 **#14/15 —— 第 3 轮第 14 站**；上一站 #13 态度抉择 🧭，下一站 #15 环境 🌿 · **第 3 轮收官**）
> 素材库文件：《英语二/素材库/01-作文素材句库.md》
> **主题词速记**：science and technology / technological advances / digital life / artificial intelligence / a double-edged sword / the man-machine relationship（写"科技"时轮着用，避免通篇只出现 `technology is very important`）
> **今日辨析主线**：三句话都在给科技"定性"，但**表态所占的句法位置完全不同**——
> ① `Technology **is** a useful servant **but** a dangerous master.`：**表语位置的双重定性**，一个 `be` 动词后面挂两个并列表语名词短语，靠 `but` 完成转折，靠**隐喻**完成评价；
> ② `The real problem **is not** whether machines think **but** whether men do.`：**表语从句位置的真问题平移**，`not ... but ...` 连接两个 `whether` 从句，把讨论从"机器"挪到"人"；
> ③ `Any sufficiently advanced technology **is indistinguishable from** magic.`：**形容词补语＋比较对象**，用"辨不出区别"代替"很先进"这种空泛评价。
> 一天之内钉死这三种"给事物定性"的路子，作文里就不必再靠 `Technology is very important. It has two sides.` 打天下。
> **附加结构钉子**：并列句省`be`要**两边都对得上**（`is a useful servant but (is) a dangerous master`，✗ `is a useful servant but a dangerous master is`）；`not ... but ...` **两侧必须同类**（从句配从句，✗ 从句配名词）；表语从句**只能用 `whether`，不能用 `if`**；`indistinguishable` 后**固定接 `from`**（✗ `with` / ✗ `to`）；`any + 单数可数名词`表"任何"，谓语用**单数**。

## ⭐ 主句（精读精析）

> **"Technology is a useful servant but a dangerous master."**

**出处**：素材库 · 科技 🤖 主题（写"科技利弊 / 人机关系"图画作文，可直接作中心论点句，尤其适合图画下方的"寓意句"）

**翻译**：技术是一个好用的仆人，却是一个危险的主人。

**结构拆解**：

- **骨架可先化简为一条公式**：

  $$\underbrace{\text{Technology}}_{\text{主语}}\;+\;\underbrace{\text{is}}_{\text{系动词}}\;+\;\underbrace{\text{a useful servant}}_{\text{表语 1}}\;+\;\underbrace{\text{but}}_{\text{转折连词}}\;+\;\underbrace{(\text{is})\ \text{a dangerous master}}_{\text{表语 2 · 省略 is}}$$

  整句是**"一主二表"的并列结构**：一个主语 `Technology`，一个系动词 `is`，两个表语名词短语；第二个表语前的 `is` 被**省略**（英语并列谓语中重复的助动词 / 系动词通常删去）。这是全句唯一的语法难点，也是它读起来"格言感"强的来源——短、对称、无废字。

- **省略的判定方法（考场防错）**：
  - 还原后必须语法完整：`Technology is a useful servant, but (it is) a dangerous master.` ✅
  - 不能把 `but` 当成连接两个名词的并列连词（那样 `Technology is a useful servant` 就没了着落）：✗ `Technology is a useful servant but a dangerous master are ...`
  - 判断口诀：**`but` 后面如果只剩名词短语、没有自己的主语和谓语，就一定是"承前省略主谓"**，翻译时把 `is` 补回来即可。

- **表语名词短语的冠词**：`a useful servant` / `a dangerous master` 都用**不定冠词 `a`**，表示"一种身份 / 一类角色"，而非特指某一个仆人。若换成 `the` 就变成特指，格言味立刻消失。写成 `a useful servant but a dangerous master` 时，两处 `a` **都要保留**，不能省第二处。

- **真正的力量在隐喻，不在语法**：`servant`（仆人）与 `master`（主人）构成**同一语义场内的角色对调**——同一个东西，你用它，它是仆；它用你，你是仆。`useful`（有用）与 `dangerous`（危险）则构成**价值判断的两极**。四个词两两对称，句子短到能背、又深到能论证，这是英语论说文"金句"的标准配置：**A is B but C，B 与 C 同域反义**。

- **可迁移的等价改写（考场保底）**：
  - `Technology is a good servant but a bad master.`（更短的谚语版，考场上够用）
  - `Technology is a double-edged sword: it serves those who master it and masters those who serve it.`（把隐喻展开成 `serve / master` 的动词对照，句子变长但论证更足）
  - `What matters is not technology itself but whether we remain its master rather than its servant.`（顺手复习 `not ... but ...` 与 `rather than`，把今天的句子接入已有句式网络）
  - `Technology should be a tool at our command, not a force beyond our control.`（把隐喻换成 `tool / force`，更贴近"人工智能"话题）

- **语用价值**：本句**不下命令、不做说教**，而是用一句"身份判断"把科技的双面性一次讲完，天然适合做图画作文的**第二段论点句**或**第三段收束句**。它比 `Technology has both advantages and disadvantages.` 高明之处在于：后者只陈述"有两面"，前者直接**给出了评价与立场**——这正是英语二作文"有观点"的评分点。

**词汇点**：

- `technology`（n. 技术；科技）：`technological`（adj. 技术的，✗ `technologic`）、`technological advances / innovation`（技术进步 / 创新）、`information technology (IT)`、`technologically advanced`（技术先进的）。**可数性**：泛指"技术"整体时**不可数**（`the impact of technology`）；指"某项具体技术"时可数（`new technologies`）。
- `servant`（n. 仆人；有用的工具）：`serve`（v. 服务；起作用）、`service`（n.）、`a public servant`（公仆）。`servant` 的引申义正是本句用法——"为人所用之物"。
- `master`（n. 主人；大师；v. 掌握）：`master a language / a skill`（掌握）、`mastery`（n. 精通）、`be one's own master`（自己做主）。**注意 `master` 与 `servant` 是一对固定反义角色词**，作文里可整对搬用。
- `useful` / `dangerous`：`be useful to sb.`（对某人有用）、`be useful for doing sth.`；`dangerous` 后接 `to`（`dangerous to health`），名词形式 `danger`、`endanger`（v. 危及）。
- 高频搭配：`a double-edged sword`（双刃剑）、`at our command`（受我们支配）、`beyond our control`（失控）、`serve the purpose of`（起到……的作用）。

**仿写/迁移**：

- `Money is a good servant but a bad master.`（把主语换成 `Money`，一句顶十句的"金钱观"金句，可直接用于"消费 / 物质"类图画）
- `Smartphones are convenient tools but demanding masters.`（迁移到"数字化生活"，`convenient / demanding` 换成形容词对照）
- `Technology is a useful servant but a dangerous master, and it is we who decide which role it plays.`（后面追加定语从句＋强调句，把"责任在人"点出来，适合做结尾句）

## ➕ 补充句 1（真问题平移：`not ... but ...` 连两个从句）

> **"The real problem is not whether machines think but whether men do."**

**出处**：素材库 · 科技 🤖 主题（用于"人工智能是否会取代人"类话题，作论证转折句）

**翻译**：真正的问题不在于机器是否会思考，而在于人是否还在思考。

**结构拆解**：

- 骨架：`The real problem`（主语） + `is`（系动词） + `not [whether 从句] but [whether 从句]`（**两个并列表语从句**）。
  $$\text{The real problem}\ +\ \text{is}\ +\ \underbrace{\text{not}\ [\text{whether machines think}]}_{\text{表语从句 1}}\ +\ \underbrace{\text{but}\ [\text{whether men do}]}_{\text{表语从句 2}}$$
- **`not ... but ...` 的两侧必须同类**：这里左边是 `whether` 从句，右边也必须是 `whether` 从句。✗ `is not whether machines think but the thinking of men`（从句配名词，不平衡）。
- **表语从句只能用 `whether`，不能用 `if`**：`The question is whether ...` ✅ / `The question is if ...` ✗。这是考场高频错点，凡是"问题是是否……"一律用 `whether`。
- **句末的 `do` 是代动词（pro-verb）**，替代前面的 `think`：`whether men do = whether men think`。它的作用是**避免重复、制造落差**——前半句郑重地说 `think`，后半句一个轻飘飘的 `do` 收尾，反差本身就是修辞。同理可替代 `say / know / hope` 等实义动词（`— Do you think it will work? — I hope so. I do.`）。
- **`machines` 与 `men` 的对照**：`men` 在此泛指"人 / 人类"（传统用法，现代英语更常写 `humans / people`）。考场上建议写 `humans`，避免性别争议，句子照样成立：`whether humans do`。
- **翻译处理**：`do` 不能直译成"做"，要**还原被替代的动词**——"人是否（还）思考"。

**词汇点**：

- `real`（adj. 真正的）：`the real problem / the real issue` 比 `the important problem` 更有"戳破表象"的力量；`really`（adv.）、`reality`（n.）、`in reality`（事实上）。
- `machine`（n. 机器）：`machinery`（n. 机械的总称，不可数）、`machine learning`（机器学习）、`by machine`（用机器）。
- 代动词 `do`：`do so`（这样做）、`do the same`（照做）；注意它只替代**实义动词**，不能替代 `be` 动词（替代 `be` 用 `be` 或 `so`）。
- 高频框架：`The real problem / question / issue is not A but B.` —— 作文里"递进一层"的万能句式。

**仿写/迁移**：

- `The real question is not whether technology changes our lives but whether we change with it.`（迁移"科技与个人成长"）
- `The real problem is not whether we have time but whether we use it.`（迁移"珍惜时间 ⏰"）
- `What troubles me is not whether we can afford it but whether we still want it.`（`What` 主语从句替换 `The real problem`，复习 10-16 的双 `what` 嵌套）

## ➕ 补充句 2（形容词补语＋比较对象：`indistinguishable from`）

> **"Any sufficiently advanced technology is indistinguishable from magic."**

**出处**：素材库 · 科技 🤖 主题（用于"科技发展速度 / 人工智能惊人进步"类话题，作画面描述后的评价句）

**翻译**：任何足够先进的科技，都与魔法无异。

**结构拆解**：

- 骨架：`Any [sufficiently advanced] technology`（主语，含**前置定语＋后置形容词短语**） + `is`（系动词） + `indistinguishable from magic`（**形容词短语作表语，带 `from` 引出比较对象**）。
  $$\underbrace{\text{Any}\ +\ \text{sufficiently advanced}\ +\ \text{technology}}_{\text{主语}}\ +\ \underbrace{\text{is indistinguishable from}}_{\text{系表结构}}\ +\ \underbrace{\text{magic}}_{\text{比较对象}}$$
- **`any + 单数可数名词`表"任何一类中的任何一个"**，谓语用**单数**：`Any ... technology **is** ...`，✗ `are`。对比：`any technologies`（任何多项技术）也可，但本句取"任何一项足够先进的技术"，故用单数。
- **`sufficiently` 是程度副词，修饰形容词 `advanced`**，不能修饰名词：✗ `sufficient advanced technology`。`sufficient`（adj. 充足的）修饰名词，`sufficiently`（adv.）修饰形容词/副词，两个词形分工要清。
- **`indistinguishable from X`**：`in-`（否定前缀） + `distinguish`（区分） + `-able`（可……的）＝"无法与 X 区分开的"。介词**固定为 `from`**：`distinguish A from B`（把 A 与 B 区分开）→ `A is indistinguishable from B`（A 与 B 分不清）。
- **为什么这句比 `Technology is very advanced.` 强**：它**不直接评价"先进"，而是描写"先进到何种程度"**——先进到与魔法无异。写作中这叫"以效果代评价"，是全篇最容易提分的一招：不说 `very important / very fast`，而说它到了什么地步。

**词汇点**：

- `distinguish`（v. 区分；辨别）：`distinguish A from B` / `distinguish between A and B`、`distinguish oneself`（使自己出众）、`distinguished`（adj. 杰出的）、`distinguishable`（可分辨的）、`indistinguishable`（无法分辨的）。
- `sufficient`（adj. 足够的）／`sufficiently`（adv.）：`be sufficient for`、`sufficient evidence`；同义 `enough`（位置灵活：`enough money` / `good enough`）。
- `advanced`（adj. 先进的；高级的）：`advanced technology / countries / levels`；动词原形 `advance`（v./n. 前进、进步），`advances in ...`（在……方面的进步）。
- `magic`（n. 魔法；魅力）：`as if by magic`（像变魔术一样）、`magical`（adj.）、`work like magic`（效果奇佳）。

**仿写/迁移**：

- `Any sufficiently advanced artificial intelligence is indistinguishable from a human mind.`（迁移"人工智能"）
- `Any sufficiently long separation is indistinguishable from forgetting.`（迁移"友情 / 亲情"话题，句式不动、主题词换掉即可）
- `So rapidly does technology develop that what was magic a decade ago is now routine.`（倒装＋`so ... that ...`，把"速度"写出来，适合做段落收尾）

## 🧩 三句同框 · 结构对比速览

| 句子 | 表态落在哪个位置 | 核心手段 | 最该背的一个点 |
|---|---|---|---|
| 主句 `Technology is a useful servant but a dangerous master.` | **表语**（两个并列名词短语） | 隐喻＋对称＋省略 `is` | `A is B but C`，B、C 同域反义 |
| 补充 1 `The real problem is not whether ... but whether ...` | **表语从句**（两个 `whether` 从句） | `not ... but ...` 平移焦点 | 表语从句只用 `whether`，✗ `if` |
| 补充 2 `Any ... technology is indistinguishable from magic.` | **形容词补语＋比较对象** | 以效果代评价 | `indistinguishable **from**`，介词固定 |

**共同点**：三句都**没有一句在喊口号**，全靠"判断句"完成立场表达。这正是英语二作文与中式作文最大的差别——**陈述事实比发出号召更高级**。

## 🧠 记忆任务（今日打卡）

**① 三遍朗读（5 分钟）**
- 第 1 遍：慢读，读到 `but` 处停顿，心里补出省略的 `is`。
- 第 2 遍：中速，注意 `not ... but ...` 的**重音落在 `but` 后面的从句**上。
- 第 3 遍：快读成句，三句一口气念完，练"格言节奏"。

**② 默写填空（合上原文，10 分钟）**

1. Technology is a useful servant ______ a dangerous master.
2. The real problem is ______ whether machines think but ______ men do.
3. Any sufficiently ______ technology is indistinguishable ______ magic.
4. 改错：`The question is if we can live without our phones.` → ______
5. 改错：`Any sufficiently advanced technologies is indistinguishable with magic.` → ______

> **答案**：1. `but`（后省略 `is`）；2. `not` / `whether`；3. `advanced` / `from`；4. `if` → `whether`（表语从句）；5. `technologies is` 主谓不一致（应为 `technology is` 或 `technologies are`），且 `with` → `from`。

**③ 仿写迁移（15 分钟，写在自己的本子上）**
- 用 `A is B but C` 写 1 句，主题自选（金钱 / 手机 / 网络 / 竞争）。
- 用 `The real problem is not ... but ...` 写 1 句，主题选"学习"或"时间"。
- 用 `indistinguishable from` 写 1 句，主题选"人工智能"或"习惯"。

**④ 输出检验（口语 3 分钟）**
不看笔记，用今天三句中的**任意两句**，口头说一段 40 秒的"科技利弊"小段落，要求出现至少一次 `but` 转折、一次 `not ... but ...`。
