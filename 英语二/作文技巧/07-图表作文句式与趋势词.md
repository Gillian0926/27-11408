# ✍️ 英语作文技巧 07 · 图表作文句式与趋势词（速查）

## 一、趋势动词（升 / 降）

| 类型 | 动词 | 名词形式 |
| --- | --- | --- |
| 上升 | rise / increase / grow / climb / go up | a rise / an increase / a growth |
| 下降 | fall / decline / drop / decrease / go down | a fall / a decline / a drop |
| 持平 | remain stable / level off / stay steady | —— |
| 波动 | fluctuate | fluctuation |
| 达到峰值 | peak / reach a peak (at) | a peak |
| 触底 | bottom out / hit a low (of) | a low |

## 二、程度副词（修饰变化快慢）

- 大幅：**sharply / dramatically / significantly / considerably / markedly**
- 小幅：**slightly / marginally / modestly / steadily**
- 缓慢平稳：**gradually / steadily / slowly**
- 翻倍 / 减半：**double / triple**；**halve**；**increase by 20%**（增了）/ **increase to 20%**（增到）

## 三、描述占比 / 对比

- **account for / make up / constitute + 百分数**（占…）
- **The proportion / percentage of X is twice as high as that of Y.**
- **Compared with A, B is far larger / much smaller.**
- **A ranks first, followed by B and C.**
- **While X rose sharply, Y remained almost unchanged.**（对比句）

## 四、图表开头句型（第一段）

- As is vividly illustrated in the **bar chart**, ...
- The **pie chart** clearly reveals the **proportion** of ...
- As can be seen from the **table**, there was a **sharp rise** in ____ from ____ to ____.
- The **line graph** shows how ____ changed over the period from 20xx to 20xx.

## 五、分析原因句型（第二段）

- This **noticeable trend / striking contrast** can be attributed to several factors.
- **To begin with / First of all**, ...
- **Moreover / In addition / What's more**, ...
- **A case in point is that** ... / **Take ____ as an example** ...
- The **root cause** lies in ... / This is largely **due to** ...

## 六、结论 / 预测句型（第三段）

- **From the data above, we can draw the conclusion that** ...
- **It can be predicted that** ____ will ____ in the years to come.
- **Accordingly, it is advisable for us to** ... / **Measures should be taken to** ...
- **Only in this way can we** ____.
- **There is every reason to believe that** ...

## 七、四种图表一眼识别

| 图表 | 关键信息 | 描述重点 |
| --- | --- | --- |
| 柱状图 bar chart | 不同类别/年份的数量 | 高低对比 + 变化 |
| 饼图 pie chart | 各部分占比 | 最大/最小占比 + 排序 |
| 折线图 line graph | 随时间的变化 | 上升/下降/波动/峰值 |
| 表格 table | 多维数据 | 挑最突出的行/列对比 |

> 🎯 背熟 10 个趋势动词 + 3 个开头句 + 3 个结尾句，图表作文就能稳拿 11-13 分。
