## 📌 一、内积 · 范数 · 正交（速查）

| 概念 | 公式 / 结论 |
|---|---|
| 内积 | $(\alpha,\beta)=\alpha^{T}\beta=\sum a_ib_i$ |
| 长度（范数） | $\|\alpha\|=\sqrt{(\alpha,\alpha)}$；$\|k\alpha\|=|k|\,\|\alpha\|$ |
| 距离 | $\|\alpha-\beta\|$ |
| 正交 | $(\alpha,\beta)=0\Leftrightarrow\alpha\perp\beta$ |
| 夹角 | $\cos\theta=\dfrac{(\alpha,\beta)}{\|\alpha\|\|\beta\|}$ |

> **核心结论**：**正交（非零）向量组必线性无关**；$n$ 维空间里 $n$ 个标准正交向量 = **标准正交基**。

## 📌 二、施密特正交化（步骤速查）

对线性无关组 $\alpha_1,\dots,\alpha_s$：
$$\beta_1=\alpha_1;\quad \beta_k=\alpha_k-\sum_{i=1}^{k-1}\frac{(\alpha_k,\beta_i)}{(\beta_i,\beta_i)}\beta_i\ (k=2,\dots,s).$$
再**单位化**：$\gamma_i=\dfrac{\beta_i}{\|\beta_i\|}$。

> **口算提醒**：$\dfrac{(\alpha_k,\beta_i)}{(\beta_i,\beta_i)}$ 是"**投影系数**"——分子是内积（标量），分母是 $\beta_i$ 的长度的平方，**别写反、别漏平方**。

## 📌 三、正交矩阵性质一览

| 性质 | 内容 |
|---|---|
| 定义 | $Q^{T}Q=E\Leftrightarrow Q^{-1}=Q^{T}$ |
| 行列式 | $\|Q\|=\pm1$ |
| 列 / 行向量 | 都是**标准正交组**（两两正交且单位） |
| 运算封闭 | 逆、转置、乘积仍正交 |
| 保度量 | $\|Qx\|=\|x\|,\ (Qx,Qy)=(x,y)$（长度与内积不变） |
| 特征值 | 实特征值 $\pm1$；复特征值 $\|\lambda\|=1$ |

## 📌 四、实对称矩阵正交对角化（模板）

**定理**：$A^{T}=A\Rightarrow$ 存在正交阵 $Q$，使 $Q^{T}AQ=\operatorname{diag}(\lambda_1,\dots,\lambda_n)$（**既相似又合同**）。

**四步模板**：
1. $|\lambda E-A|=0$ 求全部特征值；
2. 各特征值解 $(\lambda E-A)x=0$ 求基础解系；
3. **同重根内**施密特正交化（不同根间**天然正交**，跳过）；
4. **全部单位化** → 拼成 $Q=(\gamma_1,\dots,\gamma_n)$，对角元顺序与列一一对应。

> **一句话**：**同组正交化 → 全体单位化 → 排列成 $Q$**。

## 📌 五、相似 / 合同 / 正交对角化 对照（承接 #032）

| 变换 | 形式 | 要求 $P$ | 保持不变 |
|---|---|---|---|
| **等价** | $PAQ$ | $P,Q$ 可逆 | **秩** |
| **相似** | $P^{-1}AP$ | $P$ 可逆 | 特征值（多项式）、迹、行列式、秩 |
| **合同** | $C^{T}AC$ | $C$ 可逆 | 正负惯性指数（符号差） |
| **正交相似（= 正交合同）** | $Q^{T}AQ=Q^{-1}AQ$ | $Q$ **正交** | 特征值 **且** 惯性指数（实对称阵专属） |

> **链条**：正交相似 ⇒ 相似 **且** 合同；实对称矩阵**相似 ⇒ 合同**；反之一般都不成立。

## ⚠️ 易错点（速查版）

1. **只对角化 ≠ 正交对角化**：一般矩阵能对角化但**未必能正交对角化**；**只有实对称矩阵保证能正交对角化**。（"实对称"这条最常被漏！）
2. **正交化与单位化的顺序**：**先正交化、后单位化**；单位化漏做 ⇒ $Q$ 不是正交阵。
3. **施密特正交化只在同重根内进行**：不同特征值向量已正交，重复做浪费时间且易错。
4. **$|Q|=\pm1$**：不要记成恒为 1；$-1$ 常见（如交换两行的正交阵）。
5. **$\Lambda$ 对角元顺序 = $Q$ 列顺序**：重排 $Q$ 的列时必须同步重排 $\Lambda$，否则 $Q^{T}AQ$ 不是对角阵。
6. **正交变换不改变特征值**：$Q^{T}AQ$ 与 $A$ 特征值相同（相似不变量），化标准形时标准形系数**正是特征值**。
7. **投影系数分母是 $\|\beta_i\|^2$**：写成 $\|\beta_i\|$ 是常见算错点。

## ✏️ 例题（速查应用）

**例 1（正交矩阵）** $Q=\dfrac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$ 是否正交矩阵？求 $|Q|$。
**解**：两列长度均为 $\tfrac{\sqrt2}{\sqrt2}=1$，内积 $\tfrac{1}{2}(1-1)=0$，故正交；$|Q|=\tfrac12(1\cdot(-1)-1\cdot1)=\tfrac12(-2)=-1$。

**例 2（重根正交化）** 将 $A=\begin{pmatrix}1&2&2\\2&1&2\\2&2&1\end{pmatrix}$ 正交对角化。
**解**：$\lambda_1=5$（向量 $(1,1,1)^{T}$），$\lambda_2=\lambda_3=-1$（二重根，解 $(A+E)x=0$ 得基础解系 $(1,-1,0)^{T},(1,0,-1)^{T}$，二者**不正交**）。
对二重根做施密特正交化：$\beta_2=(1,-1,0)^{T}$，$\beta_3=(1,0,-1)^{T}-\tfrac{1}{2}(1,-1,0)^{T}=\tfrac12(1,1,-2)^{T}$。
单位化后与 $\tfrac{1}{\sqrt3}(1,1,1)^{T}$ 拼成 $Q$，得 $Q^{T}AQ=\operatorname{diag}(5,-1,-1)$。

**例 3（正交对角化）** 将 $\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 正交对角化。
**解**：$\lambda=3,1$，特征向量 $(1,1)^{T},(1,-1)^{T}$ 已正交；单位化得 $Q=\tfrac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$，$Q^{T}AQ=\operatorname{diag}(3,1)$。

> 套路：**实对称阵 → 求特征值/向量 → 同重根施密特 → 全体单位化 → $Q^{T}AQ=\Lambda$**。
