# 🧮 数学一 · 知识点卡片 #004

> **科目：线性代数** ｜ 主题：**矩阵运算核心公式速查** ｜ 难度：⭐⭐（必拿分）

## 📌 公式速查表（背熟！）

**1. 运算规则**
- $A+B = B+A$；$(A+B)+C = A+(B+C)$
- $(AB)C = A(BC)$；$(kA)B = A(kB) = k(AB)$
- $(A+B)^2 = A^2 + AB + BA + B^2$（**≠ $A^2+2AB+B^2$**，除非 $AB=BA$）

**2. 转置**
- $(A^T)^T = A$；$(A+B)^T = A^T + B^T$
- $(AB)^T = B^T A^T$（**反序**！）
- $(kA)^T = kA^T$

**3. 逆矩阵**
- $AA^{-1} = A^{-1}A = E$（$A$ 可逆 $\Leftrightarrow |A| \neq 0$）
- $(A^{-1})^{-1} = A$；$(kA)^{-1} = \frac{1}{k}A^{-1}$（$k \neq 0$）
- $(AB)^{-1} = B^{-1}A^{-1}$（**反序**！）
- $(A^T)^{-1} = (A^{-1})^T$

**4. 伴随矩阵**
- $AA^* = A^*A = |A|E$
- $A^{-1} = \dfrac{1}{|A|}A^*$（$|A| \neq 0$）
- $|A^*| = |A|^{n-1}$；$(A^*)^* = |A|^{n-2}A$（$n \geq 2$）

**5. 行列式**
- $|AB| = |A||B|$；$|kA| = k^n|A|$
- $|A^T| = |A|$；$|A^{-1}| = |A|^{-1}$

**6. 特征值（交叉考点）**
- $|A| = \lambda_1 \lambda_2 \cdots \lambda_n$（特征值之积）
- $\mathrm{tr}(A) = \lambda_1 + \lambda_2 + \cdots + \lambda_n$（迹 = 特征值之和）

## ⚠️ 易错点（高频失分）

1. **$(AB)^T = B^TA^T$、$(AB)^{-1} = B^{-1}A^{-1}$ 都要反序**——"穿衣脱衣"记忆法
2. **矩阵乘法不满足交换律**：$AB \neq BA$ 一般情况；$(A+B)^2$ 展开别想当然
3. $(A+B)^{-1}$ **没有**简单公式（不像 $|A+B|$ 也无公式）——别硬套
4. $A^*$ 与 $A^{-1}$ 混用：$A^{-1} = A^*/|A|$，求伴随先算行列式

## ✏️ 例题

已知 $A$ 为 3 阶矩阵，$|A| = 2$，求 $|(2A)^{-1} + A^*|$ 型题目先拆步：先分别求 $(2A)^{-1}$ 和 $A^*$ 的表达式：

- $(2A)^{-1} = \dfrac{1}{2}A^{-1}$（$kA$ 逆矩阵，$k$ 取倒数）
- $A^* = |A|A^{-1} = 2A^{-1}$
- 于是原式 $= |\frac{1}{2}A^{-1} + 2A^{-1}| = |\frac{5}{2}A^{-1}| = (\frac{5}{2})^3 \cdot |A^{-1}| = \frac{125}{8} \cdot \frac{1}{2} = \boxed{\frac{125}{16}}$

> 套路总结：**先统一化成 $A^{-1}$ 的倍数，再提公因子**——抽象矩阵题的标准解法。

## 🎯 真题联想

- 数一真题必考一题"抽象行列式"：给 $|A|$ 或 $A$ 的方程，求 $|kA|$、$|A^*|$、$|A^{-1}|$ 的组合——这张表全覆盖
- 特征值之积 = 行列式：求特征值后快速验算 $|A|$，防算错
