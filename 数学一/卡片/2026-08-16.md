# 🧮 数学一 · 知识点卡片 #001

> **科目：微积分** ｜ 主题：**等价无穷小替换** ｜ 难度：⭐（必拿分）

## 📌 知识点

当 $x \to 0$ 时，以下**等价无穷小**必须背熟：

| 表达式 | 等价于 |
|---|---|
| $\sin x$ | $x$ |
| $\tan x$ | $x$ |
| $\arcsin x$ | $x$ |
| $\arctan x$ | $x$ |
| $\ln(1+x)$ | $x$ |
| $e^x - 1$ | $x$ |
| $1 - \cos x$ | $\frac{1}{2}x^2$ |
| $(1+x)^a - 1$ | $ax$ |
| $\tan x - \sin x$ | $\frac{1}{2}x^3$ |
| $x - \ln(1+x)$ | $\frac{1}{2}x^2$ |

## ⚠️ 使用铁律（易错点！）

1. **乘除可换，加减慎换**：作为因子（乘/除）可以替换；在加减法中，若两项**不等价**（比值极限 ≠ 1）才能替换
2. 替换的本质是取**主部**（最低阶项），别丢高阶项
3. 等价无穷小可以**传递**：$a \sim b, b \sim c \Rightarrow a \sim c$

## ✏️ 例题

求 $\displaystyle\lim_{x\to 0} \frac{1-\cos x}{x\sin x}$

**解**：
- $1-\cos x \sim \frac{1}{2}x^2$（分子，乘除场景可直接换）
- $\sin x \sim x$（分母）
- 原式 $= \lim_{x\to0} \dfrac{\frac{1}{2}x^2}{x \cdot x} = \dfrac{1}{2}$

## 🎯 真题联想

- 2020 数一：$\lim_{x\to0}\dfrac{1-\cos2x}{x^2}$（答案 2，直接套 $1-\cos x \sim \frac12 x^2$ 的推广）
- 极限题第一思路永远是：**定型 → 化简 → 等价替换/洛必达**
