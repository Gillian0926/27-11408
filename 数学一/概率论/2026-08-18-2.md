# 🧮 数学一 · 知识点卡片 #006

> **科目：概率论** ｜ 主题：**条件概率与全概率、贝叶斯公式速查** ｜ 难度：⭐⭐⭐（大题必考）

## 📌 公式速查表（背熟！）

**1. 概率基本性质**
- $0 \le P(A) \le 1$；$P(\Omega)=1$，$P(\varnothing)=0$
- $P(\overline{A}) = 1 - P(A)$
- 加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
- 三事件：$P(A \cup B \cup C) = P(A)+P(B)+P(C) - P(AB)-P(AC)-P(BC) + P(ABC)$

**2. 条件概率**
$$P(B|A) = \frac{P(AB)}{P(A)} \quad (P(A) > 0)$$

**3. 乘法公式**
- $P(AB) = P(A) \cdot P(B|A) = P(B) \cdot P(A|B)$
- 推广：$P(ABC) = P(A)P(B|A)P(C|AB)$（链式法则）

**4. 全概率公式**（$A_1, \dots, A_n$ 是**完备事件组**：两两互斥且并集为 $\Omega$）
$$P(B) = \sum_{i=1}^{n} P(A_i) P(B|A_i)$$

**5. 贝叶斯公式**（已知结果求原因）
$$P(A_i|B) = \frac{P(A_i) P(B|A_i)}{\sum_{j=1}^{n} P(A_j) P(B|A_j)}$$
> 记忆：分母就是全概率 $P(B)$；贝叶斯 = 全概率公式的"反向使用"

**6. 独立性**
- $A$、$B$ 独立 $\Leftrightarrow$ $P(AB) = P(A)P(B)$
- 独立时：$P(A|B) = P(A)$，$P(B|A) = P(B)$
- $n$ 个事件**相互独立**（任取 $k$ 个都满足乘积公式）比**两两独立**强，两两独立不一定相互独立

## ⚠️ 易错点（高频失分）

1. **条件概率是"缩小样本空间"**：$P(B|A)$ 在 A 发生的范围内看 B，分母是 $P(A)$ 不是 1；$P(B|A)$ 与 $P(AB)$ 千万别混
2. 用全概率公式前**先验证完备事件组**：$A_i$ 必须两两互斥且 $\sum P(A_i) = 1$，漏一项全错
3. **独立 ≠ 互斥**：独立要求 $P(AB) = P(A)P(B)$（概率乘积）；互斥要求 $AB = \varnothing$。若 $P(A),P(B) > 0$，互斥必不独立！直观理解：互斥意味着"知道 A 发生就知道 B 不可能发生"，信息相关
4. "有放回"抽样独立、"无放回"不独立——无放回必须用条件概率链式算

## ✏️ 例题（贝叶斯标准题）

某工厂由甲、乙、丙三台机器生产同一种零件，产量分别占 30%、30%、40%，次品率分别为 1%、2%、1.5%。现从产品中任取一件，发现是次品，求它由甲机器生产的概率。

**解**（设 A₁=甲，A₂=乙，A₃=丙，B=次品）：
- 先求全概率：$P(B) = 0.3 \times 0.01 + 0.3 \times 0.02 + 0.4 \times 0.015 = 0.003 + 0.006 + 0.006 = 0.015$
- 贝叶斯：$P(A_1|B) = \dfrac{0.3 \times 0.01}{0.015} = \dfrac{0.003}{0.015} = \boxed{0.2}$

> 套路总结：**先全概率求分母，再贝叶斯求分子**——"由果溯因"题两步走，分子就是"这条路"的贡献，分母是"所有路"的贡献之和。

## 🎯 真题联想

- 数一必考：条件概率/全概率/贝叶斯组合题（常作大题第一问或填空），"抽检""发报""患病检测"都是经典模型
- 独立性与二项分布挂钩：$n$ 重伯努利试验 $P(X=k) = C_n^k p^k (1-p)^{n-k}$——独立是它的前提
