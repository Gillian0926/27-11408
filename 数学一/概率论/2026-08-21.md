# 🧮 数学一 · 知识点卡片 #009

> **科目：概率论** ｜ 主题：**随机变量与分布函数** ｜ 难度：⭐⭐⭐（大题基础）

## 📌 知识点

**随机变量**：把样本空间 $\Omega$ 的每个样本点映射为一个实数 $X$——本质是"给随机结果编号"。
- 离散型：$X$ 取值有限或可列无限个
- 连续型：$X$ 取值充满一个区间（不可列）

**分布函数**（累积分布函数 CDF，核心定义）：
$$F(x) = P(X \le x), \quad x \in \mathbb{R}$$

**分布函数四大性质**（背熟，选择题高频）：
1. **单调不减**：$x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)$
2. **有界**：$0 \le F(x) \le 1$，且 $F(-\infty)=\lim_{x\to-\infty}F(x)=0$，$F(+\infty)=1$
3. **右连续**：$F(x+0)=F(x)$（离散型是阶梯函数，连续型是连续函数）
4. $P(a < X \le b) = F(b) - F(a)$

**离散型**：分布律 $P(X=x_k)=p_k$（$k=1,2,\dots$），要求 $p_k \ge 0$ 且 $\sum_k p_k = 1$（归一化）。

**连续型**：密度函数 $f(x)$ 满足 $f(x) \ge 0$ 且 $\int_{-\infty}^{+\infty} f(x)\,dx = 1$，
$$F(x) = \int_{-\infty}^{x} f(t)\,dt, \qquad P(a < X < b) = \int_a^b f(x)\,dx$$

## ⚠️ 易错点（高频失分）

1. **分布函数是右连续不是左连续**：$P(X=x_0) = F(x_0) - F(x_0 - 0)$（跳跃高度 = 该点概率）；连续型则 $P(X=x_0)=0$（单点概率恒为 0，所以"≤"和"<"无所谓）
2. 判断某个函数是否是分布函数，四条性质**逐条验证**，漏一条就错
3. 离散型分布函数是"阶梯状"，跳跃点就是可能取值，跳跃高度就是对应概率 $p_k$
4. **连续型单点概率为 0 ≠ 事件不可能**：$P(X=a)=0$ 但 $\{X=a\}$ 仍可能发生（如掷针正好落在某一点）

## ✏️ 例题

设连续型随机变量 $X$ 的密度函数为 $f(x)=\begin{cases} kx, & 0 \le x \le 2 \\ 0, & \text{其他} \end{cases}$，求常数 $k$、分布函数 $F(x)$，以及 $P(1 < X \le 2)$。

**解**：
- 归一化求 $k$：$\int_{-\infty}^{+\infty} f(x)dx = \int_0^2 kx\,dx = k \cdot \dfrac{x^2}{2}\Big|_0^2 = 2k = 1 \Rightarrow \boxed{k = \dfrac{1}{2}}$
- 分布函数（分段讨论）：
$$F(x) = \begin{cases} 0, & x < 0 \\ \int_0^x \tfrac12 t\,dt = \dfrac{x^2}{4}, & 0 \le x < 2 \\ 1, & x \ge 2 \end{cases}$$
- $P(1 < X \le 2) = F(2) - F(1) = 1 - \dfrac{1}{4} = \boxed{\dfrac{3}{4}}$

> 套路：**先归一化定系数，再分段积分求 CDF**；求概率优先用 $F(b)-F(a)$（分布函数法），比直接积分更不易错。

## 🎯 真题联想

- 数一选择/填空常考：给密度函数求 $k$、求 $F(x)$、求某区间概率——"三段式"固定流程
- 分布函数性质综合：判断 $F(x)$ 是否合法（单调、有界、右连续）
- 与条件概率结合：$P(X > a \mid X > b)$ 用 $P(A|B)=\dfrac{P(AB)}{P(B)}$ 化为分布函数之比
