# 🧮 数学一 · 知识点卡片 #005

> **科目：概率论** ｜ 主题：**随机事件的关系与古典概型** ｜ 难度：⭐⭐（必拿分）

## 📌 知识点

**基本概念**：
- 随机试验：可重复、结果不止一个、事先不能确定哪个发生
- 样本空间 $\Omega$：所有可能结果的集合；随机事件 = 样本空间的子集
- 必然事件 $\Omega$、不可能事件 $\varnothing$、基本事件（单个样本点）

**事件的关系与运算**（重点！）：
1. 包含 $A \subset B$（A 发生 ⇒ B 发生）
2. 相等 $A = B$；和 $A \cup B$（A 或 B 发生）；积 $A \cap B$ 或 $AB$（A 且 B）
3. 差 $A - B = A\overline{B}$（A 发生 B 不发生）
4. **互斥（互不相容）**：$AB = \varnothing$，不能同时发生
5. **对立**：$A \cup \overline{A} = \Omega$ 且 $A\overline{A} = \varnothing$——"A 不发生"就是 $\overline{A}$

**运算律（背熟）**：
- 交换律、结合律、分配律
- **德摩根律（对偶律）**：$\overline{A \cup B} = \overline{A} \cap \overline{B}$，$\overline{AB} = \overline{A} \cup \overline{B}$（"并的对立 = 对立的交"）

**古典概型**：样本点有限且**等可能** ⇒ $P(A) = \dfrac{A \text{ 包含的样本点数}}{\Omega \text{ 的样本点总数}}$

## ⚠️ 易错点（高频失分）

1. **互斥 ≠ 对立**：对立 ⇒ 互斥，但互斥不一定对立（还要求 $A \cup B = \Omega$）。"掷骰子，点数 1 与点数 2"互斥不对立；"奇数与偶数"才是对立
2. 古典概型必须**等可能**——凭直觉数"有利情况"前先确认每个样本点概率相同
3. 德摩根律口诀："**并的对立 = 对立的交；交的对立 = 对立的并**"——长杠变短杠、且变或
4. "恰有一个发生" = $A\overline{B} \cup \overline{A}B$（别忘了是并，不是交）

## ✏️ 例题

同时掷两枚质地均匀的骰子，求点数之和为 7 的概率。

**解**：
- 样本点总数：$6 \times 6 = 36$（两枚骰子有序，别算成 $C_6^2$！）
- 和为 7 的点对：$(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)$ 共 **6 种**
- $P = \dfrac{6}{36} = \boxed{\dfrac{1}{6}}$

> 秒杀技巧：和为定值的对称性——和为 7 是"中间值"，种数最多；和为 2 或 12 只有 1 种。做选择题可直接枚举对称轴。

**变式**：至少有一枚骰子点数为 6 的概率？用**对立事件**：$1 - P(\text{两枚都不为 6}) = 1 - \frac{25}{36} = \boxed{\frac{11}{36}}$——"至少"出现优先想对立（正难则反）。

## 🎯 真题联想

- 数一选择/填空常考：事件运算用字母表示（"A、B、C 恰有两个发生"= $AB\overline{C} \cup A\overline{B}C \cup \overline{A}BC$，三个互斥事件相加）
- 古典概型常与排列组合结合：$P_n^k$、$C_n^k$ 数清"有序/无序"，有放回/无放回
- 德摩根律 + 概率性质综合：$\overline{A \cup B}$ 的概率 = $1 - P(A) - P(B) + P(AB)$
