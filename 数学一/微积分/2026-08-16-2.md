# 🧮 数学一 · 知识点卡片 #002

> **科目：微积分** ｜ 主题：**洛必达法则** ｜ 难度：⭐⭐（必拿分）

## 📌 知识点

**洛必达法则**：若 $\lim_{x\to a}\dfrac{f(x)}{g(x)}$ 为 $\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$ 型，且 $f'(x)$、$g'(x)$ 存在、$g'(x)\neq 0$，则

$$\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}$$

（可连续使用，直到不再是不定型）

**适用不定型**：
- 直接适用：$\dfrac{0}{0}$、$\dfrac{\infty}{\infty}$
- 转化后适用：$0\cdot\infty$（化成 $\frac{0}{1/\infty}$）、$\infty-\infty$（通分）、$1^\infty$、$0^0$、$\infty^0$（取 $\ln$）

## ⚠️ 易错点（高频失分）

1. **不是不定型不能用**！$\lim_{x\to0}\dfrac{\cos x}{x}$ 直接 = $\infty$，别洛必达
2. 洛必达后**结果必须存在或为 $\infty$**；若新极限不存在（振荡），法则失效，换方法
3. $\dfrac{0}{0}$ 型优先考虑**等价无穷小替换**（更简单），洛必达作为备选
4. 有条件别忘：$\dfrac{f'(x)}{g'(x)}$ 中 $g'(x)\neq 0$（邻域内）

## ✏️ 例题

求 $\displaystyle\lim_{x\to 0} \frac{x-\sin x}{x^3}$

**解**：
- 直接洛必达：$= \lim_{x\to0} \dfrac{1-\cos x}{3x^2}$（还是 $\frac00$，继续）
- $= \lim_{x\to0} \dfrac{\sin x}{6x} = \dfrac{1}{6}$
- 或用等价无穷小：$x-\sin x \sim \dfrac{1}{6}x^3$（记忆：与 $1-\cos x\sim\frac12x^2$ 联动推导）

## 🎯 真题联想

- 求极限大题第一问常考：先定型 → 等价替换或洛必达 → 出结果
- $0\cdot\infty$ 型：$x\to\infty$ 时 $x\ln(1+\frac{1}{x})$ → 换元 $t=\frac1x$ 转 $\frac00$
