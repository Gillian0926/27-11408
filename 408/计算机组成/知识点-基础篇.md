## 一、计算机系统八大设计思想（计组必背）

1. **Design for Moore's Law**（设计紧跟摩尔定律）：设计要考虑"完成时"的硬件条件，而非"开始时"——集成电路资源约 18-24 个月翻一番
2. **Use Abstraction to Simplify Design**（抽象简化设计）：层次化、模块化（指令集架构是软硬件分界）
3. **Make the Common Case Fast**（加速大概率事件）
4. **Performance via Parallelism**（并行提高性能）
5. **Performance via Pipelining**（流水线提高性能）：各流程同时进行、对象为相邻任务；希望各阶段时间均匀
6. **Performance via Prediction**（预测提高性能）：预测成功加速、失败纠正成本低（如分支预测）
7. **Hierarchy of Memories**（存储器层次）：Disk → Main Memory(DRAM) → L2 Cache(SRAM) → L1 Cache → Registers
8. **Dependability via Redundancy**（冗余提高可靠性）：部分故障不影响整体

## 二、冯·诺依曼架构（核心考点）

- **存储程序**：数据和指令放在**同一个存储器**
- **计算与存储分离**：运算器（ALU）负责计算，存储器负责存放
- 五大部件：运算器、控制器、存储器、输入设备、输出设备

⚠️ 与哈佛结构对比：哈佛结构指令和数据**分开存储**，可并行取指取数。

## 三、存储层次（Cache 相关考点基础）

- 层次：寄存器 → L1 Cache（片内）→ L2 Cache（SRAM）→ 主存（DRAM）→ 磁盘
- 越往上：速度越快、容量越小、价格越贵
- **局部性原理**是 Cache 能生效的根本原因（时间局部性 + 空间局部性）

## 四、数制与进制转换（选择题送分题）

**通用公式**：$(A_{n-1}A_{n-2}...A_1A_0.A_{-1}...A_{-m})_r = \sum A_i r^i$

**快速转换技巧**：
- **二进制 ↔ 八进制**：三位一组（小数位从小数点向两边分组）
- **二进制 ↔ 十六进制**：四位一组
- 十进制转 r 进制：整数除 r 取余（倒序），小数乘 r 取整（正序）

**常见考点**：
- 二进制补码表示范围：n 位补码范围 $[-2^{n-1}, 2^{n-1}-1]$
- 真值 ↔ 原码/反码/补码/移码转换
- 为什么用二进制：二值器件常见（晶体管）+ 电路成本低

## 五、加法器原理（底层基础）

- **一位全加器**：输入 A、B、Cin，输出 S、Cout
  - $S = (A \oplus B) \oplus C_{in}$
  - $C_{out} = (A \& B) \ | \ ((A \oplus B) \& C_{in})$
- **串行加法器**：每位全加器的 Cout 接到高一位的 Cin（速度慢）
- **并行/超前进位加法器**：提前计算进位，减少等待（考查概念）

## 六、数字信号基础（了解即可）

- 模拟信号 vs 数字信号；二进制 = 高电位(1) / 低电位(0)
- 输入判定范围比输出大（"宽进严出"），抗噪声
- 高低电平之间的区域为未定义（floating），输出落在此区结果随机
