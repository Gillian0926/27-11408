## ⭐ 关键考点提炼

### 1. CPU 调度（ch5）
- **CPU-I/O burst 周期**：进程执行 = CPU 执行和 I/O 等待交替
- **调度决策时机**（4 种）：运行→等待、运行→就绪、等待→就绪、终止
  - ①④ 非抢占；②③ 抢占
- **Dispatcher**：上下文切换 + 切换到用户态 + 跳转重启；**dispatch latency**
- **算法对比**（408 计算题）：
  - FCFS：简单，有 **convoy effect**（短进程被长进程阻塞）
  - SJF：平均等待时间最小（理论最优），需预测下一 CPU burst 长度（指数平均）
  - Priority：**aging（老化）** 防止低优先级饥饿
  - RR：时间片轮转；时间片大小影响性能
- 多处理器调度：对称/非对称

### 2. 进程同步（ch6）
- 临界区三条件：互斥、有限等待、空闲让进
- **信号量**：二值（0/1）/计数；wait/signal 原子操作
- 经典问题：**Bounded-Buffer（生产者消费者）**、读者-写者、哲学家就餐
- 高级抽象：管程、原子事务（ACID：原子性/一致性/隔离性/持久性）

### 3. 死锁（ch7）
- 四条件 + 资源分配图 + 银行家算法（详见本站《知识点-存储管理与死锁》）

### 4. 内存管理（ch8/ch9）
- 基址/界限寄存器、分页（页表）、分段、段页式
- 虚拟内存：缺页中断、**页面置换**（FIFO/LRU/Clock/Optimal）、**工作集模型**、抖动（thrashing）

### 5. 文件系统（ch10/11）
- 文件逻辑结构 vs 物理结构
- **UNIX inode 多级索引**：前 12 个直接指针 + 单重/双重/三重间接（408 常考：文件最大大小计算）
- 目录实现、空闲空间管理（位图/链表）

### 6. I/O 系统（ch13）
- **三种控制方式**：轮询（busy-wait）、中断驱动、**DMA**（绕过 CPU 直接内存-设备传输）
- 缓冲（buffering）、缓存（caching）、假脱机（spooling）
- 块设备 vs 字符设备

### 7. Linux 专题（408 近年爱考）⭐
- **进程管理**：task_struct（进程描述符）包含状态/标识/族亲/调度/时间/虚存/文件/IPC 信息；进程状态标志（TASK_RUNNING/INTERRUPTIBLE 等）；**schedule() 调度函数**流程；2.6 调度器用优先级 + counter（时间片）
- **内存管理**：**buddy（伙伴系统）**——页帧按 2ⁿ 划分管理；**四级页表**（2.6.11+）；**写时复制 copy-on-write**（fork 时共享页，写时才复制）；**kswapd 守护进程**（内存回收）；LRU 页面置换；do_mmap 映射可执行映像
- 系统调用：fork/execve 流程、系统调用入口
