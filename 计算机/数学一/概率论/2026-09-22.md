# 🦉 数学一 · 知识点卡片 #039

> **科目：概率论** ｜ 主题：**数理统计基础：抽样分布（χ²、t、F）与点估计（矩估计 / 极大似然）** ｜ 难度：⭐⭐⭐（大题必考：求统计量分布 + 参数估计）

## 📖 知识点

### 一、总体、样本与统计量

- **总体 $X$**：所研究对象的全体（一个随机变量，分布 $F(x;\theta)$）；**个体**：单个对象。
- **简单随机样本 $X_1,\dots,X_n$**：**相互独立**且**与总体同分布**（i.i.d.）。样本是**$n$ 维随机变量**，观测后得**样本值** $x_1,\dots,x_n$。
- **统计量**：不含任何未知参数的样本函数 $g(X_1,\dots,X_n)$。**含未知参数就不是统计量**（超高频陷阱）。
- **常用统计量**：
  - 样本均值 $\bar X=\dfrac1n\sum_{i=1}^n X_i$；
  - 样本方差 $S^2=\dfrac{1}{n-1}\sum_{i=1}^n (X_i-\bar X)^2$（**分母 $n-1$，无偏**）；
  - 样本 $k$ 阶原点矩 $A_k=\dfrac1n\sum X_i^k$，$k$ 阶中心矩 $B_k=\dfrac1n\sum(X_i-\bar X)^k$。

> **两个恒等式**：$\sum(X_i-\bar X)^2=\sum X_i^2-n\bar X^2$；$E(S^2)=\sigma^2$（无论总体是否正态）。

### 二、三大抽样分布（正态总体下）

设 $X_1,\dots,X_n$ i.i.d. $\sim N(0,1)$：

**① $\chi^2$ 分布**：$\displaystyle \chi^2=\sum_{i=1}^n X_i^2\ \sim\ \chi^2(n)$，$n$ 为自由度；$E(\chi^2)=n,\ D(\chi^2)=2n$。
可加性：$\chi^2(n_1)+\chi^2(n_2)\sim\chi^2(n_1+n_2)$（**相互独立**时）。

**② $t$ 分布**：设 $X\sim N(0,1)$、$Y\sim\chi^2(n)$ 且**独立**，
$$t=\frac{X}{\sqrt{Y/n}}\ \sim\ t(n).$$
关于 $y$ 轴对称，$n\to\infty$ 时趋近 $N(0,1)$；$t_{1-\alpha}(n)=-t_\alpha(n)$。

**③ $F$ 分布**：设 $U\sim\chi^2(n_1)$、$V\sim\chi^2(n_2)$ 独立，
$$F=\frac{U/n_1}{V/n_2}\ \sim\ F(n_1,n_2).$$
**关键倒数关系**：$\dfrac1F\sim F(n_2,n_1)$，故 $\boxed{F_{1-\alpha}(n_1,n_2)=\dfrac{1}{F_{\alpha}(n_2,n_1)}}$（查表必用）。

### 三、正态总体的抽样分布定理（**核心考点**）

设 $X_1,\dots,X_n$ i.i.d. $\sim N(\mu,\sigma^2)$，则
$$\bar X\sim N\!\left(\mu,\frac{\sigma^2}{n}\right);\qquad \frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1);\qquad \bar X\ \text{与}\ S^2\ \text{相互独立}.$$

**由此推出**：
- **σ 已知（用 σ²）**：$\dfrac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$；
- **σ 未知（用 S）**：$\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$；$\dfrac{\bar X-\mu}{S/\sqrt{n-1}}\sim t(n-1)$ 需注意分母写法；
- **两总体**：$\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}\sim F(n_1-1,n_2-1)$；方差相等时
$$\frac{(\bar X-\bar Y)-(\mu_1-\mu_2)}{S_w\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}}\sim t(n_1+n_2-2),\quad S_w^2=\frac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}.$$

### 四、点估计：矩估计与极大似然

**① 矩估计（Moment）**：用**样本矩 = 总体矩**解参数。
- 一个参数：$\bar X=E(X)$ 解之；两个参数：$\bar X=E(X),\ A_2=E(X^2)$ 联立。

**② 极大似然估计（MLE）**：
1. 写似然 $L(\theta)=\prod_{i=1}^n f(x_i;\theta)$（离散用 $\prod P(X=x_i)$）；
2. 取对数 $\ln L$；
3. 令 $\dfrac{\partial \ln L}{\partial\theta}=0$ 解出 $\hat\theta$（多个参数解方程组）；
4. 若解在边界/不可导，用**单调性**直接判断（如均匀分布 $U(0,\theta)$ 的 $\hat\theta=\max X_i$）。

> **MLE 不变性**：若 $\hat\theta$ 是 $\theta$ 的极大似然估计，则 $g(\hat\theta)$ 是 $g(\theta)$ 的 MLE（求 $\sigma^2$、$\mu^2$ 等的好用性质）。

## ⚠️ 易错点（高频失分）

1. **统计量不能含未知参数**：如 $X_1-\mu$ 不是统计量（$\mu$ 未知）；样本方差分母是 **$n-1$** 不是 $n$。
2. **$S^2$ 与 $\sigma^2$ 的关系式要用 $n-1$**：$\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$，**自由度 $n-1$**（因用 $\bar X$ 消去一个自由度）。
3. **$\bar X$ 与 $S^2$ 独立**——**这是正态总体特有的**，非正态总体一般不成立，务必记住前提"**正态**"。
4. **$F$ 的倒数关系方向别记反**：$F_{1-\alpha}(n_1,n_2)=1/F_\alpha(n_2,n_1)$，括号内自由度**顺序对调**。
5. **$t$ 分布分母 $\sqrt{Y/n}$**：别漏 $/n$ 或写成 $Y/n$ 开外；$t(n)$ 自由度 = $\chi^2$ 的自由度，不是 $n+1$。
6. **MLE 用对数求导**：先取 $\ln L$ 再求导（连乘变连加），别忘令导数为 0 后**验证最大值**（二阶导 / 单调性）。
7. **矩估计与 MLE 可能不同**：同一参数两种方法结果常不一样，**题目问哪种就用哪种**，别混。

## ✏️ 例题

**例 1（统计量分布）** 设 $X_1,\dots,X_{16}$ i.i.d. $\sim N(\mu,4)$，求 $\dfrac{\bar X-\mu}{S/2}$ 的分布（$S$ 为样本标准差）。

**解**：$\mu$ 未知用 $S$，得 $\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$。此处 $n=16,S$ 为**样本标准差**，$\sqrt n=4$，
$$\frac{\bar X-\mu}{S/4}=\frac{4(\bar X-\mu)}{S}=\frac{\bar X-\mu}{S/\sqrt{16}}\sim t(15).$$
（若题给 $\sigma=2$，则用 $\dfrac{\bar X-\mu}{\sigma/\sqrt n}=\dfrac{\bar X-\mu}{2/4}=\dfrac{2(\bar X-\mu)}{1}\sim N(0,1)$。）

**例 2（三大分布构造）** 设 $X_1,X_2,X_3$ i.i.d. $\sim N(0,1)$，问 $Y=\dfrac{X_1}{\sqrt{(X_2^2+X_3^2)/2}}$ 服从什么分布？

**解**：$X_1\sim N(0,1)$，$X_2^2+X_3^2\sim\chi^2(2)$，二者独立。由 $t$ 定义（$n=2$）得 $Y\sim t(2)$。

**例 3（矩估计 + MLE）** 设总体 $X\sim N(\mu,\sigma^2)$，$X_1,\dots,X_n$ 为样本，求 $\mu,\sigma^2$ 的矩估计与极大似然估计。

**解**：**矩估计**：$E(X)=\mu,\ E(X^2)=\sigma^2+\mu^2$。由 $\bar X=\mu$、$A_2=\sigma^2+\mu^2$ 得
$$\hat\mu_{M}=\bar X,\qquad \hat\sigma^2_{M}=A_2-\bar X^2=\frac1n\sum X_i^2-\bar X^2=\frac1n\sum(X_i-\bar X)^2.$$
**MLE**：$L(\mu,\sigma^2)=\prod\dfrac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x_i-\mu)^2}{2\sigma^2}}$，取对数
$$\ln L=-\frac n2\ln(2\pi)-\frac n2\ln\sigma^2-\frac{1}{2\sigma^2}\sum(x_i-\mu)^2.$$
对 $\mu$ 求导令 0：$\hat\mu_{L}=\bar X$；对 $\sigma^2$ 求导令 0：$\hat\sigma^2_{L}=\dfrac1n\sum(X_i-\bar X)^2$。
> 对比：$\hat\mu$ 两种方法相同；$\hat\sigma^2$ 矩估计 = MLE = $\frac1n\sum(X_i-\bar X)^2$（**有偏**），而 $S^2$ 是**无偏**——三者别混。
