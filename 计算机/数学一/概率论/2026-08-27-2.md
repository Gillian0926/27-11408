# 🧮 数学一 · 知识点卡片 #014

> **科目：概率论** ｜ 主题：**数字特征公式速查（期望 / 方差 / 协方差 / 相关系数）** ｜ 难度：⭐⭐⭐（大题必考）

## 📌 公式速查表（背熟！）

**1. 期望 $E(X)$**
- 离散型：$E(X)=\sum_k x_k p_k$；连续型：$E(X)=\int_{-\infty}^{+\infty} x f(x)\,dx$
- **线性性（无条件成立）**：$E(aX+bY)=aE(X)+bE(Y)$，$E(C)=C$

**2. 方差 $D(X)$**
- $D(X)=E\big[(X-E(X))^2\big]=E(X^2)-[E(X)]^2$（**计算首选第二式**）
- $D(C)=0$，$D(aX+b)=a^2D(X)$
- $D(X\pm Y)=D(X)+D(Y)\pm 2\,\mathrm{Cov}(X,Y)$

**3. 协方差 $\mathrm{Cov}(X,Y)$**
$$\mathrm{Cov}(X,Y)=E(XY)-E(X)E(Y)$$
- 对称性：$\mathrm{Cov}(X,Y)=\mathrm{Cov}(Y,X)$；$\mathrm{Cov}(X,X)=D(X)$
- 分配律：$\mathrm{Cov}(aX+bY, Z)=a\,\mathrm{Cov}(X,Z)+b\,\mathrm{Cov}(Y,Z)$
- 独立 ⇒ $\mathrm{Cov}(X,Y)=0$（$E(XY)=E(X)E(Y)$），**但反之不成立**（协方差为 0 只是"不相关"）

**4. 相关系数 $\rho_{XY}$**
$$\rho_{XY}=\dfrac{\mathrm{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}},\qquad -1\le \rho\le 1$$
- $|\rho|=1 \iff X,Y$ 几乎处处线性相关（$Y=aX+b$，$a\neq0$）
- $\rho=0 \iff$ 不相关；**独立 ⇒ 不相关，不相关 ⇏ 独立**（仅二维正态时二者等价）
- 常用结论：$D(X\pm Y)=D(X)+D(Y)\pm2\rho\sqrt{D(X)D(Y)}$

## ⚠️ 易错点（高频失分）

1. **"独立 ⇒ 不相关"单向成立**：独立必 $\mathrm{Cov}=0$；但 $\mathrm{Cov}=0$ 不代表独立，除非 $X,Y$ 服从二维正态分布
2. **方差公式符号**：$D(X-Y)=D(X)+D(Y)\color{red}{-}2\mathrm{Cov}$（注意是减号），$D(X+Y)$ 才是加号
3. 计算 $D(X)$ 优先用 $E(X^2)-[E(X)]^2$，别硬套定义式（积分更繁琐）
4. $D(aX+b)=a^2D(X)$ 是 **$a^2$**（常数 $b$ 不影响方差）；$E(aX+b)=aE(X)+b$

## ✏️ 例题（协方差与相关系数）

设 $X\sim N(0,1)$，$Y=X^2$，求 $\mathrm{Cov}(X,Y)$ 和 $\rho_{XY}$。

**解**：
- $E(X)=0$，$E(Y)=E(X^2)=D(X)+[E(X)]^2=1+0=1$
- $E(XY)=E(X\cdot X^2)=E(X^3)=0$（标准正态的奇数阶矩为 0）
- 协方差：$\mathrm{Cov}(X,Y)=E(XY)-E(X)E(Y)=0-0\cdot1=\boxed{0}$
- 相关系数：$\rho_{XY}=\dfrac{\mathrm{Cov}}{\sqrt{D(X)D(Y)}}=\boxed{0}$，即 $X$ 与 $Y$ **不相关**，但显然 $Y=X^2$ 与 $X$ 不独立

> 套路：这个例题是"**不相关但不独立**"的经典反例——$Y$ 完全由 $X$ 决定却与 $X$ 不相关，说明相关系数只衡量**线性**关系，衡量不了非线性关系。

## 🎯 真题联想

- 数一必考：求 $E(X)$、$D(X)$、$\mathrm{Cov}(X,Y)$、$\rho_{XY}$，以及 $D(aX+bY)$ 的展开

- 与独立性结合：独立 ⇒ 协方差为 0，多用于"证不独立"（找到 $E(XY)\neq E(X)E(Y)$ 即反证）
